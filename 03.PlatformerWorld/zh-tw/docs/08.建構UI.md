## 學習目標
- 理解不是逐一控制個別UI元素，而是以單一UI實體單位加以分組，並依遊戲狀態(標題、遊戲中、結果)有效率切換畫面的結構。
- 製作在遊戲結束時呼叫的結果畫面(Result Popup)，並學習如何連動GameLogic與UIManagerLogic，將目前分數與最高分數同步到UI文字。

## 觀看該影片後可嘗試執行的內容
- 在Hierarchy視窗中，將標題、遊戲中、結果畫面所需的UI元素，各自分組到對應的父實體(UI Group)底下，並透過開關最上層實體的Enable屬性，測試畫面是否正常切換。
- 在遊戲中故意撞上障礙物讓遊戲結束後，親自確認結果彈窗中，剛才獲得的分數與既有最高分是否正確顯示在文字UI上。

- 在UI中也可以像製作一般實體一樣製作實體。
- 差異在於，建立空實體時不是使用Create Empty，而是使用Create UIEmpty。

- 在Hierarchy視窗中，對想新增實體的ui group按右鍵。
- 點擊Create Entity。
點擊Create UIEmpty即可建立空的UI實體。
<br>

## 為UI實體賦予Component

- UI實體也和一般實體一樣，可以賦予Component來執行額外功能。
- 賦予Component的方法與一般實體使用Add Component的方式相同。
- 在本單元中，將說明常用的Component。
    - **SpriteGUIRendererComponent**：這是用來在UI中顯示圖片的Component。在UI中輸出圖片時，比起SpriteRendererComponent，更建議使用該Component。
    - **TextGUIRendererComponent**：這是用來在UI中顯示文字的Component。
    - **ButtonComponent**：當UI需要執行按鈕功能時所使用的Component。
<br>

### 使用UI Groups進行群組單位控制
<p align = "Center">
<img src = "https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Running/MSW-100_Running_8_001.png" alt="MSW-100_Running_8_001.png">
</p>

1. 當某個群組最上層的實體要素Enable值為true時，子實體可以個別切換Enable為true或false來開啟或關閉。
2. 將最上層實體要素的Enable狀態取消勾選為false。
3. 即可確認當父實體停用時，子實體也會自動一併停用。

- 依實體特性，若停用父實體，屬於該實體的子實體也會自動一併停用。
- 使用這個特性，就不需要針對各個要素逐一控制不同遊戲狀況下應顯示的UI，而是只要啟用、停用群組單位的最上層實體，就能輕鬆控制。
<br>

- 直接停用TitleUI群組的時機，是玩家選擇角色並進入正式遊戲狀態時。

```lua
在角色選擇視窗中，透過角色Slot(UICharacterSelect)的角色選擇按鈕開始遊戲的情況
UICharacterInfoComponent的CloseSelectPopup方法

void CloseSelectPopup()
{
    -- 儲存Title UI群組的最上層實體。
    local TitlePanel = _EntityService:GetEntityByPath("/ui/ToastGroup/UITitle")

    -- 停用最上層實體。
    TitlePanel.Enable = false

    -- 請求GameLogic呼叫開始遊戲。
    _GameLogic:GameStart(self.characterId)
}
```

```lua
在遊戲結果視窗中，玩家透過「主選單」按鈕回到標題畫面的情況
UIManagerLogic的ReturnToMenu方法

Entity mainTitlePanel
Entity resultPopup
Entity resultToMenuButton

void OnBeginPlay()
{
    -- 世界執行時，登錄結果彈跳視窗的「主選單」按鈕事件。
    self.resultToMenuButton:ConnectEvent(ButtonClickEvent,self.ReturnToMenu)
}

void ReturnToMenu()
{
    -- 停用結果彈跳視窗。
    self.resultPopup.Enable = false
    -- 啟用TitleUI最上層實體。
    self.mainTitlePanel.Enable = true
}

```

遊戲中結束並顯示結果彈跳視窗的情況
UIManagerLogic的ShowResultPopup方法

-- 登錄結果視窗內實際原有最高分數值的Text實體
Entity resultBestScoreText
-- 登錄結果視窗內實際目前分數值的Text實體
Entity currentScoreText

void ShowResultPopup(string bestScore, string currentScore)
{
    -- 將最高分數值文字變更為透過參數傳入的文字。
    self.resultBestScoreText.TextComponent.Text = bestScore

    -- 將目前分數值文字變更為透過參數傳入的文字。
    self.currentScoreText.TextComponent.Text = currentScore

    -- 啟用結果視窗。
    self.resultPopup.Enable = true;
}

number bestScore

void EndMainGame()
{
    -- 執行遊戲結束時所需功能

## 最低製作標準
- 必須讓可切換TitleUI、InGameUI、ResultPopup三種狀態的各按鈕UI，以及開始遊戲、結束遊戲、回到主選單等功能都能正常運作。
- 在GameLogic中計算出的currentScore與bestScore值，必須正確傳遞到各UI文字元件。
<br>

## 應用與進階應用
- ResultPopup出現時，不只是單純顯示，而是可加入像是尺寸變大或透明度變化、逐漸顯示的效果。
- 點擊按鈕時或結果視窗出現時，可播放效果音以提升操作手感。
