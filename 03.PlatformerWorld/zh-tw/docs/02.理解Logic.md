## Manager概念
<p align="center">
<img src = "https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Running/MSW-100_Running_2_003_tw.png" alt="MSW-100_Running_2_003_tw.png">
</p>

- Logic可以指定特定功能或角色，並以負責該功能的類型製作。
- 負責單一功能或角色的單位稱為Manager。
- 若特定功能發生問題，只需修改Manager內容即可快速解決。
    - Case 1：角色計算傷害並傳遞給怪物的情況
        - 每次變更傷害公式或新增計算要素時，都需要修改公式。
        - 必須逐一找出並修改所有角色的程式碼。
    - Case 2：將傷害計算交由Logic製作的Manager處理
        - 在Logic中修改傷害計算公式。
        - 因為所有角色與怪物的傷害計算都由Logic負責，不需要再修改其他部分。
        - 即使之後傷害計算出現問題，也只需修改Manager即可解決。
<br>

## 範例世界內Logic使用範例

### GameLogic的情況
- 當遊戲開始時，會處理持續減少體力並增加分數的功能。
- 當管理中的體力變成0時，會請求結果畫面，並比較目前分數與既有最高分數後更新玩家最高分數。
- 當遊戲正式進行時，執行每隔一定時間切換關卡的計時器功能。
<br> 

### DataSetLogic的情況
- 用楓之谷世界的內建功能DataService，讀取道具、圖塊、角色資訊等原始資料。
- 為了讓讀取的資料在程式碼中只要輸入名稱就能立刻找到，會加上標籤(Key)，並整理成容易理解的Lua資料表變數類型。
<br>

### UIManagerLogic的情況
- 集中管理遊戲內存在的UI元素之參照路徑，例如標題畫面、角色選擇視窗、體力與分數顯示、結果彈窗等。
- 將尋找各UI元素的複雜路徑整合為一處，方便其他腳本在需要特定UI操作時能輕鬆存取。
- 在設定為實體參照的狀態下，會依遊戲狀態(開始、遊玩、結束)執行只批次開啟或關閉所需UI群組的彈窗控制功能。
<br>

## 撰寫GameLogic程式碼
```lua
@Logic
script GameLogic extends Logic

property number discript = 0 -- 這是用來控制遊戲整體流程的邏輯。

property ScrollingController scrollingController = nil

property number currentScore = 0 -- 這是用來存放目前遊戲分數值的變數。

@Sync
property number bestScore = 0 -- 這是用來存放玩家最高分數的變數。

property number scoreIncreaseTimer = 0 -- 這是用來定期更新分數的計時器變數。

property number currentStage = 1 -- 這是用來儲存目前關卡編號的變數。

property number stageTimer = 0 -- 這是用來測量關卡切換時機的計時器變數。

property number hp = 0 -- 這是用來儲存玩家體力值的變數。

property boolean isEnd = true -- 這是用來記錄遊戲已結束的狀態變數。

property boolean isMobile = true -- 這是用來儲存執行環境是否為手機環境的狀態變數。

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- 這是在世界開始時呼叫的方法。

-- 進行遊戲邏輯的初始化。
self:Init()

-- 以狀態變數儲存世界是否在手機環境中進行。
self.isMobile = Environment:IsMobilePlatform()

-- 在世界開始時播放背景音樂。
_SoundService:PlayBGM("f5bb92d91e134c699e7bb2cf1aaca8e6",0.4)
end

@ExecSpace("ClientOnly")
method void Init()
-- 進行管理整體遊戲的主要邏輯初始化。

-- 連接內部成員參照。
self:ConnectRefs()

-- 進行其他核心邏輯的初始化。
self:OrderInit()
-- 初始化分數值。
self:SetScore(0)
-- 初始化目前體力值。
self:SetHP(100)
end

@ExecSpace("ClientOnly")
method void ConnectRefs()
-- 這是用來連接內部成員參照的方法。

-- 連接捲動畫面控制器實體。
self.scrollingController = _EntityService:GetEntityByPath("/maps/MainGame/Scrolling").ScrollingController
end

@ExecSpace("ClientOnly")
method void OrderInit()
-- 由遊戲邏輯對各核心邏輯、元件發出初始化命令。

-- 進行捲動畫面控制器初始化。
self.scrollingController:Init()
-- 進行資料集邏輯初始化。
_DataSetLogic:Init()
-- 執行UI管理器邏輯初始化。
_UIManagerLogic:Init()
-- 進行物件池邏輯初始化。
_ObjectPoolLogic:Init()
end

@ExecSpace("ClientOnly")
method void OnUpdate(number delta)
-- 這是每一幀都會被呼叫的方法。

-- 如果遊戲並未進行中
if self.isEnd == true then
	-- 就結束該方法。
	return
end

-- 依delta值自動減少體力。
self:AutoDecreaseHp(delta)
-- 依delta值自動增加分數。
self:AutoIncreaseScore(delta)

-- /分支1/ 如果關卡計時器還有剩餘時間
if self.stageTimer > 0 then
	-- 就在關卡計時器的值上減少delta值。
	self.stageTimer -= delta
-- /分支2/ 如果關卡計時器沒有剩餘時間值
else 
	-- 就呼叫關卡切換。
	self:StageChange()
	-- 將關卡計時器值初始化為Config中設定的數值。
	self.stageTimer = _Config.stageChangeTime
end


end

@ExecSpace("ClientOnly")
method void AutoIncreaseScore(number delta)
-- 這是每當increaseScoreIntervalSecond(週期)時增加分數的方法。

-- /分支1/ 如果測量計時器的值小於作為基準的Interval值
if self.scoreIncreaseTimer < _Config.increaseScoreInterval then
	-- 就在計時器上加上delta值後結束方法。
	self.scoreIncreaseTimer += delta
	return
end

-- /分支2/ 如果測量計時器的值大於或等於作為基準的Interval值(即到達特定週期的時點。)

-- 增加分數。
self:AddScore(_Config.increaseScore)
-- 初始化測量計時器。
self.scoreIncreaseTimer = 0
end

@ExecSpace("ClientOnly")
method void AutoDecreaseHp(number delta)
-- 這是自動減少體力的方法。

-- 將應該減少的數值傳遞到目前體力值。
self:AddHP(delta * _Config.decreaseHpValue)
end

@ExecSpace("ClientOnly")
method void SetScore(number value)
-- 這是將作為參數傳入的值設定為Score值的方法。

-- 參數1 number value：傳入要設定為分數值的數值。

-- 將目前分數值設定為特定數值。
self.currentScore = value
-- 將特定數值設定到登錄於UIManager的Text中。
_UIManagerLogic:SetScoreText(value)
end

@ExecSpace("ClientOnly")
method void AddScore(number addValue)
-- 這是把作為參數傳入的值加到Score值上的方法。

-- 參數1 number addValue：傳入要加到原有分數值上的數值。

-- 將傳入的數值加到目前分數中。
self.currentScore += addValue
-- 將目前分數值傳遞到登錄於UIManager的Text中。
_UIManagerLogic:SetScoreText(self.currentScore)
end

@ExecSpace("ClientOnly")
method void SetHP(number value)
-- 這是將作為參數傳入的值設定為Hp值的方法。

-- 參數1 number value：傳入要設定為Hp值的數值。

-- 將體力值設定為特定數值。(clamp用來限制低於與超過的情況。)
self.hp = math.clamp(value,0,_Config.maxHp)

-- 將體力值更新到登錄在UIManager的滑桿上。
_UIManagerLogic:SetHpSliderValue(self.hp)
end

@ExecSpace("ClientOnly")
method void AddHP(number addValue)
-- 這是把作為參數傳入的值加到體力值上的方法。

-- 參數1 number addValue：傳入要增加的體力值。

-- 將參數值加到目前體力上。
self.hp += addValue

-- 使用clamp限制低於與超過的情況。
self.hp = math.clamp(self.hp,0,_Config.maxHp)

-- 將體力值更新到登錄在UIManager的滑桿上。
_UIManagerLogic:SetHpSliderValue(self.hp)

-- 如果體力值小於或等於0
if self.hp <= 0 then
	-- 就執行遊戲結束邏輯。
	self:EndMainGame()
end
end

@ExecSpace("Client")
method void EndMainGame()
-- 這是用來結束遊戲的方法。(僅客戶端方法)

-- 切換為遊戲已結束狀態。
self.isEnd = true

-- 將角色設為不可見。
_UserService.LocalPlayer.Visible = false

-- 遊戲結束時若執行環境為手機，則停用搖桿。
_UIManagerLogic:ShowMobileJoyStick(false)

-- 指定並輸出要設定在結果彈跳視窗中的數值。(傳遞最高分與目前分數。)
_UIManagerLogic:ShowResultPopup(tostring(math.floor(self.bestScore)),tostring(math.floor(self.currentScore)))

-- 要求捲動畫面控制器回收(停用)所有圖塊集物件。
self.scrollingController:ReturnAllTiles()

-- 降低背景捲動畫面速度。
self.scrollingController.background.ScrollRate = 0.5

-- 如果目前分數高於客戶端內所管理的最高分數
if self.currentScore > self.bestScore then
	-- 就將最高分數值設為目前分數。
	self.bestScore = self.currentScore
	-- 因為是最高分數變更的時點，所以更新伺服器端的最高分數值。
	self:UpdateScore(self.bestScore)
end

-- 更新主標題的最高分數值。
_UIManagerLogic:UpdateTitleBestScore(self.bestScore)
end

@ExecSpace("ClientOnly")
method void GameStart(number selectCharacterId)
-- 開始主遊戲時呼叫的方法。

-- 從CharacterInfoTable取得在角色選擇視窗中選擇角色的速度值。
local scrollSpeed = _DataSetLogic.characterInfoTable[selectCharacterId].Speed
-- 登錄基本速度值。
self:SetDefaultScrollSpeed(scrollSpeed)

-- 將目前(開始)階段初始化為1。
self.currentStage = 1

-- 請求變更階段。
self:StageChange()

self:SetScore(0)

-- 初始化分數計時器值。
self.scoreIncreaseTimer = 0

-- 初始化體力值。
self:SetHP(100)

-- 將階段計時器設為config中設定的切換時間。
self.stageTimer = _Config.stageChangeTime

-- 若為行動裝置環境則顯示行動搖桿。
_UIManagerLogic:ShowMobileJoyStick(true)

-- 進行捲動控制器的初始化。
self.scrollingController:Reset()

-- 進行玩家角色的初始化。
_UserService.LocalPlayer.CustomPlayerController:ResetCharacter()

-- 設定顯示應提供給使用者的UI。
_UIManagerLogic:ShowPlayerInfo(true)

-- 進行技能邏輯的初始化。
_SkillLogic:Reset()

-- 為防止技能特效資源緩衝延遲，只播放資源特效。
_SkillLogic:PlaySkillEffect()

-- 套用各角色所擁有的專屬技能圖示圖片。
_UIManagerLogic:RegistSkillIcon()

-- 執行道具邏輯的初始化。
_ItemLogic:Reset()

-- 正式開始遊戲前執行3、2、1倒數。(包含Wait方法。)
_UIManagerLogic:CountTimerStart()

-- 切換為遊戲進行中的狀態。
self.isEnd = false

end

@ExecSpace("ClientOnly")
method void SetDefaultScrollSpeed(number speed)
-- 設定角色的基本捲動速度值。
-- 區分Defalut與Currrent的原因：使用加速器道具時速度值會變更，因此需另外儲存角色的基本速度值。

-- 參數1 number speed：傳入遊戲進行時套用的捲動速度值。

-- 將捲動元件的基本速度值設為參數值。
self.scrollingController.defaultSpeed = speed
-- 將捲動元件的目前速度值設為參數值。
self.scrollingController.currentScrollSpeed = speed
end

@ExecSpace("ClientOnly")
method void StageChange()
-- 變更階段的方法。

-- 階段編號增加1，但利用%運算子使資源要素可循環。
self.currentStage = (self.currentStage % (_DataSetLogic.stageResourceCount+1)) + 1

-- 切換為目前設定階段編號對應的背景畫面。
self.scrollingController:ChangeBackground()
end

@ExecSpace("Server")
method void LoadData()
-- 取得已記錄資訊的方法。(僅伺服器方法)
-- 伺服器端執行：為取得伺服器端管理中的資料。

-- 利用資料儲存服務取得名為「MyData」的資料儲存空間。
local data = _DataStorageService:GetGlobalDataStorage("MyData")

-- 取得該資料儲存空間內'BestScore'鍵所對應的Value值。
local errorCode,value = data:GetAndWait("BestScore")

-- 登錄臨時分數值變數。
local tempScore

-- 若沒有已儲存資料
if value == nil then
	-- 將臨時分數值設為0。
	tempScore = 0
	
-- 若有已儲存資料
else
	-- 將臨時分數值設為原有分數值。
	tempScore = tonumber(value)
end

-- 更新bestScore值。
-- 因為是以Sync宣告的屬性，當值發生變更時，
-- 客戶端也會同步該值並自動呼叫OnSyncProperty方法。
self.bestScore = tonumber(tempScore)
end

@ExecSpace("Server")
method void SaveScore(number score)
-- 儲存使用者資訊的方法。

-- 將分數儲存至資料儲存空間的方法。(僅伺服器方法)

-- 利用資料儲存服務取得名為「MyData」的資料儲存空間。
local data = _DataStorageService:GetGlobalDataStorage("MyData")

-- 在該儲存空間內'BestScore'鍵對應的Value值登錄'score'值。
local errorCode = data:SetAndWait("BestScore",tostring(score))
end

@ExecSpace("Server")
method void UpdateScore(number score)
-- 更新伺服器端管理分數值的方法。(僅伺服器方法)

-- 參數1 number score：傳入客戶端管理的分數值。

-- 將伺服器端bestScore值設為參數值。
self.bestScore = score
end

@ExecSpace("ClientOnly")
method void OnSyncProperty(string name, any value)
-- 僅限以Sync宣告的屬性，當伺服器端值變更時自動呼叫的方法。
-- 但若伺服器端變更的值與原本客戶端值相同，則不會呼叫此方法。

-- 若變更的屬性變數名稱為bestScore
if name == "bestScore" then
	-- 請求UIManagerLogic更新主標題畫面的最高分文字。
	_UIManagerLogic:UpdateTitleBestScore(tonumber(value))
end
end

@EventSender("Service", "UserService")
handler HandleUserEnterEvent(UserEnterEvent event)
-- 使用者進入、登入時呼叫的方法。

-- 載入伺服器端資料。
self:LoadData()

end

@EventSender("Service", "UserService")
handler HandleUserLeaveEvent(UserLeaveEvent event)
-- 使用者離開時呼叫的方法。

-- 執行向伺服器端登錄最高分的方法。
self:SaveScore(self.bestScore)
end

end
```

## 撰寫DataSetLogic程式碼
```lua
@Logic
script DataSetLogic extends Logic

property string discript = "" -- 用來管理該世界所管理資料的邏輯。

property table tileSetInfoTable = {} -- 用來儲存圖塊集資料的表格。

property number totalTileSetCount = -1 -- 儲存圖塊種類數量的變數。

property table itemInfoTable = {} -- 用來儲存道具資料的表格。

property table tilesFloorInfoTable = {[1]={} , [2]={}} -- 用來儲存圖塊集樓層資訊的表格。/ ex table[1] = {2,4} 2、4號圖塊集從1樓開始。

property table characterInfoTable = {} -- 儲存角色資訊的表格。

property table skillInfoTable = {} -- 儲存技能資訊的表格。

property table stageRenderInfoTable = {} -- 儲存各階段需渲染資源資訊的表格。

property number stageResourceCount = 0 -- 階段資源種類數。

@ExecSpace("ClientOnly")
method void Init()
-- 進行DataSetLogic元件初始化的方法。

-- 初始化圖塊集表格。
self:InitTileSetInfoTable()
-- 初始化道具表格。
self:InitItemInfoTable()
-- 初始化角色表格。
self:InitCharacterInfoTable()
-- 初始化技能表格。

	local firstTileFloor = self.tileSetInfoTable[i].FirstFloor
```
