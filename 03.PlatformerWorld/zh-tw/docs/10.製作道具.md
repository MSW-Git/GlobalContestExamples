- 在範例世界中，道具登錄的元件有SpriteRendererComponent、TriggerComponent、Item。
- SpriteRendererComponent是用來登錄道具外型的元件。 
- TriggerComponent是用來偵測與角色的碰撞，並用來防止角色被推開等實際物理碰撞發生。
- Item元件是自行製作的腳本，是在偵測到與角色碰撞時，用來區分該道具是什麼道具的元件。

### 製作Item腳本
- Item腳本只會單純登錄道具名稱與道具固有效果值變數。
- 如下撰寫程式碼。
- 該程式碼是以Plain Text為基準撰寫。

```lua
@Component
script Item extends Component

property number discript = 0 -- 這是包含道具基本功能、變數的元件。

property number value = 0 -- 這是道具所擁有的固有數值。

property string name = "" -- 這是用來儲存道具名稱的變數。

end
```

### 登錄道具資料集表格
- 以DataSet製作的各道具資訊，會登錄到DataSetLogic的itemInfoTable中。
- 登錄成資料表的功能，是透過DataSetLogic腳本的InitItemInfoTable方法流程進行。
- 若需要DataSetLogic程式碼內容，可參考「2.理解Logic」單元附上的DataSetLogic腳本內容。 

```lua
DataSetLogic的InitItemInfoTable方法

table itemInfoTable

void InitItemInfoTable()
{
    -- 這是ItemInfo表格的Row數。
    local rowCount = _DataService:GetRowCount("ItemInfo")

    -- 用來儲存各列資料的變數。
    local rowData

    -- 從1開始依資料集Row數進行巡覽。
    for i = 1 , rowCount , 1 do
        rowData = 
        {
            -- 儲存道具名稱。
            Name = tostring(_DataService:GetCell(dataSetName,i,"Name")),
            -- 儲存道具的RUID。
            RUID = tostring(_DataService:GetCell(dataSetName,i,"RUID")),
            -- 儲存道具擁有的效果固有數值。
            Value = tonumber(_DataService:GetCell(dataSetName,i,"Value")),
            -- 儲存道具生成機率。
            SpawnRate = tonumber(_DataService:GetCell(dataSetName,i,"SpawnRate")),
            -- 儲存道具模型(Prefab)的EntryID值。
            EntryID = tostring(_DataService:GetCell(dataSetName,i,"EntryID"))
        }

        -- 將以rowData儲存的資料存入表格。
        self.itemInfoTable[i] = rowData
    end
}
```

### 使用道具資料
- 從ItemInfo DataSet儲存資料到DataSetLogic之後，即可再從DataSetLogic中取出資料。
- 在範例世界中，生成道具時需要用到道具資料表。
- 在物件池中，在世界開始時預先生成道具實體。
- 下列程式碼是ObjectPoolLogic在世界開始時生成道具的CreateItem方法。

```lua
ObjectPoolLogic的CreateItem

table itemDataSetIDTable = {["Coin"] = 1,["Health"] = 2,["Booster"] = 3}

void CreateItem(string itemName, number createCount)
{
  local tempTable

  local dataSetID = self.itemDataSetIDTable[itemName]

  local entryID = _DataSetLogic.itemInfoTable[dataSetID].EntryID
  -- 載入資料集中目標道具模型的Name值。
  local name = _DataSetLogic.itemInfoTable[dataSetID].Name
  -- 載入資料集中目標道具模型的Value值。
  local value = _DataSetLogic.itemInfoTable[dataSetID].Value

  -- 進行目標表格有效性檢查。

  -- /分支1/ 若目標道具池內沒有目標池(表格)
  if isvalid(self.itemPool[name]) == false or self.itemPool[name] == nil then
    -- 建立新的臨時表格。
    tempTable = {}
    -- 將道具池中的內部池(表格)設為臨時表格。
    self.itemPool[name] = tempTable
    
  -- /分支2/ 若目標道具池內已存在目標池
  else
    -- 將臨時表格(池)設為既有使用中的表格。
    tempTable = self.itemPool[name]
  end

  -- 執行參數2 createCount次迴圈。
  for i = 1 , createCount, 1 do 
    -- 使用SpawnService建立物件。
    local entity = _SpawnService:SpawnByModelId(entryID,name,Vector3.up * 100, self.ItemPoolParent)
    
    -- 進行建立物件的設定作業。
    
    -- 設定建立物件的道具固有數值。
    entity.Item.value = value
    -- 設定建立物件的道具name變數。
    entity.Item.name = name
    
    -- 將建立的實體插入應存放的表格(池)。
    table.insert(tempTable,entity)
    
    -- 停用生成的實體物件。
    entity.Enable = false
  end
}
```

## 依道具生成機率產生道具
<p align = "Center">
<img src = "https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Running/MSW-100_Running_10_004.png" alt="MSW-100_Running_10_004.png">
</p>

- 在範例世界中製作的道具共有3種，分別是可取得分數的金幣、可恢復角色體力的恢復型道具，以及可暫時提高捲動畫面速度的加速器道具。
- 若所有道具都以相同機率生成，則可能會因恢復型道具太常出現，而產生遊戲無法結束的平衡性問題。
- 也就是說，可以透過設定生成機率來調整道具的出現頻率。
- 在生成道具時，會抽出0到1之間的亂數(Random)，再與ItemInfo資料集中的SpawnRate值比較，若亂數小於或等於該值，便設計成生成該道具。

```lua
TileSet的SpawnItem方法

    -- 進行機率型生成。(產生隨機數字。)
    local randomRate = math.random(0,100) * 0.01
    
    -- 宣告要設定為Entity型態的區域變數。
    ---@type Entity
    local tempEntity
    
    -- /分支1/ 若隨機機率值小於或等於healthSpawnRate值 
    if _DataSetLogic.itemInfoTable[2].SpawnRate >= randomRate then
    -- 從物件池取得Health道具。
      tempEntity = _ObjectPoolLogic:GetItem("Health")
      
    -- /分支2/ 若隨機機率值小於或等於boosterSpawnRate
    elseif _DataSetLogic.itemInfoTable[3].SpawnRate >= randomRate then
    -- 從物件池取得Booster道具。
      tempEntity = _ObjectPoolLogic:GetItem("Booster")
      
    -- /分支3/ 若未符合其他已設定道具的生成機率，則生成基本道具(Coin)。
    else
      tempEntity = _ObjectPoolLogic:GetItem("Coin")
      
    end
```

## 在指定位置配置道具
<p align = "Center">
<img src = "https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Running/MSW-100_Running_10_005.png" alt="MSW-100_Running_10_005.png">
</p>

- 在地板圖塊集內，已登錄用來設定道具位置的ItemParent實體。
- 從物件池生成的道具，也必須與地板圖塊一樣一起移動。
- 生成的道具會先附加(Attach)為作為基準點實體的子實體(Child)，再將其本地座標初始化為原點(0, 0, 0)，以設定成與父層完全相同的位置。
- 依照ItemParent的子要素數量進行巡覽，重複生成道具。

```lua
TileSet的SpawnItem方法

Entity itemParent -- 這是用來設定道具位置之實體的父實體。

void SpawnItem
{
  -- 進行巡覽用來設定道具位置之實體的子要素。
  for index, child in pairs(self.itemParent.Children) do

  local tempEntity

  -- 比較隨機機率與SpawnRate值後，設定tempEntity的道具實體過程

  -- 將道具實體的父層設為child。
  tempEntity:AttachTo(child)

  -- 將道具實體的本地座標值設為原點，使其與父層處於相同位置。
  tempEntity.TransformComponent.Position = Vector3(0,0,0)
}
```
<br>

## 最低製作標準
- 當道具生成時，必須附加在地板圖塊集上，並隨著地圖捲動畫面移動正常往畫面左側移動。
- 當角色與道具發生Trigger碰撞時，道具實體必須從畫面上消失並回收至物件池。
<br>

## 應用與進階應用
- 隨著遊戲進入後半段，除了正面效果道具之外，也可以機率性生成像是取得後反而遮蔽視野或扣分的陷阱道具，以調整遊戲難度。
- 也可以企劃並以專用腳本擴充新的機制道具，例如在一定時間內無視障礙物碰撞的護盾道具，或一次吸收周圍Coin的磁鐵道具等。.
