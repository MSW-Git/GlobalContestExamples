## 學習目標
- 理解為了營造角色持續奔跑效果，而讓背景與圖塊朝反方向移動的捲動系統核心原理。
- 使用OnUpdate方法與delta時間，撰寫不受幀數影響、能依時間以固定速度平順移動實體的腳本。
- 可透過控制背景畫面與地板圖塊的速度來設定遊戲難度。
- 理解依遊戲進行，關卡環境是如何動態變化的。

## 理解捲動系統的基本結構與原理
- 在跑酷遊戲中，若讓角色無限向右奔跑，將會遇到地圖必須無限延長製作的限制。
- 若角色座標值無限變大，可能在系統上發生致命錯誤。
- 為了克服物理限制並穩定演出無限地圖，有必要導入捲動系統。
<br>

- 不移動攝影機與玩家角色，而是將其固定在畫面某個位置。
- 取而代之的是，將角色踩著的地板圖塊、障礙物、背景元素持續朝角色前進反方向，也就是左方移動。
- 透過這種方式，會在玩家視覺上產生角色向前奔跑的錯覺效果。
- 如此一來，便無需擔心地圖大小或終點，也能製作原地持續奔跑的環境。

## 製作ScrollingController
<p align="Center">
<img src ="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Running/MSW-100_Running_3_002.png" alt="MSW-100_Running_3_002.png">
</p>

- 在空白實體上 建立ScrollingController元件。
  - ScrollingController是管理遊戲整體捲動環境的主體。
  - 將建立實體的TransformComponent之Position值設為(0,0,0)。
- 建立空白實體，並設定為附加ScrollingController元件之實體的子實體。
  - 該實體扮演移動整個圖塊集的父實體角色。
  - 將建立實體的TransformComponent之position值設為(0,0,0)，使其與父層位於同一位置。
<br>

### 建構ScrollingController Component
- 必須撰寫用來控制背景、地板圖塊的程式碼。
- 如下撰寫程式碼。
- 該程式碼是以Plain Text為基準撰寫。

```lua
@Component
script ScrollingController extends Component

property string disscript = "" -- 這是用來在跑酷遊戲內負責整體橫向移動的邏輯。

property Entity tileParent = nil

property number scrollDist = -1 -- 這是用來儲存目前捲動距離的變數。// config中設定每個圖塊集距離為10

property number lastSpawnedTileNumber = -1 -- 這是最後建立的圖塊編號。

property number spawnedCount = -1 -- 這是用來記錄已建立多少個圖塊的變數。

property BackgroundComponent background = nil

property number currentScrollSpeed = 0 -- 這是用來儲存目前捲動畫面速度值的變數。

property number currentBackgroundScrollSpeed = 0 -- 這是用來儲存目前背景捲動畫面速度值的變數。

property number lastTileFloor = 1 -- 這是用來記錄最後建立的最後圖塊樓層的變數。

property number defaultSpeed = -1 -- 這是在選擇角色時設定的捲動畫面速度值。

@ExecSpace("ClientOnly")
method void Scroll(number moveDistance)
-- 將目前設定中的捲動畫面，依傳入的移動距離移動已啟用的圖塊集物件。

-- 移動父物件(TileParent)。
self.tileParent.TransformComponent:Translate(moveDistance,0)
end

@ExecSpace("ClientOnly")
method void ConnectRefs()
-- 連接內部所需成員參照的方法。

-- 連接將成為所有圖塊集父層的物件實體。
self.tileParent = _EntityService:GetEntityByPath("/maps/MainGame/Scrolling/TileParent")

-- 連接Background元件。
self.background = _EntityService:GetEntityByPath("/maps/MainGame/Background").BackgroundComponent
end

@ExecSpace("ClientOnly")
method void Init()
-- 進行Scrolling Controller元件內部初始化的方法。

-- 進行內部參照連接。
self:ConnectRefs()

-- 將背景畫面捲動畫面速度值設為Config中設定的背景捲動畫面速度。
self.background.ScrollRate = _Config.backgroundScrollSpeed

-- 指定實際背景物件進行捲動畫面的速度值。
self.currentBackgroundScrollSpeed = _Config.backgroundScrollSpeed

-- 初始化已建立圖塊集數量。
self.spawnedCount = 0
end

@ExecSpace("ClientOnly")
method void OnUpdate(number delta)
-- 這是每一幀都會被呼叫的方法。

-- 如果主遊戲已結束
if _GameLogic.isEnd == true then
	-- 中止Update方法運作。
	return
end

-- 依設定的捲動畫面速度執行地板物件移動。
self:Scroll(-1 * delta * self.currentScrollSpeed)
end

@ExecSpace("ClientOnly")
method void SpawnRandomTile()
-- 建立隨機圖塊集的方法。

-- 取得與最後建立圖塊編號不重複的隨機編號。
local randomNumber = self:GetRandomTileNumber()

-- 建立隨機編號的圖塊。
self:SpawnTile(randomNumber)
end

@ExecSpace("ClientOnly")
method number GetRandomTileNumber()
-- 用來取得隨機圖塊編號的方法。

-- 這是取得一個表格，其中包含可與最後建立圖塊集終點樓層相連的圖塊集編號之流程。
-- ex) 終點樓層：2樓 / 包含從2樓開始的圖塊集編號的表格 O
-- ex) 終點樓層：1樓 / 包含從2樓開始的圖塊集編號的表格 X
-- 這是為了建立可相連的圖塊集。

-- 這是程序化地圖建立的核心邏輯。

-- 假設最後建立圖塊的結束點樓層為N樓時，
-- 取得包含可從N樓開始的圖塊集編號的表格。
local tileSetFloorInfoTable = _DataSetLogic.tilesFloorInfoTable[self.lastTileFloor]

-- 確認該表格的總數。
local tileSetTableTotalCount = #tileSetFloorInfoTable

-- 以1到圖塊種類數為範圍取得隨機編號。
local randomNumber = math.random(1,tileSetTableTotalCount)

-- 在只包含目標樓層的表格中，抽取第「randomNumber」個圖塊集編號。
local selectedTileNumber = tileSetFloorInfoTable[randomNumber]



-- 用來防止連續建立相同圖塊的邏輯。(若希望允許連續建立相同圖塊集，則不需執行下列語句。)

-- 如果任意抽出的數字編號與之前建立的圖塊編號相同(為防止選到重複圖塊而再次執行隨機抽取。)
if selectedTileNumber == self.lastSpawnedTileNumber then
	
	-- 再次抽取任意隨機數字。(在符合該樓層的圖塊集要素中抽取隨機要素。)
	local tempNumber = math.random(1,tileSetTableTotalCount)
	
	-- 如果臨時數字又再次相同
	if tempNumber == randomNumber then
		-- 將臨時抽出的數字值加1後利用餘數運算。
		tempNumber = (tempNumber + 1) % tileSetTableTotalCount+1
		
		-- 因資料集的起始值是從1開始，若餘數運算結果為0
		if tempNumber == 0 then
			-- 則將tempNumber值設為1。
			tempNumber = 1
		end
		
	end
	-- 在只包含目標樓層的表格中，選擇任意抽出的第'tempNumber'個要素。
	selectedTileNumber = tileSetFloorInfoTable[tempNumber]
end

-- 回傳該圖塊集編號。
return selectedTileNumber
end

@ExecSpace("ClientOnly")
method void SetScrollSpeed(number speed)
-- 調整地板圖塊物件移動速度的方法。

-- 參數1 number speed：傳入欲設定的速度值。

-- 將目前速度值設為作為參數傳入的速度值。
self.currentScrollSpeed = speed
end

@ExecSpace("ClientOnly")
method void SetBackgroundScrollSpeed(number speed)
-- 調整背景畫面捲動畫面速度的方法。

-- 參數1 number speed：傳入欲設定的速度值。

-- 將背景的捲動畫面速度設為參數值。
self.background.ScrollRate = speed
end

@ExecSpace("ClientOnly")
method void ReturnAllTiles()
-- 將所有已建立圖塊集物件全部回收(停用)的方法

-- 從「tileParent」的子層中以遞迴方式存取，將「TileSet」元件存入表格。
local tileSetTable = self.tileParent:GetChildComponentsByTypeName("TileSet",true)

-- 依存有「TileSet」元件的表格數量進行巡覽。
for	i = 1, #tileSetTable, 1 do
	
	-- 若各要素物件目前處於開啟(啟用)狀態時(為了只回收已開啟的物件。)
	if tileSetTable[i].Entity.Enable == true then
			
		-- 存取各要素的圖塊集元件。
		local tempTileset = tileSetTable[i].Entity.TileSet
		-- 將配置為圖塊集子層的道具全部回收。
		tempTileset:ReturnAllItems()
		-- 將該圖塊集再次回收至物件池。
		_ObjectPoolLogic:ReturnTile(tempTileset.Entity)
	end
	
	
end
end

method void SpawnTile(number tileSetNumber)
-- 建立圖塊集物件的方法。

-- 參數1 number tileSetNumber：為建立該參數編號的圖塊集而傳入。

-- 從物件池取得「參數」編號的圖塊物件。
local spawnedTile = _ObjectPoolLogic:GetTile(tileSetNumber)

-- 記錄從物件池生成的圖塊集的結束點樓層。
self.lastTileFloor = _DataSetLogic.tileSetInfoTable[tileSetNumber].LastFloor

-- 設定圖塊集相對於作為基準父物件的x軸距離。
-- spawnedCount(既有生成的圖塊集數) * 10(圖塊集Prefab的基準距離單位)
spawnedTile.TransformComponent.Position = Vector3(self.spawnedCount * 10,0,0)

-- 將已建立圖塊集數加1。
self.spawnedCount += 1
-- 將最後建立的圖塊集編號替換為從物件池取得的圖塊集編號。
self.lastSpawnedTileNumber = tileSetNumber

-- 進行從物件池取得的圖塊集初始化。
spawnedTile.TileSet:Init()
end

@ExecSpace("ClientOnly")
method void Reset()
-- 初始化遊戲進行所需成員要素的方法。

-- 將已建立的圖塊數初始化為0。
self.spawnedCount = 0
-- 將成為所有圖塊集物件父層的「tileParent」物件位置初始化為原點。
self.tileParent.TransformComponent.Position = Vector3(0,0,0)
-- 將背景畫面捲動畫面速度設為Config中作為基準設定的數值。
self:SetBackgroundScrollSpeed(_Config.backgroundScrollSpeed)

-- 開始遊戲時依序建立1到5號圖塊集。

-- 執行從1到5的迴圈時
for	i = 1, 5, 1 do
	-- 建立第i號圖塊。
	self:SpawnTile(i)
end
end

@ExecSpace("ClientOnly")
method void ChangeBackground()
-- 變更背景畫面的方法。

-- 參照登錄在遊戲邏輯中的目前階段編號，將背景畫面設為資料集中儲存的背景RUID值。
self.background:ChangeBackgroundByTemplateRUID(_DataSetLogic.stageRenderInfoTable[_GameLogic.currentStage].BackgroundRUID)
end

end
```

### 階段變更方式
- 管理階段編號的資料，是以GameLogic的currentStage這個number型態變數來管理。
- 在GameLogic的OnUpdate方法中，經過一定時間後會呼叫變更階段的功能。
- 在範例世界中，雖然總共只登錄了3個階段，但利用%運算子，製作成1、2、3 -> 1、2這樣循環階段的結構。
- 地板圖塊與障礙物則是在實體被啟用時，確認GameLogic的currentStage編號，並套用符合目前編號的RUID值。
- 以下程式碼是GameLogic程式碼中的一部分。

```lua
GameLogic
number currentStage = 1 -- 這是用來記錄目前階段資訊的變數。
number stageTimer = 0 -- 這是用來記錄距離階段切換還剩幾秒的變數。

void OnUpdate(number delta) -- 每一幀都會呼叫的方法。
{
    if(stageTimer > 0) then -- 若計時器仍有剩餘時間
        self.stageTimer -= delta -- 計時器減去delta值

    else -- 若計時器沒有剩餘時間
        self.StageChange() -- 呼叫StageChange方法。
        self.stageTimer = _Config.stageChagneTime -- 將計時器初始化為初始時間值。
}

void StageChange() -- 變更階段的方法。
{
    -- 製作成可讓階段編號持續以1、2、3、1循環的結構。
    self.currentStage = (self.currentStage % (totalStageCount+1))+1
    scrollingController:ChangeBackground()
}
```

        _DataSetLogic.stageRenderInfoTable[_GameLogic.currentStage].BackgroundRUID)
}

## 應用與進階應用
- 可在管理地板圖塊、障礙物、背景RUID的DataSet內新增RUID，以組成更豐富的階段。
- 可調整階段切換計時器，在想要的時機切換階段。
