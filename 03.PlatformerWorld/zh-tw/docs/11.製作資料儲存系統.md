## 儲存伺服器端的最高分數值
- 不會在每次分數上升時都與伺服器通訊，而是只在遊戲結束等真正必要的時刻才儲存資料，以減少伺服器負擔。
- 由伺服器端管理的BestScore值，只有在GameOver(體力為0)時，目前分數高於原有最高分數的情況下才會更新。

```lua
更新伺服器端管理的BestScore值的方法
GameLogic中在遊戲結束時呼叫的EndGame方法

[Sync] number bestScore;
[None] number currentScore;

[client] -- 僅客戶端方法
void EndMainGame()
{
    -- 遊戲結束時呼叫的功能

    -- 若目前分數高於原有最高分數
    if self.currentScore > self.bestScore then
        -- 更新由客戶端(本地環境)管理的bestScore分數
        self.bestScore = self.currentScore
        -- 同時請求伺服器端更新分數
        self:UpdateScore(self.bestScore)

    end
}

[server] -- 僅伺服器方法
void UpdateScore(number score)
{
    -- 更新由伺服器端管理而非本地端的bestScore值
    self.bestScore = score
}
```
<br>

## 透過資料儲存儲存使用者最高分數值
- 即使已有由伺服器端管理的資料值，若未另外儲存就再次連線到世界，仍無法載入使用者先前的資料值。
- 若要儲存使用者資料或遊戲資料，需使用DataStorage服務。
- 建議在HandleUserLeaveEvent、HandleUserEnterEvent事件中使用DataStorage功能。

```lua
使用資料儲存來儲存使用者與遊戲資料
GameLogic的SaveScore方法

HandleUserLeaveEvent(UserLeaveEvent event)
{
    self:SaveScore(self.bestScore)
}

[server] -- 僅伺服器方法
void SaveScore(number score)
{
    local data = _DataStorageService:GetGlobalDataStorage("MyData")
    local errorCode = data:SetAndWait("BestScore",tostring(score))
}
```
<br>

## 載入最高分數值
- 與資料儲存相同，在初次進入世界時只請求一次資料，以避免不必要的伺服器通訊。
- 如果玩家連線到世界時已有先前紀錄的最高分數值，則載入該分數值。
<br>

### 使用資料儲存與OnSyncProperty載入先前分數值

1. 可在腳本的Method分頁中，對「＋」按鈕按右鍵後，透過OnSyncProperty建立方法。
<br>

- 若要載入使用者資料或遊戲資料，需使用DataStorage服務。
- 設為Sync的變數，可透過OnSyncProperty方法精準偵測來自伺服器的值已完成同步的時點。

```lua
使用DataStorage來載入使用者與遊戲資料
GameLogic的LoadData方法

[Sync] number bestScore

HandleUserEnterEvent(UserEnterEvent event)
{
    self:LoadData()
}

[server] -- 僅伺服器方法
void LoadData()
{
    -- 利用資料儲存服務取得名為「MyData」的資料儲存空間。
    local data = _DataStorageService:GetGlobalDataStorage("MyData")

    -- 取得該資料儲存空間內'BestScore'鍵所對應的Value值。
    local errorCode,value = data:GetAndWait("BestScore")

    -- 登錄臨時分數值變數。
    local tempScore

    -- 若沒有已儲存資料
    if value == nil then
        -- 將臨時分數值設為0。
        tempScore = 0
        
    -- 若有已儲存資料
    else
        -- 將臨時分數值設為原有分數值。
        tempScore = tonumber(value)
    end

    -- 更新bestScore值。
    -- 因為是以Sync宣告的屬性，當值發生變更時，
    -- 客戶端也會同步該值並自動呼叫OnSyncProperty方法。
    self.bestScore = tonumber(tempScore)
}

[client only]
void OnSyncProperty(string name, any value)
{
    -- 當偵測到變數(屬性)的變更時

    -- 若變更的變數名稱是「bestScore」
    if name == "bestScore" then
    -- 則請求UIManagerLogic更新主標題畫面的最高分文字。
	_UIManagerLogic:UpdateTitleBestScore(tonumber(value))
    end
}
```
<br>

## 最低製作標準
- 當玩家在遊戲中達成新的最高分，並完全結束世界後再次連線時，標題畫面上顯示的先前最高分不能被重設為0，而必須正常顯示。
- 在伺服器分數資料同步完成之前，UI文字不可先行更新而顯示空值或錯誤，因此必須讓透過OnSyncProperty進行的時點控制能完美運作。
<br>
