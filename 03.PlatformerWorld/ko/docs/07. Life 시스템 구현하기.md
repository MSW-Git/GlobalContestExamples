## 학습 목표
- OnUpdate메서드와 delta시간의 개념을 이해하고, 기기 프레임에 구애받지 않고 시간에 따라 일정하게 체력이 감소하는 로직을 구현할 수 있습니다.
- 캐릭터의 체력이 0 이하로 떨어졌을 때 이를 감지하여 게임 오버 처리를 수행하는 상태 제어 흐름을 학습합니다.
- UI 엔티티에 SliderComponent를 부착하여 시각적인 체력 바를 만들고, 내부 데이터와 화면상의 UI를 실시간으로 동기화하는 방법을 익힙니다.
<br>

## 해당 영상 시청 후 수행해 볼 내용
- Config Logic스크립트에 설정된 decreaseHpValue 변수값을 변경해 테스트를 진행하며 얼마나 체력을 빠르게 감소시킬지 설정해 봅니다.
- 인게임에서 시간이 지남에 따라 UI의 체력 게이지가 부드럽게 감소하는지, 그리고 체력이 0이 되었을 때 결과 창으로 정상 전환되는지 플레이 버튼을 눌러 테스트해 봅니다.

## 시간에 따른 체력 감소 기능 구현
<p align = "Center">
<img src="../../_images/MSW-100_Running_7_001.gif" alt="MSW-100_Running_7_001.gif">
</p>

- 체력 제어 기능은 아이템 획득 및 장애물 충돌 시의 즉각적인 변화뿐만 아니라, 시간이 지남에 따라 주기적으로 체력이 감소하는 기능도 함께 포함하여 제작되었습니다.
- 코드로 체력을 감소시키는 기능은 GameLogic의 AutoDecreaseHp와 AddHP, SetHP메서드의 기능으로 정의되어 있으며, 각 기능은 GameLogic의 OnUpdate메서드 내에서 수행됩니다.
- GameLogic코드의 내용이 필요한 경우 '2.Logic 이해하기' 단원에 첨부된 GameLogic스크립트 내용이 첨부되어 있습니다.
<br>

### 체력 설정 기능
- 체력을 추가, 감소 시키는 기능은 GameLogic의 AddHP메서드를 활용합니다.

```lua
GameLogic 내 AddHP 메서드

number hp;

void AddHP(number addValue)
{
    -- 매개변수로 전달받은 값을 현재 체력에 그대로 더하거나 뺍니다.
    -- AddHP 메서드를 호출할 때 양수 또는 음수를 전달하여 회복과 감소 기능을 모두 유연하게 수행할 수 있습니다.

    self.hp += addValue;

    -- 체력값의 변동이 발생되었으므로 UIManagerLogic이 관리하는 슬라이더의 정보를 갱신하도록 요청합니다. 
    _UIManagerLogic.SetHpSliderValue(self.hp)

    -- 체력이 0 이하로 떨어진 경우 (게임 오버 조건 충족 시)
    if self.hp <= 0 then
        -- 게임 종료 기능 수행
    end
}

```
<br>

### 지속적인 체력감소 기능 구현
- 매 프레임 호출되는 OnUpdate 메서드를 활용하면 체력이 서서히 줄어드는 연출을 구현할 수 있습니다.
- 단, 이때 프레임 간 시간 변화량인 delta를 곱해주지 않으면, 기기의 프레임 속도(FPS)에 따라 체력이 비정상적으로 빠르게 증발하는 치명적인 문제가 발생합니다.
- 초당 프레임이 60FPS인 경우 프레임 간 시간 변화량 delta값은 1Sec/60FPS = 0.0167Sec 입니다.
- 만약 1초당 5의 체력을 감소시키고 싶다면, 매 프레임마다 5 * delta 값을 계산하여 감소시키면 됩니다. 기기가 60프레임으로 동작하든 30프레임으로 동작하든, 1초가 지났을 때 누적 감소량은 정확히 5가 됩니다.

```lua
GameLogic의 OnUpdate메서드의 체력감소 기능 부분 예시

void OnUpdate(number delta)
{
    -- Config : 한번 설정된 값이 변경되지 않을 경우 해당 Logic스크립트에 등록되어 관리되고 있습니다.
    -- 설정한 초당 체력 감소값 * delta 만큼 체력을 반영
    self:AddHP(delta * _Config.decreaseHpValue)
}

void AddHP(number addValue)
{
    -- 매개변수로 전달받은 값을 체력값 그대로 추가, 감소시켜주도록 합니다.
    -- AddHP메서드를 활용할때 양수값, 음수값을 전달해 의도대로 기능을 수행할 수 있습니다.

    self.hp += addValue;

    -- 체력값의 변동이 발생되었으므로 UIManagerLogic이 관리하는 슬라이더의 정보를 갱신하도록 요청합니다. 
    _UIManagerLogic.SetHpSliderValue(self.hp)

    -- 체력값이 0이 되었을 경우(더 이상 게임을 진행할 수 없을 때)
    if self.hp <= 0 then
        -- 게임 종료 기능 수행
    end
}
```

## SliderComponent를 활용한 체력 바(UI) 연동

### 체력 바 UI 제작하기

<img src="../../_images/MSW-100_Running_7_002.png" alt="MSW-100_Running_7_002.png">

1. Ui 하위 항목 내에서 캔버스 역할을 수행하는 엔티티를 선택합니다.
2. Create Entity as Child에서 Create UISprite를 선택하여 Sprite로 활용될 UI를 생성합니다.
3. 해당 UI는 체력바의 배경이 될 Sprite 이미지입니다.
<br>

<p align = "Center">
<img src="../../_images/MSW-100_Running_7_003.png" alt="MSW-100_Running_7_003.png">

- 생성된 엔티티에서 SpriteGUIRendererComponent에서 체력바의 배경으로 활용할 이미지 RUID, 색상을 설정합니다.

✅ 생성된 UI 엔티티가 보이지 않는다면, 엔티티에 기본적으로 등록되는 Component인 UITransformComponent의 좌표가 잘못되어 있는지 확인합니다.
<br>

<p align = "Center">

</p>

- 체력바의 배경 위를 덮을 수 있도록 SliderComponent를 등록합니다.
- FillRectColor 색상을 설정하고 정상적으로 배경 이미지를 덮는지 확인합니다.
- 컴포넌트의 내부 속성인 Value를 변경해 보며 정상적으로 게이지 역할을 수행하는지 체크합니다.
- 샘플 월드의 경우 최대 체력값은 100이라는 설정하에 제작이 진행되어 있습니다.
<br>

### UIManagerLogic으로 체력 바 UI 제어하기
- 게이지 역할을 수행할 엔티티는 UIManagerLogic에 등록되어 있습니다.
- UIManagerLogic코드의 내용이 필요한 경우 '2.Logic 이해하기' 단원에 첨부된 UIManagerLogic스크립트 내용이 첨부되어 있습니다.
- SliderComponent가 부착된 엔티티의 참조를 연결하고, GameLogic에서 체력이 변할 때마다 이 로직을 호출하여 Slider의 Value 속성에 최신 체력값을 실시간으로 덮어씌웁니다.

```lua
UIManagerLogic의 SetHpSliderValue메서드 구현 예시

SliderComponent hpSlider;

void SetHpSliderValue(number value)
{   
    -- 설정될 슬라이더값을 math.clamp메서드를 활용해 0 미만, 100 초과의 값을 넘지 않도록 설정합니다.
    self.hpSlider.Value = math.clamp(value, 0, 100)
}

```
<br>

## 최소 구현 기준
- 스크립트 내부의 체력 데이터(hp)변화가 UIManagerLogic을 통해 전달되어, 화면 상의 SliderComponent 게이지 UI에 실시간으로 동기화되어야 합니다.
- 체력이 0 이하로 떨어지는 즉시 이를 감지하여 더 이상 체력이 마이너스로 내려가지 않도록 제한하고, 게임 오버 처리가 정상적으로 호출되어야 합니다.
<br>

## 응용 및 확장 방향
- 체력이 일정 수치(예:20%) 이하의 위험 상태로 떨어졌을 때, SliderComponent의 게이지 색상을 붉은색으로 깜빡이게 변경하여 플레이어에게 시각적인 긴장감과 경고 피드백을 제공해 볼 수 있습니다.
