## Manager 개념
<p align="center">
<img src = "https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Running/MSW-100_Running_2_003.png" alt="MSW-100_Running_2_003.png">
</p>

- Logic은 특정한 기능이나 역할을 지정하고, 해당하는 기능을 수행하도록 담당자 형태로 제작할 수 있습니다.
- 하나의 기능이나 역할을 담당하는 담당자를 Manager라고 칭합니다.
- 만약 특정 기능에 문제가 생겼을 경우, Manager의 내용만 수정하여, 기능을 빠르고 편하게 해결할 수 있습니다.
    - Case 1: 캐릭터가 데미지 계산을 완료하고 몬스터에게 전달하는 경우
        - 데미지 계산식이 변경될 때마다, 데미지 계산에 신규 요소가 추가될 때마다 계산식을 변경해야 합니다.
        - 모든 캐릭터의 코드를 일일이 찾아 수정해야 합니다.
    - Case 2: 데미지 계산을 Logic으로 제작한 Manager에게 요청하는 경우
        - Logic 내에 있는 데미지 계산식을 변경합니다.
        - 모든 캐릭터, 몬스터의 데미지 계산을 Logic이 담당하므로 더 이상 수정할 요소가 없습니다.
        - 추후 데미지 계산식에 문제가 생겨도, Manager를 수정하면 해결할 수 있습니다.
<br>

## 샘플 월드 내 Logic 사용 예시

### GameLogic의 경우
- 게임이 시작되면, 지속적해서 체력을 감소하며 점수를 증가시키는 기능을 처리하고 있습니다.
- 관리되고 있는 체력이 0이 될 경우 결과 화면을 요청하며 현재 점수와 기존 최고 점수를 비교하여 유저의 최고 점수를 갱신합니다.
- 본격적인 게임이 진행될 때, 일정시간마다 스테이지의 전환을 위한 타이머 기능을 수행합니다.
<br> 

### DataSetLogic의 경우
- 메이플스토리 월드의 내장 기능인 DataService를 활용해 아이템, 타일, 캐릭터 정보 등의 원본 데이터를 읽어옵니다.
- 읽어온 데이터를 코드에서 이름만 대면 바로 찾을 수 있도록 꼬리표(Key)를 달아, 알아보기 쉬운 Lua 테이블 변수 형태로 정리해 두는 역할을 합니다.
<br>

### UIManagerLogic의 경우
- 타이틀 화면, 캐릭터 선택 창, 체력 및 점수 표시, 결과 팝업 등 게임 내 존재하는 UI요소의 참조 경로를 중앙에서 통합하여 관리합니다.
- 각 UI요소를 찾기 위한 복잡한 경로를 하나로 모아두어, 다른 스크립트에서 특정 UI 조작이 필요할 때 간편하게 접근할 수 있도록 돕습니다.
- 엔티티 참조로 설정한 상태에서 게임 상태(시작,플레이,종료)에 따라 필요한 UI 그룹만 일괄적으로 켜고 끄는 팝업 제어 기능을 수행합니다.
<br>

## GameLogic 코드 작성하기
```lua
@Logic
script GameLogic extends Logic

property number discript = 0 -- 게임의 전체적인 흐름을 제어하기 위한 로직입니다.

property ScrollingController scrollingController = nil

property number currentScore = 0 -- 현재 게임 점수값을 담기 위한 변수입니다.

@Sync
property number bestScore = 0 -- 플레이어의 최고 점수를 담기 위한 변수입니다.

property number scoreIncreaseTimer = 0 -- 주기적으로 점수를 갱신하기 위한 타이머 변수입니다.

property number currentStage = 1 -- 현재 스테이지 번호를 저장하기 위한 변수입니다.

property number stageTimer = 0 -- 스테이지가 전환 될 타이밍을 측정하기 위한 타이머 변수입니다.

property number hp = 0 -- 플레이어의 체력값을 저장하기 위한 변수입니다.

property boolean isEnd = true -- 게임이 종료되었음을 기록하는 상태 변수입니다.

property boolean isMobile = true -- 구동환경이 모바일 환경인지 상태를 저장하는 변수입니다.

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- 월드 시작 시 호출되는 메서드입니다.

-- 게임 로직의 초기화를 진행합니다.
self:Init()

-- 월드 진행이 모바일로 진행되는지 상태변수로 저장합니다.
self.isMobile = Environment:IsMobilePlatform()

-- 월드 시작 시 배경음악을 재생합니다.
_SoundService:PlayBGM("f5bb92d91e134c699e7bb2cf1aaca8e6",0.4)
end

@ExecSpace("ClientOnly")
method void Init()
-- 전반적인 게임을 관리하는 메인 로직의 초기화를 진행합니다.

-- 내부 멤버 참조를 연결합니다.
self:ConnectRefs()

-- 다른 핵심 로직들의 초기화를 진행합니다.
self:OrderInit()
-- 점수값을 초기화합니다.
self:SetScore(0)
-- 현재 체력값을 초기화합니다.
self:SetHP(100)
end

@ExecSpace("ClientOnly")
method void ConnectRefs()
-- 내부 멤버의 참조를 연결하는 메서드입니다.

-- 스크롤링 컨트롤러 엔티티를 연결합니다.
self.scrollingController = _EntityService:GetEntityByPath("/maps/MainGame/Scrolling").ScrollingController
end

@ExecSpace("ClientOnly")
method void OrderInit()
-- 게임 로직으로부터 각 핵심 로직, 컴포넌트들의 초기화 명령을 진행합니다.

-- 스크롤링 컨트롤러 초기화를 진행합니다.
self.scrollingController:Init()
-- 데이터셋 로직 초기화를 진행합니다.
_DataSetLogic:Init()
-- UI매니저로직 초기화를 진행합니다.
_UIManagerLogic:Init()
-- 오브젝트 풀 로직 초기화를 진행합니다.
_ObjectPoolLogic:Init()
end

@ExecSpace("ClientOnly")
method void OnUpdate(number delta)
-- 매 프레임마다 호출되는 메서드입니다.

-- 게임이 진행중이 아니라면
if self.isEnd == true then
	-- 메서드를 종료합니다.
	return
end

-- delta 값만큼 자동으로 체력을 감소합니다.
self:AutoDecreaseHp(delta)
-- delta 값만큼 자동으로 점수를 증가합니다.
self:AutoIncreaseScore(delta)

-- /분기1/ 스테이지 타이머의 남은 시간이 있다면
if self.stageTimer > 0 then
	-- 스테이지 타이머의 값에 delta값을 감소합니다.
	self.stageTimer -= delta
-- /분기2/ 스테이지 타이머에 남은 시간값이 없다면
else 
	-- 스테이지 전환을 호출합니다.
	self:StageChange()
	-- 스테이지 타이머 값을 Config에 설정한 값으로 초기화합니다.
	self.stageTimer = _Config.stageChangeTime
end


end

@ExecSpace("ClientOnly")
method void AutoIncreaseScore(number delta)
-- increaseScoreIntervalSecond(주기) 마다 점수를 증가시키는 메서드입니다.

-- /분기1/ 측정 타이머의 값이 기준이 되는 Interval 값보다 작다면
if self.scoreIncreaseTimer < _Config.increaseScoreInterval then
	-- 타이머에 delta값을 추가시킨뒤 메서드 종료합니다.
	self.scoreIncreaseTimer += delta
	return
end

-- /분기2/ 측정 타이머의 값이 기준이 되는 Interval 값보다 크거나 같다면 (특정 주기 도달시점입니다.)

-- 점수를 추가합니다.
self:AddScore(_Config.increaseScore)
-- 측정 타이머를 초기화합니다.
self.scoreIncreaseTimer = 0
end

@ExecSpace("ClientOnly")
method void AutoDecreaseHp(number delta)
-- 자동으로 체력을 감소시키는 메서드입니다.

-- 현재 체력값에 감소되어야하는 값을 전달합니다.
self:AddHP(delta * _Config.decreaseHpValue)
end

@ExecSpace("ClientOnly")
method void SetScore(number value)
-- 매개변수로 전달받은 값을 Score 값으로 설정시키는 메서드입니다.

-- 매개변수 1 number value : 점수값으로 설정되는 값입니다.

-- 현재 점수값을 특정값으로 설정합니다.
self.currentScore = value
-- UIManager에 등록된 Text에 특정값으로 설정합니다.
_UIManagerLogic:SetScoreText(value)
end

@ExecSpace("ClientOnly")
method void AddScore(number addValue)
-- 매개변수로 전달받은 값을 Score 값에 추가시키는 메서드입니다.

-- 매개변수 1 number addValue : 기존 점수값에 추가되는 값을 전달받습니다.

-- 현재 점수에 전달받은 값을 추가시킵니다.
self.currentScore += addValue
-- UIManager 에 등록된 Text에 현재 점수값을 전달합니다.
_UIManagerLogic:SetScoreText(self.currentScore)
end

@ExecSpace("ClientOnly")
method void SetHP(number value)
-- 매개변수로 전달받은 값을 Hp 값으로 설정시키는 메서드입니다.

-- 매개변수 1 number value : Hp 값으로 설정되는 값을 전달받습니다.

-- 체력값을 특정값으로 설정합니다. (clamp 를 활용해 미만, 초과를 제한합니다.)
self.hp = math.clamp(value,0,_Config.maxHp)

-- UIManager에 등록된 슬라이더에 체력값을 반영합니다.
_UIManagerLogic:SetHpSliderValue(self.hp)
end

@ExecSpace("ClientOnly")
method void AddHP(number addValue)
-- 매개변수로 전달받은 값을 체력값에 추가시키는 메서드입니다.

-- 매개변수 1 number addValue : 추가되는 체력값을 전달받습니다.

-- 현재 체력에 매개변수값을 추가합니다.
self.hp += addValue

-- clamp 를 활용해 미만, 초과를 제한합니다.
self.hp = math.clamp(self.hp,0,_Config.maxHp)

-- UIManager에 등록된 슬라이더에 체력값을 반영합니다.
_UIManagerLogic:SetHpSliderValue(self.hp)

-- 체력값이 0보다 작거나 같다면
if self.hp <= 0 then
	-- 게임 종료 로직을 수행합니다.
	self:EndMainGame()
end
end

@ExecSpace("Client")
method void EndMainGame()
-- 게임을 종료하는 메서드입니다. (클라이언트전용 메서드)

-- 게임이 종료되었음 상태로 전환합니다.
self.isEnd = true

-- 캐릭터를 보이지 않게 설정합니다.
_UserService.LocalPlayer.Visible = false

-- 게임종료 시 구동환경이 모바일이라면 조이스틱을 비활성화합니다.
_UIManagerLogic:ShowMobileJoyStick(false)

-- 결과창 팝업내 설정될 값을 지정하고 화면 내 출력합니다. (최고 점수와, 현재 점수를 전달합니다.)
_UIManagerLogic:ShowResultPopup(tostring(math.floor(self.bestScore)),tostring(math.floor(self.currentScore)))

-- 스크롤링 컨트롤러에게 모든타일셋 오브젝트 반환(비활성화)을 진행합니다.
self.scrollingController:ReturnAllTiles()

-- 배경 스크롤링 속도를 감소시킵니다.
self.scrollingController.background.ScrollRate = 0.5

-- 현재 점수가 클라이언트 내에서 관리되고 있는 최고 점수보다 높다면
if self.currentScore > self.bestScore then
	-- 최고 점수값을 현재 점수로 설정합니다.
	self.bestScore = self.currentScore
	-- 최고 점수가 변경된 시점으므로 서버측의 최고 점숫값을 갱신합니다.
	self:UpdateScore(self.bestScore)
end

-- 메인타이틀의 최고 점숫값을 반영합니다.
_UIManagerLogic:UpdateTitleBestScore(self.bestScore)
end

@ExecSpace("ClientOnly")
method void GameStart(number selectCharacterId)
-- 메인게임을 시작할때 호출되는 메서드입니다.

-- CharacterInfoTable에서 캐릭터 선택 창에서 선택했던 캐릭터의 속도값을 가져옵니다.
local scrollSpeed = _DataSetLogic.characterInfoTable[selectCharacterId].Speed

	else
```

```lua
@ExecSpace("ClientOnly")
method void UpdateTitleBestScore(number score)
-- 메인 타이틀 화면에서 표기되는 최고 점수값을 설정하는 메서드입니다.

-- 매개변수 1 number score : 전달받는 값으로 타이틀의 화면내 점수값을 설정합니다.

-- score 값이 없을 경우
if score == nil or score <= 0 then
	-- 메인 타이틀 화면의 최고 점수 텍스트값을 '0'으로 설정합니다.
	self.titleBestScore.Text = "0"

-- score 값이 있었다면 
else
	-- 메인 타이틀 화면의 최고 점수를 전달받은 값으로 등록합니다. math.floor를 활용해 소수점 이하 부분을 버립니다.
	self.titleBestScore.Text = tostring(math.floor(score))
	
end
end
```

## 응용 및 확장 방향
- 매 초마다 점수를 추가하는 기능을 자신만의 점수 부여 공식으로 변경하여 게임의 흐름을 변경합니다.
- Logic을 활용하여 **변경 예정이 없는** 고정값을 관리하기 위한 'Config' 로직을 제작하여 사용합니다.
  - EX: 기존에 설정된 최대 체력값을 변경하여 게임의 난이도를 수정합니다.
  - EX: 시간에 따라 지속해서 감소하는 체력을 변경하여 게임의 난이도를 수정합니다.
