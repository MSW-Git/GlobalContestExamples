# 러닝플랫포머 학습 가이드 문서
<br>
<br>
<br>

## 학습 목표

- 가이드 문서와 샘플 월드를 통하여 러닝플랫포머 게임의 핵심 기능들을 구현하는 방법에 대해 학습합니다.
- 메이플스토리 월드에서 제작하려는 게임의 방식에 따라 맵을 세팅하는 방법에 대해 학습합니다.
- Logic에 대해 이해하고, 이를 활용하여 게임 구조를 설계하는 방법을 학습합니다.
- 학습한 내용을 바탕으로 월드를 원하는 형태로 가공하고 응용할 수 있습니다.
<br>

---

<br>

## 학습 핵심 기능
- **Physics Component**: 기본 제공되는 Body 컴포넌트(Rigid, Kinematic, Sideview)외에도, 물리 엔진이 적용된 PhysicsBody와 PhysicsCollider 컴포넌트의 사용법을 학습합니다.
- **절차적 맵 생성**: 캐릭터가 달릴 수 있는 발판을 단순히 무작위로 무작위로 생성하는 것을 넘어, 타일이 자연스럽게 연결되도록 생성하는 방법을 학습합니다.
- **오브젝트 풀**: 다수의 발판 타일, 아이템을 관리하기 위해 오브젝트 풀 기법의 원리를 학습하고, 제작할 수 있습니다.

<br>

## 🔄 핵심 게임플레이 루프

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Running/MSW-100_Running_0_001.png" alt="MSW-100_Running_0_001.png">
</p>
<br>

**1. 게임 시작**: 타이틀 화면과 함께 게임 시작 또는 게임의 조작방법을 확인할 수 있습니다.<br>
**2. 플레이 캐릭터 선택**: 타이틀 화면에서 게임 시작 버튼을 눌렀을 경우 캐릭터를 선택하는 UI가 출력됩니다.<br>
**3. 인게임 시작**: 카운트다운을 진행하고 본격적인 게임을 시작합니다. 캐릭터별 스크롤 속도가 적용되어 타일, 배경요소가 캐릭터 반대 방향으로 이동되며 아이템, 장애물 요소와 상호작용이 일어납니다. <br>
**4. 캐릭터 체력 상태 검사**: 게임 종료 조건인 시간에 따라 시간 흐름에 따라 지속해서 감소하는 체력이 0이 되었는지 확인합니다. <br>
**5. 결과 확인**: 현재 점수와 기존 최고 점숫값을 게임 결과 창에 출력하며 만약 현재 점수가 기존 최고 점숫값보다 높다면 유저의 최고 점숫값을 새로 갱신합니다. <br>
**6. 재시작 요청 확인**: 게임 결과 창에서 타이틀 화면 복귀를 요청하면, 초기 타이틀 상태로 돌아갑니다.

## 구현 순서

- 💡 **기초 학습**: 메이플스토리 월드의 기본 기능 및 해당 장르의 기초적인 기능을 담은 학습 항목입니다.
- 📖 **심화 학습**: 샘플 월드에 구현된 기능을 학습하고 구현하는 항목입니다. 해당 과정의 학습을 통해 장르의 기능 확장과 학습 이해도를 높일 수 있습니다. 

### [💡기초 학습]1. 월드 환경 구성하기
- 메이플스토리 월드에서 제공하는 맵의 종류와 각 Body 컴포넌트의 관계에 대해 학습합니다.
- 러닝플랫포머 게임을 제작할 때 어떠한 게임제작 환경이 필요한지 학습합니다.
- PhysicsRigidbody, PhysicsCollider 컴포넌트에 대해 학습합니다.
- 실제 월드에 적용해보며, 필요한 설정이 무엇인지 파악합니다.
<br>

### [💡기초 학습]2. Logic 이해하기
- Logic이 어떤 역할을 하는지에 대해 학습합니다.
- Manager에 대한 개념을 이해하고, 사용 방법을 학습합니다.
- GameLogic, DataSetLogic, UIManagerLogic 구성 이유와 목적을 이해합니다.
<br>

### [💡기초 학습]3. 스크롤 시스템 구성하기
- 러닝플랫포머 게임을 제작할 때 캐릭터와 환경요소의 이동방식을 학습합니다.
- 월드에서 보이는 배경 요소를 제어하는 방법을 학습합니다.
- 게임 진행 시점 이후로 시간이 지남에 따라 환경요소의 외형을 변경하는 방법을 학습합니다.
<br>

### [💡기초 학습]4. 절차적 생성 방식을 통한 맵 관리하기
- 러닝플랫포머에서 절차적 생성 방식이 무엇인지, 필요한 이유에 대해 학습합니다.
- 게임에서 활용될 바닥 타일을 제작하며 이를 Model로 구성하는 방법을 학습합니다.
- 데이터 테이블을 기반으로 절차적 생성 방식으로 바닥 타일이 생성될 수 있도록 DataSet을 제작합니다.
- 절차적 생성 방식을 활용한 바닥 타일을 생성하며 무한한 스크롤링 환경을 구현합니다. 
<br>

### [💡기초 학습]5. 오브젝트 풀 생성하기
- 오브젝트 풀에 대한 개념을 학습하고 오브젝트 풀의 목적을 이해합니다.
- 오브젝트 풀 Logic을 구현합니다.
- 오브젝트 풀의 생성과 반환을 통해 작동 방식을 직접 확인합니다.
- 바닥 타일이 파괴되었을 때, 타일을 새로 생성하는 방법에 대해 학습합니다.
<br>

### [💡기초 학습]6. 플레이어 캐릭터 구현하기
- 러닝플랫포머 게임에서 캐릭터에게 점프, 슬라이딩 동작을 수행 시키는 방법을 학습합니다.
- 다양한 캐릭터를 만들기 위해 필요한 DataSet을 구성하는 방법을 학습하고 제작해봅니다.
- 게임이 재시작 될 경우 캐릭터의 상태 및 정보를 되돌리는 방법에 대해 학습합니다.
- 플레이어가 스킬 키 입력 시 발동되는 캐릭터별 스킬을 수행 시키는 방법을 알아봅니다.
- 플레이어에게 다양한 캐릭터를 선택할 수 있는 선택창을 제공하는 방법과 캐릭터를 선택하는 기능을 구현합니다.
<br>

### [💡기초 학습]7. Life 시스템 구현하기
- 본격적인 게임이 시작된 이후, 지속적으로 체력이 감소되는 기능을 제작하는 방법을 학습합니다.
- 체력이 지속적으로 감소될 때 이를 유저가 확인할 수 있는 UI 요소를 제작하는 방법을 학습합니다.
<br>

### [💡기초 학습]8. UI 구성하기
- UIGroup이 무엇인지, 활용 및 편집 방법에 대해 학습합니다.
- 타이틀 화면에 활용되는 UI 요소를 제작하며 UI 편집 방법에 대해 학습합니다.
- 타이틀 화면에 나타나는 UI 요소를 Manager Logic을 통해 코드로 제어하는 방법을 학습합니다.
- 인게임 내에 표기되어야 하는 UI 요소를 제작하며 실시간으로 연동되도록 구현합니다.
- 게임이 종료되었을 때 각 점수를 나타내는 결과창을 나타내는 UI를 구성합니다.
<br>

### [📖심화 학습]9. 장애물 오브젝트 구현하기
- 지속적으로 움직이고 있는 바닥 타일에 장애물 요소를 어떻게 배치할지에 대해 학습합니다.
- 캐릭터와 장애물의 충돌을 감지할 수 있도록 설정하는 방법에 대해 학습합니다.
- 캐릭터와 장애물이 충돌되었을 때 캐릭터의 체력이 감소되는 기능을 반영합니다.
<br>

### [📖심화 학습]10. 아이템 구현하기
- 지속적으로 움직이고 있는 바닥 타일에 아이템 요소를 어떻게 배치할지에 대해 학습합니다.
- 다양한 효과를 갖는 아이템을 구성하기 위해 DataSet을 구성하는 방법에 대해 학습합니다.
- 저장된 아이템 데이터 테이블을 기반으로 효과와 고윳값을 설정하는 방법에 대해 학습합니다.
- 캐릭터와 아이템의 충돌 시 발생되는 다양한 아이템 효과를 발동시키는 방법과 실제 동작을 구현합니다.
<br>

### [📖심화 학습]11. 데이터 저장 시스템 구현하기
- 플레이어의 캐릭터 사망 시, 현재 점수가 기존 최고 점수보다 높을 경우 이를 갱신하여 저장하는 방법에 대해 학습합니다.
- 플레이어가 월드를 실행했을 때 이전에 최고 점수가 있었다면 이를 불러와서 타이틀 화면에 보일 수 있도록 제작합니다.
<br>
