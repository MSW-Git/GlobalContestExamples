## 학습 목표
- DataSet에 아이템의 고유 정보(효과 값, 스폰 확률 등)를 정의하고, 이를 활용하기 위해 테이블 형태로 변환하여 관리하는 과정을 이해합니다.
- 오브젝트 풀링 시스템을 응용하여, 난수 연산을 통해 확률적으로 아이템을 스폰하고 맵 타일에 종속시키는 방법을 구현할 수 있습니다.
- 캐릭터와 아이템의 충돌을 감지하고, ItemLogic을 통해 획득한 아이템의 종류에 맞는 개별 효과(점수 증가, 체력 회복, 부스터 등)를 발동시키는 흐름을 학습합니다.

- 획득한 아이템 수치가 UI와 시스템에 정상적으로 반영되는지 플레이를 통해 점검해 봅니다.

```lua
@Component
script Item extends Component
```

### 아이템 데이터셋 테이블 등록하기
- DataSet으로 제작된 아이템별 정보는 DataSetLogic의 itemInfoTable에 등록됩니다.
- 데이터 테이블로 등록하는 기능은 DataSetLogic 스크립트의 InitItemInfoTable메서드 과정으로 진행됩니다.
- DataSetLogic코드의 내용이 필요한 경우 '2.Logic 이해하기' 단원에 첨부된 DataSetLogic스크립트 내용이 첨부되어 있습니다. 

```lua
DataSetLogic의 InitItemInfoTable메서드

table itemInfoTable

void InitItemInfoTable()
{
    -- ItemInfo 테이블의 Row수입니다.
    local rowCount = _DataService:GetRowCount("ItemInfo")

    -- 각 줄의 데이터를 담기 위한 변수입니다.
    local rowData

    -- 1 부터 데이터셋의 Row수만큼 순회 시작합니다.
    for i = 1 , rowCount , 1 do
        rowData = 
        {
            -- 아이템 이름을 저장합니다.
            Name = tostring(_DataService:GetCell(dataSetName,i,"Name")),
            -- 아이템의 RUID 를 저장합니다.
            RUID = tostring(_DataService:GetCell(dataSetName,i,"RUID")),
            -- 아이템이 가지는 효과 고윳값을 저장합니다.
            Value = tonumber(_DataService:GetCell(dataSetName,i,"Value")),
            -- 아이템 생성 확률을 저장합니다.
            SpawnRate = tonumber(_DataService:GetCell(dataSetName,i,"SpawnRate")),
            -- 아이템의 모델(프리팹)의 EntryID 값을 저장합니다.
            EntryID = tostring(_DataService:GetCell(dataSetName,i,"EntryID"))
        }

        -- rowData로 저장한 데이터들을 테이블에 저장합니다.
        self.itemInfoTable[i] = rowData
    end
}
```

### 아이템 데이터 활용하기
- ItemInfo DataSet으로부터 DataSetLogic으로 데이터를 저장한 후 DataSetLogic으로부터 데이터를 가져올 수 있습니다.
- 샘플 월드에서 아이템을 생성할 때 아이템에 대한 데이터 테이블이 필요합니다.
- 오브젝트 풀에서 월드 시작 시 아이템 엔티티를 미리 생성해둡니다.
- 다음의 코드는 월드 시작 시 아이템을 생성하는 ObjectPoolLogic의 CreateItem메서드입니다.

```lua
ObjectPoolLogic의 CreateItem

table itemDataSetIDTable = {["Coin"] = 1,["Health"] = 2,["Booster"] = 3}

void CreateItem(string itemName, number createCount)
{
  local tempTable

  local dataSetID = self.itemDataSetIDTable[itemName]

  local entryID = _DataSetLogic.itemInfoTable[dataSetID].EntryID
  -- 데이터셋의 대상 아이템 모델의 Name 값을 불러옵니다.
  local name = _DataSetLogic.itemInfoTable[dataSetID].Name
  -- 데이터셋의 대상 아이템 모델의 Value 값을 불러옵니다.
  local value = _DataSetLogic.itemInfoTable[dataSetID].Value

  -- 대상 테이블의 유효성 검사를 진행합니다.

  -- /분기 1/ 대상 아이템 풀 내에 대상 풀(테이블) 이 없을 경우
  if isvalid(self.itemPool[name]) == false or self.itemPool[name] == nil then
    -- 새로운 임시 테이블을 생성합니다.
    tempTable = {}
    -- 아이템 풀에서 내부 풀(테이블)을 임시테이블로 설정합니다.
    self.itemPool[name] = tempTable
    
  -- /분기 2/ 대상 아이템 풀 내에 대상 풀이 이미 있을 경우
  else
    -- 임시 테이블(풀) 을 기존에 활용하고 있던 테이블로 선언합니다.
    tempTable = self.itemPool[name]
  end

  -- 매개변수2 createCount 만큼의 반복문을 수행합니다.
  for i = 1 , createCount, 1 do 
    -- SpawnService를 활용해 오브젝트를 생성합니다.
    local entity = _SpawnService:SpawnByModelId(entryID,name,Vector3.up * 100, self.ItemPoolParent)
    
    -- 생성한 오브젝트의 설정작업을 진행합니다.
    
    -- 생성한 오브젝트의 아이템의 고윳값을 설정합니다.
    entity.Item.value = value
    -- 생성한 오브젝트의 아이템의 name 변수를 설정합니다.
    entity.Item.name = name
    
    -- 담겨야 하는 테이블(풀)로 생성된 엔티티를 삽입합니다.
    table.insert(tempTable,entity)
    
    -- 생성된 엔티티 오브젝트를 비활성화합니다.
    entity.Enable = false
  end
}
```

## 아이템 스폰 확률에 따른 아이템 생성
<p align = "Center">
<img src = "https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Running/MSW-100_Running_10_004.png" alt="MSW-100_Running_10_004.png">
</p>

- 샘플 월드에 구현된 아이템은 총 3가지로, 점수를 획득하는 코인, 캐릭터의 체력을 회복하는 회복형 아이템, 일시적으로 스크롤 속도를 올려주는 부스터 아이템이 존재합니다.
- 모든 아이템이 동일한 확률로 생성될 경우, 회복형 아이템이 너무 자주 등장하여 게임이 끝나지 않는 밸런스 문제가 발생할 수 있습니다.
- 즉, 생성될 확률을 설정하여 아이템의 출현 빈도를 조절할 수 있습니다.
- 아이템 스폰 시 0부터 1 사이의 난수(Random)를 추출하고, 이를 ItemInfo 데이터셋의 SpawnRate 값과 비교하여 난수가 더 낮거나 같을 경우 해당 아이템을 스폰하도록 확률 로직이 설계되었습니다.

```lua
TileSet의 SpawnItem메서드

    -- 확률형 스폰을 진행합니다.(무작위 숫자를 생성합니다.)
    local randomRate = math.random(0,100) * 0.01
    
    -- 엔티티타입으로 설정할 지역변수를 선언합니다.
    ---@type Entity
    local tempEntity
    
    -- /분기1/ 랜덤 확률값이 healthSpawnRate값보다 작거나 같다면 
    if _DataSetLogic.itemInfoTable[2].SpawnRate >= randomRate then
    -- 오브젝트 풀로부터 Health 아이템을 가져옵니다.
      tempEntity = _ObjectPoolLogic:GetItem("Health")
      
    -- /분기2/ 랜덤 확률값이 boosterSpawnRate 작거나 같다면
    elseif _DataSetLogic.itemInfoTable[3].SpawnRate >= randomRate then
    -- 오브젝트 풀로부터 Booster 아이템을 가져옵니다.
      tempEntity = _ObjectPoolLogic:GetItem("Booster")
      
    -- /분기3/ 설정한 다른 아이템들의 생성확률에 들지 못했다면 기본 아이템(코인)을 생성합니다.
    else
      tempEntity = _ObjectPoolLogic:GetItem("Coin")
      
    end
```

## 지정된 위치에 아이템 배치하기
<p align = "Center">
<img src = "https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Running/MSW-100_Running_10_005.png" alt="MSW-100_Running_10_005.png">
</p>

- 바닥 타일셋 내에는 ItemParent로 아이템의 위치를 설정하기 위한 엔티티들이 등록되어 있습니다.
- 오브젝트 풀로부터 스폰되는 아이템은 바닥 타일과 동일하게 이동되어야 합니다.
- 스폰된 아이템은 기준점 역할을 하는 엔티티의 자식(Child)으로 부착(Attach)한 뒤, 로컬 좌표를 원점(0, 0, 0)으로 초기화하여 부모와 완벽히 동일한 위치에 배치되도록 설정합니다.
- ItemParent의 자식요소의 개수만큼 순회를 진행하며 아이템 스폰을 반복합니다.

```lua
TileSet의 SpawnItem메서드

Entity itemParent -- 아이템 위치를 설정하기 위한 엔티티들의 부모 엔티티입니다.

void SpawnItem
{
  -- 아이템 위치를 설정하기 위한 엔티티들의 자식요소들의 순회를 진행합니다.
  for index, child in pairs(self.itemParent.Children) do

  local tempEntity

  -- 랜덤 확률과 SpawnRate값을 비교해 tempEntity의 아이템 엔티티 설정 과정

  -- 아이템 엔티티의 부모를 child로 설정합니다.
  tempEntity:AttachTo(child)

  -- 아이템 엔티티의 로컬 좌표값을 원점으로 부모와 동일한 위치로 설정합니다.
  tempEntity.TransformComponent.Position = Vector3(0,0,0)
}
```

## 최소 구현 기준
- 아이템이 스폰될 경우 바닥 타일셋에 부착되어 맵의 스크롤 이동과 함께 정상적으로 화면 왼쪽으로 이동해야 합니다.
- 캐릭터가 아이템의 Trigger 충돌 발생 시 화면에서 아이템 엔티티가 사라지며 오브젝트 풀로 반환되어야 합니다.

## 응용 및 확장 방향
- 게임 후반부로 갈수록 긍정적인 효과의 아이템뿐만 아니라, 획득 시 오히려 시야가 가려지거나 점수가 깎이는 함정 아이템을 확률적으로 스폰하여 게임의 난이도를 조절할 수 있습니다.
- 일정 시간 동안 장애물 충돌을 무시하는 실드 아이템이나, 주변의 코인을 한 번에 습득하는 자석 아이템 등 새로운 기믹의 아이템을 기획하고 전용 스크립트로 확장할 수 있습니다..
