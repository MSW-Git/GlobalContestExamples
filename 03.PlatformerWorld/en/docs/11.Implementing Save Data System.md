## Saving High Score Value on Server Side
- Instead of communicating with the server every time the score goes up, reduce server load by storing data only when it's absolutely necessary, such as when the game ends.
- The BestScore value managed from the server is only refreshed if the current score is higher than the existing best score at the time of game over (0 HP).

```lua
How to update BestScore value managed from the server
EndGame method called at the end of the game from GameLogic

[Sync] number bestScore;
[None] number currentScore;

[client] -- client-only method
void EndMainGame()
{
    -- Function called on game over.

    -- If the current score is higher than the previous best score
    if self.currentScore > self.bestScore then
        -- Update the bestScore managed on the client (local environment).
        self.bestScore = self.currentScore
        -- Request score updates server-side as well.
        self:UpdateScore(self.bestScore)

    end
}

[server] -- server-only methods
void UpdateScore(number score)
{
    -- Update the bestScore value managed by a non-local server.
    self.bestScore = score
}
```

## Store Player High Scores with DataStorage
- Even if data values are managed on the server side, if they are not explicitly saved and the player reconnects to the world, the player's previous data values cannot be retrieved.
- To save player data or game data, utilize the DataStorage service.
- It is recommended to utilize the functionality of DataStorage within the HandleUserLeaveEvent and HandleUserEnterEvent.

```lua
Storing player and game data with DataStorage
SaveScore Method of GameLogic

HandleUserLeaveEvent(UserLeaveEvent event)
{
    self:SaveScore(self.bestScore)
}

[server] -- server-only methods
void SaveScore(number score)
{
    local data = _DataStorageService:GetGlobalDataStorage("MyData")
    local errorCode = data:SetAndWait("BestScore",tostring(score))
}
```
<br>

## Retrieving High Score Value
- As with data storage, only request data once, upon first entering the world, to avoid unnecessary server communication.
- If there was a previously-recorded best score when the player entered the world, it will be retrieved.

### Retrieving Previous Score Values Using DataStorage and OnSyncProperty
<p align = "Center">
<img src = "https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Running/MSW-100_Running_11_001.png" alt="MSW-100_Running_11_001.png">
</p>

1. In the Method tab of the script, right-click the '+' button and create a method via OnSyncProperty.
<br>

- To retrieve player data or game data, utilize the DataStorage service.
- Variables set to Sync can use the OnSyncProperty method to detect exactly when a value has been synchronized from the server.

```lua
Loading player and game data with DataStorage
LoadData Method of GameLogic

[Sync] number bestScore

HandleUserEnterEvent(UserEnterEvent event)
{
    self:LoadData()
}

[server] -- server-only methods
void LoadData()
{
    -- Utilize the data storage service to get data storage named 'MyData'.
    local data = _DataStorageService:GetGlobalDataStorage("MyData")

    -- Get the Value corresponding to the 'BestScore' key within that data storage.
    local errorCode,value = data:GetAndWait("BestScore")

    -- Register a temporary score value variable.
    local tempScore

    -- If no data is stored
    if value == nil then
        -- Set the temporary score value to 0.
        tempScore = 0
        
    -- If there is any stored data
    else
        -- Set the temporary score value to the existing score value.
        tempScore = tonumber(value)
    end

    -- Update the bestScore value.
    -- When a property declared with Sync changes its value,
    -- The value is synchronized on the client side as well, and the OnSyncProperty method is called automatically.
    self.bestScore = tonumber(tempScore)
}

[client only]
void OnSyncProperty(string name, any value)
{
    -- When a change in a variable (property) is detected

    -- If the changed variable is named "bestScore"
    if name == "bestScore" then
    -- Ask UIManagerLogic to update the best score text on the main title screen.
	_UIManagerLogic:UpdateTitleBestScore(tonumber(value))
    end
}
```

## Minimum Implementation Standards
- When a player achieves a new best score in the game, quits the world completely, and then logs back in, the title screen should display the previous best score correctly instead of resetting to zero.
- The timing control via OnSyncProperty must be fully functional, so the UI text doesn't update first when the score data hasn't finished syncing from the server and display empty values or errors.
