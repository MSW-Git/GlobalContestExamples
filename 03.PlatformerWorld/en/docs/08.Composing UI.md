## Learning Goals
- Instead of controlling individual UI elements one by one, understand how to bundle them into a single UI entity to efficiently transition screens based on the state of the game (title, in-game, result).
- Create a Result Popup that is called at the end of the game, and learn how to integrate GameLogic with UIManagerLogic to synchronize the current score and best score to UI text.
<br>

## Practical Exercises to Do After Watching the Video
- In the Hierarchy window, group the UI elements needed for the Title, In-Game, and Results screens into their respective parent entities (UI Group), toggle the Enable property of the top-level entity on and off, and test to see if the screens transition properly.
- In-game, intentionally hit an obstacle to end the game, then check to see if the results popup correctly displays the score just earned and the existing best score in the text UI.

## Applying a Component to a UI Entity

- Like normal entities, you can add Components to UI entities to execute additional functions.
- Adding Components is done the same way as the Add Component function for regular entities.
- This lesson will talk about the often used Components.
    - **SpriteGUIRendererComponent**: A Component used when outputting an image for the UI. It's recommended to use this Component rather than SpriteRendererComponent when outputting images in the UI.
    - **TextGUIRendererComponent**: A Component used when outputting text on the UI.
    - **ButtonComponent**: A Component used when the UI needs a button function.
<br>

### Group-Level Control Utilizing UI Groups
<p align = "Center">
<img src = "https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Running/MSW-100_Running_8_001.png" alt="MSW-100_Running_8_001.png">
</p>

1. When the Enable value of the highest-ranking entity element of a group is checked to true, child entities can individually toggle Enable to true or false.
2. Clear the Enable state by toggling the top-level entity element to false.
3. When the parent entity is deactivated, the child entities are automatically deactivated as well.

- Due to the nature of entities, disabling a parent entity will automatically disable any child entities that belong to the entity.
- This makes it easy to control the UI that should be displayed in different situations in the game by enabling and disabling only the top-level entities in a group, rather than controlling each element individually.
<br>

- For the TitleUI group, players should be able to see them immediately at the start of world, so the default Enable is set to true.
- The time to activate the TitleUI group directly is when the full game has ended and transitioning from the results window back to the main menu.
- The time to disable the TitleUI group directly is when the player selects a character and enters the actual game state.

```lua
Situations where the game starts with the character select button in the character slot (UICharacterSelect) in the character selection screen.
CloseSelectPopup method of UICharacterInfoComponent

void CloseSelectPopup()
{
    -- Stores the top-level entity of the Title UI group.
    local TitlePanel = _EntityService:GetEntityByPath("/ui/ToastGroup/UITitle")

    -- Disables the top-level entity.
    TitlePanel.Enable = false

    -- Asks GameLogic to call Start Game.
    _GameLogic:GameStart(self.characterId)
}
```

```lua
-- A situation where the player is returned to the title screen via the 'Main Menu' button in the game results window.
-- ReturnToMenu method of UIManagerLogic

Entity mainTitlePanel
Entity resultPopup
Entity resultToMenuButton

void OnBeginPlay()
{
    -- Register an event on the 'Main Menu' button in the results window popup when executing the world.
    self.resultToMenuButton:ConnectEvent(ButtonClickEvent,self.ReturnToMenu)
}

void ReturnToMenu()
{
    -- Disables the results window popup.
    self.resultPopup.Enable = false
    -- Enable the TitleUI top-level entity.
    self.mainTitlePanel.Enable = true
}

```

- The time to activate the InGameUI group directly is when the player has completed character selection and the actual game is starting.
- The only time to disable the InGameUI group directly is when the character dies and goes from the results window to the main menu.

```lua
-- Calling the necessary in-game UIs when a player finishes selecting a character
-- ShowPlayerInfo method of UIManagerLogic

SliderComponent hpSlider
Entity inGameCurrentScoreText
Entity inGameScoreText
SpriteGUIRendererComponent skillRenderer

void ShowPlayerInfo(boolean active)
{
    -- Transition to active state, to receive the entity representing the HP gauge.
    self.hpSlider.Entity.Enable = active
    -- Transition to active state, to receive the entity representing the player's score value.
    self.inGameCurrentScoreText.Entity.Enable = active
    -- Toggle the UI element that displays the 'score' text to active.
    self.inGameScoreText.Enable = active
    -- Transition to the active state to receive the entity representing the character's skill information.
    self.skillRenderer.Entity.Enable = active
}

GameStart method in GameLogic

void GameStart()
{
    _UIManagerLogic:ShowPlayerInfo(true)
    
    -- Perform any necessary initialization before starting in-game.
}

```

- The time to activate the ResultPopup group directly is when the actual game proceeds and the character is no longer playable.
- The time to disable the ResultPopup group directly is when the 'MainMenu' button is selected within the results screen to switch to the Title state.

```lua
-- In-game ends and a results screen pops up.
-- ShowResultPopup method of UIManagerLogic

-- A Text entity that registers the actual previous high score registered in the results screen.
Entity resultBestScoreText
-- A Text entity that registers the actual current score value registered in the results screen
Entity currentScoreText

void ShowResultPopup(string bestScore, string currentScore)
{
    -- Change the highest score value text to the text passed as a parameter.
    self.resultBestScoreText.TextComponent.Text = bestScore

    -- Change the current score value text to the text passed as a parameter.
    self.currentScoreText.TextComponent.Text = currentScore

    -- Activates the results screen.
    self.resultPopup.Enable = true;
}


EndMainGame method of GameLogic called when a character dies

number bestScore
number currentScore

void EndMainGame()
{
    -- Perform necessary functions at end game.

    _UIManagerLogic:ShowResultPopup(tostring(self.bestScore),tostring(self.currentScore))
}
```

## Minimum Implementation Standards
- The UI of each button to switch between the three states, TitleUI, InGameUI, and ResultPopup, as well as the ability to start the game, exit the game, and return to the main menu should work properly.
- Make sure that the currentScore and bestScore values calculated by GameLogic are passed to each UI text component correctly.
<br>

## Usage and Extension Direction
- Adds effects to the ResultPopup so that when it appears, it doesn't just appear, but gradually grows in size or changes transparency.
- Play sound effects when clicking a button or when a result window pops up to increase the sense of control.
