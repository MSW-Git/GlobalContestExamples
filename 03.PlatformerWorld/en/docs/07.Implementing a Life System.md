## HP Decrease per Time Implementation

- HP control was built to include both immediate changes when picking up items and hitting obstacles as well as periodic HP decreases over time.
- The ability to decrease HP in code is defined as a function of GameLogic's AutoDecreaseHp, AddHP, and SetHP methods, each of which are performed within GameLogic's OnUpdate method.
- If the contents of the GameLogic code are needed, the GameLogic script is attached in the '2. Understanding Logic' section.

### HP Setting Function
- The ability to add and decrease HP utilizes GameLogic's AddHP method.

```lua
AddHP Method in GameLogic

number hp;

void AddHP(number addValue)
{
    -- Adds or subtracts the value passed as a parameter to the current HP as is.
    -- When calling the AddHP method, there's a flexibility to pass a positive or negative number to perform both recovery and reduction functions.

    self.hp += addValue;

    -- Request that the information in the sliders managed by UIManagerLogic be updated because a change in the HP value has occurred. 
    _UIManagerLogic.SetHpSliderValue(self.hp)

    -- If HP drops below 0 (when the Game Over condition is met)
    if self.hp <= 0 then
        -- Perform the End Game function.
    end
}

```
<br>

### Continuous HP Decrease Function Implementation
- By utilizing the OnUpdate method, which is called every frame, the feature of gradually decreasing HP can be achieved.
- However, if this is not multiplied by delta, which is the amount of time change between frames, there will be a fatal problem where the HP will evaporate unusually quickly depending on the device's frame rate (FPS).
- If frames per second is 60 FPS, the delta value of the time change between frames is 1Sec/60FPS = 0.0167Sec.
- If the desired effect is to decrease 5 HP per sec, the value of 5* delta will be calculated and reduced for every frame. Whether the device is running at 60 frames or 30 frames, the cumulative reduction at the end of one second will be exactly 5.

```lua
Example of the HP reduction function part of GameLogic's OnUpdate method:

void OnUpdate(number delta)
{
    -- Config : If the value is not changed once set, it is registered and managed in the corresponding Logic script.
    -- Reflects HP by the set HP loss per second * delta
    self:AddHP(delta * _Config.decreaseHpValue)
}

void AddHP(number addValue)
{
    -- Adds or subtracts the value passed in as a parameter as it is to the HP value.
    -- When utilizing the AddHP method, pass the positive and negative values to perform the intended function.

    self.hp += addValue;

    -- Request that the information in the sliders managed by UIManagerLogic be updated because a change in the HP value has occurred. 
    _UIManagerLogic.SetHpSliderValue(self.hp)

    -- When HP reaches 0 (when game can no longer proceed)
    if self.hp <= 0 then
        -- Perform the End Game function.
    end
}
```

### Controlling HP Bar UI with UIManagerLogic
- The entity that will act as the gauge is registered in UIManagerLogic.
- If the contents of the UIManagerLogic code are needed, the UIManagerLogic script is attached in the '2. Understanding Logic' section.
- Establishes a reference to the entity to which the SliderComponent is attached to and calls this logic whenever the HP changes in GameLogic to overwrite the Slider's Value property with the latest HP value in real time.

```lua
Example of implementing the SetHpSliderValue method of UIManagerLogic:

SliderComponent hpSlider;

void SetHpSliderValue(number value)
{   
    -- Set the value of the slider to be set using the math.clamp method so that it is never less than 0 and never more than 100.
    self.hpSlider.Value = math.clamp(value, 0, 100)
}

```
<br>

## Minimum Implementation Standards
- Changes in HP data (hp) within the script should be passed through UIManagerLogic and synchronized in real-time to the on-screen SliderComponent gauge UI.
- As soon as HP drops to 0 or lower, it should be detected and prevented from going any further into negative HP, and game over handling should be called successively.
<br>

## Usage and Extension Direction
- The gauge color of the SliderComponent can be changed to flash red when the HP drops to a critical state below a certain number (for example, 20%) to provide visual tension and warning feedback to the player.
