## What is an Object Pool?
- Many entities are used when executing the game.
- Of those entities, bullets or platforms that are spawned frequently must be removed from the screen after a set time. 
- However, spawning and destroying entities comes with taking up memory, and when those processes repeat over a short window of time, it could cause the computer to be overwhelmed (frame drops).
- However, if the activation is removed instead of creating and eliminating entities, it can lower the load on your computer.
- This is because the memory is used and reused like flipping a switch.
- In other words, the **Object Pool** is a Pool where created entities can be placed and pulled out for use before being returned to the pool, optimizing the normal creation and destruction process.
<br>

## Creating an Object Pool
- The sample world's object pool is created as a central Manager where it can be accessed from all places like GameLogic or DataSetLogic, to easily rent out entities.
- Create a new logic in Workspace and write as an ObjectPoolLogic.

## Writing ObjectPoolLogic Scripts
- Write the following code.
- The target code is based on Plain Text.

```lua
@Logic
script ObjectPoolLogic extends Logic

property number discript = 0 -- The logic used to effectively manage objects that have frequent creation and destruction.

property table tilePool = {} -- The table that fulfills the role of a pool to manage tile set objects.

property table itemPool = {} -- The table that fulfills the role of a pool to manage item objects.

property Entity ItemPoolParent = "9e9e98bd-4f7b-46ed-9a93-f0e7d74fac1c"

property table itemDataSetIDTable = {["Coin"] = 1 ,["Health"] = 2 ,["Booster"] = 3} -- key : Item Name , value : The table meant to save the Index number for the data set.

@ExecSpace("ClientOnly")
method void ReturnTile(Entity entity)
-- This method returns a tile object to the object pool.

-- Parameter 1 entity: Receives the object that will be returned (deactivated).
-- Parameter 2 tileNumber: Receives the tile number.

-- Extracts the tile set entity's number. (This is to manage the tile set objects by number in the table.)
local tileNumber = self:GetTileNumber(entity)

-- Checks whether the pool (table) that corresponds to the tile number is valid.
if isvalid(self.tilePool[tileNumber]) == false or self.tilePool[tileNumber] == nil then
	-- Creates a new table space if there is no table.
	self.tilePool[tileNumber] = {}
end

-- Saves the target entity (object) to the target table.
table.insert(self.tilePool[tileNumber],entity)
-- Deactivates the entity (object).
entity.Enable = false
end

@ExecSpace("ClientOnly")
method Entity GetTile(number tileNumber)
-- This method returns the designated tile entity from the tile pool.

-- Parameter 1 number tileNumber: Receives a specified tile set number.

-- This is to discard the decimal point for tileNumber using the math.floor method. ex) 4.0 => 4
tileNumber = math.floor(tileNumber)

-- Proceeds with checking the target pool (table).

-- If there is no pool (table) that manages the received tileNumber tile objects,
if isvalid(self.tilePool[tileNumber]) == false or self.tilePool[tileNumber] == nil then
	-- a new table space is created.
	self.tilePool[tileNumber] = {}
end

-- /Branch 1/ Newly-created and returned if none exist.

-- If there are no objects that are contained in the target pool (a new object creation takes place from the model (prefab)),
if #self.tilePool[tileNumber] <= 0 then
	
	-- checks the EntryID saved to the table set.
	local entryID = _DataSetLogic.tileSetInfoTable[tileNumber].EntryID
	-- Saves the name in the already saved (prefab) name format.
	local name = "Model_TileSet0"..tileNumber
	
	-- Creates a target model (prefab) object in a temporary position.
	local tempTile = _SpawnService:SpawnByModelId(entryID,name,Vector3.up*100,_EntityService:GetEntity("d24b5917-1821-4743-ae07-77cc9bfc2d0a"))
	
	-- Returns the target object.
	return tempTile
end

-- /Branch 2/ Returns the last element if one does exist.

-- View the number of target tables.
local tableCount = #self.tilePool[tileNumber]

-- Receives the last element returned from the target table and removes the target entity from the table.
local tempTile = table.remove(self.tilePool[tileNumber],tableCount)

-- Activates the selected object.
tempTile.Enable = true

-- Returns the object.
return tempTile


end

@ExecSpace("ClientOnly")
method Entity GetItem(string itemName)
-- This method receives the returned item object from the object pool.

-- Parameter 1 string itemName: Receives the item name.

-- Loads the table that contains the relevant items from the item pool.
local targetTable = self.itemPool[itemName]

-- When the table has no internal elements,
if #targetTable == 0 then
	-- proceeds with additional creations of the target item a number of times equal to the creation number set in config.
	self:CreateItem(itemName,_Config.itemPoolInitCount)
end


-- Loads the entity from the intended table. (table's last element)
---@type Entity
local targetEntity = targetTable[#targetTable]

-- Removes the last element of the table, since the entity has been saved.
table.remove(targetTable,#targetTable)

-- Activates the entity (object).
targetEntity.Enable = true

-- Returns the saved entity.
return targetEntity
end

@ExecSpace("ClientOnly")
method void ReturnItem(Entity entity)
-- This method returns the item object to the object pool again.

-- Parameter 1 Entity entity: Delivers the item object entity that will be returned.

-- Confirms the name of the returning item.
local itemName = entity.Item.name
-- Slots entity into the target table.
table.insert(self.itemPool[itemName],entity)

-- From the tile set's existing Parent (an object that was preregistered to place the tile set item), 
-- moves the Parent to ItemPool again.
entity:AttachTo(self.ItemPoolParent)
-- Deactivates the entity (object).
entity.Enable = false
end

@ExecSpace("ClientOnly")
method void CreateItem(string itemName, number createCount)
-- This method creates a new item object from the model (prefab) and places it into the target pool.

-- Parameter 1 string itemName: Receives the name of the item that will be created.
-- Parameter 2 number createCount: Determines the amount to be created and how many objects will be created and placed inside the object pool.

-- Declares a temporary table.
local tempTable

-- Sets the Id number that will be referenced by the data set.
local dataSetID = self.itemDataSetIDTable[itemName]

-- Loads the EntryID value of the target item model from the data set.
local entryID = _DataSetLogic.itemInfoTable[dataSetID].EntryID
-- Loads the Name value of the target item model from the data set.
local name = _DataSetLogic.itemInfoTable[dataSetID].Name
-- Loads the Value value of the target item model from the data set.
local value = _DataSetLogic.itemInfoTable[dataSetID].Value

-- Determines if the target table is valid.

-- /Branch 1/ If no target pool (table) exists within the target item pool,
if isvalid(self.itemPool[name]) == false or self.itemPool[name] == nil then
	-- a new temporary table is created.
	tempTable = {}
	-- Sets the internal pool (table) from the item pool as the temporary table.
	self.itemPool[name] = tempTable
	
-- /Branch 2/ If the target pool is already in the target item pool,
else
	-- the temporary table (pool) will be declared as a table that was previously in use.
	tempTable = self.itemPool[name]
end

-- Performs a loop as many times as parameter2 createCount.
for i = 1 , createCount, 1 do 
	-- Utilizes SpawnService to create the object.
	local entity = _SpawnService:SpawnByModelId(entryID,name,Vector3.up * 100, self.ItemPoolParent)
	
	-- Proceeds with configuring the created object.
	
	-- Sets the item's unique value of the created object.
	entity.Item.value = value
	-- Sets the name variable of the item of the created object.
	entity.Item.name = name
	
	-- Inserts the entity created for the target table (pool).
	table.insert(tempTable,entity)
	
	-- Disables the created entity object.
	entity.Enable = false
end
end

@ExecSpace("ClientOnly")
method void InitItemPool()
-- This method resets the item pool.

-- Loads the table that contains the item data set from DataSetLogic.
local itemDataTable = _DataSetLogic.itemInfoTable

-- Creates an amount of the Coin item equal to the creation count set in Config.
self:CreateItem("Coin",_Config.itemPoolInitCount)
-- Creates an amount of the Health item equal to the creation count set in Config.
self:CreateItem("Health",_Config.itemPoolInitCount)
-- Creates an amount of the Booster item equal to the creation count set in Config.
self:CreateItem("Booster",_Config.itemPoolInitCount)
end

@ExecSpace("ClientOnly")
method void Init()
-- This method proceeds with resetting ObjectPool Logic.

-- Proceeds with resetting the item pool.
self:InitItemPool()
end

@ExecSpace("ClientOnly")
method number GetTileNumber(Entity entity)
-- This method extracts the tile number.

-- Parameter 1 Entity entity: Receives the target entity.

-- Extracts the entity's name.
local tileSetName = entity.Name
-- Extracts the last string of the name. (Extract 14th, 15th character from the 'Model_TileSet02' string > 02)
local numberStr = string.sub(tileSetName,14,15)
-- Converts strings to number values and returns them.
return tonumber(numberStr)
end

end
```

- ObjectPoolLogic manages the floor tile sets and each item element that's regularly generated and destroyed.
- The created GetTile serves the role of bringing out floor tiles that are in standby in the tile pool and is called when the ScrollingController component spawns a new map chunk.
- When a floor tile that leaves the screen collides with the DeadZone, the ReturnTile method is used by the TileDeadZone script to return the target tile to the pool (deactivate) instead of destroying them.

## Minimum Implementation Standards
- Implemented so that the tile set entities aren't repeatedly generated and destroyed while a map is scrolling, but instead create a cycle of deactivation and reactivation through the object pool system.
- Implemented in a form so that all tile sets are created in the object pool or returning usable entities.
