## What is Logic?

- It is one of the script types provided by MapleStory Worlds.
- When creating a Logic, it will be marked with a green plug icon within the Workspace.
- Also, unlike Components, it can access scripts even when not added to an entity.
<br>

## Manager Concepts
<p align="center">
<img src = "https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Running/MSW-100_Running_2_003_en.png" alt="MSW-100_Running_2_003_en.png">
</p>

- Logic can be created as a manager that executes specific functions or roles.
- The manager of a single function or role is called a Manager.
- When there are issues with a specific function, it can be fixed quickly and conveniently by only changing the content of the Manager.
    - Case 1: When a character completes damage calculation and delivers it to a monster.
        - Each time the damage formula changes or each time a new element is added to damage calculation, the formula needs to be changed.
        - All character codes must be individually found and edited.
    - Case 2: When making a request for damage calculation from a Logic-created Manager.
        - Change the damage formula inside the Logic.
        - The Logic handles the damage calculation of all characters and monsters, so there are no more elements that require editing.
        - Even if there are issues with the damage formula in future, editing the Manager can solve them.
<br>

## Logic Usage Example Within the Sample World

### GameLogic Example
- Processes the function that continuously decreases HP and increases the score once the game begins.
- If the HP that is managed reaches 0, the results screen is requested and compares the current score to the previous high score and updates the user's high score as needed.
- Executes the timer function used for stage transitions that happen in set intervals when the main game begins.
<br> 

### DataSetLogic Example
- Reads the original data such as items, tiles, character info, etc. using DataService, which is a built-in function for MapleStory Worlds.
- Serves the role of attaching a tag (Key) to create an easily-readable Lua table variable format so that inputting the name is enough to find something in the data that was read.
<br>

### UIManagerLogic Example
- Consolidates the reference path for UI elements, such as the title screen, character selection window, HP and score display, results pop-up, etc. for management.
- Gathers complex pathing to search each UI element into one and ensures ease of access is possible when another script needs to control specific UI controls.
- Executes the pop-up control function that only turns the necessary UI groups on or off based on the game state (start, play, end) while an entity is set as a reference.
<br>

## Writing GameLogic Code
```lua
@Logic
script GameLogic extends Logic

property number discript = 0 -- The logic used to control the game's overall flow.

property ScrollingController scrollingController = nil

property number currentScore = 0 -- The variable needed to contain the current game score value.

@Sync
property number bestScore = 0 -- The variable needed to contain the player's high score.

property number scoreIncreaseTimer = 0 -- The timer variable needed to regularly update the score.

property number currentStage = 1 -- The variable needed to save the current stage number.

property number stageTimer = 0 -- The timer variable needed to measure the timing when the stage changes.

property number hp = 0 -- The variable needed to save the player's HP value.

property boolean isEnd = true -- The state variable that records that the game ended.

property boolean isMobile = true -- The variable that saves whether the launching environment is a mobile environment.

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- This method is called when the world starts.

-- Proceeds with resetting the game logic.
self:Init()

-- Saves whether the world progression is done on mobile as a state variable.
self.isMobile = Environment:IsMobilePlatform()

-- Plays the background music when the world starts.
_SoundService:PlayBGM("f5bb92d91e134c699e7bb2cf1aaca8e6",0.4)
end

@ExecSpace("ClientOnly")
method void Init()
-- Proceeds with resetting the main logic that manages the overall game.

-- Links the internal member references.
self:ConnectRefs()

-- Proceeds with resetting the other core logics.
self:OrderInit()
-- Resets the score value.
self:SetScore(0)
-- Resets the current HP value.
self:SetHP(100)
end

@ExecSpace("ClientOnly")
method void ConnectRefs()
-- This method links the internal member references.

-- Links the scrolling controller entity.
self.scrollingController = _EntityService:GetEntityByPath("/maps/MainGame/Scrolling").ScrollingController
end

@ExecSpace("ClientOnly")
method void OrderInit()
-- Proceeds with the reset command of the core logics and components from the game logic.

-- Proceeds with the scrolling controller reset.
self.scrollingController:Init()
-- Proceeds with data set logic reset.
_DataSetLogic:Init()
-- Proceeds with the UI manager logic reset.
_UIManagerLogic:Init()
-- Proceeds with the object pool logic reset.
_ObjectPoolLogic:Init()
end

@ExecSpace("ClientOnly")
method void OnUpdate(number delta)
-- This method is called for each frame.

-- If the game isn't in progress,
if self.isEnd == true then
	-- the method is halted.
	return
end

-- Automatically reduces HP by the delta value.
self:AutoDecreaseHp(delta)
-- Automatically increases the score by the delta value.
self:AutoIncreaseScore(delta)

-- /Branch 1/ If there is time remaining in the stage timer,
if self.stageTimer > 0 then
	-- the delta value is deducted from the stage timer value.
	self.stageTimer -= delta
-- /Branch 2/ If there is no time remaining in the stage timer,
else 
	-- the stage change is called.
	self:StageChange()
	-- Resets the stage timer value to the value set in Config.
	self.stageTimer = _Config.stageChangeTime
end


end

@ExecSpace("ClientOnly")
method void AutoIncreaseScore(number delta)
-- This method increases the score every increaseScoreIntervalSecond (interval).

-- /Branch 1/ If the measuring timer value is smaller than the Interval value that is the standard,
if self.scoreIncreaseTimer < _Config.increaseScoreInterval then
	-- the delta value is added to the timer and the method ends.
	self.scoreIncreaseTimer += delta
	return
end

-- /Branch 2/ If the measuring timer value is equal to or larger than the Interval value that is the standard (the point when a specific interval is reached),

-- the score is added.
self:AddScore(_Config.increaseScore)
-- Resets the measuring timer.
self.scoreIncreaseTimer = 0
end

@ExecSpace("ClientOnly")
method void AutoDecreaseHp(number delta)
-- This method automatically decreases the HP.

-- Delivers the value that must be deducted from the current HP.
self:AddHP(delta * _Config.decreaseHpValue)
end

@ExecSpace("ClientOnly")
method void SetScore(number value)
-- This method sets the value that was delivered from the parameter as the Score value.

-- Parameter 1 number value: The value that is set as the score value.

-- Sets the current score value to a specified value.
self.currentScore = value
-- Sets the Text registered to UIManager as a specified value.
_UIManagerLogic:SetScoreText(value)
end

@ExecSpace("ClientOnly")
method void AddScore(number addValue)
-- This method adds the value that was delivered from a parameter to the Score value.

-- Parameter 1 number addValue: Receives the value that is added to the existing score value.

-- Adds the received value to the current score.
self.currentScore += addValue
-- Delivers the current score value to the Text registered to UIManager.
_UIManagerLogic:SetScoreText(self.currentScore)
end

@ExecSpace("ClientOnly")
method void SetHP(number value)
-- This method sets the value that was delivered from a parameter as the Hp value.

-- Parameter 1 number value: Receives the value that is set as the Hp value.

-- Sets the HP value as a specified value. (Limit the minimum and maximum using clamp.)
self.hp = math.clamp(value,0,_Config.maxHp)

-- Applies the HP value to the slider registered to UIManager.
_UIManagerLogic:SetHpSliderValue(self.hp)
end

@ExecSpace("ClientOnly")
method void AddHP(number addValue)
-- This method adds the values that were delivered from a parameter to the HP value.

-- Parameter 1 number addValue: Receives the HP value that will be added.

-- Adds the parameter value to the current HP.
self.hp += addValue

-- Limits the minimum and maximum using clamp.
self.hp = math.clamp(self.hp,0,_Config.maxHp)

-- Applies the HP value to the slider registered to UIManager.
_UIManagerLogic:SetHpSliderValue(self.hp)

-- If the HP value is equal to or smaller than 0,
if self.hp <= 0 then
	-- the end game logic is executed.
	self:EndMainGame()
end
end

@ExecSpace("Client")
method void EndMainGame()
-- This method ends the game. (client-exclusive method)

-- Converts to the end game state.
self.isEnd = true

-- Sets the character as not visible.
_UserService.LocalPlayer.Visible = false

-- Deactivates the joy stick if the launching environment is mobile when the game ends.
_UIManagerLogic:ShowMobileJoyStick(false)

-- Designates the values that will be set in the results window pop-up and outputs it on the screen. (Delivers the high score and current score.)
_UIManagerLogic:ShowResultPopup(tostring(math.floor(self.bestScore)),tostring(math.floor(self.currentScore)))

-- Proceeds with returning (deactivating) all tile set objects in the scrolling controller.
self.scrollingController:ReturnAllTiles()

-- Decreases the background scrolling speed.
self.scrollingController.background.ScrollRate = 0.5

-- If the current score is higher than the high score that's managed within the client,
if self.currentScore > self.bestScore then
	-- the high score value is replaced with the current score.
	self.bestScore = self.currentScore
	-- Updates the high score value in the server, since the high score has been changed.
	self:UpdateScore(self.bestScore)
end

-- Applies the main title's high score value.
_UIManagerLogic:UpdateTitleBestScore(self.bestScore)
end

@ExecSpace("ClientOnly")
method void GameStart(number selectCharacterId)
-- This method is called when the main game starts.

-- Loads the character's speed value that was selected in the character selection window from CharacterInfoTable.
local scrollSpeed = _DataSetLogic.characterInfoTable[selectCharacterId].Speed
-- Registers the default speed value.
self:SetDefaultScrollSpeed(scrollSpeed)

-- Resets the current (starting) stage to 1.
self.currentStage = 1

-- Requests a stage change.
self:StageChange()

self:SetScore(0)

-- Resets the score timer value.
self.scoreIncreaseTimer = 0

-- Resets the HP value.
self:SetHP(100)

-- Sets the stage timer to the change time that's set in config.
self.stageTimer = _Config.stageChangeTime

-- Displays the mobile joy stick for mobile environments.
_UIManagerLogic:ShowMobileJoyStick(true)

-- Proceeds with resetting the scrolling controller.
self.scrollingController:Reset()

-- Proceeds with resetting the player character.
_UserService.LocalPlayer.CustomPlayerController:ResetCharacter()

-- Sets the UI that should be provided to the user as visible.
_UIManagerLogic:ShowPlayerInfo(true)

-- Proceeds with resetting the skill logic.
_SkillLogic:Reset()

-- Only plays the resource effect to prevent the skill effect resource buffering.
_SkillLogic:PlaySkillEffect()

-- Applies the image as unique skill icons that each character has.
_UIManagerLogic:RegistSkillIcon()

-- Proceeds with the resetting of item logic.
_ItemLogic:Reset()

-- Proceeds with the 3, 2, 1 count before the main game starts. (Includes Wait method.)
_UIManagerLogic:CountTimerStart()

-- Converts the game state to in-progress.
self.isEnd = false

end

@ExecSpace("ClientOnly")
method void SetDefaultScrollSpeed(number speed)
-- Sets the character's default scrolling speed value.
-- Why Default and Current Are Divided: This is to separately save the character's default speed, since the speed value changes when a booster item is used.

-- Parameter 1 number speed: Receives the scrolling speed value that will be applied when the game is running.

-- Sets the scrolling component's default speed value as the parameter value.
self.scrollingController.defaultSpeed = speed
-- Sets the scrolling component's current speed value as the parameter value.
self.scrollingController.currentScrollSpeed = speed
end

@ExecSpace("ClientOnly")
method void StageChange()
-- This method changes the stage.

-- Increases the stage number by 1, but sets to loop the resource element using the % operator.
self.currentStage = (self.currentStage % (_DataSetLogic.stageResourceCount+1)) + 1

-- Converts to the background screen that fits the current stage number.
self.scrollingController:ChangeBackground()
end

@ExecSpace("Server")
method void LoadData()
-- This method loads the recorded information. (server-exclusive method)
-- Server-Side Execution: Needed to load the data managed by the server.

-- Utilizes the data storage service to get data storage named 'MyData'.
local data = _DataStorageService:GetGlobalDataStorage("MyData")

-- Gets the Value value corresponding to the 'BestScore' key within that data storage.
local errorCode,value = data:GetAndWait("BestScore")

-- Registers a temporary score value variable.
local tempScore

-- If no data is stored,
if value == nil then
	-- sets the temporary score value to 0.
	tempScore = 0
	
-- If there is any stored data,
else
	-- sets the temporary score value to the existing score value.
	tempScore = tonumber(value)
end

-- Updates the bestScore value.
-- When a property declared with Sync changes its value,
-- the value is synchronized on the client side as well, and the OnSyncProperty method is called automatically.
self.bestScore = tonumber(tempScore)
end

@ExecSpace("Server")
method void SaveScore(number score)
-- This method saves the user's information.

-- This method saves the score to data storage. (server-exclusive method)

-- Utilizes the data storage service to get data storage named 'MyData'.
local data = _DataStorageService:GetGlobalDataStorage("MyData")

-- Registers the 'score' value to the Value value that corresponds to the 'BestScore' key in the target storage.
local errorCode = data:SetAndWait("BestScore",tostring(score))
end

@ExecSpace("Server")
method void UpdateScore(number score)
-- This method updates the score value that's managed server-side. (server-exclusive method)

-- Parameter 1 number score: Receives the score value managed by the client.

-- Sets the server-side bestScore value as the parameter value.
self.bestScore = score
end

@ExecSpace("ClientOnly")
method void OnSyncProperty(string name, any value)
-- This method is called automatically when there is a value change server-side limited to properties that were declared by Sync.
-- However, if the changed value from the server is the same as the existing client value, this method isn't called.

-- If the changed property name is bestScore,
if name == "bestScore" then
	-- a high score text update in the title screen is requested to UIManagerLogic.
	_UIManagerLogic:UpdateTitleBestScore(tonumber(value))
end
end

@EventSender("Service", "UserService")
handler HandleUserEnterEvent(UserEnterEvent event)
-- This method is called when accessing users and entering.

-- Loads the data from server-side.
self:LoadData()

end

@EventSender("Service", "UserService")
handler HandleUserLeaveEvent(UserLeaveEvent event)
-- This method is called when a user leaves.

-- Executes the method that registers the high score to the server.
self:SaveScore(self.bestScore)
end

end
```

## Writing DataSetLogic Code
```lua
@Logic
script DataSetLogic extends Logic

property string discript = "" -- The logic needed to manage the data that's managed in the target world.

property table tileSetInfoTable = {} -- The table needed to contain the tile set data.

property number totalTileSetCount = -1 -- The variable that saves the number of tile types.

property table itemInfoTable = {} -- The table needed to contain the items' data.

property table tilesFloorInfoTable = {[1]={} , [2]={}} -- The table that contains the floor information of the tile set. / ex table[1] = {2,4} Tile set no. 2 and 4 will start from Fl. 1.

property table characterInfoTable = {} -- The table that saves character information.

property table skillInfoTable = {} -- The table that saves skill information.

property table stageRenderInfoTable = {} -- The table that saves resource information that needs to be rendered by each stage.

property number stageResourceCount = 0 -- The number of stage resource types.

@ExecSpace("ClientOnly")
method void Init()
-- This method resets the DataSetLogic component.

-- Resets the tile set table.
self:InitTileSetInfoTable()
-- Resets the item table.
self:InitItemInfoTable()
-- Resets the character table.
self:InitCharacterInfoTable()
-- Resets the skill table.
self:InitSkillInfoTable()
-- Resets the stage render table.
self:InitStageRenderInfoTable()
end

@ExecSpace("ClientOnly")
method void InitTileSetInfoTable()
-- This method is needed to save the data set that's related to tile object.

-- This variable is needed to access the name of the data set that is saved in world space as local.
local dataSetName = "TileSetInfo"

-- The number of Rows of the target data set.
local rowCount = self:GetDataSetRowCount(dataSetName)

-- Saves the number of tile set types.
self.totalTileSetCount = rowCount

-- This variable is needed to contain the data in each line.
local rowData

-- Starts iterations a number of times equal to the number of data set Rows starting from 1.
for i = 1 , rowCount , 1 do
	rowData = 
	{
		-- The number of floors for the first tile of the tile set object.
		FirstFloor = tonumber(_DataService:GetCell(dataSetName,i,"FirstFloor")),
		-- The number of floors for the last tile of the tile set object.
		LastFloor = tonumber(_DataService:GetCell(dataSetName,i,"LastFloor")),
		-- The original entity model (prefab) Id needed to create a tile set object.
		EntryID = _DataService:GetCell(dataSetName,i,"EntryID")
	}

	-- Saves the data saved to rowData to the table.
	self.tileSetInfoTable[i] = rowData
	
	-- Saves the number of floors currently registered in the tile set as a variable.
	local firstTileFloor = self.tileSetInfoTable[i].FirstFloor
	
	-- /Branch 1/ If the first tile floor number is Fl. 1,
	if firstTileFloor == 1 then
		-- saves to the Fl. 1 table list.
		table.insert(self.tilesFloorInfoTable[1],i)
	-- /Branch 2/ If the first tile floor number isn't Fl. 1,
	else
		-- saves to the Fl. 2 table list.
		table.insert(self.tilesFloorInfoTable[2],i)
	end
end


end

@ExecSpace("ClientOnly")
method number GetDataSetRowCount(string Name)
-- Returns the number of Rows of the target data set.

-- Parameter 1 string Name: Receives the name of the target data set.

-- Returns the number of Rows of the verified data set.
return _DataService:GetRowCount(Name)
end

@ExecSpace("ClientOnly")
method void InitItemInfoTable()
-- This method is needed to save the item data set.

-- This variable is needed to access the name of the data set that is saved in world space as local.
local dataSetName = "ItemInfo"

-- The number of Rows of the target data set.
local rowCount = self:GetDataSetRowCount(dataSetName)

-- This variable is needed to contain the data in each line.
local rowData

-- Iterates a number of times equal to the number of Rows of the data set starting from 1.
for i = 1 , rowCount , 1 do
	rowData = 
	{
		-- Saves the item name.
		Name = tostring(_DataService:GetCell(dataSetName,i,"Name")),
		-- Saves the item's RUID.
		RUID = tostring(_DataService:GetCell(dataSetName,i,"RUID")),
		-- Saves the unique effect value that the item has.
		Value = tonumber(_DataService:GetCell(dataSetName,i,"Value")),
		-- Saves the item creation chance.
		SpawnRate = tonumber(_DataService:GetCell(dataSetName,i,"SpawnRate")),
		-- Saves the item model (prefab) EntryID value.
		EntryID = tostring(_DataService:GetCell(dataSetName,i,"EntryID"))
	}

	-- Saves the data saved to rowData to the table.
	self.itemInfoTable[i] = rowData
end
end

@ExecSpace("ClientOnly")

-- This method is needed to save the character data set.

-- This variable is needed to access the name of the data set that is saved in world space as local.

		-- Saves the character's unique skill Id.

	-- Saves the data saved to rowData to the table.
	self.characterInfoTable[i] = rowData

@ExecSpace("ClientOnly")

	rowData =

		-- Saves the skill name.

		-- Saves the skill use effect's unique value.

		-- Saves the skill effect RUID value.
		EffectRUID = tostring(_DataService:GetCell(dataSetName,i,"EffectRUID")),
		-- Saves the in-game UI RUID value.
		UI_RUID = tostring(_DataService:GetCell(dataSetName,i,"UI_RUID"))
	}

	-- Saves the data saved to rowData to the table.
	self.skillInfoTable[i] = rowData
end
end

@ExecSpace("ClientOnly")
method void InitStageRenderInfoTable()
-- This method is needed to save the resource information data set for each stage.

-- This variable is needed to access the name of the data set that is saved in world space as local.
local dataSetName = "StageRenderInfo"

-- Verifies the number of rows in the target data set.
local rowCount = self:GetDataSetRowCount(dataSetName)

-- This variable is needed to contain the data in each line.
local rowData

-- Iterates a number of times equal to the number of Rows of the data set starting from 1.

	rowData = 
	{
		-- Saves the floor tile RUID value that will be applied for each stage.
		TileRUID = tostring(_DataService:GetCell(dataSetName,i,"TileRUID")),
		-- Saves the obstacle object RUID value that will be applied for each stage.
		ObstacleRUID = tostring(_DataService:GetCell(dataSetName,i,"ObstacleRUID")),
		-- Saves the background RUID value that will be applied to each stage.
		BackgroundRUID = tostring(_DataService:GetCell(dataSetName,i,"BackgroundRUID"))
	}

	-- Saves the data saved to rowData to the table.
	self.stageRenderInfoTable[i] = rowData
end
end

end
```

## Writing UIManagerLogic Code
```lua
@Logic
script UIManagerLogic extends Logic

property number discript = 0 -- The logic needed to manage the overall UI, entities, and internal values.

property SliderComponent hpSlider = nil

property Entity toastUIGroup = nil

property TextComponent inGameCurrentScoreText = nil

property Entity resultPopup = nil

property Entity resultBestScoreText = nil

property Entity currentScoreText = nil

property Entity resultToMenuButton = nil

property Entity mainTitlePanel = nil

property Entity characterSelectPopup = nil

property SpriteGUIRendererComponent skillRenderer = nil

property TextComponent titleBestScore = nil

property Entity inGameScoreText = nil

property TextComponent counterText = nil

property Entity titleGameStartButton = nil

property Entity defaultUIGroup = nil

property Entity mobileSlideButton = nil

property Entity mobileJumpButton = nil

@ExecSpace("ClientOnly")
method void Init()
-- This method proceeds with resetting UIManagerLogic.

-- Links the references of internal members.
self:ConnectRefs()

-- Activates the main canvas that contains the UI entities when proceeding with a reset.
```
