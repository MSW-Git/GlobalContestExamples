# Running Platformer Learning Guide Document
<br>
<br>
<br>

## Learning Goals

- Learn how to implement core running platformer game functions using the guide document and the sample world.
- Learn how to set the map up based on the game that is to be created in MapleStory Worlds.
- Understand Logic and use it to design the game's structure.
- Modify and utilize the world based on the lessons.
<br>

---

<br>

## Learning Core Functions
- **Physics Component**: Learn about how to use the default Body component (Rigid, Kinematic, Sideview) as well as the PhysicsBody and PhysicsCollider components, which have the physics engine applied to them.
- **Procedural Map Creation**: Learn how to naturally link tiles beyond the random generation of platforms that the character can run on.
- **Object Pool**: Learn about the principles of the object pool techniques in order to manage multiple platform tiles and items.

<br>

## 🔄 Core Gameplay Loop

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Running/MSW-100_Running_0_001_en.png" alt="MSW-100_Running_0_001_en.png">
</p>
<br>

**1. Game Start**: Start the game from the title screen or view the controls for the game.<br>
**2. Select Play Character: When the Start Game button is pressed on the title screen, the UI for selecting a character is displayed.<br>
**3. In-Game Start**: Proceed with a countdown and start the game proper. A scroll speed will apply for each character, making the tiles and background elements move in the opposite direction of the character, and you can now interact with items and obstacles. <br>
**4. Character HP Status Check**: Check if the HP reached 0 as it continually decreases over time in accordance with the game end condition. <br>
**5. Results Check**: Displays the current score and the previous high score on the results window, and if the current score is higher than the high score, the user's high score is now updated. <br>
**6. Restart Request Check**: Return to the first title screen upon requesting a return to the title screen from the results window.

## Implementation Order

- 💡 **Basic Training**: The training material for MapleStory Worlds's basic functions and the fundamental functions of each target genre.
- 📖 **Advanced Training**: Category of training for learning and implementing functions visible in the sample world. Using these materials can increase the functions for the genre and understanding of the training materials. 

### [💡 Basic Training] 1. Composing a World Environment
- Learn about the map types provided by MapleStory Worlds and their relationships with each Body component.
- Learn what kind of game creation environment is needed when making a running platformer game.
- Learn about the PhysicsRigidbody and PhysicsCollider components.
- Apply them to an actual world and learn which settings are required.
<br>

### [💡Basic Training] 2. Understanding Logic
- Learn about what role Logic serves.
- Understand the concept of the Manager and how to use it.
- Understand the compositional reasoning and objectives of GameLogic, DataSetLogic, and UIManagerLogic.
<br>

### [💡Basic Training]3. Implementing the Scroll System
- Learn about how the character and environmental elements move when making a running platformer game.
- Learn about how to control the background elements that are visible in the world.
- Learn how to change the appearance of the environmental element based on the passage of time after the game starts.
<br>

### [💡Basic Training]4. Manage the Map Through Procedural Creation Methods
- Learn about the procedural creation method in a running platformer and why it's needed.
- Create floor tiles that will be used in the game and learn how to compose it as a Model.
- Create a DataSet so that the floor tile can be created through procedural generation based on the data table.
- Implement an infinite scrolling environment by creating floor tiles utilizing procedural creation methods. 
<br>

### [💡Basic Training] 5. Creating an Object Pool
- Understand the concept of an object pool and what its objective is.
- Implement the object pool Logic.
- See for yourself how the object pool functions by creating and returning one.
- Learn how to create new tiles when a floor tile is destroyed.
<br>

### [💡Basic Training]6. Implementing the Player Character
- Learn how to allow the character to jump and slide in a running platformer game.
- Learn how to compose and create a DataSet needed to create various characters.
- Learn how to revert the character's state and information when the game is restarted.
- Learn how to implement skills for each character that activates when the player makes the skill key input.
- Implement the function that can provide the player various characters to choose from and how characters can be selected.
<br>

### [💡Basic Training]7. Implementing the Life System
- Learn how to create a function that decreases the character's HP continuously over time once the main game begins.
- Learn how to create a UI element that the user can view as the HP continuously decreases over time.
<br>

### [💡Basic Training] 8. Composing UI
- Learn what a UIGroup is and how to use and edit it.
- Create UI elements used in the title screen and learn how to edit the UI.
- Learn how to control the UI elements in the title screen through code using Manager Logic.
- Create UI elements that should be marked in-game and implement it so it's synchronized in real time.
- Implement a UI that displays the results window that shows each score when the game ends.
<br>

### [📖Advanced Training]9. Implementing Obstacle Objects
- Learn how to place obstacle elements on floor tiles that are continuously moving.
- Learn about how to set it so that collisions between characters and obstacles can be detected.
- Implement the function that decreases the character's HP when the character collides with an obstacle.
<br>

### [📖Advanced Training] 10. Implementing Items
- Learn how to place item elements on floor tiles that are continuously moving.
- Learn how to compose a DataSet to compose an item with various effects.
- Learn how to set effects and unique effects based on the saved item data table.
- Implement how various item effects are activated and the actual action that's triggered when the character and the item collide.
<br>

### [📖Advanced Training]11. Implementing a Data Save System
- Learn how the high score is updated when the current score is higher than the previous high score when the player character dies.
- Create the system so that the previous high score is loaded and visible in the title screen if there is one when the player launches the world.
<br>
