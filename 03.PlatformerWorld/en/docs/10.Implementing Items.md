- In the sample world, the components registered as item are SpriteRendererComponent, TriggerComponent, and Item.
- The SpriteRendererComponent is a component for registering the appearance of an item. 
- The TriggerComponent is intended to detect collisions with the character, not to cause actual physical collisions such as the character being pushed.
- The Item component is a custom-made script designed to classify the specific type of item whenever a collision with a character is detected.

### Registering Item Dataset Table
- Item-specific information created with a DataSet is registered in the itemInfoTable of DataSetLogic.
- The ability to register as a data table is done in the InitItemInfoTable method of the DataSetLogic script.
- If the contents of the DataSetLogic code are needed, the DataSetLogic script is attached in the '2. Understanding Logic' section. 

```lua
-- InitItemInfoTable method of DataSetLogic

table itemInfoTable

void InitItemInfoTable()
{
    -- The number of rows in the ItemInfo table.
    local rowCount = _DataService:GetRowCount("ItemInfo")

    -- A variable to hold the data for each line.
    local rowData

    -- Start iteration, ranging from 1 up to the number of rows in the dataset.
    for i = 1 , rowCount , 1 do
        rowData = 
        {
            -- Save the item name.
            Name = tostring(_DataService:GetCell(dataSetName,i,"Name")),
            -- Stores the item RUID.
            RUID = tostring(_DataService:GetCell(dataSetName,i,"RUID")),
            -- Stores the item effect's unique value.
            Value = tonumber(_DataService:GetCell(dataSetName,i,"Value")),
            -- Stores the item creation rate.
            SpawnRate = tonumber(_DataService:GetCell(dataSetName,i,"SpawnRate")),
            -- Stores the EntryID value of the item's model (prefab).
            EntryID = tostring(_DataService:GetCell(dataSetName,i,"EntryID"))
        }

        -- Saves the data stored as rowData to a table.
        self.itemInfoTable[i] = rowData
    end
}
```

### Utilizing Item Data
- After saving data from an ItemInfo DataSet to DataSetLogic, data can be retrieved from DataSetLogic.
- When creating an item in the sample world, a data table for the item is needed.
- Pre-create item entities at the start of world from the Object Pool.
- The following code is the CreateItem method of ObjectPoolLogic that creates an item at the start of the world.

```lua
CreateItem of ObjectPoolLogic

table itemDataSetIDTable = {["Coin"] = 1,["Health"] = 2,["Booster"] = 3}

void CreateItem(string itemName, number createCount)
{
  local tempTable

  local dataSetID = self.itemDataSetIDTable[itemName]

  local entryID = _DataSetLogic.itemInfoTable[dataSetID].EntryID
  -- Retrieves the Name value of the target item model in the dataset.
  local name = _DataSetLogic.itemInfoTable[dataSetID].Name
  -- Retrieves the Value of the target item model in the dataset.
  local value = _DataSetLogic.itemInfoTable[dataSetID].Value

  -- Performs validation on the target table.

  -- /branch 1/ If no target pool (table) exists within the target item pool
  if isvalid(self.itemPool[name]) == false or self.itemPool[name] == nil then
    -- Create a new temporary table.
    tempTable = {}
    -- Set the inner pool (table) in the item pool as a temporary table.
    self.itemPool[name] = tempTable
    
  -- /branch 2/ If the target pool already exists within the target item pool
  else
    -- Declare the temporary table (pool) as the table already being utilized.
    tempTable = self.itemPool[name]
  end

  -- Performs a loop as many times as parameter2 createCount.
  for i = 1 , createCount, 1 do 
    -- Utilizes SpawnService to create the object.
    local entity = _SpawnService:SpawnByModelId(entryID,name,Vector3.up * 100, self.ItemPoolParent)
    
    -- Proceed with configuring the created object.
    
    -- Sets the item's unique value of the created object.
    entity.Item.value = value
    -- Sets the name variable of the item of the created object.
    entity.Item.name = name
    
    -- Inserts the entity created for the target table (pool).
    table.insert(tempTable,entity)
    
    -- Disable the created entity object.
    entity.Enable = false
  end
}
```

## Creating Items Based on Item Spawn Rate
<p align = "Center">
<img src = "https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Running/MSW-100_Running_10_004.png" alt="MSW-100_Running_10_004.png">
</p>

- There are three types of items implemented in the sample world: coins that award points, healing items that restore HP to the character, and booster items that temporarily increase scrolling speed.
- If all items spawn with the same probability, this can lead to balance issues where recovery items appear too often and the game never ends.
- As such, how often an item appears can be adjusted by setting the creation probability.
- The probability logic is designed to extract a random number between 0 and 1 when an item spawns, compare it to the SpawnRate value in the ItemInfo dataset, and spawn that item if the random number is lower or equal.

```lua
SpawnItem method of TileSet

    -- Proceed with a randomized spawn. (Generates a random number).
    local randomRate = math.random(0,100) * 0.01
    
    -- Declare the local variable to be set to the entity type.
    ---@type Entity
    local tempEntity
    
    -- /branch 1/ If the random probability is less than or equal to the value of healthSpawnRate 
    if _DataSetLogic.itemInfoTable[2].SpawnRate >= randomRate then
    -- Get the Health item from the object pool.
      tempEntity = _ObjectPoolLogic:GetItem("Health")
      
    -- /branch 2/ If the random probability value is less than or equal to boosterSpawnRate
    elseif _DataSetLogic.itemInfoTable[3].SpawnRate >= randomRate then
    -- Get the Booster item from the object pool.
      tempEntity = _ObjectPoolLogic:GetItem("Booster")
      
    -- /branch 3/ Spawns a default item (coin) if it's not within the probability of spawning any of the other set items.
    else
      tempEntity = _ObjectPoolLogic:GetItem("Coin")
      
    end
```

## Placing Items in Specified Locations
<p align = "Center">
<img src = "https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Running/MSW-100_Running_10_005.png" alt="MSW-100_Running_10_005.png">
</p>

- Within the floor tileset, entities are registered with ItemParent to set the location of items.
- Items spawned from the object pool should be moved the same as floor tiles.
- The spawned item is (Attach)ed as a (Child) of the entity that serves as the reference point, then has its local coordinates reset to the origin (0, 0, 0) so that it is placed in the exact same location as its parent.
- Repeat item spawning by iterating through the child elements of ItemParent.

```lua
SpawnItem method of TileSet

Entity itemParent -- The parent entity of the entities for setting the item location.

void SpawnItem
{
  -- Iterate the children of the entity to set the item's position.
  for index, child in pairs(self.itemParent.Children) do

  local tempEntity

  -- Process of setting the item entity of tempEntity by comparing the random probability to the SpawnRate value

  -- Sets the parent of the item entity to child.
  tempEntity:AttachTo(child)

  -- Sets the local coordinates of the item entity to the same position as its parent, using the parent's location as the origin.
  tempEntity.TransformComponent.Position = Vector3(0,0,0)
}
```

## Minimum Implementation Standards
- When an item spawns, it should attach to the floor tileset and move normally to the left side of the screen with the scroll movement of the map.
- When a character collides with an item's Trigger, the item entity should disappear from the screen and be returned to the object pool.

## Usage and Extension Direction
- Toward the end of the game, the difficulty of the game can be adjusted by randomly spawning items that have positive effects as well as trap items that will blind the character or lower the score if picked up.
