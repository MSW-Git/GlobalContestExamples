## What is the Script Function?

<p align="center">
<img src="../../_images/MSW-100_Adventure_3_001.jpg" alt="MSW-100_Adventure_3_001.jpg">
</p>

> The Sharenian Knights, a Story of MapleStory's Grand Athenaeum

- The script function is used in various games.
- It takes the role of delivering the story of the in-game universe through character dialogue, monologues, narration, and more.
- It's also used as an element that can directly talk about a character's backstory, the game's atmosphere, and more.

<br>

### Exploring the Elements of Scripts

- Various elements can be included in the script function based on how you compose it.
- As such, the method of making it changes based on how the game is going to provide the story to the player.
- But the following elements could be considered the foundational elements.

<p align="center">
<img src="../../_images/MSW-100_Adventure_3_002.png" alt="MSW-100_Adventure_3_002.png">
</p>

- **Name Output**: The window that shows who the speaker is. NPC names and the player's name can be output here, or in the case of narration, it can be left intentionally blank.
- **Text Output Window**: The window for what the speaker is saying. It can simply output the character dialogue or emphasize a portion of the text by changing the color of specific text.
- The sample world will be composed to output 2 types of content.

### Creating DialogueUIController
- Create a Component that manages the created DialogueUI.
- This Component registers and manages each entity to manage DialogueUI.

<p align="center">
<img src="../../_images/MSW-100_Adventure_3_015.png" alt="MSW-100_Adventure_3_015.png">
</p>

- Click DialogueUI from Hierarchy.
- Create a Component with the name DialogueUIController in Workspace.
- Add DialogueUIController to DialogueUI through Add Component in the Property window.

<p align="center">
<img src="../../_images/MSW-100_Adventure_3_016.png" alt="MSW-100_Adventure_3_016.png">
</p>

- Right-click My Desk in Workspace and then click Create Scripts, Create EventType.
- Create an Event with the name ShowDialogueUIEvent.
- Add string DialogueID as the Property of the created ShowDialogueUIEvent.

```lua
@Component
script DialogueUIController extends Component

property TextGUIRendererComponent dialogueComponent = "fd2aa18e-a624-4515-908d-b74bd78e454a"

property TextGUIRendererComponent nameComponent = "a25c1d68-5449-4a15-9e5c-44d6827eba50"

property number currentDialgoueIndex = 0

property table currentDialogueData = {}

property string currentDialogueID = ""

@ExecSpace("ClientOnly")
method void Show()
- Converts DialogueUI's Enable to true.
self.Entity.Enable = true
end

@ExecSpace("ClientOnly")
method void Hide()
- Converts DialogueUI's Enable to false.
self.Entity.Enable = false
end

@ExecSpace("ClientOnly")
method void InitDialogueData(table DialogueData)
- Activates DialogueUI to output the dialogue.
self:Show()
- Changes the current dialogue progression to 1.
self.currentDialgoueIndex = 1
- Registers the received DialogueData to its own Property.
self.currentDialogueData = DialogueData
- Loads the name value from CharacterNameStringData from the received Data.
local nameText = _LocalizationService:GetText(DialogueData[self.currentDialgoueIndex].NameID)
- Loads the text from DialogueLocalizeData from the received data. 
local dialogueText = _LocalizationService:GetText(DialogueData[self.currentDialgoueIndex].TextID)
- Leaves text blank if the loaded name value is nil or "".
if _UtilLogic:IsNilorEmptyString(nameText) then
	self.nameComponent.Text = ""
else
	if nameText == "Player" then
		-- Outputs the player's nickname if the name that needs to be output is Player.
		self.nameComponent.Text = _UserService.LocalPlayer.PlayerComponent.Nickname
	else
		-- If not, applies the localized name value that was loaded to the text component.
		self.nameComponent.Text = nameText
	end
end
- Leaves the text output window blank if the loaded dialogue text value is nil or "".
if _UtilLogic:IsNilorEmptyString(dialogueText) then
	self.dialogueComponent.Text = ""
else
	-- If not, applies the localized dialogue text that was loaded to the text component.
	self.dialogueComponent.Text = dialogueText
end
end

@ExecSpace("ClientOnly")
method void UpdateNextDialogue()
- Increases the current text progression stage by 1.
self.currentDialgoueIndex = self.currentDialgoueIndex + 1
- Executes the following code if the next dialogue data exists.
if isvalid(self.currentDialogueData[self.currentDialgoueIndex]) then
	-- Loads the character name for the next dialogue.
	local nameText = _LocalizationService:GetText(self.currentDialogueData[self.currentDialgoueIndex].NameID) 
	-- Loads the script for the next dialogue.
	local dialogueText = _LocalizationService:GetText(self.currentDialogueData[self.currentDialgoueIndex].TextID)
	-- Leaves the name blank if the loaded name value is nil or "".
	if not isvalid(nameText) or nameText == "" then
		self.nameComponent.Text = ""
	else
		if nameText == "Player" then
			-- Outputs the player's nickname if the name that needs to be output is Player.
			self.nameComponent.Text = _UserService.LocalPlayer.PlayerComponent.Nickname
		else
			-- If not, applies the localized name value that was loaded to the text component.
			self.nameComponent.Text = nameText
		end
	end
	-- Outputs the dialogue as blank if the loaded dialogue value is nil or "".
	if not isvalid(dialogueText) or dialogueText =="" then
		self.dialogueComponent.Text = ""
	else
		-- If not, outputs the loaded value.
		self.dialogueComponent.Text = dialogueText
	end
else
	-- If there is no next dialogue data, determines that the dialogue is over and closes the dialogue window.
	self:Hide()
	-- Activates the Component that was blocked to prevent character controls while the dialogue is taking place.
	_LocalPlayerControlLogic:EnablePlayerControl()
	-- Determines whether the quest has been cleared.
	local checkClearQuest = CheckQuestClearEvent()
	checkClearQuest.ConditionType = "Talk"
	checkClearQuest.TargetID = self.currentDialogueID
	_UserService.LocalPlayer:SendEvent(checkClearQuest)
end
end

@ExecSpace("ClientOnly")
@EventSender("Entity", "a68947ee-8f88-43b5-b8a1-91aec780b578")
handler HandleButtonClickEvent(ButtonClickEvent event)
-- Calls the method to output the next line, since the player touched the screen.
self:UpdateNextDialogue()
end

@ExecSpace("ClientOnly")
@EventSender("Self")
handler HandleShowDialogueUIEvent(ShowDialogueUIEvent event)
-- Determines whether the received DialogueID value in the event is nil.
if not _UtilLogic:IsNilorEmptyString(event.DialogueID) then
	-- Searches for text that will be output in the dialogue window.
	local findData = _DialogueLogic:GetDialogueDataByDialogueID(event.DialogueID)
	-- Registers the relevant data when it's successfully found.
	self:InitDialogueData(findData)
	self.currentDialogueID = event.DialogueID
	-- Executes the Show Method that shows itself since the dialogue window must be output.
	self:Show()
end
end

end
```

### Creating DialogueLogic
- Create a new Logic with the name DialogueLogic.

```lua
@Logic
script DialogueLogic extends Logic

property DialogueUIController dialogueUIController = "71d644e3-4527-491e-9426-b02cbdbd46ae"

property table dialogueData = {}

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- Caches the DialogueData data set when the game starts.
self:InitDialogueData()
end

@ExecSpace("ClientOnly")
method void InitDialogueData()
-- Attempts a reset if the dialogueData hasn't been reset.
if not isvalid(self.dialogueData) or not next(self.dialogueData) then
	-- Searches for a DataSet named DialogueData from Workspace.
	local getData = _DataService:GetTable("DialogueData")
	-- Leaves a log and halts code execution if there is no DataSet with that name or if it can't be normally loaded.
	if not isvalid(getData) then
		log("DialogueData DataSet not found!")
		return
	end
	
	local rowCount = getData:GetRowCount()
	-- Starts to navigate the length of the loaded DataSet.
	for i = 1, rowCount do
		-- Loads the DialogueID value.
		local tableKey = tostring(getData:GetCell(i, "DialogueID"))
		-- If DialogueID isn't normal, it is detected as an invalid value or an abnormal table and code execution is halted.
		if tableKey == nil or tableKey == "" then
			log("The DialogueID value is nil or empty.")
			return
		end
		-- Creates a table to place in Value.
		local rowData = {
			-- Loads the DialogueData DataSet's NameID value.
			NameID = tostring(getData:GetCell(i, "NameID")),
			-- Loads the DialogueData DataSet's TextID value.
			TextID = tostring(getData:GetCell(i, "TextID"))
		}
		-- Executes a reset if there is no self.dialogueData in key value format.
		if not isvalid(self.dialogueData[tableKey]) or not next(self.dialogueData[tableKey]) then
			self.dialogueData[tableKey] = {}
		end
		-- Adds the rowData Value to the Key value's dialogueData.
		table.insert(self.dialogueData[tableKey], rowData)
	end
end
end

method table GetDialogueDataByDialogueID(string DialogueID)
-- Navigates for a Value that has the delivered DialogueID as a Key.
if isvalid(self.dialogueData[DialogueID]) and next(self.dialogueData[DialogueID]) then
	-- Returns the Value with the target Key value, since one exists.
	return self.dialogueData[DialogueID]
else
	-- Leaves a log and returns nil if that is not the case.
	log("There is no Value that has DialogueID as a Key!")
	return nil
end
end

end
```

> This code is written based on Plain Text.

- Write the above code to DialogueLogic.
- The following is the Method composition.
    - `OnBeginPlay`: The Method needed to execute the InitDialogueData Method when the world is launched.
    - `InitDialogueData`: The method needed to register the already created DialogueData.
    - `GetDialogueDataByDialogueID`: Returns data bundles with the relevant ID value based on the DialogueID value parameter.
