## Creating QuestLogic
- You will need a Logic that can manage the already created `QuestData` DataSet.
- QuestLogic caches `QuestData` and delivers data in whatever way is required based on the QuestID value.
- Create a Logic from `Workspace` and `MyDesk` and then set the Logic's name as `QuestLogic`.
```lua
@Logic
script QuestLogic extends Logic

property table questData = {}

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- Attempts a reset to load QuestData DataSet.
self:InitQuestData()
end

@ExecSpace("ClientOnly")
method void InitQuestData()
-- Determines whether questData is empty.
if not isvalid(self.questData) or not next(self.questData) then
	-- If empty, loads QuestData from Workspace.
	local getData = _DataService:GetTable("QuestData")
	-- Generates a log and halts code execution if getData is nil, since no DataSet is found.
	if not isvalid(getData) then
		log_error("Couldn't find QuestData!")
		return
	end
	-- Navigates all values in DataSet by repeating an amount of times equal to QuestData's RowCount.
	for i = 1, getData:GetRowCount() do
		local findQuestID = getData:GetCell(i, "QuestID")
		-- Determines that there is an issue with the DataSet and exits if the found QuestID is Nil.
		if _UtilLogic:IsNilorEmptyString(findQuestID) then
			log_error("Couldn't find QuestID in QuestData!")
			return			
		end
		- Starts to enter the value after determining that there are normal values in all other cases.
		local rowData = QuestDataType()
		rowData.QuestID = findQuestID
		rowData.QuestNameID = getData:GetCell(i, "QuestNameID")
		rowData.InfoTextID = getData:GetCell(i, "InfoTextID")
		rowData.ConditionType = getData:GetCell(i, "ConditionType")
		rowData.TargetID = getData:GetCell(i, "TargetID")
		rowData.TargetCount = tonumber(getData:GetCell(i, "TargetCount"))
		rowData.NeedDialogue = getData:GetCell(i, "NeedDialogue")
		rowData.RewardID = getData:GetCell(i, "RewardID")
		rowData.NextQuestID = getData:GetCell(i, "NextQuestID")
		-- Saves the relevant values to questData once all values have been loaded.
		self.questData[findQuestID] = rowData
	end
	log("QuestData parsing complete!")
end
end

@ExecSpace("ClientOnly")
method void SetQuestNewGame()
-- Searches for local players.
local localPlayer = _UserService.LocalPlayer
-- Determines whether it was found normally.
if not isvalid(localPlayer) then
	--Generates an error log and halts code execution if playerQuestController is unusable.
	log_error("Couldn't find localPlayer!")
	return
end
-- Determines whether questData can be used normally.
if not isvalid(self.questData) or not next(self.questData) then
	-- Attempts a reset if normal use is impossible.
	self:InitQuestData()
end
-- Searches for the first QuestID in DataSet.
local firstQuestID = _DataService:GetTable("QuestData"):GetCell(1, "QuestID")
-- Loads data from questData based on the relevant ID values.
local findData = self.questData[firstQuestID]
-- Creates an Event for delivery after a reset.
local sendEvent = OnUpdatePlayerQuestData()
sendEvent.QuestID = findData.QuestID
sendEvent.QuestNameID = findData.QuestNameID
sendEvent.InfoTextID = findData.InfoTextID
sendEvent.ConditionType = findData.ConditionType
sendEvent.TargetID = findData.TargetID
sendEvent.NeedDialogue = findData.NeedDialogue
sendEvent.RewardID = findData.RewardID
sendEvent.NextQuestID = findData.NextQuestID
-- Delivers the completed Event to localPlayer.
localPlayer:SendEvent(sendEvent)
end

@ExecSpace("ClientOnly")
method void UpdateNextQuest(string NextQuestID)
-- Searches for LocalPlayer.
local localPlayer = _UserService.LocalPlayer
-- Determines whether it was found normally.
if not isvalid(localPlayer) then
	--Generates an error log and halts code execution if playerQuestController is unusable.
	log_error("Couldn't find localPlayer!")
	return
end
-- Searches for the following quest's information.
local findData = self.questData[NextQuestID]
local sendEvent = OnUpdatePlayerQuestData()
sendEvent.QuestID = findData.QuestID
sendEvent.QuestNameID = findData.QuestNameID
sendEvent.InfoTextID = findData.InfoTextID
sendEvent.ConditionType = findData.ConditionType
sendEvent.TargetID = findData.TargetID
sendEvent.NeedDialogue = findData.NeedDialogue
sendEvent.RewardID = findData.RewardID
sendEvent.NextQuestID = findData.NextQuestID
-- Delivers the event to LocalPlayer.
localPlayer:SendEvent(sendEvent)
end

@ExecSpace("ClientOnly")
method void SetQuestDataByQuestID(string QuestID)
-- Searches for local players.
local localPlayer = _UserService.LocalPlayer
-- Determines whether it was found normally.
if not isvalid(localPlayer) then
	--Generates an error log and halts code execution if playerQuestController is unusable.
	log_error("Couldn't find localPlayer!")
	return
end
-- Determines whether questData can be used normally.
if not isvalid(self.questData) or not next(self.questData) then
	-- Attempts a reset if normal use is impossible.
	self:InitQuestData()
end
-- Loads data from questData based on the relevant ID values.
local findData = self.questData[QuestID]
-- Creates an Event for delivery after a reset.
local sendEvent = OnUpdatePlayerQuestData()
sendEvent.QuestID = findData.QuestID
sendEvent.QuestNameID = findData.QuestNameID
sendEvent.InfoTextID = findData.InfoTextID
sendEvent.ConditionType = findData.ConditionType
sendEvent.TargetID = findData.TargetID
```

- Write the above code to `QuestLogic`.
- Each Method serves the following roles.
    - `OnBeginPlay`: Executes the `InitQuestData` Method when the world is launched.
    - `InitQuestData`: Executes the role that searches for the created `QuestData` and registers it to questData Property.
    - `SetQuestNewGame`: Executes the role of registering the quest that the player needs to complete next as shown on the top of `QuestData` when the game is launched for the first time.
    - `UpdateNextQuest`: Executes the role of registering the quest that the player needs to complete next with the same `QuestID` based on the `NextQuestID` that was received.
    - `SetQuestDataByQuestID`: Executes the role of loading existing data and registering a quest as what the player needs to complete next based on the relevant Quest information if the player started through Continue.

## Create PlayerQuestComponent
- The Component needed for the player to have the quest information.
- Create `PlayerQuestComponent` in `MyDesk` from `Workspace` and add to the `DefaultPlayer` of `Workspace`.

```lua
@Component
script PlayerQuestComponent extends Component

property QuestDataType currentQuestData = QuestDataType()

@EventSender("Self")
handler HandleOnUpdatePlayerQuestData(OnUpdatePlayerQuestData event)
-- Updates currentQuestData with received quest data.
self.currentQuestData.QuestID = event.QuestID
self.currentQuestData.QuestNameID = event.QuestNameID
self.currentQuestData.InfoTextID = event.InfoTextID
self.currentQuestData.ConditionType = event.ConditionType
self.currentQuestData.TargetID = event.TargetID
self.currentQuestData.NeedDialogue = event.NeedDialogue
self.currentQuestData.RewardID = event.RewardID
self.currentQuestData.NextQuestID = event.NextQuestID
end

@EventSender("Self")
handler HandleCheckQuestClearEvent(CheckQuestClearEvent event)
-- Determines whether the received event's values meet the quest's clear requirements.
if event.ConditionType == self.currentQuestData.ConditionType and event.TargetID == self.currentQuestData.TargetID then
	-- Proceed with processing based on clears if the requirements are met.
	if not (_UtilLogic:IsNilorEmptyString(self.currentQuestData.NeedDialogue)) then
		-- Searches for DialogueUI, since a dialogue window must be output.
		local dialogueUIGroup = _EntityService:GetEntityByPath("/ui/DialogueUI")
		-- Enters the DialogueID that must be output in Event.
		local eventValue = ShowDialogueUIEvent()
		eventValue.DialogueID = self.currentQuestData.NeedDialogue
		-- Delivers Event to DialogueUI.
		dialogueUIGroup:SendEvent(eventValue)
	end
	-- Distributes the appropriate rewards as necessary.
	if not _UtilLogic:IsNilorEmptyString(self.currentQuestData.RewardID) then
		local lootItemEvent = OnPlayerLootItem()
		lootItemEvent.ItemID = self.currentQuestData.RewardID
		lootItemEvent.ItemCount = 1
		self.Entity:SendEvent(lootItemEvent)
	end
	-- Generates the Dialogue when there is Dialogue that needs to be output.
	if not _UtilLogic:IsNilorEmptyString(self.currentQuestData.NeedDialogue) then
		local findDialogueUI = _EntityService:GetEntityByPath("/ui/DialogueUI")
		local showDialogueEvent = ShowDialogueUIEvent()
		showDialogueEvent.DialogueID = self.currentQuestData.NeedDialogue
		findDialogueUI:SendEvent(showDialogueEvent)
	end
	
	-- Requests a Quest update if there is a linked quest.
	if not _UtilLogic:IsNilorEmptyString(self.currentQuestData.NextQuestID) then
		_QuestLogic:UpdateNextQuest(self.currentQuestData.NextQuestID)
	end
end
end

end
```

> This code is written based on Plain Text.

- The written code executes the following roles.
    - `HandleOnUpdatePlayerQuestData`: Resets the `currentQuestData` Property with the received event value.
    - `HandleCheckQuestClearEvent`: Checks the clear condition based on the received event. Fulfills the following functions if those conditions are met.
        - Requests that the `DialogueID` received be output if a Dialogue needs to be output.
        - Distributes the `RewardID` value if there is a reward that needs to be distributed.
        - Requests a quest update when there is a linked quest.

## Creating PlayerItemComponent
- The Component that allows the player to manage items.
- If the player obtains an item, executes the role that registers items received as `OnPlayerLootItem`.
- Create a Component to `MyDesk` in `Workspace`.
- Register the created Component with the name `PlayerItemComponent`.
- Add the created Component to the DefaultPlayer of the `Workspace`.

```lua
@Component
script PlayerItemComponent extends Component

property table playerInventory = {}

@ExecSpace("ClientOnly")
@EventSender("Service", "InputService")
handler HandleKeyDownEvent(KeyDownEvent event)
-- Detects the i-key press event.
if event.key == KeyboardKey.I then
	-- Opens the inventory UI if the i-key was input.
	self.Entity:SendEvent(ShowInventoryUIEvent())
end
end

@EventSender("Self")
handler HandleOnPlayerLootItem(OnPlayerLootItem event)
log("Item acquisition reception complete!")
local checkClearQuestEvent = CheckQuestClearEvent()
checkClearQuestEvent.ConditionType = "Item"
checkClearQuestEvent.TargetID = event.ItemID
self.Entity:SendEvent(checkClearQuestEvent)
-- 1. Check if the item already exists in the inventory first.
for i = 1, #self.playerInventory do
    if self.playerInventory[i] and self.playerInventory[i].ItemID == event.ItemID then
        self.playerInventory[i].ItemCount = self.playerInventory[i].ItemCount + event.ItemCount
        return -- Ends the function, since an item was found and added.
    end
end

-- 2. If there is no such item, find the first empty slot (nil) and add it.
-- Check only up to slot no. 8. (itemIndex < 9 condition implemented)
for i = 1, 8 do
    if self.playerInventory[i] == nil then
        self.playerInventory[i] = {ItemID = event.ItemID, ItemCount = event.ItemCount}
        return -- Ends the function, since an item was added.
    end
end
end

end
```

> This code is written based on Plain Text.

- `HandleKeyDownEvent`: The Method that requests the inventory UI if the player presses the I key on their keyboard.
- `HandleOnPlayerLootItem`: Executes the role of adding to the player's inventory based on the event value received.
