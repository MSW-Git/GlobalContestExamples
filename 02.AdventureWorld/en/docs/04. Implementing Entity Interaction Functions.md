## Creating InteractionObjectComponent
- InteractionObjectComponent is a Component created in the sample world.
- Searches for InteractionComponent from the entity that has this Component and then executes any functions related to interactions with InteractionComponent.

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Adventure/MSW-100_Adventure_4_005.png" alt="MSW-100_Adventure_4_005.png">
</p>

- Click the NPC that was added to Hierarchy.
- Create and add a Component with the name InteractionObjectComponent from the Property window.

```lua
@Component
script InteractionObjectComponent extends Component

property InteractionComponent interactionComponent = nil

property string interactionType = ""

property string targetID = ""

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- Determines if its interactionComponent was registered.
if not isvalid(self.interactionComponent) then
	-- Searches its own Entity and InteractionComponent if its own interactionComponent isn't registered.
	local findComponent = self.Entity.InteractionComponent
	-- Leaves an error log and returns if an InteractionComponent wasn't found.
	if not isvalid(findComponent) then
		log_error(self.Entity.Name.." doesn't have an InteractionComponent!")
		return
	end
	-- Registers a found Component when it's successfully found.
	self.interactionComponent = findComponent
end
-- Edits and applies the language to the interaction object text based on the country the game is played in.
self.interactionComponent.ActionName = _LocalizationService:GetText(self.interactionComponent.ActionName)
end

@ExecSpace("ClientOnly")
method void CallDialogue()
-- Temporarily disables the player's movements.
_LocalPlayerControlLogic:DisablePlayerControl()
-- Creates an event to call DialogueUI.
local showDialogueEvent = ShowDialogueUIEvent()
-- Registers dialogueID that will be used as a parameter in the event.
showDialogueEvent.DialogueID = self.targetID
-- Searches for DialogueUI.
local dialogueUI = _EntityService:GetEntityByPath("/ui/DialogueUI")
-- Delivers the event to the DialogueUI entity when it was normally found.
if isvalid(dialogueUI) then
	dialogueUI:SendEvent(showDialogueEvent)
end
end

@ExecSpace("ClientOnly")
method void GiveItem()
-- Creates an event meant for item distribution to the player.
local giveItemEvent = OnPlayerLootItem()
-- Registers the ID and quantity of items to distribute.
giveItemEvent.ItemID = self.targetID
giveItemEvent.ItemCount = 1
-- Searches for LocalPlayer and delivers the event to the relevant Player.
local localPlayer = _UserService.LocalPlayer
localPlayer:SendEvent(giveItemEvent)
end

@ExecSpace("Server")
method void SaveData()
_DataStorageLogic:RequestSaveData()
end

@ExecSpace("Client")
method void RequestSaveData()
self:SaveData()
end

@ExecSpace("ClientOnly")
@EventSender("Self")
handler HandleInteractionEvent(InteractionEvent event)
log("Start interaction.")
-- Changes the interaction processing based on an interactionType value.
if _UtilLogic:IsNilorEmptyString(self.interactionType) then
	-- Outputs a log and halts code execution when there is no designated interactionType.
	log_error("The "..self.Entity.Name.." entity's InteractionObjectComponent element, interactionType, is empty or nil!")
	return
-- Requests a DialogueUI output if interactionType is Dialogue.
elseif self.interactionType == "Dialogue" then
	self:CallDialogue()
elseif self.interactionType == "GiveItem" then
	self:GiveItem()
-- Requests a save if interactionType is Save.
elseif self.interactionType == "Save" then
	self:RequestSaveData()
end
end

end
```
> This code was written based on Plain Text.

- Write the above code to `InteractionObjectComponent`.
- Each Method executes the following roles.
    - **OnBeginPlay**: Searches for `InteractionComponent` applied to entities when the world is launched and registers to `interactionComponent` Property. If the search is successful, it searches for the ActionName for `InteractionComponent`, and if there is a Key registered, the `LocaleDataSet` searches for it to execute localization.
        - Please refer to UIStringDat for MyDesk, Datatable, and Localization in the sample world.
    - **CallDialogue**: Loads the Dialogue based on the targetID value.
    - **GiveItem**: Distributes items to the player based on the targetID value.
    - **SaveData**: Saves the player's current position, map, and owned item information.
    - **RequestSaveData**: The Method needed to execute SaveData.
    - **HandleInteractionEvent**: Executes the dialogue, item distribution, and save functions based on interactionType value during an interaction.

## Event Processing when Accessing/Exiting Interactive Entities

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Adventure/MSW-100_Adventure_4_008.png" alt="MSW-100_Adventure_4_008.png">
</p>

- InteractionEnterEvent, InteractionEvent, and InteractionLeaveEvent exist in the InteractionObjectComponent's EventHandler.
- Currently, the interaction processing is done by InteractionEvent.
- However, you can add functions at Collide's access and exit timings using InteractionEnterEvent and InteractionLeaveEvent.
    - `InteractionEnterEvent`: You can write a function that will process right as a player and entity collides.
    - `InteractionLeaveEvent`: You can write a function that will process right as the player leaves the entity's collision range.

<br>

## Minimum Implementation Standards
- Proceed with dialogue by outputting the dialogue window when interacting with an entity.
- Randomly set and change the collision area based on the entity's image.
- Implements a function so that different dialogue is displayed for each NPC.

## Usage and Extension Direction
- Use InteractionEnterEvent and InteractionLeaveEvent so that certain NPCs appear or disappear when the player enters or leaves an area.
- Expands a function that can do various roles based on the InteractionObjectComponent's interactionType value.
