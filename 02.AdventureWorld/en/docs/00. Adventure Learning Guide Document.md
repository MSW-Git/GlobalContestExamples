## Learning Goals

- Learn how to implement core adventure game functions using the guide document and the sample world.
- Learn about Events in MapleStory Worlds and how to utilize them.
- Learn how to use Event to loosely link each script to one another.
- Modify and create a world in the form of your choosing.
<br>

---

<br>

## Learning Core Functions

- **Event Utilization**: Learn how to create the processing needed when the creator creates a custom event and when receiving Event.
- **Quest System Creation**: You can create a system that determines clear states through Event based on requirements and proceed with processing.

- DataTable: The folder that contains the DataSets that manage the data used in the adventure world.
    - DataSet: The folder containing DataSet, which controls the game's information.
    - Localization: The folder containing the LocaleDataSet, the table related to translation.
- Event: The folder that contains the Events created in the sample world.
- Model: The folder holding the entities created with Model in the sample world.
- ScriptFolder: The Folder containing all the Scripts used in the world.
    - ComponentFolder: The folder containing Component Script.
    - LogicFolder: The folder containing Logic Script.
- TypeFolder The folder containing Type Script.

## Implementation Order

- 💡 **Basic Training**: The training material for the most basic functions for MapleStory Worlds or for the relevant genre.
- 📖 **Advanced Training**: Category of training for learning and implementing functions visible in the sample world. Using these materials can expand the functions for the genre and understanding of the training materials.

<br>

### [💡 Basic Training] 1. Composing a World Environment
- Learn about the traits of the TileMap in MapleStory Worlds.
- Learn how to place Tiles in a TileMap.
- Learn about the RigidbodyComponent's Property composition and learn what role it serves.

<br>

### [💡 Basic Training] 2. Implementing Character Position Movement
- Learn how to move the character through TeleportService.
- Learn how to move the character using PortalComponent.
- Learn about the difference between TeleportService and PortalComponent to deduce which movement function should be used based on the situation.

<br>

### [💡 Basic Training] 3. Implementing the Script Output Function
- Implement the script output function that outputs NPCs or the story while progressing in quests.
- Output additional script using DataSet.
- Understand the function's composition, design improvements, and expand.

<br>

### [💡 Basic Training] 4. Implementing the Entity Interaction Function
- Implement a function, so the player can interact with entities placed on the map.
- Learn about how to implement interaction functions such as dialogue, investigating, saving, etc., by interacting with objects.
- Learn about developing additional functions outside of what's implemented in the sample world.

<br>

### [📖 Advanced Training] 5. Implementing the Inventory Function
- Create an inventory that can output items obtained by the player.
- Implement a function that outputs item information and allows detailed information to be viewed.

<br>

### [📖 Advanced Training] 6. Implementing the Quest System
- Learn about DataSet composition to compose quests.
- Implements a function that can determine a quest's clear status based on the player's actions.
- Learn how to use Event to compose a quest system.

<br>

### [📖 Advanced Training] 7. Implementing the Event Function
- Learn about the Event function that's provided by MapleStory Worlds.
- Learn about Event's traits and design how to utilize it.
- Learn about the pros and cons of Event and select Event or Logic based on the conditions and situation.

<br>

### [📖 Advanced Training] 8.Implementing the Save and Load Functions Utilizing DataStorage
- Implement the save and load functions of player information utilizing DataStorageService.
- Understand the DataStorageService function and design the save method based on the format of the world you wish to create.
