## Understanding RigidbodyComponent

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Adventure/MSW-100_Adventure_1_014.png" alt="MSW-100_Adventure_1_014.png">
</p>

- An entity needs a bodyComponent to interact with the map in MapleStory Worlds.
- RigidbodyComponent is the Component that allows the Tile to interact with entities in a TileMap.
- Click on DefaultPlayer in Workspace to open the Property window and view the Components applied to the player.

<br>

### ☑️ The Role of RigidbodyComponent

- This Component allows the TileMap and entity to interact with each other.
- You can also adjust the physics values of an entity that interacts with the map, such as density, acceleration, gravity value, etc.
- If an entity doesn't have a RigidbodyComponent, the entity **can't** interact with the Tiles on a TileMap.

## Minimum Implementation Standards

- Compose a Map for the player character to move around in.
- Change the player character's physics values based on what kind of world you intend to create.

## Usage and Extension Direction

- Create various Maps to design even more spaces.
- Compose various Maps with their own unique traits.
