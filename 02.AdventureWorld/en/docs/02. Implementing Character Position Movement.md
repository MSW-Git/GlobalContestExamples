## Character Movement in MapleStory Worlds

<p align="center">
<img src="../../_images/MSW-100_Adventure_2_001.png" alt="MSW-100_Adventure_2_001.png">
</p>

- The player can move around the adventure world to explore the map.
- However, when all maps are navigated by directed movement, it may cause the player to get bored.
- This also necessitates more work from the creator, since they will now have to create maps that represent the border between maps.
- To solve this issue, there is a need for a function that can instantly move the player to another location.
- MapleStory Worlds provides the TeleportService and PortalComponent functions to solve this issue.

#### ⚠️ What is the Collider?

<p align="center">
<img src="../../_images/MSW-100_Adventure_2_004.png" alt="MSW-100_Adventure_2_004.png">
</p>

> On the Collider editing screen, the square with the green outline is the Collider's area.

- The Collider's area is usually denoted with a green outline.
- This area is where a collision will be detected.
- When overlapping or colliding with another entity with Collider within the area, it will detect a collision.
- Add a collision detection function to use it for various systems like attacks, interactions, event triggers, etc.

## Understanding TeleportService

<p align="center">
<img src="../../_images/MSW-100_Adventure_2_008.png" alt="MSW-100_Adventure_2_008.png">
</p>

- TeleportService is an API provided by MapleStory Worlds.
- Various functions are provided, such as scheduled character movement, instant movement, movement based on entity, etc.
- Learn about entity-based movement and map Position-based movement in the sample world.
    - If you want to learn about additional functions, you can do so through API Reference in the Help menu seen on the top of the MapleStory Worlds editor.

<br>

### Learning About TeleportToEntityPath

<p align="center">
<img src="../../_images/MSW-100_Adventure_2_009.png" alt="MSW-100_Adventure_2_009.png">
</p>

- This moves the character to where the entity placed in Hierarchy is placed.
- The following values are required as parameters.
    - **targetEntity**: Requires the entity that will be moved.
    - **destinationEntityPath**: Requires the entity that will be used as the position.

<br>

### Use Example of TeleportEntityPath

- The following code is written based on PlainText.
- The following code is the TeleportPlayerForNewGame Method for TeleportLogic.

```lua
@Logic
script TeleportLogic extends Logic

@ExecSpace("Server")
method void TeleportPlayerForNewGame(Entity LocalPlayerEntity)
-- Moves the relevant entity to the Tutorial map's spawn position if the received entity is usable.
if isvalid(LocalPlayerEntity) then
	_TeleportService:TeleportToEntityPath(LocalPlayerEntity, "/maps/Tutorial/SpawnLocation")
end
end
end
```

- The LocalPlayerEntity, the player playing the game is required as a parameter.
- The target location is set to be the entity that has the name SpawnLocation on the Tutorial map.

<br>

## Understanding TeleportToMapPosition

<p align="center">
<img src="../../_images/MSW-100_Adventure_2_010.png" alt="MSW-100_Adventure_2_010.png">
</p>

- The character is moved to the set location on the Hierarchy's map.
- The following values are required as parameters.
    - **targetEntity**: Requires the entity that will be moved.
    - **destinationPosition**: Requires the position on the map as the destination.
    - **destinationMapName**: Requires the name of the map that will be moved that is inside Hierarchy and maps.

<br>

### Use Example of TeleportEntityPath

- The following code is written based on PlainText.
- The following code is the TeleportContinueGame Method for TeleportLogic.

```lua
@Logic
script TeleportLogic extends Logic

@ExecSpace("Server")
method void TeleportContinueGame(Entity LocalPlayerEntity, string MapName)
-- Moves the relevant entity to the saved coordinates on the map if the received entity is usable.
if isvalid(LocalPlayerEntity) then
	_TeleportService:TeleportToMapPosition(LocalPlayerEntity, _DataStorageLogic.lastPosition, MapName)
end
end

end
```
- The LocalPlayerEntity, the player playing the game is required as a parameter.
- Requires the name of the destination map.
- The location for TeleportToMapPosition that actually moves the character is set to be the player's last positional value.

## Creating TeleportLogic

- Create a TeleportLogic that is meant to move the player in the sample world.
- Write code that can do separate functions, like when the player plays in the world for the first time or is continuing through TeleportLogic.

<p align="center">
<img src="../../_images/MSW-100_Adventure_2_011.png" alt="MSW-100_Adventure_2_011.png">
</p>

- Right-click MyDesk from Workspace.
- Click Create Scripts and then Create Logic.
- Change the name of the Logic that was created in Workshpace to TeleportLogic.

```lua
@Logic
script TeleportLogic extends Logic

@ExecSpace("Server")
method void TeleportPlayerForNewGame(Entity LocalPlayerEntity)
-- Moves the relevant entity to the Tutorial map's spawn position if the received entity is usable.
if isvalid(LocalPlayerEntity) then
	_TeleportService:TeleportToEntityPath(LocalPlayerEntity, "/maps/Tutorial/SpawnLocation")
end
end

@ExecSpace("Server")
method void TeleportContinueGame(Entity LocalPlayerEntity, string MapName)
-- Moves the relevant entity to the saved coordinates on the map if the received entity is usable.
if isvalid(LocalPlayerEntity) then
	_TeleportService:TeleportToMapPosition(LocalPlayerEntity, _DataStorageLogic.lastPosition, MapName)
end
end

end
```
> This code is written based on Plain Code in MapleStory Worlds.

-  Each Method executes the following functions.
    - `TeleportPlayerForNewGame`: Moves the player at the starting location when the player clicks the Start New button from the title screen.
    - `TeleportContinueGame`: A Method composed to move the player to that last saved position based on the game information when the Continue button is clicked.

## Creating PlayerTeleportComponent

- Prevents the player's character from being visible while in the title screen.
- Determines if the player character is visible based on whether it's the Title map or not.

<p align="center">
<img src="../../_images/MSW-100_Adventure_2_012.png" alt="MSW-100_Adventure_2_012.png">
</p>

- Right-click MyDesk from Workspace.
- Click Create Scripts and then Create Logic.
- Change the created Component's name to PlayerTeleportComponent.

<p align="center">
<img src="../../_images/MSW-100_Adventure_2_013.png" alt="MSW-100_Adventure_2_013.png">
</p>

- Click DefaultPlayer from Workspace to add the created Component.
- Search for and add PlayerTeleportComponent after clicking Add Component at the very bottom of the Property window.

<p align="center">
<img src="../../_images/MSW-100_Adventure_2_014.png" alt="MSW-100_Adventure_2_014.png">
</p>

- Check if the PlayerTeleportComponent is registered to the Property window.

```lua
@Component
script PlayerTeleportComponent extends Component

@ExecSpace("ServerOnly")
method void OnBeginPlay()
-- Code used to prevent the character from being output in the title screen when the game first starts.
self.Entity.Enable = false
self.Entity.Visible = false
end

@EventSender("Self")
handler HandleEntityMapChangedEvent(EntityMapChangedEvent event)
-- Activates the character if the current map state isn't Title.
if not(event.NewMap.CurrentMapName == "Title") then
	self.Entity.Enable = true
	self.Entity.Visible = true
-- Deactivates the character if the current map state is Title.
else
	self.Entity.Enable = false
	self.Entity.Visible = false
end
end

end
```

> This code was written based on MapleStory Worlds' Plain Text.

- Each Method executes the following roles.
    - `OnBeginPlay`: A Method that stops the user's character from being visible on the title screen when the game is first launched.
    - `HandleEntityMapChangeEvent`: Stops the character from being visible when the player character entity detects map movement into the Title map.
