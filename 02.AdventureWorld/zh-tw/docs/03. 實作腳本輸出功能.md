## 什麼是腳本功能?

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Adventure/MSW-100_Adventure_3_001.jpg" alt="MSW-100_Adventure_3_001.jpg">
</p>

> 楓之谷世界的次元圖書館及威廉騎士

- 腳本是各個遊戲中都會使用的功能。
- 透過角色的對話、獨白、旁白等各式各樣發話者，以傳遞遊戲的世界觀。
- 也可以用來當作呈現角色敘事、遊戲氣氛的元素。

<br>

### 了解腳本的組成項目

- 依照腳本功能的組成，其中可以包含各式各樣的元素。
- 因此，會隨著遊戲的故事劇情而改變製作方法。
- 但基本上具備的組成元素如下。

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Adventure/MSW-100_Adventure_3_002.png" alt="MSW-100_Adventure_3_002.png">
</p>

- **顯示名稱**：顯示發話者身分的視窗。使用方式多樣，可以顯示NPC名稱或玩家名稱，若為旁白則不顯示。
- **文字顯示視窗**：顯示發話者說話內容的視窗。可以單純顯示角色的台詞，或變更特定文字顏色以強調特定文字內容。
- 預計實作功能在範例世界中能夠顯示2種內容。

### 製作DialogueUIController
- 製作用來管理已製作DialogueUI的Component。
- 此Component會記錄並管理各實體，以管理DialogueUI。

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Adventure/MSW-100_Adventure_3_015.png" alt="MSW-100_Adventure_3_015.png">
</p>

- 在「Hierarchy」中點擊「DialogueUI」。
- 在「Workspace」中建立名稱為「DialogueUIController」的Component。
- 在「Property」視窗中透過「Add Component」，將「DialogueUIController」新增至「DialogueUI」。

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Adventure/MSW-100_Adventure_3_016.png" alt="MSW-100_Adventure_3_016.png">
</p>

- 在「Workspace」中以滑鼠右鍵點擊「MyDesk」之後，再點擊「Create Scripts」、「Create EventType」。
- 將建立的Event名稱建立為「ShowDialogueUIEvent」。
- 在已建立的「ShowDialogueUIEvent」新增名稱為「string DialogueID」的Property。

```lua
@Component
script DialogueUIController extends Component

property TextGUIRendererComponent dialogueComponent = "fd2aa18e-a624-4515-908d-b74bd78e454a"

property TextGUIRendererComponent nameComponent = "a25c1d68-5449-4a15-9e5c-44d6827eba50"

property number currentDialgoueIndex = 0

property table currentDialogueData = {}

property string currentDialogueID = ""

@ExecSpace("ClientOnly")
method void Show()
-- 將DialogueUI的Enable轉換為true。
self.Entity.Enable = true
end

@ExecSpace("ClientOnly")
method void Hide()
-- 將DialogueUI的Enable轉換為false。
self.Entity.Enable = false
end

@ExecSpace("ClientOnly")
method void InitDialogueData(table DialogueData)
-- 啟用DialogueUI以輸出對話。
self:Show()
-- 將目前對話進度變更為1。
self.currentDialgoueIndex = 1
-- 將傳入的DialogueData記錄至自身的Property。
self.currentDialogueData = DialogueData
-- 從傳入的Data中，取得CharacterNameStringData的名稱值。
local nameText = _LocalizationService:GetText(DialogueData[self.currentDialgoueIndex].NameID)
-- 從傳入的Data中，取得DialogueLocalizeData的文字。 
local dialogueText = _LocalizationService:GetText(DialogueData[self.currentDialgoueIndex].TextID)
-- 如果取得的名稱值為nil或""，則文字顯示為空白。
if _UtilLogic:IsNilorEmptyString(nameText) then
	self.nameComponent.Text = ""
else
	if nameText == "Player" then
		-- 如果要輸出的名稱為Player，則顯示玩家的暱稱。
		self.nameComponent.Text = _UserService.LocalPlayer.PlayerComponent.Nickname
	else
		-- 若非上述情況，則將取得的在地化名稱值套用至名稱文字元件。
		self.nameComponent.Text = nameText
	end
end
-- 若取得的台詞文字值為nil或""，則文字顯示視窗為空白。
if _UtilLogic:IsNilorEmptyString(dialogueText) then
	self.dialogueComponent.Text = ""
else
	-- 若非上述情況，則顯示取得的在地化台詞文字。
	self.dialogueComponent.Text = dialogueText
end
end

@ExecSpace("ClientOnly")
method void UpdateNextDialogue()
-- 使目前文字進行階段增加1。
self.currentDialgoueIndex = self.currentDialgoueIndex + 1
-- 如果存在下一句台詞資料，則執行以下程式碼。
if isvalid(self.currentDialogueData[self.currentDialgoueIndex]) then
	-- 取得下一句台詞的角色名稱。
	local nameText = _LocalizationService:GetText(self.currentDialogueData[self.currentDialgoueIndex].NameID) 
	-- 取得下一句台詞的文本。
	local dialogueText = _LocalizationService:GetText(self.currentDialogueData[self.currentDialgoueIndex].TextID)
	-- 若取得的名稱值為nil或""，則名稱顯示為空白。
	if not isvalid(nameText) or nameText == "" then
		self.nameComponent.Text = ""
	else
		if nameText == "Player" then
			-- 如果要輸出的名稱為Player，則顯示玩家的暱稱。
			self.nameComponent.Text = _UserService.LocalPlayer.PlayerComponent.Nickname
		else
			-- 若非上述情況，則將取得的在地化名稱值套用至名稱文字元件。
			self.nameComponent.Text = nameText
		end
	end
	-- 若取得的台詞值為nil或""，則台詞顯示為空白。
	if not isvalid(dialogueText) or dialogueText =="" then
		self.dialogueComponent.Text = ""
	else
		-- 若非上述情況，則顯示取得的值。
		self.dialogueComponent.Text = dialogueText
	end
else
	-- 若沒有下一句台詞資料，則判斷台詞結束並結束台詞視窗。
	self:Hide()
	-- 重新啟用台詞進行期間禁止角色操作的Component。
	_LocalPlayerControlLogic:EnablePlayerControl()
	-- 用來檢查任務是否完成。
	local checkClearQuest = CheckQuestClearEvent()
	checkClearQuest.ConditionType = "Talk"
	checkClearQuest.TargetID = self.currentDialogueID
	_UserService.LocalPlayer:SendEvent(checkClearQuest)
end
end

@ExecSpace("ClientOnly")
@EventSender("Entity", "a68947ee-8f88-43b5-b8a1-91aec780b578")
handler HandleButtonClickEvent(ButtonClickEvent event)
-- 由於玩家觸碰了螢幕，因此呼叫方法以顯示下一句台詞。
self:UpdateNextDialogue()
end

@ExecSpace("ClientOnly")
@EventSender("Self")
handler HandleShowDialogueUIEvent(ShowDialogueUIEvent event)
-- 檢查傳入的event內的DialogueID值是否為nil。
if not _UtilLogic:IsNilorEmptyString(event.DialogueID) then
	-- 尋找用來對話視窗顯示的文字。
	local findData = _DialogueLogic:GetDialogueDataByDialogueID(event.DialogueID)
	-- 若成功找到資料，則記錄該筆資料。
	self:InitDialogueData(findData)
	self.currentDialogueID = event.DialogueID
	-- 由於必須顯示對話視窗，因此執行顯示自身的Show Method。
	self:Show()
end
end

end
```
- 在「DialogueUIController」中編寫以上程式碼。
- 該程式碼是以「Plain Text」為基準編寫而成。

### 製作DialogueLogic
- 製作名稱為「DialogueLogic」的新Logic。

```lua
@Logic
script DialogueLogic extends Logic

property DialogueUIController dialogueUIController = "71d644e3-4527-491e-9426-b02cbdbd46ae"

property table dialogueData = {}

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- 遊戲開始時，快取DialogueData資料集。
self:InitDialogueData()
end

@ExecSpace("ClientOnly")
method void InitDialogueData()
-- 如果之前dialogueData沒有重置，則嘗試重置。
if not isvalid(self.dialogueData) or not next(self.dialogueData) then
	-- 在Workspace中找到名稱為DialogueData的DataSet。
	local getData = _DataService:GetTable("DialogueData")
	-- 如果沒有該名稱的DataSet，或無法正常讀取的情況下，則留下log並中斷程式碼執行。
	if not isvalid(getData) then
		log("找不到DialogueData DataSet！")
		return
	end
	
	local rowCount = getData:GetRowCount()
	-- 依照取得的DataSet長度開始搜尋。
	for i = 1, rowCount do
		-- 取得DialogueID值。
		local tableKey = tostring(getData:GetCell(i, "DialogueID"))
		-- 如果DialogueID不正常，則偵測為錯誤值或非正常資料表並中斷程式碼執行。
		if tableKey == nil or tableKey == "" then
			log("DialogueID值為nil或空白！")
			return
		end
		-- 製作table以加入至Value。
		local rowData = {
			-- 取得DialogueData DataSet的NameID值。
			NameID = tostring(getData:GetCell(i, "NameID")),
			-- 取得DialogueData DataSet的TextID值。
			TextID = tostring(getData:GetCell(i, "TextID"))
		}
		-- 如果key值型態的self.dialogueData不存在，則進行重置。
		if not isvalid(self.dialogueData[tableKey]) or not next(self.dialogueData[tableKey]) then
			self.dialogueData[tableKey] = {}
		end
		-- 在key值的self.dialogueData中新增rowData這個Value。
		table.insert(self.dialogueData[tableKey], rowData)
	end
end
end

method table GetDialogueDataByDialogueID(string DialogueID)
-- 檢查是否有Value以傳入的DialogueID為Key值。
if isvalid(self.dialogueData[DialogueID]) and next(self.dialogueData[DialogueID]) then
	-- 由於存在，因此回傳擁有該Key值的Value。
	return self.dialogueData[DialogueID]
else
	-- 若非上述情況，則留下log並回傳nil。
	log("不存在以DialogueID為Key值的Value！")
	return nil
end
end

end
```

> 該程式碼是以Plain Text為基準編寫而成。

- 在DialogueLogic中輸入以上程式碼。
- Method的結構如下。
    - 「OnBeginPlay」：世界執行時，用來執行「InitDialogueData」Method的Method。
    - 「InitDialogueData」：用來記錄前面製作的DialogueData的Method。
    - 「GetDialogueDataByDialogueID」：以參數DialogueID值為基準，一併回傳具有ID值的資料集合。
