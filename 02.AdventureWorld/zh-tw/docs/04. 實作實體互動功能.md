## 配置實體

- 在「Preset List」中點擊「NPC」之後，選擇想要的NPC。
- 將選擇的「NPC」配置在「Scene」畫面中想要的位置。

- 點擊「Hierarchy」中新增的NPC。
- 檢查「Property」視窗中是否有「InteractionComponent」之後，如果沒有「InteractionComponent」，則透過「Add Component」來新增。
- 將Collide變更為想要的大小及型態。
- 將「ActionName」、「ActionKey」、「InteractionType」、「HoldingDuration」變更為想要的型式。

## 製作InteractionObjectComponent
- InteractionObjectComponent是範例世界製作的Component。
- 在此Component的實體中找到「InteractionComponent」之後，並負責與「InteractionComponent」互動時需要處理的功能。

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Adventure/MSW-100_Adventure_4_005.png" alt="MSW-100_Adventure_4_005.png">
</p>

- 點擊「Hierarchy」中新增的NPC。
- 在「Property」視窗中製作並新增名稱為「InteractionObjectComponent」的Component。

```lua
@Component
script InteractionObjectComponent extends Component

property InteractionComponent interactionComponent = nil

property string interactionType = ""

property string targetID = ""

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- 檢查自身的interactionComponent是否已記錄。
if not isvalid(self.interactionComponent) then
	-- 如果自身的interactionComponent沒有記錄，則尋找自身的Entity，並找到InteractionComponent。
	local findComponent = self.Entity.InteractionComponent
	-- 如果找不到InteractionComponent，則留下log並回傳。
	if not isvalid(findComponent) then
		log_error(self.Entity.Name.."不具備此InteractionComponent！")
		return
	end
	-- 如果成功找到，則將找到的Component記錄。
	self.interactionComponent = findComponent
end
-- 依照目前遊玩中的國家，修改互動物件的文字語言並套用。
self.interactionComponent.ActionName = _LocalizationService:GetText(self.interactionComponent.ActionName)
end

@ExecSpace("ClientOnly")
method void CallDialogue()
-- 暫時解除玩家移動限制。
_LocalPlayerControlLogic:DisablePlayerControl()
-- 建立用來呼叫DialogueUI的事件。
local showDialogueEvent = ShowDialogueUIEvent()
-- 記錄要當作事件參數使用的dialogueID。
showDialogueEvent.DialogueID = self.targetID
-- 尋找DialogueUI。
local dialogueUI = _EntityService:GetEntityByPath("/ui/DialogueUI")
-- 如果正常找到DialogueUI，則將事件傳遞至該UI實體。
if isvalid(dialogueUI) then
	dialogueUI:SendEvent(showDialogueEvent)
end
end

@ExecSpace("ClientOnly")
method void GiveItem()
-- 建立用來發放道具給玩家的事件。
local giveItemEvent = OnPlayerLootItem()
-- 記錄要發放的道具ID及數量。
giveItemEvent.ItemID = self.targetID
giveItemEvent.ItemCount = 1
-- 找到LocalPlayer之後，將事件傳遞至該Player。
local localPlayer = _UserService.LocalPlayer
localPlayer:SendEvent(giveItemEvent)
end

@ExecSpace("Server")
method void SaveData()
_DataStorageLogic:RequestSaveData()
end

@ExecSpace("Client")
method void RequestSaveData()
self:SaveData()
end

@ExecSpace("ClientOnly")
@EventSender("Self")
handler HandleInteractionEvent(InteractionEvent event)
log("互動開始")
-- 依照interactionType的值，來變更互動處理。
if _UtilLogic:IsNilorEmptyString(self.interactionType) then
	-- 如果沒有指定interactionType，則輸出log之後中斷執行。
	log_error(self.Entity.Name.."實體的InteractionObjectComponent元素 interactionType為空白或nil！")
	return
-- 如果interactionType是Dialogue，則請求輸出DialogueUI。
elseif self.interactionType == "Dialogue" then
	self:CallDialogue()
elseif self.interactionType == "GiveItem" then
	self:GiveItem()
-- 如果interactionType是Save，則請求儲存。
elseif self.interactionType == "Save" then
	self:RequestSaveData()
end
end

end
```
> 此程式碼是以Plain Text為基準編寫而成。

- 「InteractionObjectComponent」的程式碼依上述方式編寫。
- 各自的Method則負責執行以下角色。
    - **OnBeginPlay**：世界開始執行的瞬間，找到在實體的「InteractionComponent」，並記錄至「interactionComponent」Property。如果成功找到，則取得「InteractionComponent」的「ActionName」之後，並且如果有記錄在「LocaleDataSet」的Key，則進行尋找並執行在地化。
        - 以範例世界為基準，請參考「MyDesk」、「Datatable」、「Localization」的「UIStringDat」。
    - **CallDialogue**：以「targetID」值為基準讀取Dialogue。
    - **GiveItem**：以「targetID」值為基準發送道具給玩家。
    - **SaveData**：儲存玩家目前位置、地圖、持有道具資訊。
    - **RequestSaveData**：用來執行「SaveData」的Method。
    - **HandleInteractionEvent：進行互動時，依照「interactionType」值來執行對話、發放道具、儲存功能。

## 處理進入和離開互動實體時的事件

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Adventure/MSW-100_Adventure_4_008.png" alt="MSW-100_Adventure_4_008.png">
</p>

- 「InteractionObjectComponent」的「Event Handler」中有「InteractionEnterEvent」、「InteractionEvent」、「InteractionLeaveEvent」。
- 目前互動時的處理由「InteractionEvent」進行。
- 但可以透過「InteractionEnterEvent」、「InteractionLeaveEvent」在Collide的進入離開時機新增功能。
    -「InteractionEnterEvent」：可以編寫在玩家與實體碰撞瞬間要處理的功能。
    - 「InteractionLeaveEvent」：可以編寫在玩家離開與實體碰撞範圍的瞬間要處理的功能。

<br>

## 最低實作標準
- 與實體進行互動時，可以顯示對話視窗並進行台詞。
- 依照實體圖片任意指定及變更碰撞範圍。
- 實作每個NPC輸出不同台詞的功能。

## 應用與擴展方向
- 運用「InteractionEnterEvent」、「InteractionLeaveEvent」，可以製作使特定NPC在角色離開的瞬間消失或出現的功能。
- 依照「InteractionObjectComponent」的「interactionType」值，擴充功能以執行不同的角色功能。
