## 인벤토리 기능이란?

<p align="center">
<img src="../../_images/MSW-100_Adventure_5_001.jpg" alt="MSW-100_Adventure_5_001.jpg">
</p>

> 메이플스토리의 인벤토리 UI. 다양한 아이템을 저장하고 확인할 수 있습니다.

- 플레이어가 모험을 하면서 얻은 아이템이 있다면, 아이템을 확인할 수 있는 UI가 필요합니다.
- 인벤토리는 플레이어가 아이템을 습득했을 때, UI로 어떤 아이템을 습득했는지 확인시켜주는 UI입니다.
- 또한 게임의 특성마다 아이템의 사용 역할을 수행하기도 합니다.

## 인벤토리 UI 제작하기

<br>

### Frame UI 제작하기
- 앞선 UI를 추가하는 방법을 활용하여 `InventoryUI`를 추가합니다.

<p align="center">
<img src="../../_images/MSW-100_Adventure_5_002.png" alt="MSW-100_Adventure_5_002.png">
</p>

- 생성한 `InventoryUI`에 2개의 자식 엔티티를 제작합니다.
    - 제작한 엔티티의 이름을 `InventoryFrame`, `InfoFrame`으로 설정합니다.
    - 제작된 엔티티에 `SpriteGUIRendererComponent`를 추가한 뒤 배경으로 사용할 이미지를 선택합니다.
    - 그 후 `Scene`화면에서 원하는 크기와 형태로 배치합니다.

<br>

### InventoryFrame 제작하기

<p align="center">
<img src="../../_images/MSW-100_Adventure_5_003.png" alt="MSW-100_Adventure_5_003.png">
</p>

- 제작한 `InventoryFrame`에 자식 엔티티를 2개 생성합니다.
    - 2개의 엔티티 이름을 각각 `SlotLayout`, `ExitButton`으로 생성합니다.
    - `ExitButton`에는 `SpriteGUIRendererComponent`, `ButtonComponent`를 추가합니다.
    - `SpriteGUIRendererComponent`의 `ImageRUID`를 닫기 버튼으로 사용할 이미지로 등록합니다.

<p align="center">
<img src="../../_images/MSW-100_Adventure_5_004.png" alt="MSW-100_Adventure_5_004.png">
</p>

- `Hierarchy`에서 `SlotLayout`을 클릭합니다.
- `SlotLayout`에 `ScrollLayoutGroupComponent`를 추가합니다.
- `Scene`화면에서 적당한 범위로 인벤토리 슬롯이 출력될 공간을 설정합니다.
- `Property`창에서 `ScrollLayoutGroupComponent`의 값을 변경합니다.
    - **Type**: 바둑판 형태로 정렬될 수 있도록 Grid로 설정합니다.
    - **CellSize**: 자식 엔티티의 크기를 지정합니다. 추후 제작할 `InventoryItemSlot`을 기준으로 사이즈를 조정합니다.
    - **GridSpacing**: 자식 엔티티간 간격을 두고 싶을 경우 X, Y의 값을 입력합니다.
    - **StartCorner**: 좌측 상단부터 정렬될 수 있도록 UpperLeft로 설정합니다.
    - **GridChildAlignment**: 엔티티에 여유 공간이 있어도 좌측 상단부터 정렬되도록 UpperLeft로 설정합니다.
    - **StartAxis**: 자식 엔티티의 정렬을 수평으로 정렬되도록 Horizontal로 설정합니다.
    - **Constraint**: 자식 엔티티의 정렬이 유동적으로 정렬되도록 Flexible로 설정합니다.
    - **ConstraintCount**: Constraint값을 Flexible값이 아닌 다른 값으로 설정했을 경우, 원하는 개수만큼 정렬되도록 값을 입력합니다.

### InfoFrame 제작하기

<p align="center">
<img src="../../_images/MSW-100_Adventure_5_005.png" alt="MSW-100_Adventure_5_005.png">
</p>

- `Hierarchy`에서 앞서 제작한 `InfoFrame`을 클릭한 뒤, 자식 엔티티들을 생성합니다.
- 생성된 자식 엔티티들은 다음의 이름으로 변경합니다.
    - `ItemIconFrame`: 아이템의 아이콘 배경으로 사용될 엔티티입니다.
    - `NameFrame`: 이름이 출력되는 곳의 배경으로 사용될 엔티티입니다.
    - `DescriptionFrame`: 아이템의 설명이 출력되는 곳의 배경으로 사용될 엔티티입니다.
    - 3개의 엔티티는 `SpriteGUIRendererComponent`를 가져야 합니다.
    - 각 프레임 이미지를 적절한 크기로 배치합니다.
- `ItemIconFrame`, `NameFrame`, `DescriptionFrame`의 자식 엔티티를 하나씩 추가합니다.
    - `ItemIcon`: `ItemIconFrame`의 자식 엔티티로 아이템의 이미지를 출력합니다.
        - `ItemIcon`은 `SpriteGUIRendererComponent`를 Component로 보유합니다.
        - `ItemIconFrame`의 크기에 맞춰 이미지의 크기를 설정합니다.
    - `NameText`: `NameFrame`의 자식 엔티티로 아이템의 이름을 출력합니다.
    - `DescriptionText`: `DescriptionFrame`의 자식 엔티티로 아이템의 설명을 출력합니다.
        - `NameText`, `DescriptionText`는 `TextGUIRendererComponent`를 보유합니다.
        - `Nameframe`, `DescriptionFrame`의 크기에 맞춰 텍스트가 출력될 범위를 설정합니다.

### InventoryItemSlot 제작하기

<p align="center">
<img src="../../_images/MSW-100_Adventure_5_006.png" alt="MSW-100_Adventure_5_006.png">
</p>

- `InventoryItemSlot`은 인벤토리의 슬롯으로 사용하기 위한 Model입니다.
- `InventoryUI`의 `SlotLayout` 엔티티의 자식 엔티티로 사용됩니다.
- `InventoryUI`에 자식 엔티티로 `InventoryItemSlot`을 제작합니다.
- `InventoryItemSlot`은 본인, 자식 엔티티인 `Icon`으로 이뤄져있습니다.
    - `InventoryItemSlot`: 인벤토리의 슬롯을 출력하는 기능과, 클릭을 감지하는 역할, 아이템의 정보를 가지고 있는 역할을 수행합니다.
    - `Icon`: 자신에게 할당된 아이템의 이미지를 출력하기 위한 엔티티입니다.
- 각 엔티티에 다음의 Component를 추가합니다.
    - `InventoryItemSlot`: `SpriteGUIRendererComponent`, `ButtonComponent`
    - `Icon`: `SpriteGUIRendererComponent`
- 마지막으로 `InventoryItemSlot`을 관리하기 위한 Component인 `InventorySlotComponent`를 제작한 뒤 등록합니다.

<p align="center">
<img src="../../_images/MSW-100_Adventure_5_007.png" alt="MSW-100_Adventure_5_007.png">

- 정상적으로 `Workspace`, `MyDesk`에 Model이 제작되어 있는지 확인합니다.
- 정상적으로 Model이 제작되었다면 인벤토리 UI 준비가 완료되었습니다.

## UIInventoryController 제작하기
- `InventoryUI`의 요소를 관리하기 위한 Component인 `UIInventoryController`를 제작합니다.
- 제작한 Component를 `InventoryUI`에 `Add Component`로 등록합니다.

```lua
@Component
script UIInventoryController extends Component

property Entity infoEntity = "21856f11-da9c-4d39-869f-38679e45396a"

property Entity slotLayoutEntity = "413114e4-bc44-4702-8c59-04c097ccab27"

property table itemSlotTable = {}

property SpriteGUIRendererComponent infoFrameItemIcon = "a114218d-e9af-4529-a361-c40ff4b026a0"

property TextGUIRendererComponent infoFrameName = "cfae0263-8821-4d04-9d51-7cbf70f1f963"

property TextGUIRendererComponent infoFrameDesc = "651d2c82-7c70-4f17-bf92-43ab69b4fa5d"

property string itemSlotModelID = "model://b99d554b-893e-4e9b-9afd-fd91ad4b9805"

property number maxSlotCount = 8

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- 아이템의 정보를 출력하는 InfoFrame이 사용 가능한지 검증합니다.
if not isvalid(self.infoEntity) then
	-- 만약 아이템의 정보를 보여주는 InfoFrame이 nil일 경우, 에러 로그를 출력한 뒤 코드 실행을 중단합니다.
	log_warning("InventoryUI에 정보를 보여주기 위한 InfoFrame이 등록되어 있지 않습니다!")
	return
end
-- 사용이 가능 할 경우, infoEntity를 비활성화 처리합니다.
self.infoEntity.Enable = false

-- 인벤토리의 슬롯 개수가 1 미만인 경우, 인벤토리 슬롯을 생성합니다.
if #(self.itemSlotTable) < 1 then
	for i = 1, self.maxSlotCount do
		-- 빈 인벤토리 슬롯을 1개 생성합니다.
		local slotEntity = _SpawnService:SpawnByModelId(self.itemSlotModelID, tostring("ItemSlot_"..i), Vector3.zero, self.slotLayoutEntity)
		-- 정상적으로 엔티티가 생성되었다면, 최초 상태로 초기화를 시도합니다.
		if isvalid(slotEntity) then
			slotEntity.InventorySlotComponent:SetDefault()
			--itemSlotTable에 생성한 엔티티를 등록합니다.
			self.itemSlotTable[i] = slotEntity.InventorySlotComponent
		end
	end
end

-- 게임 시작시 인벤토리 UI가 출력되는걸 막기 위해 인벤토리 UI를 비활성화합니다.
self.Entity.Visible = false
self.Entity.Enable = false
end

@ExecSpace("ClientOnly")
method void ShowInventory()
-- 자기 자신의 상태를 보여주기로 변경합니다.
self.Entity.Visible = true
self.Entity.Enable = true
end

@ExecSpace("ClientOnly")
method void HideInventory()
-- 자기 자신의 상태를 숨기기로 변경합니다.
self.infoEntity.Enable = false
self.Entity.Visible = false
self.Entity.Enable = false
end

@ExecSpace("ClientOnly")
method void UpdateItemSlot(OnPlayerLootItem event)
-- 플레이어가 아이템을 습득하면 인벤토리 업데이트를 시도합니다.
for i = 1, #(self.itemSlotTable) do
	-- 현재 존재하는 인벤토리 슬롯에 동일한 아이템이 존재하는지 찾습니다.
	local slotItemName = self.itemSlotTable[i]:ReturnItemID()
	-- 가져온 ItemName이 nil인지 체크합니다.
	if not _UtilLogic:IsNilorEmptyString(slotItemName) then
		-- 정상적으로 ItemName이 있다면, 전달받은 itemID의 Count를 증가시킵니다.
		if slotItemName == event.ItemID then
			self.itemSlotTable[i]:UpdateItemCount(event.ItemCount)
			return
		end
	end
end
-- 한바퀴 탐색했음에도 동일한 이름의 ItemSlot이 없으므로, 빈 슬롯을 찾아 업데이트합니다.
for i = 1, #(self.itemSlotTable) do
	-- i번째 슬롯에 등록된 ItemID값을 가져옵니다.
	local slotItemName = self.itemSlotTable[i]:ReturnItemID()
	-- 만약 가져온 값이 nil일 경우, 빈 슬롯이므로 등록합니다.
	if _UtilLogic:IsNilorEmptyString(slotItemName) then
		-- ItemLogic에서 ItemID값을 기준으로 Dataset의 값을 가져옵니다.
		local getTableItemData = _ItemLogic:ReturnItemData(event.ItemID)
		-- ItemType형태로 전달할 값을 생성합니다.
		local inputItemData = ItemType()
		-- 아이템 구분, 인벤토리 내 슬롯의 값을 부여하기 위한 ItemID값을 등록합니다.
		inputItemData.ItemID = event.ItemID
		-- 아이템 아이콘을 출력하기 위한 ItemImage값을 등록합니다.
		inputItemData.ItemImage = getTableItemData.ItemImage
		-- 아이템 이름을 출력하기 위한 ItemName값을 등록합니다.
		inputItemData.ItemNameID = getTableItemData.ItemNameID
		-- 아이템의 타입을 지정하기 위한 ItemTypeValue값을 등록합니다.
		inputItemData.ItemTypeValue = getTableItemData.ItemTypeValue
		-- 아이템 설명을 출력하기 위한 ItemDescID값을 등록합니다.
		inputItemData.ItemDescID = getTableItemData.ItemDescID
		-- 저장한 데이터를 슬롯에 등록합니다.
		self.itemSlotTable[i]:InitItemData(getTableItemData, event.ItemCount)
		self.itemSlotTable[i]:UpdateItemCount(event.ItemCount)
		return
	end
end
end

@ExecSpace("ClientOnly")
method void ShowItemInfo(ShowInventoryItemInfoEvent ItemData)
-- 아이템 정보 창을 활성화합니다.
self.infoEntity.Enable = true
self.infoEntity.Visible = true
-- 아이템 정보 창의 아이템 이미지를 출력시킵니다.

-- 아이템 정보 창의 이름을 Localize를 통해 번역된 값을 출력합니다.
self.infoFrameName.Text = _LocalizationService:GetText(ItemData.ItemNameID)
-- 아이템 정보 창의 아이템 설명을 Localize를 통해 번역된 값을 출력합니다.
self.infoFrameDesc.Text = _LocalizationService:GetText(ItemData.ItemDescID)
end
```

## InventorySlotComponent 제작하기
- 인벤토리의 슬롯으로 사용하기 위한 `InventoryItemSlot`을 관리하는 Component입니다.
- 해당 Component는 아이템의 정보를 받으면 슬롯에 아이템의 정보를 등록하고 UI를 갱신합니다.
- 또한 자신이 클릭될 때 아이템 정보창을 출력하도록 기능이 구성되어 있습니다.

```lua
@Component
script InventorySlotComponent extends Component

property SpriteGUIRendererComponent spriteComponent = "09988a83-db6c-4895-a2a8-f13daae52688"

property ItemType itemData = ItemType()

property number itemCount = 0

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- 게임 시작시 Default상태로 초기화합니다.
self:SetDefault()
end

@ExecSpace("ClientOnly")
method void SetDefault()
-- spriteComponent가 비어있을 경우 해당 엔티티의 자식 엔티티에서 Icon을 찾아 등록합니다.
if self.spriteComponent == nil then
	local findIcon = self.Entity:GetChildByName("Icon")
	if isvalid(findIcon.SpriteGUIRendererComponent) then
		self.spriteComponent = findIcon.SpriteGUIRendererComponent
	end
end
-- 빈 인벤토리만 보이도록 아이콘을 출력하는 엔티티의 Visible을 false로 전환합니다.
self.spriteComponent.Entity.Visible = false
-- 아이템 정보를 담는 itemData의 값을 빈 상태로 초기화합니다.
self.itemData = ItemType()
end

@ExecSpace("ClientOnly")
method string ReturnItemID()
-- 해당 슬롯의 ItemID를 반환합니다.
return self.itemData.ItemID
end

@ExecSpace("ClientOnly")
method void InitItemData(ItemType ItemData)
-- 전달받은 데이터가 정상적으로 사용 가능한지 검증합니다.
if not isvalid(ItemData) or ItemData.ItemID == "" or ItemData.ItemID == nil then
	-- 만약 전달받은 데이터가 사용 불가능한 경우, 에러 로그를 출력합니다.
	log_error("전달받은 아이템 데이터가 nil이거나 사용이 불가능합니다!")
	return
end
-- 전달받은 데이터가 사용 가능하기 때문에 받은 정보를 기반으로 데이터를 가져옵니다.
self.itemData = ItemData
local getData = _ItemLogic:ReturnItemData(self.itemData.ItemID)
-- 찾은 DataSet에서 이미지 RUID를 입력한 뒤, 아이템 이미지를 출력합니다.
self.spriteComponent.ImageRUID = getData.ItemImage
self.spriteComponent.Entity.Visible = true
self.spriteComponent.Entity.Enable = true
end

@ExecSpace("ClientOnly")
method void UpdateItemCount(number Count)
-- 전달받은 수 만큼, 현재의 Count에서 증가시킵니다.
self.itemCount = self.itemCount + Count
end

@EventSender("Self")
handler HandleButtonClickEvent(ButtonClickEvent event)
-- 슬롯에 등록된 아이템 ID가 없을 경우, 아이템 정보창을 띄우지 않습니다.
if _UtilLogic:IsNilorEmptyString(self.itemData.ItemID) then
	return
-- 슬롯에 아이템ID가 있을 경우, 아이템 정보창을 출력하도록 Event를 호출합니다.
else
	-- 전달하기 위한 이벤트의 Property값들을 모두 입력합니다.
	local itemData = ShowInventoryItemInfoEvent()
	itemData.ItemNameID = self.itemData.ItemNameID
	itemData.ItemImage = self.itemData.ItemImage
	itemData.ItemDescID = self.itemData.ItemDescID
	-- InventoryUI를 찾은 뒤, 해당 UIGroup에 이벤트를 전달합니다.
	local inventoryUI = _EntityService:GetEntityByPath("/ui/InventoryUI")
	inventoryUI:SendEvent(itemData)
end
end

end
```
> 해당 코드는 Plain Text를 기준으로 작성되어 있습니다.

- 위의 코드를 InventorySlotComponent에 입력합니다.
- Method들은 다음의 역할을 수행합니다.
- **OnBeginPlay**: 월드가 실행되는 순간 SetDefault를 실행하기 위한 Method입니다.
- **SetDefault**: 인벤토리 슬롯을 초기 상태로 설정하기 위한 Method입니다.
- **ReturnItemID**: 해당 인벤토리 슬롯이 가지고 있는 ItemID를 반환하는 Method입니다.
- **InitItemData**: 전달받은 ItemData를 기준으로 슬롯의 UI를 업데이트합니다.
- **UpdateItemCount**: 전달받은 개수만큼 개수값인 `itemCount`를 증가시킵니다.
- **HandleButtonClickEvent**: 자기 자신이 클릭되었을 때, `InventoryUI`를 찾아 자신에게 등록된 아이템 정보를 전달하여 아이템 정보창을 출력하도록 Event를 호출합니다.

## ItemLogic 제작하기
- `ItemLogic`은 `ItemData` DataSet을 관리하기 위한 Logic입니다.
- `ItemData`기준 `ItemID`값을 전달받으면 해당하는 값의 정보를 반환하는 기능을 수행합니다.
- `ItemLogic`을 생성한 뒤 아래의 코드를 작성합니다.
```lua
@Logic
script ItemLogic extends Logic

property table itemData = {}

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- ItemData DataSet을 불러오기 위해 게임 시작 시 메소드를 호출합니다.
self:InitItemData()
end

@ExecSpace("ClientOnly")
method void InitItemData()
-- itemData가 nil 또는 데이터가 없는지 점검합니다.
if not isvalid(self.itemData) or not next(self.itemData) then
	-- 만약 itemData가 nil 또는 데이터가 없을 경우, 초기화를 시도합니다.
	local findData = _DataService:GetTable("ItemData")
	-- findData가 nil일 경우, 에러 로그를 출력하고 코드 실행을 중단합니다.
	if not isvalid(findData) then
		log_error("ItemData DataSet을 찾을 수 없습니다!")
		return
	end
	-- 정상적으로 DataSet을 찾았다면, 데이터를 등록합니다.
	-- ItemData의 행 개수를 가져옵니다.
	local rowCount = findData:GetRowCount()
	-- ItemData의 행 개수만큼 행들을 탐색하며 데이터를 등록합니다.
	for i = 1, rowCount do
		-- i번째 행의 ItemID값을 가져옵니다.
		local itemKey = tostring(findData:GetCell(i, "ItemID"))
		-- 가져온 ItemID가 nil 또는 ""일 경우, 에러 로그를 출력하고 코드 실행을 중단합니다.
		if not isvalid(itemKey) or itemKey == "" then
			log_error("i번째 ItemData DataSet의 Item ID값이 nil 또는 공란입니다!")
			break
		end
		-- 정상적으로 값이 있다면 등록을 시도합니다.
		local dataValue = ItemType()
		-- 아이템 정보의 Index를 i값으로 등록합니다.
		dataValue.Index = i
		-- 아이템 정보의 ItemID를 기존에 찾은 Key값으로 등록합니다.
		dataValue.ItemID = itemKey
		-- 아이템 정보의 ItemTypeValue를 i번째 행의 Cell에서 찾아 등록합니다.
		dataValue.ItemTypeValue = tostring(findData:GetCell(i, "ItemTypeValue"))
		-- 아이템 정보의 ItemNameID를 i번째 행의 Cell에서 찾아 등록합니다.
		dataValue.ItemNameID = tostring(findData:GetCell(i, "ItemNameID"))
		-- 아이템 정보의 ItemDescID를 i번째 행의 Cell에서 찾아 등록합니다.
		dataValue.ItemDescID = tostring(findData:GetCell(i, "ItemDescID"))
		-- 아이템 정보의 ItemImage를 i번째 행의 Cell에서 찾아 등록합니다.
		dataValue.ItemImage = tostring(findData:GetCell(i, "ItemImage"))
		-- 입력한 데이터를 등록합니다.
		self.itemData[itemKey] = dataValue
	end
	-- 정상적으로 등록을 마쳤다면, log를 출력합니다.
	log("ItemData ItemLogic에 등록 완료!")
	return
end
-- 아이템 파싱을 시도하지 않았으므로, 해당 내용을 log로 전달합니다.
log("ItemLogic에 ItemData를 등록하지 않았습니다. 이미 파싱이 되어있거나, DataSet을 정상적으로 읽지 못했습니다!")
end

@ExecSpace("ClientOnly")
method table ReturnItemData(string ItemID)
-- ItemID를 Key로 가지는 itemData가 존재한다면, 해당 값을 return합니다.
if isvalid(self.itemData[ItemID]) or next(self.itemData[ItemID]) then
	return self.itemData[ItemID]
else
	-- 만약 ItemID를 Key로 가지는 itemData가 존재하지 않을 경우, 에러 로그를 출력합니다.
	log_error(ItemID.."를 Key로 가지는 ItemData가 존재하지 않습니다.")
	return nil
end
end

end
```

> 해당 코드는 Plain Text를 기준으로 작성된 코드입니다.
