<br>
<br>

## 영상 타임라인
- 강의 영상내 아래의 타임라인에서 학습할 수 있습니다.
- 캐릭터 위치 이동 구현하기: `00:15:25`

<br>

## 학습 목표

- 캐릭터의 위치 이동 방식의 대표 방법인 TeleportService와 PortalComponent를 활용한 방법에 대해 학습합니다.
- 학습한 2가지의 방법을 토대로 어떤 방식으로 구현할 지 설계할 수 있습니다.
- TeleportService와 PortalComponent의 특징과 활용법을 설명할 수 있습니다.

<br>

## 해당 영상 시청 후 수행해 볼 내용

- 캐릭터의 위치를 이동시키는 PortalComponent를 구성합니다.
- 버튼 클릭 시 특정 위치로 이동하도록 UI 버튼과 TeleportService를 활용한 Component를 제작합니다.
- 제작된 Component를 활용하여 타이틀 화면에서 실제 게임 맵으로 이동하는 기능을 구성합니다.

<br>

## 메이플스토리 월드의 캐릭터 이동

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Adventure/MSW-100_Adventure_2_001.png" alt="MSW-100_Adventure_2_001.png">
</p>

- 어드벤처 월드에서 플레이어가 직접 이동을 통해 맵을 탐험할 수 있습니다.
- 그러나 모든 맵을 직접 이동하는 형태로 구현할 경우 플레이어는 피로감을 느낄 수 있습니다.
- 또한 맵 제작자 역시 맵을 제작할 때 맵과 맵 사이의 경계선을 표현하는 맵을 제작해야 하는 작업 공수가 발생합니다.
- 이러한 문제를 해결하기 위해 플레이어를 즉시 다른 지역으로 이동하는 기능이 필요합니다.
- 메이플스토리 월드에서 이런 문제를 해결하기 위해 `TeleportService`와 `PortalComponent` 기능을 제공합니다.

#### ⚠️ Collider란?

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Adventure/MSW-100_Adventure_2_004.png" alt="MSW-100_Adventure_2_004.png">
</p>

> Collider 편집 화면입니다. 초록색 사각형 테두리가 Collider의 범위입니다.

- Collider의 범위는 주로 초록색 선으로 표시됩니다.
- 해당 범위가 충돌을 감지하는 범위입니다.
- 해당 범위 내에 Collider를 가진 다른 엔티티와 겹치거나 부딪힐 경우, 충돌했다고 감지합니다.
- 충돌 감지에 따라 기능을 추가하여 공격, 상호작용, 이벤트 트리거 등 다양한 활용이 가능합니다.

### TeleportToEntityPath 살펴보기

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Adventure/MSW-100_Adventure_2_009.png" alt="MSW-100_Adventure_2_009.png">
</p>

- 캐릭터 이동 시 `Hierarchy`에 배치된 엔티티의 위치로 이동시킵니다.
- 매개 변수로는 다음의 값을 요구합니다.
    - **targetEntity**: 이동시키려는 엔티티를 요구합니다.
    - **destinationEntityPath**: 위치로 삼을 엔티티를 요구합니다.

<br>

### TeleportEntityPath 사용 예시

- 아래의 코드는 PlainText를 기준으로 작성된 코드입니다.
- 해당 코드는 샘플 월드 기준 `TeleportLogic`의 `TeleportPlayerForNewGame` Method입니다.

```lua
@Logic
script TeleportLogic extends Logic

@ExecSpace("Server")
method void TeleportPlayerForNewGame(Entity LocalPlayerEntity)
-- 전달받은 엔티티가 사용 가능한 엔티티라면, 해당 엔티티의 위치를 Tutorial맵의 스폰 지점으로 이동시킵니다.
if isvalid(LocalPlayerEntity) then
	_TeleportService:TeleportToEntityPath(LocalPlayerEntity, "/maps/Tutorial/SpawnLocation")
end
end
end
```

- 매개 변수로 LocalPlayerEntity, 게임을 플레이하는 플레이어를 요구합니다.
- 목적지는 Tutorial맵의 SpawnLocation이라는 이름을 가진 엔티티의 위치로 이동하도록 구성되어 있습니다.

## TeleportLogic 제작하기

- 샘플 월드에서 플레이어를 이동시키기 위해 제작된 TeleportLogic을 제작합니다.
- TeleportLogic을 통해 플레이어가 월드를 처음 시작하거나, 이어하기를 할 때 개별의 기능이 작동하도록 코드를 작성합니다.

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Adventure/MSW-100_Adventure_2_011.png" alt="MSW-100_Adventure_2_011.png">
</p>

- `Workspace`에서 `MyDesk`를 우클릭합니다.
- `Create Scripts`를 클릭한 뒤 `Create Logic`을 클릭합니다.
- 이후 `Workspace`에 생성된 Logic의 이름을 TeleportLogic으로 변경합니다.

```lua
@Logic
script TeleportLogic extends Logic

@ExecSpace("Server")
method void TeleportPlayerForNewGame(Entity LocalPlayerEntity)
-- 전달받은 엔티티가 사용 가능한 엔티티라면, 해당 엔티티의 위치를 Tutorial맵의 스폰 지점으로 이동시킵니다.
if isvalid(LocalPlayerEntity) then
	_TeleportService:TeleportToEntityPath(LocalPlayerEntity, "/maps/Tutorial/SpawnLocation")
end
end

@ExecSpace("Server")
method void TeleportContinueGame(Entity LocalPlayerEntity, string MapName)
-- 전달받은 엔티티가 사용 가능한 엔티티라면, 해당 엔티티의 위치를 저장된 맵의 좌표로 이동시킵니다.
if isvalid(LocalPlayerEntity) then
	_TeleportService:TeleportToMapPosition(LocalPlayerEntity, _DataStorageLogic.lastPosition, MapName)
end
end

end
```
> 해당 코드는 메이플스토리 월드 기준 Plain Text를 기준으로 작성되어 있습니다.

-  각 Method는 다음의 기능을 수행합니다.
    - `TeleportPlayerForNewGame`: 타이틀 화면에서 새로하기 버튼을 클릭할 시, 최초 시작 위치에서 게임을 시작하도록 이동시킵니다.
    - `TeleportContinueGame`: 이어하기 버튼을 클릭할 시, 저장된 플레이어의 게임 정보를 불러와 마지막으로 저장된 위치를 기준으로 시작할 수 있도록 구성된 Method입니다.

## PlayerTeleportComponent 제작하기

- 플레이어의 캐릭터가 타이틀 화면에 있을 때 출력되는 상황을 방지합니다.
- 플레이어 캐릭터가 Title 맵일 경우, 그렇지 않을 경우를 판단하여 캐릭터 출력 여부를 결정하도록 합니다.

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Adventure/MSW-100_Adventure_2_013.png" alt="MSW-100_Adventure_2_013.png">

- `Property` 창의 최하단에 있는 `Add Component`를 클릭한 뒤 생성한 `PlayerTeleportComponent`를 검색해 추가합니다.

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Adventure/MSW-100_Adventure_2_014.png" alt="MSW-100_Adventure_2_014.png">
</p>

- 정상적으로 등록되었는지 `Property` 창에서 `PlayerTeleportComponent`가 등록되어 있는지 확인합니다.

```lua
@Component
script PlayerTeleportComponent extends Component

@ExecSpace("ServerOnly")
method void OnBeginPlay()
-- 게임이 최초 시작될 경우, 타이틀 화면에서 캐릭터가 출력되지 않도록 하기 위한 코드입니다.
self.Entity.Enable = false
self.Entity.Visible = false
end

@EventSender("Self")
handler HandleEntityMapChangedEvent(EntityMapChangedEvent event)
-- 현재 맵 상테가 Title이 아닐 경우, 캐릭터를 활성화합니다.
if not(event.NewMap.CurrentMapName == "Title") then
	self.Entity.Enable = true
	self.Entity.Visible = true
-- 현재 맵 상테가 Title일 경우, 캐릭터를 비활성화합니다.
else
	self.Entity.Enable = false
	self.Entity.Visible = false
end
end

end
```

> 해당 코드는 메이플스토리 월드의 Palin Text 기준으로 작성된 코드입니다.

- 각 Method는 다음의 역할을 수행합니다.
    - `OnBeginPlay`: 월드가 처음 실행될 때, 타이틀 화면에 유저의 캐릭터가 출력되는 상황을 막기 위한 Method입니다.
    - `HandleEntityMapChangeEvent`: 플레이어 캐릭터 엔티티가 맵 이동을 감지 할 경우 이동한 맵이 Title일 경우 캐릭터 출력을 멈추게 합니다.

<br>

## 최소 구현 기준

- 캐릭터의 위치를 이동시키는 PortalComponent를 배치, 이동이 가능하도록 구현합니다.
- UI 버튼을 클릭하면 캐릭터가 이동하도록 Component와 기능을 구현합니다.
- 제작된 Component를 타이틀 화면에서 사용할 수 있도록 기능을 재구축합니다.

<br>

## 응용 및 확장 방향

- 단방향으로만 이동 가능한 PortalComponent를 배치하여 플레이어를 고립된 지역에서 탈출하도록 맵을 구성합니다.
- TeleportService를 활용하여 추후 아이템 제작시 마을 이동 아이템을 제작합니다.
- 저장 및 불러오기 기능을 구현하여 저장된 정보를 불러오면 마지막으로 저장한 위치에 플레이어를 스폰하도록 기능을 구현합니다.
