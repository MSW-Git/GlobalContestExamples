- 不過，範例世界是以客戶端為基礎運作，因此並非正式方法。

### 製作DataStorageLogic
- DataStorageLogic是在範例世界中為了儲存及讀取玩家資訊而製作的Logic。
- 可透過該Logic儲存或讀取玩家最高紀錄。

```lua
@Logic
script DataStorageLogic extends Logic

@Sync
property number serverBestWave = 0

property number clientBestWave = 0

property string storageKey = "BestWave"

@ExecSpace("ServerOnly")
method void SaveBestWave(string userId, number BestWave)
-- 將伺服器上的serverBestWave更新為Client收到的BestWave值。
self.serverBestWave = BestWave
-- 以userId為基準取得該user的資料。
local userDataStorage = _DataStorageService:GetUserDataStorage(userId)
-- 儲存最高波數值。        
userDataStorage:SetAsync(self.storageKey, tostring(self.serverBestWave), function(errorCode, key)
	if errorCode == 0 then
		log(userId .."的最高Wave值儲存完成！: " ..self.serverBestWave)
	else
		log("儲存失敗！錯誤代碼：" ..errorCode)
	end
end)
end

@ExecSpace("ServerOnly")
method void LoadBestWave(string userId)
-- 以userId為基準取得使用者資訊。
local userDataStorage = _DataStorageService:GetUserDataStorage(userId)
-- 從取得的資訊中取得擁有storageKey的資訊。
userDataStorage:GetAsync(self.storageKey, function(errorCode, key, value)
-- 若成功正常取得，則將serverBestWave值更新為取得的值。
if errorCode == 0 then
	self.serverBestWave = tonumber(value) or 0
	end
end)
end

@ExecSpace("ClientOnly")
method void OnSyncProperty(string name, any value)
-- 若serverBestWave的值發生更改，則也一起更新clientBestWave的值。
if name == "serverBestWave" then
	self.clientBestWave = value
end
end

@ExecSpace("Server")
method void RequestLoadBestWave(string userId)
self:LoadBestWave(userId)
end

@ExecSpace("Server")
method void RequestSaveBestWave(string userId, number CurrentBestWave)
self:SaveBestWave(userId, CurrentBestWave)
end

end
```

> 該程式碼是以PlainText為基準撰寫的程式碼。

- 若程式碼內storageKey的值更改，即可儲存各種值。
