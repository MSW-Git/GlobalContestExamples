- 메이플스토리 월드에서 맵을 교체하는 방법에 대해 학습합니다.

### TileSet 제작하기

<p align="center">
<img src="../../_images/MSW-100_Idle_1_006.png" alt="MSW-100_Idle_1_006.png">
</p>

1. TileSet 에디터에서 `+` 버튼을 클릭합니다.
2. `Create` 메뉴에서 `Create TileSet From Template을 클릭하여 메이플스토리 월드가 제공하는 Tile 리소스를 사용합니다.
    - 만약 자신만의 TileSet을 제작하고 싶을 경우 `Create Empty TileSet`을 통해 빈 TileSet을 생성할 수 있습니다.
3. 원하는 리소스를 선택하여 TileSet을 제작합니다.

<br>

#### 💬 TileSet이란?

<p align="center">
<img src="../../_images/MSW-100_Idle_1_007.png" alt="MSW-100_Idle_1_007.png">
</p>

- **TileSet**은 **Tile**들을 모은 팔레트의 개념입니다.
- 그림을 그릴 때 팔레트에 물감을 짠 뒤 짜 둔 물감을 사용합니다.
- 다양한 종류의 물감인 **Tile**을 하나의 **TileSet**이라는 팔레트에 물감을 짜 둡니다.
- 개발자는 **TileSet**이라는 팔레트에 넣어 둔 **Tile**을 찍어 `Scene`에 칠하기만 하면 됩니다.

## 슬롯 배치하기

<p align="center">
<img src="../../_images/MSW-100_Idle_1_010.png" alt="MSW-100_Idle_1_010.png">
</p>

- 캐릭터의 배치 위치를 지정하고, 사용하기 위한 슬롯을 제작하기 위해 엔티티를 생성해야 합니다.
- 다수의 엔티티를 하나의 맵에 정렬하면 관리에 어려움이 발생합니다.
- 이런 문제를 해결하기 위해 빈 엔티티의 자식으로 관리하는 방법이 있습니다.

<br>

### 엔티티 생성하기

- 엔티티의 생성 방법은 크게 2가지가 있습니다.
    - 일반적인 엔티티의 생성: 현재 편집중인 맵의 자식으로 엔티티를 생성할 수 있습니다.
    - 자식 엔티티로 생성: 현재 선택중인 엔티티의 자식으로 엔티티를 배치합니다. 
- 필요에 따라 빈 엔티티를 생성한 뒤, 자식 엔티티를 빈 엔티티의 자식으로 설정하여 엔티티의 특성에 따라 구분할 수 있습니다.
    - 샘플 월드의 경우 CharacterSlotPosGroup이라는 엔티티에 자식으로 CharacterSlotPos를 설정하였습니다.
    - 이를 통해 CharacterSlotPosGroup 엔티티는 자신의 자식인 CharacterSlotPos들을 담아 포장지 역할을 할 수 있습니다.

<p align="center">
<img src="../../_images/MSW-100_Idle_1_011.png" alt="MSW-100_Idle_1_011.png">
</p>

- `Hierarchy` 창에서 편집중인 맵을 마우스 우클릭합니다.
- `Create Entity`를 클릭하여 확장 메뉴를 엽니다.
- `Create Empty`를 클릭하여 빈 엔티티를 생성합니다.

<br>

#### 자식으로 엔티티 생성하기

<p align="center">
<img src="../../_images/MSW-100_Idle_1_012.png" alt="MSW-100_Idle_1_012.png">
</p>

- 부모로 사용할 엔티티를 마우스 우클릭합니다.
- `Create Entity as Child`를 클릭하여 확장메뉴를 엽니다.
- `Create Empty`를 통해 빈 엔티티를 자식 엔티티로 생성할 수 있습니다.

<br>

#### ⚠️ 엔티티 그룹으로 담을 때 주의사항
<p align="center">
<img src="../../_images/MSW-100_Idle_1_013.gif" alt="MSW-100_Idle_1_013.gif">

- 따라서 단순히 엔티티들을 관리하기 위한 용도라면 부모 엔티티의 좌표가 이동하지 않도록 주의해야 합니다.

### 슬롯 엔티티에 Component 부여하기

- Component는 메이플스토리 월드에서 엔티티가 특정한 기능을 수행하도록 만들기 위한 요소입니다.
- Component를 통해 엔티티가 이미지를 출력, 데이터의 처리 등 다양한 기능들을 수행할 수 있습니다.

<p align="center">
<img src="../../_images/MSW-100_Idle_1_015.png" alt="MSW-100_Idle_1_015.png">
</p>

- `Hierarchy`에서 Component를 추가하려는 엔티티를 클릭합니다.
- `Property` 창의 가장 하단에 있는 `Add Component`를 클릭합니다.

<p align="center">
<img src="../../_images/MSW-100_Idle_1_016.png" alt="MSW-100_Idle_1_016.png">
</p>

- Component의 이름을 검색하여 Componnet를 추가할 수 있습니다.
- 혹은 새롭게 제작해야 할 경우 `New Component`를 통해 새 Component를 제작 및 추가할 수 있습니다.
- 샘플 월드에서는 CharacterSlotComponent로 제작하였습니다.
- CharacterSlotPos를 관리하기 위한 CharacterSlotPosGroup에는 CharacterSlotGroupComponent를 부여합니다.
- 아래는 CharacterSlotComponent, CharacterSlotPosGroup Component입니다.

```lua
@Component
script CharacterSlotComponent extends Component

property Entity currentCharacterEntity = nil

property number slotNumber = 0

@ExecSpace("ClientOnly")
method boolean CheckCanSpawnCharacter()
-- 만약 슬롯에 등록된 캐릭터가 없을 경우 캐릭터 스폰 가능 여부를 true로 반환합니다.
if not(self.currentCharacterEntity) then
	return true
else
-- 그렇지 않을 경우 false로 반환합니다.
	return false
end
end

@ExecSpace("ClientOnly")
method void InitCharacterEntity(Entity CharacterEntity)
-- currentCharacterEntity를 전달받은 엔티티로 등록합니다.
self.currentCharacterEntity = CharacterEntity
end

@ExecSpace("ClientOnly")
method void InitSlotNumber(number SlotNumber)
-- 게임 시작시 자기 자신에게 할당되는 번호를 등록합니다.
self.slotNumber = SlotNumber
end

@ExecSpace("ClientOnly")
method number GetSlotNumber()
-- 자기 자신에게 할당된 SlotNumber를 반환합니다.
return self.slotNumber
end

end
```

> 해당 코드는 Plain Text를 기준으로 작성된 코드입니다.

```lua
@Component
script CharacterSlotGroupComponent extends Component

property table characterSlotList = {}

property Entity characterGroup = nil

@Description("현재 드래그 중인 엔티티가 있는지 확인하는 잠금 변수")
property boolean isDragging = false

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- 게임이 시작되면 자식 슬롯 List를 찾습니다.
self:InitCharacterSlotList()
-- 게임이 시작되면 characterGroup을 찾습니다.
self:InitCharacterGroup()
end

@ExecSpace("ClientOnly")
method void InitCharacterSlotList()
-- characterSlotList가 비어있을 경우 초기화를 시도합니다.
if not isvalid(self.characterSlotList) or not next(self.characterSlotList) then
	-- 현재 엔티티의 자식들을 가져옵니다.
	local childrenCount = self.Entity.Children.Count
	-- 1번부터 childrenCount만큼 반복합니다.
	for i = 1, childrenCount do
		-- 자식 엔티티의 이름 형식을 지정합니다.
		local entityName = "CharacterSlotPos"..i
		-- 자기 자신의 자식 엔티티를 이름으로 찾습니다.
		local getChildEntity = self.Entity:GetChildByName(entityName)
		-- 정상적으로 값을 찾았다면 이를 등록합니다.
		if isvalid(getChildEntity) then
			self.characterSlotList[i] = getChildEntity.CharacterSlotComponent
			self.characterSlotList[i]:InitSlotNumber(i)
			end
	end
end
end

@ExecSpace("ClientOnly")
method void InitCharacterGroup()
-- characterGroup이 비어있는지 확인합니다.
if not isvalid(self.characterGroup) then
	-- 비어있을 경우 CharacterGroup을 찾아 등록합니다.
	local findEntity = self.Entity:GetChildByName("CharacterGroup")
	-- 정상적으로 찾았을 경우 CharacterGroup을 등록합니다.
	self.characterGroup = findEntity
end
end

@ExecSpace("ClientOnly")
method number ReturnEmptySlotNumber()
-- characterSlotList의 수 만큼 탐색을 시작합니다.
for i = 1, #self.characterSlotList do
	-- i번째 슬롯이 비어있는지 체크합니다.
	if self.characterSlotList[i]:CheckCanSpawnCharacter() then
		-- 만약 i번째 슬롯이 비어있을 경우, i를 반환합니다.
		return i
	end
end
-- 만약 빈 슬롯이 없을 경우 0을 반환합니다.
return 0
end

@ExecSpace("ClientOnly")
method void SpawnCharacter(number SlotNumber, CharacterData CharacterData)
-- 전달받은 Data를 기준으로 Model을 복제합니다.
local SpawnCharacter = _SpawnService:SpawnByModelId(CharacterData.ModelID, CharacterData.CharacterID, Vector3.zero, self.characterGroup)
-- 스폰된 캐릭터의 위치를 전달받은 SlotNumber에 위치합니다.
SpawnCharacter.TransformComponent.WorldPosition = self.characterSlotList[SlotNumber].Entity.TransformComponent.WorldPosition
-- 스폰된 캐릭터에게 캐릭터 정보를 등록하고 활성화시킵니다.
SpawnCharacter.UnitController:InitCharacterData(CharacterData, self.characterSlotList[SlotNumber].Entity)
-- 전달받은 SlotNumber에 스폰된 캐릭터를 등록합니다.
self.characterSlotList[SlotNumber]:InitCharacterEntity(SpawnCharacter)
end

@ExecSpace("ClientOnly")
method void SwitchSlotCharacter(number TargetSlotNumber, Entity TargetEntity, number BeforeSlotNumber)
if not isvalid(self.characterSlotList[TargetSlotNumber].currentCharacterEntity) then
	-- 빈 슬롯일 경우 이동하려는 슬롯이 비어있는 상태이므로 이전을 수행합니다.
	TargetEntity.UnitController:ChangeSlot(self.characterSlotList[TargetSlotNumber].Entity) 
	-- 이동하려는 슬롯에 전달받은 엔티티를 등록합니다.
	self.characterSlotList[TargetSlotNumber]:InitCharacterEntity(TargetEntity)
	-- 기존의 슬롯을 nil 상태로 전환합니다.
	self.characterSlotList[BeforeSlotNumber]:InitCharacterEntity(nil)
else
	-- 슬롯에 이미 다른 엔티티가 있는 경우 타겟 슬롯에 원래 들어있던 기존 엔티티를 변수에 저장해둡니다.
	local existingEntity = self.characterSlotList[TargetSlotNumber].currentCharacterEntity
        
	-- 기존 엔티티를 비어있는 Before 슬롯 위치로 이동시킵니다.
	existingEntity.UnitController:ChangeSlot(self.characterSlotList[BeforeSlotNumber].Entity)
        
	-- 드래그해 온 엔티티를 타겟 슬롯 위치로 이동시킵니다.
	TargetEntity.UnitController:ChangeSlot(self.characterSlotList[TargetSlotNumber].Entity)
        
	-- 각 슬롯의 정보를 서로 교환합니다.
	self.characterSlotList[BeforeSlotNumber]:InitCharacterEntity(existingEntity)
	self.characterSlotList[TargetSlotNumber]:InitCharacterEntity(TargetEntity)
end
end

@ExecSpace("ClientOnly")
method void ClearCharacterList()
-- characterGroup이 유효한지 먼저 확인합니다.
if isvalid(self.characterGroup) then
	local children = self.characterGroup.Children
        
	-- 자식 엔티티들을 뒤에서부터(역순으로) 순회하며 삭제합니다.
	for i = children.Count, 1, -1 do
		local childEntity = children[i]
		if isvalid(childEntity) then
			childEntity:Destroy()
		end
	end
end

-- characterSlotList에 남아있는 엔티티 참조 데이터를 nil로 초기화합니다.
for i = 1, #self.characterSlotList do
	local slot = self.characterSlotList[i]
	if isvalid(slot) then
		slot:InitCharacterEntity(nil)
	end
end
end

end
```

> 해당 코드는 Plain Text를 기준으로 작성된 코드입니다.

## BGM 출력하기

- 단순히 엔티티 뿐만 아니라 맵에도 Component를 부여할 수 있습니다.
- `Hierarchy`에서 편집중인 맵에 `Add Component`를 통해 새 Component를 추가합니다.
- 해당 Component의 이름을 BGMPlayer로 작성합니다.
- 이어서 코드를 다음과 같이 작성합니다.

```lua
@Component
script BGMPlayer extends Component

property string bgmID = ""

@ExecSpace("ClientOnly")
method void OnBeginPlay()
self:PlayBGM()
end

@ExecSpace("ClientOnly")
```
