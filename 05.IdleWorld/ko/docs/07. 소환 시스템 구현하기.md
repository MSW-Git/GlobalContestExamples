## UI 제작하기
- 플레이어가 버튼을 눌러 캐릭터를 소환할 수 있도록 UI를 구성해야 합니다.
- UI의 버튼을 클릭하여 소환을 요청하고, 조건 충족 여부 판단과 소환을 수행할 수 있도록 기능을 구성합니다.

<br>

### UI Groups 제작하기

<p align="center">
<img src="../../_images/MSW-100_Idle_7_002.png" alt="MSW-100_Idle_7_002.png">
</p>

- 메이플스토리 월드 에디터 상단의 UI 버튼을 클릭합니다.
- 메이플스토리 월드 에디터 하단의 UI Groups 창에서 `+` 버튼을 클릭합니다.
- 새롭게 UI Group이 생성되었다면, `Hierarchy`에서 생성한 UI Group의 이름을 변경합니다.
    - 샘플 월드에서는 InGameUI로 제작했습니다.

<br>

### 버튼 제작하기

<p align="center">
<img src="../../_images/MSW-100_Idle_7_003.png" alt="MSW-100_Idle_7_003.png">
</p>

- `Hierarchy`에서 InGameUI를 마우스 우클릭합니다.
- `Create Entity`를 클릭하여 메뉴를 엽니다.
- `Create UIEmpty`를 클릭하여 빈 엔티티를 생성합니다.
- 생성한 엔티티 이름을 SummonButton으로 지정합니다.

<p align="center">
<img src="../../_images/MSW-100_Idle_7_004.png" alt="MSW-100_Idle_7_004.png">
</p>

- 제작한 엔티티에 다음의 Component들을 부여합니다.
- `SpriteGUIRendererComponent`
    - 버튼 이미지를 출력하기 위한 Component입니다.
- `ButtonComponent`
    - 버튼의 기능을 수행하기 위한 Componnet입니다.

<p align="center">
<img src="../../_images/MSW-100_Idle_7_005.png" alt="MSW-100_Idle_7_005.png">
</p>

- `Hierarchy`에서 SummonButton의 자식 엔티티로 Text를 생성합니다.
- 생성한 Text 엔티티에 `TextGUIRendererComponent`를 추가합니다.

<br>

### Component 편집하기

<p align="center">
<img src="../../_images/MSW-100_Idle_7_006.png" alt="MSW-100_Idle_7_006.png">
</p>

- `Hierarchy`에서 SummonButton의 Property를 편집합니다.
- `SpriteGUIRendererComponent`의 ImageRUID에 버튼 이미지를 등록합니다.
- `UITransformComponent`의 Width, Height, Pos값을 조정하여 버튼의 디자인을 편집합니다.

<p align="center">
<img src="../../_images/MSW-100_Idle_7_007.png" alt="MSW-100_Idle_7_007.png">
</p>

- Text 엔티티의 `TextGUIRendererComponent`를 편집합니다.
- Text에 버튼의 이름을 작성합니다.
    - 샘플 월드에서는 **소환**으로 출력하기 위해 StringData의 Key값을 입력했습니다.
- 만약 LocaleDataSet의 값을 사용하고자 할 경우 IsLocalizationKey의 체크를 활성화합니다.

<br>

#### ℹ️ LocaleDataSet

<p align="center">
<img src="../../_images/MSW-100_Idle_7_008.png" alt="MSW-100_Idle_7_008.png">
</p>

- `Workspace`에서 `MyDesk`를 우클릭합니다.
- `Create LocaleDataSet`을 클릭합니다.
- `Default`를 클릭하여 LocaleDataSet을 제작합니다.
- LocaleDataSet은 로컬라이징을 위한 DataSet입니다.

<p align="center">
<img src="../../_images/MSW-100_Idle_7_009.png" alt="MSW-100_Idle_7_009.png">
</p>

- `Key`
    - 번역을 위해 사용되는 값입니다.
    - `TextGUIRendererComponent`의 Text에 해당 값을 입력한 뒤 IsLocalizationKey를 활성화 하면 Source, ko, en등 번역된 결과를 출력할 수 있습니다.
- `Source`
    - 번역의 기준이 되는 값입니다.
    - 메이플스토리 월드의 자동 번역 기능을 사용 할 경우 해당 값을 기준으로 결과값을 가져옵니다.
- `Note`
    - 다른 월드 크리에이터에게 해당 값을 어디에서 사용할 것 인지 정보를 전달하기 위한 값입니다.
- `ko, en, zh-tw...`
    - 한국어, 영어, 중국어와 같이 월드가 실행되는 국가의 언어에 맞춰 입력한 값이 출력됩니다.

## Script 제작하기

<p align="center">
<img src="../../_images/MSW-100_Idle_7_010.png" alt="MSW-100_Idle_7_010.png">
</p>

- `Hierarchy`에서 InGameUI에 InGameUIController Component를 등록합니다.
- 이후 아래의 코드를 작성합니다.

```lua
@Component
script InGameUIController extends Component

property TextGUIRendererComponent monsterCountText = nil

property TextGUIRendererComponent waveCountText = nil

property TextGUIRendererComponent summonTokkenText = nil

property Entity timerEntity = nil

property TextGUIRendererComponent timerText = nil

@ExecSpace("ClientOnly")
method void OnBeginPlay()
self:InitMonsterCountText()
self:InitWaveCountText()
self:InitTimer()
self:InitSummonTokken()
end

@ExecSpace("ClientOnly")
method void InitMonsterCountText()
-- monsterCountText가 nil 상태인지 점검합니다.
if not isvalid(self.monsterCountText) then
	-- 경로를 기준으로 CountText 엔티티를 찾습니다.
	local findEntity = _EntityService:GetEntityByPath("/ui/InGameUI/MonsterCount/CountText")
	-- 정상적으로 엔티티를 찾는데 성공했다면 찾은 엔티티의 TextGUIRendererComponent를 등록합니다.
	if isvalid(findEntity) then
		self.monsterCountText = findEntity.TextGUIRendererComponent
	end
end
end

@ExecSpace("ClientOnly")
method void CountLeftMonster(number CurrentMonsterCount, number MaxMonsterCount)
-- 현재 남은 몬스터 수와 현재 웨이브에서 생성되는 최대 몬스터 수를 받아온 뒤 UI에 갱신합니다.
if not isvalid(self.monsterCountText) then
	self:InitMonsterCountText()
end
self.monsterCountText.Text = _LocalizationService:GetTextFormat("UI_RemainMonsterCount",CurrentMonsterCount, MaxMonsterCount)
end

@ExecSpace("ClientOnly")
method void InitWaveCountText()
-- waveCountText가 nil인지 검사합니다.
if not isvalid(self.waveCountText) then
	-- 만약 nil일 경우 경로를 기반으로 WaveCountText 엔티티를 찾습니다.
	local findText = _EntityService:GetEntityByPath("/ui/InGameUI/WaveCount/WaveCountText")
	if isvalid(findText) then
		-- 정상적으로 찾는데 성공했다면 찾은 엔티티의 TextGUIRendererComponent를 등록합니다.
		self.waveCountText = findText.TextGUIRendererComponent
	end
end
end

@ExecSpace("ClientOnly")
method void UpdateWaveCount(number WaveCount)
-- waveCountText가 nil일 경우 초기화를 요청합니다.
if not isvalid(self.waveCountText) then
	self:InitWaveCountText()
end
-- 전달받은 현재 웨이브 값으로 UI를 갱신합니다.
self.waveCountText.Text = _LocalizationService:GetTextFormat("UI_WaveCount", WaveCount)
end

@ExecSpace("ClientOnly")
method void InitTimer()
-- timerEntity가 nil인지 점검합니다.
if not isvalid(self.timerEntity) then
	-- 만약 nil일 경우 경로를 통해 LeftTime 엔티티를 찾습니다.
	local findEntity = _EntityService:GetEntityByPath("/ui/InGameUI/LeftTime")
	-- 만약 findEntity가 True일 경우 해당 값을 timerEntity에 적용합니다.
	if isvalid(findEntity) then
		self.timerEntity = findEntity
	end
end
-- timerText가 nil인지 점검합니다.
if not isvalid(self.timerText) then
	-- 만약 nil일 경우, TimerText 엔티티를 찾습니다.
	local findTextEntity = _EntityService:GetEntityByPath("/ui/InGameUI/LeftTime/TimerText")
	-- 찾은 findTextEntity가 True일 경우 해당 값을 timerText에 적용합니다.
	if isvalid(findTextEntity) then
		self.timerText = findTextEntity.TextGUIRendererComponent
	end
end
if self.timerEntity.Enable == true then
	self.timerEntity.Enable = false
end
end

@ExecSpace("ClientOnly")
method void UpdateTimer(number deltaTimer)
-- 전달받은 deltaTimer 값을 기준으로 남은 시간 UI를 갱신합니다.
if self.timerEntity.Enable == false then
	self.timerEntity.Enable = true
end

local timeString = string.format("%.2f", deltaTimer)

self.timerText.Text = "LeftTime\n"..timeString
end

@ExecSpace("ClientOnly")
method void DisableTimer()
-- Timer를 비활성화하도록 요청합니다.
self.timerEntity.Enable = false
end

@ExecSpace("ClientOnly")
method void InitSummonTokken()
-- summonTokkenText가 사용 가능한 상태인지 점검합니다.
if not isvalid(self.summonTokkenText) then
	-- 만약 summonTokkenText가 nil일 경우 경로를 기준으로 SummonTokkenText를 찾습니다.
	local findEntity = _EntityService:GetEntityByPath("/ui/InGameUI/SummonTokken/IconImage/SummonTokkenText")
	if isvalid(findEntity) then
		-- SummonTokkenText를 찾았다면 해당 엔티티의 TextGUIRendererComponent를 등록합니다.
		self.summonTokkenText = findEntity.TextGUIRendererComponent
	end
end
end

@ExecSpace("ClientOnly")
method void UpdateSummonTokkenUI(number TokkenValue)
-- summonTokkenText가 nil일 경우 초기화를 시도합니다.
if not isvalid(self.summonTokkenText) then
	self:InitSummonTokken()
end
-- 전달받은 TokkenValue를 기준으로 남은 토큰 수 UI를 갱신합니다.
self.summonTokkenText.Text = tostring(math.floor(TokkenValue))
end

@EventSender("Entity", "b3964a11-f347-420c-a354-2698b88a6181")
handler HandleButtonClickEvent(ButtonClickEvent event)
-- 소환하기 버튼을 클릭 할 경우 캐릭터 소환을 실행합니다.
_CharacterGachaLogic:RequestSpawnCharacter()
end

end
```

> 해당 코드는 Plain Text를 기준으로 작성된 코드입니다.

## 최소 구현 기준
- 플레이어가 UI를 통해 캐릭터를 소환할 수 있어야 합니다.
- 소환에 따라 소환 재화의 차감, 예외 사항에 대한 안내 UI가 출력되어야 합니다.

<br>

## 응용 및 확장 방향
- 플레이어가 캐릭터 슬롯을 비울 수 있는 수단(캐릭터 판매, 캐릭터 합성 등)을 추가하여 지속적으로 캐릭터를 소환할 수 있도록 기능을 추가합니다.
- 소환 재화를 점점 비싸게 만들어 재화를 부족한 환경을 조성합니다.
- 소환 재화의 비용 증가와 함께 캐릭터 강화 기능을 추가하여 플레이어가 재화를 선택하고, 전략적으로 사용할 수 있도록 기능을 확장합니다.
