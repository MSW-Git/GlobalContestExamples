- 플레이어의 기록을 저장하고 불러오는 기능을 구현하여 정보가 유실되지 않도록 기록해야 합니다.
- 메이플스토리 월드는 DataStorage를 활용하여 서버에 저장하고 불러오는 기능을 구현할 수 있습니다.
- 다만, 샘플 월드의 경우 클라이언트 기반으로 작동하기 때문에 정식적인 방법은 아닙니다.
- 따라서 여러분들이 샘플 월드를 상용화 수준으로 개발하고자 하실 경우 값들이 서버에서 관리되도록 구현해야 합니다.

<br>

### DataStorageLogic 제작하기
- DataStorageLogic은 샘플 월드에서 플레이어의 정보를 저장하고 불러오기 위해 제작된 Logic입니다.
- 해당 Logic을 통하여 플레이어의 최고 기록을 저장하거나 불러올 수 있습니다.

```lua
@Logic
script DataStorageLogic extends Logic

@Sync
property number serverBestWave = 0

property number clientBestWave = 0

property string storageKey = "BestWave"

@ExecSpace("ServerOnly")
method void SaveBestWave(string userId, number BestWave)
-- 서버에 있는 serverBestWave를 Client에서 전달받은 BestWave 값으로 업데이트합니다.
self.serverBestWave = BestWave
-- userId를 기준으로 해당 user의 데이터를 가져옵니다.
local userDataStorage = _DataStorageService:GetUserDataStorage(userId)
-- 최고 웨이브 값을 저장합니다.        
userDataStorage:SetAsync(self.storageKey, tostring(self.serverBestWave), function(errorCode, key)
	if errorCode == 0 then
		log(userId .. "의 최고 Wave값 저장 완료! : " .. self.serverBestWave)
	else
		log("저장 실패! 에러 코드: " .. errorCode)
	end
end)
end

@ExecSpace("ServerOnly")
method void LoadBestWave(string userId)
--userId를 기준으로 유저의 정보를 가져옵니다.
local userDataStorage = _DataStorageService:GetUserDataStorage(userId)
-- 가져온 정보에서 storageKey를 가지는 정보를 가져옵니다.
userDataStorage:GetAsync(self.storageKey, function(errorCode, key, value)
-- 정상적으로 가져오는데 성공했다면 serverBestWave 값을 가져온 값으로 갱신합니다.
if errorCode == 0 then
	self.serverBestWave = tonumber(value) or 0
	end
end)
end

@ExecSpace("ClientOnly")
method void OnSyncProperty(string name, any value)
-- 만약 serverBestWave의 값이 변경되었다면 clientBestWave의 값도 같이 갱신합니다.
if name == "serverBestWave" then
	self.clientBestWave = value
end
end

@ExecSpace("Server")
method void RequestLoadBestWave(string userId)
self:LoadBestWave(userId)
end

@ExecSpace("Server")
method void RequestSaveBestWave(string userId, number CurrentBestWave)
self:SaveBestWave(userId, CurrentBestWave)
end

end
```

> 해당 코드는 PlainText를 기준으로 작성된 코드입니다.

- 코드 내 storageKey의 값이 변경되면 다양한 값들을 저장할 수 있습니다.
