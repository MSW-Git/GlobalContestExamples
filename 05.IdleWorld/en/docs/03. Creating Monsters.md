## Understanding Monster Composition
- There are 2 roles that monsters serve in the sample world.
    1. Moving down a set path.
    2. Distributing summoning currency when it's defeated.
- So the monsters can be implemented simply as entities with HP, movement, damage taken, and death processing functions.

#### ⚠️ IsPassive for TriggerComponent

- Collision calculations through TriggerComponent are a tasks that have the highest calculation costs.
- When all objects detect a collision, it will greatly increase calculation costs.
- If IsPassive is activated, objects with an active IsPassive will not proceed with collision calculations.
- However, other Collision Groups that detect collisions with it can detect objects set to IsPassive.
- If collision detection has a 1:1 format like in the sample world, one side can be changed to IsPassive to save on calculation costs.

## Creating Monster Data
- Data to manage monsters, Logic that can make use of said Data, and a StructType that can manage values as a single element must be created.
- The sample world created MonsterData DataSet, MonsterSpawnLogic, and MonsterData StructType.

<br>

### Creating MonsterData DataSet
- MonsterData DataSet has the following structure.
- `MonsterID`
    - The value that differentiates monsters.
- `OneCycleMoveTime`
    - The value that determines how many seconds it will take for a TweenLineComponent that was assigned to a monster entity to reach the destination.
- `StartHP`
    - The HP value that is reset when a monster is created.
- `ModelID`
    - The value that's needed to register the Entry ID of a monster Model that was already created.
- Compose and create a DataSet based on the relevant values.
- Create a StructType to use the DataSet format.

## Composing Monster Components
- A MonsterController must be created to implement the monster's function.
- The following is the full code for MonsterController.

```lua
@Component
script MonsterController extends Component

property TweenLineComponent tweenLineComponent = nil

property string moveAnimationKey = "8257566e41aa4234929e81c6c2dab2e4"

property string dieAnimationKey = "65a2bfb039614f2e9e4ccc354340153d"

property SpriteRendererComponent monsterSpriteRenderer = nil

property boolean isAlive = false

property MonsterData monsterData = MonsterData()

property number currentHP = 0

property Entity hpBar = nil

property MonsterSpawnController spawnController = nil

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- Determines whether tweenLineComponent is nil.
if not isvalid(self.tweenLineComponent) then
	-- If it's nil, searches for the TweenLineComponent that's assigned to itself.
	local findEntity = self.Entity.TweenLineComponent
	-- If a Component is found normally, registers it to tweenLineComponent.
	if isvalid(findEntity) then
		self.tweenLineComponent = findEntity
	else
		-- Since a Component wasn't found normally, displays an error log.
		log_error("The Monster's TweenLine is nil!")
		return
	end	
end
-- Checks whether monsterSpriteRenderer is nil.
if not isvalid(self.monsterSpriteRenderer) then
	-- Searches for and registers the SpriterRenderer among its own Components.
	self.monsterSpriteRenderer = self.Entity.SpriteRendererComponent
end

-- If the hpBar is nil, it is searched for and registered.
if not isvalid(self.hpBar) then
	local findEntity = self.Entity:GetChildByName("HPBar")
	if isvalid(findEntity) then
		self.hpBar = findEntity
	end
end

self.isAlive = true
end

@ExecSpace("ClientOnly")
method void OnUpdate(number delta)
-- If the monster didn't make a full lap, requests that it start again.
if self.tweenLineComponent.CurrentState == TweenState.Idle then
	self.tweenLineComponent:RestartFromCurrentPosition()
end
end

@ExecSpace("ClientOnly")
method void InitData(MonsterData MonsterData, Vector3 StartPos, MonsterSpawnController MonsterSpawnController)
-- Resets its own monsterData with the received MonsterData.
self.monsterData = MonsterData
-- Resets the tweenLineComponent's Duration to the received value.
self.tweenLineComponent.Duration = self.monsterData.OneCycleMoveTime
-- Resets the current HP to the received HP.
self.currentHP = self.monsterData.StartHP
-- Converts the current state to activated.
self.isAlive = false
self.Enable = false
-- Resets tweenLine to its initial state.
self.tweenLineComponent:Stop(true)
-- Edits the current position to the received position.
self.Entity.TransformComponent.WorldPosition = StartPos
-- Updates the monster's HP bar to match the current hp.
self.hpBar.TransformComponent.Scale.x = self.currentHP / self.monsterData.StartHP * 20
-- Registers MonsterSpawnController.
self.spawnController = MonsterSpawnController
end

@ExecSpace("ClientOnly")
method void SetEnableState()
-- Resets the values, so the monsters can make their actions.
self.tweenLineComponent:Stop(true)
self.tweenLineComponent:Play()
self.currentHP = self.monsterData.StartHP
self.monsterSpriteRenderer.SpriteRUID = self.moveAnimationKey
self.isAlive = true
self.Enable = true
end

@ExecSpace("ClientOnly")
method void GetDamage(number AtkValue)
-- Displays damage taken.
_DamageSkinService:Play(self.Entity, "3271c3e79bf04ecba9a107d55495970d", 0.05, {AtkValue}, DamageSkinTweenType.Default, false)
-- Decreases the current by HP by the received damage.
self.currentHP = self.currentHP - AtkValue
-- Proceeds with the defeat-related processing if the current HP is 0 or lower.
if self.currentHP <= 0 then
	-- Resets to 0 to prevent overflow.
	self.currentHP = 0
	-- Changes the current survival state to false.
	self.isAlive = false
	-- Stops the monster's movement.
	self.tweenLineComponent:Pause()
	-- Changes the monster's animation to death.
	self.monsterSpriteRenderer.SpriteRUID = self.dieAnimationKey
	-- Resets the HPBar size to 0.
	self.hpBar.TransformComponent.Scale.x = 0
	-- Directs MonsterSpawnManager to decrease the number remaining since it was defeated.
	self.spawnController:UpdateRemainMonsterCount(-1)
	-- Directs GameLogic to increase summon tokens by 1.
	_GameLogic:UpdateSummonTokken(1)
else
	-- Applies the calculated value, so the UI is modified to fit the set size in exceptional cases.
	self.hpBar.TransformComponent.Scale.x = self.currentHP / self.monsterData.StartHP * 20
end
end

@EventSender("Self")
handler HandleSpriteAnimPlayerEndFrameEvent(SpriteAnimPlayerEndFrameEvent event)
-- Deactivates the entity if the monster death animation played to the end.
if self.monsterSpriteRenderer.SpriteRUID == self.dieAnimationKey then
	self.Entity.Enable = false
end
end

end
```

### Creating Logic to Load Monster Information
- Create a MonsterSpawnLogic that manages monster information and monster spawns.
- MonsterSpawnLogic is a Script that is written as a Logic Script.
- The following is the full code for MonsterSpawnLogic.

```lua
@Logic
script MonsterSpawnLogic extends Logic

property table monsterData = {}

property table waveData = {}

@ExecSpace("ClientOnly")
method void OnBeginPlay()
self:InitMonsterData()
self:InitWaveData()
end

@ExecSpace("ClientOnly")
method void InitMonsterData()
-- Determines whether monsterData is unusable.
if not isvalid(self.monsterData) or not next(self.monsterData) then
	-- Confirms whether MonsterData DataSet exists normally.
	local findDataSet = _DataService:GetTable("MonsterData")
	-- Leaves an error log if the load was a failure.
	if not isvalid(findDataSet) then
		log_error("Failed to load MonsterData DataSet.")
		return
	end
	-- If the search was successful, loads the rowCount.
	local rowCount = findDataSet:GetRowCount()
	-- Repeats a number of times equal to rowCount and searches for data in order and registers them.
	for i = 1, rowCount do
		local monsterID = tostring(findDataSet:GetCell(i, "MonsterID"))
		-- Determines whether MonsterID exists normally.
		if not _UtilLogic:IsNilorEmptyString(monsterID) then
			-- If MonsterID exists normally, starts to load data after determining that it's a normal value.
			local getData = MonsterData()
			getData.MonsterID = monsterID
			getData.OneCycleMoveTime = tonumber(findDataSet:GetCell(i, "OneCycleMoveTime"))
			getData.StartHP = tonumber(findDataSet:GetCell(i, "StartHP"))
			getData.ModelID = tostring(findDataSet:GetCell(i, "ModelID"))
			if not isvalid(self.monsterData[monsterID]) then
				self.monsterData[monsterID] = {}
			end
			self.monsterData[monsterID] = getData
		end
	end
end
end

@ExecSpace("ClientOnly")
method void InitWaveData()
-- Determines whether waveData is in a usable state.
if not isvalid(self.waveData) or not next(self.waveData) then
	local findDataSet = _DataService:GetTable("WaveData")
	-- Confirms whether DataSet was found normally.
	if isvalid(findDataSet) then
		-- Loads rowCount if data exists normally.
		local rowCount = findDataSet:GetRowCount()
		-- Navigates data repetitively up to the number of rowCount.
		for i = 1, rowCount do
			local getData = WaveData()
			getData.WaveIndex = tonumber(findDataSet:GetCell(i, "WaveIndex"))
			getData.SpawnMonster = tostring(findDataSet:GetCell(i, "SpawnMonster"))
			getData.SpawnMonsterCount = tonumber(findDataSet:GetCell(i, "SpawnMonsterCount"))
			if not isvalid(self.waveData[i]) then
				self.waveData[i] = {}
			end
			self.waveData[i] = getData
		end
	end
end
end

@ExecSpace("ClientOnly")
method MonsterData GetMonsterDataByMonsterID(string MonsterID)
-- Checks if there is data that has a MonsterID as a Key.
if isvalid(self.monsterData[MonsterID]) then
	-- If data exists normally, returns the target data.
	return self.monsterData[MonsterID]
end
-- If there is no data, returns nil with an error log.
log_warning(MonsterID.."is Nil Data!")
return nil
end

@ExecSpace("ClientOnly")
method WaveData GetSpawnList(integer WaveIndex)
-- Checks if there is a WaveIndex value.
if isvalid(self.waveData[WaveIndex]) then
	-- Returns the target Data if there is a valid value.
	return self.waveData[WaveIndex]
end
end

end
```
