- You need to implement a function that can save and load a player's record so that their information isn't lost.
- MapleStory Worlds can use DataStorage to implement a function that allows saving to and loading from the server.
- However, the sample world works based on the client, so it will not be the official method.
- So if you want to develop the sample world to the point of commercialization, the values must be managed by the server.

<br>

### Creating DataStorageLogic
- DataStorageLogic is a Logic created to save and load player information for the sample world.
- You can use this Logic to save or load a player's high score.

```lua
@Logic
script DataStorageLogic extends Logic

@Sync
property number serverBestWave = 0

property number clientBestWave = 0

property string storageKey = "BestWave"

@ExecSpace("ServerOnly")
method void SaveBestWave(string userId, number BestWave)
-- Updates the serverBestWave in the server with the BestWave value received from the Client.
self.serverBestWave = BestWave
-- Loads the data of the target user based on userId.
local userDataStorage = _DataStorageService:GetUserDataStorage(userId)
-- Saves the highest wave value.        
userDataStorage:SetAsync(self.storageKey, tostring(self.serverBestWave), function(errorCode, key)
	if errorCode == 0 then
		log(userId .. "'s highest Wave value saved! : " .. self.serverBestWave)
	else
		log("Save failed! Error Code: " .. errorCode)
	end
end)
end

@ExecSpace("ServerOnly")
method void LoadBestWave(string userId)
-- Loads the user's information based on userId.
local userDataStorage = _DataStorageService:GetUserDataStorage(userId)
-- Loads the information that has storageKey from the loaded information.
userDataStorage:GetAsync(self.storageKey, function(errorCode, key, value)
-- Updates the serverBestWave value to the received value if loading was successful.
if errorCode == 0 then
	self.serverBestWave = tonumber(value) or 0
	end
end)
end

@ExecSpace("ClientOnly")
method void OnSyncProperty(string name, any value)
-- Updates the clientBestWave value as well if the serverBestWave value was changed.
if name == "serverBestWave" then
	self.clientBestWave = value
end
end

@ExecSpace("Server")
method void RequestLoadBestWave(string userId)
self:LoadBestWave(userId)
end

@ExecSpace("Server")
method void RequestSaveBestWave(string userId, number CurrentBestWave)
self:SaveBestWave(userId, CurrentBestWave)
end

end
```

> This code is written based on PlainText.

- You can save various values if the storageKey values in the code are changed.
