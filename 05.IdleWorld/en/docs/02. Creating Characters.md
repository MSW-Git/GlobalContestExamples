## Creating Character Models

### What is a Model?

<p align="center">
<img src="../../_images/MSW-100_Idle_2_001.png" alt="MSW-100_Idle_2_001.png">
</p>

> Just like a shape cutter can create multiple copies of the same shape from a single mound of dough, the Model is a function meant to use entities of the same shape.

- The Model is a method to save the same form and function for future use in MapleStory Worlds.
- It's good to use if you anticipate the repetitive utilization of an entity, the hierarchical structure, Component used, value assigned to Property, or other such elements.
- For monsters that have the same appearance and actions, creating a Model for it and then copying said Model for use would be effective.

<br>

### Why should one use Models?
-Reusability
  - There will be no need to create, script, or otherwise set individual objects when you need to place multiples of the same monster, item, obstacle, etc. 
  - As long as there is one completed Model, you can use it by copying it an infinite number of times.
- All-at-once updates
  - When making balance adjustments or any design changes, you won't need to change each individual object placed on the map.
  - By simply editing the original Model, all of the changes are applied to all copies that exist within the Scene.
- Dynamic creation during the game
  - Objects that can't be placed in the scene as advance and must be created in real-time such as bullets, skill effects, summons, etc. can be instantly loaded whenever needed through code and managed.
- Safe and efficient team cooperation
  - When multiple developers are editing a single Scene at the same time, there is a high risk of the game being broken due to collisions.
  - Modularizing entities in units of Models allows for the manager, designer, and programmer to each work on the Model they are assigned to individually without the concern of triggering collisions.

## Composing Character DataSets

### The Goal of a DataSet
- The DataSet in MapleStory Worlds is a function that saves the game's fixed stats or information in the form of an excel spreadsheet or database. 
- Separating data and logic
    - By separating stats such as HP, attack power, etc. and not writing it into the script, the code can remain clean.
- The usefulness of maintenance and balance patches
    - You can change character stats by simply changing the value in the DataSet to immediately implement the changes without having to touch the code.
- Convenience of cooperation
    - Content and balance can be adjusted independently from each other by allowing the programmer to focus on logic development and the planner to focus on the DataSet.
- High extendibility
    - When adding a new character or monster, you can easily do so by adding a new row to the DataSet without having to change the logic.

## Implementing Character Logic

- Create a Logic that selects a random character and then returns the information of the selected character.

<p align="center">
<img src="../../_images/MSW-100_Idle_2_017.png" alt="MSW-100_Idle_2_017.png">
</p>

- Right-click `Workspace` and `MyDesk`.
- Click `Create Scripts` to open the menu.
- Create a Logic through `Create Logic`.
- The sample world declares the name of the created Logic as CharacterGachaLogic.
- The following is the CharacterGachaLogic code.

```lua
@Logic
script CharacterGachaLogic extends Logic

property table characterData = {}

property table gachaRateData = {}

property table skillData = {}

property CharacterSlotGroupComponent characterSlotGroupController = nil

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- Registers the character information DataSet.
self:InitCharacterData()
-- Registers the character draw information.
self:InitGachaRateData()
-- Attempts to reset the characterSlotGroupController, which is in charge of character creation and slot management.
self:InitCharacterSlotGroup()
end

@ExecSpace("ClientOnly")
method void InitCharacterData()
-- Determines whether the CharacterData DataSet is held.
if not isvalid(self.characterData) or not next(self.characterData) then
	-- If there is no registered characterData, searches for the Workspace's CharacterData DataSet using DataService.
	local getData = _DataService:GetTable("CharacterData")
	-- Confirms whether the CharacterData loaded normally.
	if not isvalid(getData) then
		log_error("CharacterData DataSet not found!")
		return
	end
	-- If the CharacterData DataSet is found normally, loads CharacterData's rowCount.
	local rowCount = getData:GetRowCount()
	-- Iterates the DataSet a number of times equal to rowCount to search for and register data.
	for i = 1, rowCount do
		local setData = CharacterData()
		setData.CharacterID = getData:GetCell(i, "CharacterID")
		setData.Grade = tonumber(getData:GetCell(i, "Grade"))
		setData.BasicAttackValue = tonumber(getData:GetCell(i, "BasicAttackValue"))
		setData.AttackAnimationID = tostring(getData:GetCell(i, "AttackAnimationID"))
		setData.BasicAttackEffectID = tostring(getData:GetCell(i, "BasicAttackEffectID"))
		setData.BasicAttackHitEffectID = tostring(getData:GetCell(i, "BasicAttackHitEffectID"))
		setData.AttackRange = tonumber(getData:GetCell(i, "AttackRange"))
		setData.SkillData = tostring(getData:GetCell(i, "SkillData"))
		setData.BasicAttackCoolTime = tonumber(getData:GetCell(i, "BasicAttackCoolTime"))
		setData.ModelID = tostring(getData:GetCell(i, "ModelID"))
		if not isvalid(self.characterData[setData.Grade]) or not next(self.characterData[setData.Grade])	then
			self.characterData[setData.Grade] = {}
		end
		table.insert(self.characterData[setData.Grade], setData)
	end
end
end

@ExecSpace("ClientOnly")
method void InitGachaRateData()
-- Tests whether gachaRateData is empty.
if not isvalid(self.gachaRateData) or not next(self.gachaRateData) then
	-- If gachaRateData is empty, GachaRateData is loaded for a reset.
	local getData = _DataService:GetTable("GachaRateData")
	-- If the getData value that was received is nil, an error log is displayed and code execution is halted.
	if not isvalid(getData) then
		log_error("GachaRateData not found!")
		return
	end
	-- If the DataSet is found normally, loads GachaRateData's rowCount.
	local GetRowCount = getData:GetRowCount()
	-- Searches for and registers Data equal to a number of the rowCount.
	for i = 1, GetRowCount do
		local rateData = GachaRateData()
		rateData.Grade = tonumber(getData:GetCell(i, "Grade"))
		rateData.RateValue = tonumber(getData:GetCell(i, "RateValue"))
		table.insert(self.gachaRateData, rateData)
	end
end
end

@ExecSpace("ClientOnly")
method void InitCharacterSlotGroup()
-- Determines whether the current map is InGame.
if _UserService.LocalPlayer.CurrentMapName == "InGame" then
	-- If the current map is InGame, searches for CharacterSlotPosGroup based on the path.
	local findEntity = _EntityService:GetEntityByPath("/maps/InGame/CharacterSlotPosGroup")
	if isvalid(findEntity) then
		-- If an entity is normally found, registers CharacterSlotGroupComponent.
		self.characterSlotGroupController = findEntity.CharacterSlotGroupComponent
	end
end
end

@ExecSpace("ClientOnly")
method number GetRandomGrade()
-- Loads the number of saved gradeCount.
local gradeCount = #self.gachaRateData
-- Loads the value that is the sum of all the gradeCount probabilities.
-- The GachaRateData must be comprised solely of integers.
local totalValue = 0
for i = 1, gradeCount do
	totalValue = totalValue + self.gachaRateData[i].RateValue
end

-- Loads a random value from 1 to totalValue.
local getRandomNumber = _UtilLogic:RandomIntegerRange(1, totalValue)
-- Subtracts values from gachaRateData one at a time.
for i = 1, gradeCount do
	getRandomNumber = getRandomNumber - self.gachaRateData[i].RateValue
	if getRandomNumber <= 0 then
		return self.gachaRateData[i].Grade
	end
end
-- If a value isn't returned normally, it returns the lowest grade with an error log.
log_error("Failed to obtain a normal random grade value!")
return 1
end

@ExecSpace("ClientOnly")
method CharacterData GetRandomCharacterData()
-- Returns a random character selected with GetRandomCharacterByGradeValue.
return self:GetRandomCharacterByGradeValue(self:GetRandomGrade())
end

@ExecSpace("ClientOnly")
method CharacterData GetRandomCharacterByGradeValue(number GradeValue)
-- Returns a random single character of the target grade based on the received GradeValue value.
local getRandomList = self.characterData[GradeValue]

local getRandomCharacter = _UtilLogic:RandomIntegerRange(1, #getRandomList)
return getRandomList[getRandomCharacter]
end

@ExecSpace("ClientOnly")
method void RequestSpawnCharacter()
-- Tests whether there is a sufficient number of summon tokens.
if _GameLogic.summonToken >= 1 then
	-- Tests whether there is a summonable slot.
	local getSlotNumber = self.characterSlotGroupController:ReturnEmptySlotNumber()
	-- Creates a character if a normal slot number was received.
	if getSlotNumber >= 1 then
		local getData = self:GetRandomCharacterData()
		self.characterSlotGroupController:SpawnCharacter(getSlotNumber, getData)
		-- Decreases the summon token value by 1 and requests a UI update.
		_GameLogic:UpdateSummonTokken(-1)
	else
		-- Outputs the toast message if there is no empty character slot.
		_UIToast:ShowMessage(_LocalizationService:GetText("UI_NeedSpace"))
		log("All character slots are full!")
	end
else
	-- Displays the toast message if there aren't enough summon tokens.
	_UIToast:ShowMessage(_LocalizationService:GetText("UI_NeedTokken"))
end

end

end
```

## Implementing a Component for Controlling Characters

- You need to compose a UnitController to load a character's actions and data and a DragComponent to implement a character's slot movement.
- The following is the full code for UnitController and DragComponent.

```lua
@Component
script UnitController extends Component

property Entity avatarBodyComponent = nil

property table enemyTable = {}

property number basicAtkDelta = 0

property CharacterData characterData = CharacterData()

property DragComponent dragComponent = nil

property Entity currentSlot = nil

property number skillDelta = 0

property SkillData characterSkillData = SkillData()

property TriggerComponent triggerComponent = nil

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- Searches for and registers the avatarBodyComponent required to play the avatar.
if self.avatarBodyComponent == nil then
	local findComponent = self.Entity.AvatarRendererComponent:GetBodyEntity()
	if isvalid(findComponent) then
		self.avatarBodyComponent = findComponent
	end
end
-- Searches for and registers dragComponent as a child entity.
if not isvalid(self.dragComponent) then
	local findComponent = self.Entity:GetChildByName("DragEntity", true)
	if isvalid(findComponent) then
		self.dragComponent = findComponent.DragComponent
	end
end
-- Executes the dragComponent reset and deactivation of entities.
self:InitDragComponentSprite()
self.Entity.Enable = false
-- If triggerComponent is empty, resets it.
if not isvalid(self.triggerComponent) then
	-- Searches for TriggerComponent from itself.
	local findComponent = self.Entity.TriggerComponent
	-- If TriggerComponent was found within itself, registers it to triggerComponent.
	if isvalid(findComponent) then
		self.triggerComponent = findComponent
	end
end
end

@ExecSpace("ClientOnly")
method void InitCharacterData(CharacterData Data, Entity SlotEntity)
-- Activates the character.
self.Entity.Enable = true
-- Receives and registers character information.
self.characterData = Data
-- Searches for and registers character skill information.
self.characterSkillData = _SkillDataLogic:GetSkillDataBySkillID(self.characterData.SkillData)
-- Registers the current slot to the received SlotEntity.
self.currentSlot = SlotEntity
-- Updates the attack area based on the received Data.
self.triggerComponent.CircleRadius = self.characterData.AttackRange
end

@ExecSpace("ClientOnly")
method void InitDragComponentSprite()
-- Resets values to make the DragEntity's avatar the same as the character avatar that's currently in use.
local currentSprite = self.Entity.CostumeManagerComponent
local dragComponent = self.Entity:GetChildByName("DragEntity").CostumeManagerComponent
dragComponent.CustomBodyEquip = currentSprite.CustomBodyEquip
dragComponent.CustomCapeEquip = currentSprite.CustomCapeEquip
dragComponent.CustomCapEquip = currentSprite.CustomCapEquip
dragComponent.CustomCoatEquip = currentSprite.CustomCoatEquip
dragComponent.CustomEarAccessoryEquip = currentSprite.CustomEarAccessoryEquip
dragComponent.CustomEarEquip = currentSprite.CustomEarEquip
dragComponent.CustomEyeAccessoryEquip = currentSprite.CustomEyeAccessoryEquip
dragComponent.CustomFaceAccessoryEquip = currentSprite.CustomFaceAccessoryEquip
dragComponent.CustomFaceEquip = currentSprite.CustomFaceEquip
dragComponent.CustomGloveEquip = currentSprite.CustomGloveEquip
dragComponent.CustomHairEquip = currentSprite.CustomHairEquip
dragComponent.CustomLongcoatEquip = currentSprite.CustomLongcoatEquip
dragComponent.CustomOneHandedWeaponEquip = currentSprite.CustomOneHandedWeaponEquip
dragComponent.CustomPantsEquip = currentSprite.CustomPantsEquip
dragComponent.CustomShoesEquip = currentSprite.CustomShoesEquip
dragComponent.CustomSubWeaponEquip = currentSprite.CustomSubWeaponEquip
dragComponent.CustomTwoHandedWeaponEquip = currentSprite.CustomTwoHandedWeaponEquip
end

@ExecSpace("ClientOnly")
method void ChangeSlot(Entity SlotEntity)
-- Changes the current slot to the received slot.
self.currentSlot = SlotEntity
-- Resets the current character's position to the received slot position.
self.Entity.TransformComponent.WorldPosition = SlotEntity.TransformComponent.WorldPosition
end

@ExecSpace("ClientOnly")
method void OnUpdate(number delta)
-- Delta time is always added without conditions.
self.skillDelta = self.skillDelta + delta
self.basicAtkDelta = self.basicAtkDelta + delta

-- Executes the skill attack after checking the skill attack cooldown if the conditions are met.
if self.skillDelta >= self.characterSkillData.SkillCoolTime then
	self:SkillAttack()
end

-- If the skill attack is successful and the cooldown has been reset to 0, the basic attack is skipped for this frame.
if self.skillDelta == 0 then
	return
end

-- Executes the basic attack after checking the basic attack cooldown if the conditions are met.
if self.basicAtkDelta >= self.characterData.BasicAttackCoolTime then
	self:BasicAttack()
end
end

@ExecSpace("ClientOnly")
method void BasicAttack()
-- Loads the character's StateComponent.
local bodySelector = self.Entity.StateComponent
-- Loads the character's current state name.
local currentState = bodySelector.CurrentStateName
-- Does not execute the basic attack if the current state isn't IDLE.
if currentState ~= "IDLE" then
	return
end
---@type Entity
local targetEntity = nil
-- Iterates the table in reverse and safely removes invalid entities.
for i = #self.enemyTable, 1, -1 do
	local enemy = self.enemyTable[i]
	-- Checks whether the entity still exists in the world.
	if isvalid(enemy) then
		-- Checks whether MonsterController exists in the entity and whether it's still alive.
		if enemy.MonsterController and enemy.MonsterController.isAlive then
			targetEntity = enemy
			break
		end
	else
		-- If the entity is already destroyed, it is removed from the table.
		table.remove(self.enemyTable, i)
	end
end
-- If the specified targetEntity is unusable, the attack isn't executed.
if not isvalid(targetEntity) then
	return
end
-- Sets the basicAtkDelta value as 0, assuming that the attack was executed.
self.basicAtkDelta = 0
-- Creates and delivers event to play the attack animation.
local event = ActionStateChangedEvent(self.characterData.AttackAnimationID, self.characterData.AttackAnimationID, 1, SpriteAnimClipPlayType.Onetime)
self.avatarBodyComponent:SendEvent(event)
-- Plays the character effect if there is one that needs to be displayed.
if not _UtilLogic:IsNilorEmptyString(self.characterData.BasicAttackEffectID) then
	_EffectService:PlayEffect(self.characterData.BasicAttackEffectID, self.Entity, self.Entity.TransformComponent.WorldPosition, 0, Vector3.one)	
end
-- Plays the effect that plays on the enemy if there is one that needs to be displayed.
if not _UtilLogic:IsNilorEmptyString(self.characterData.BasicAttackHitEffectID) then
	_EffectService:PlayEffect(self.characterData.BasicAttackHitEffectID, targetEntity, targetEntity.TransformComponent.WorldPosition, 0, Vector3.one)		
end
-- Requests the execution of GetDamage through the MonsterController of the enemy that became the target.
targetEntity.MonsterController:GetDamage(self.characterData.BasicAttackValue)
end

@ExecSpace("ClientOnly")
method void SkillAttack()
-- Searches for and registers bodySelector that is needed for playing the animation.
local bodySelector = self.Entity.StateComponent
-- Registers CurrentStateName to search for the current state.
local currentState = bodySelector.CurrentStateName
-- Halts code execution if the current state isn't IDLE.
if currentState ~= "IDLE" then
	return
end
---@type Entity
local targetEntity = nil
-- Iterates the table in reverse and safely removes invalid entities.
for i = #self.enemyTable, 1, -1 do
	local enemy = self.enemyTable[i]
	if isvalid(enemy) then
		if enemy.MonsterController and enemy.MonsterController.isAlive then
			targetEntity = enemy
			break
		end
	else
		table.remove(self.enemyTable, i)
	end
end
-- Halts code execution if targetEntity is nil.
if not isvalid(targetEntity) then
	return
end
-- Resets the skillDelta value to 0, assuming that the skill was successfully used.
self.skillDelta = 0
-- Plays attack animation.
```

```lua
@ExecSpace("ClientOnly")
method void AddHandler(integer touchId)
-- Halts code execution to prevent repeated processing if a Handler already exists.
if self.Handler ~= nil then
	return
end
    
-- If another character is being dragged, it's ignored to prevent multiple things being dragged.
if isvalid(self.characterSlotGroup) then
	if self.characterSlotGroup.isDragging == true then
	return
end
-- Locks the other slots, so they can't respond when a drag starts.
self.characterSlotGroup.isDragging = true
end

-- Deactivates DragEntity if it's currently hidden.
if self.Entity.Visible == false then
	self.Entity.Visible = true
end
table.insert(self.Index, touchId)

self.ReleaseHandler = _InputService:ConnectEvent(ScreenTouchReleaseEvent, self.OnRelease)
end

@ExecSpace("ClientOnly")
method void OnRelease(any event)
local TouchId = event.TouchId
-- Navigates all TouchId and removes them, since the drag is removed.    
for i = 1, #self.Index do
	if self.Index[i] == TouchId then
		table.remove(self.Index, i)
		if #self.Index <= 0 then
			-- Removes the added Hold and Release events.
			_InputService:DisconnectEvent(ScreenTouchHoldEvent, self.Handler)
			_InputService:DisconnectEvent(ScreenTouchReleaseEvent, self.ReleaseHandler)
			self.Handler = nil
			self.ReleaseHandler = nil
                
			-- Removes the lock, since the drag is over.
			if isvalid(self.characterSlotGroup) then
				self.characterSlotGroup.isDragging = false
			end
                
			-- Loads the dropped position.
			local dropPos = self.Entity.TransformComponent.WorldPosition
                
			-- Sets the current slot number as -1, which doesn't have a duplicate, to navigate to the target slot that is closest to the current position.
			local targetSlotNumber = -1
			-- The max radial distance to recognize a slot.
			local closestDist = 1.5 
            -- Checks if the characterSlotList for characterSlotGroup and characterSlotGroup are usable.
			if isvalid(self.characterSlotGroup) and self.characterSlotGroup.characterSlotList then
				-- Navigates characterSlotList while running for statements.
				for slotIndex = 1, #self.characterSlotGroup.characterSlotList do
					-- Loads the slotIndex's slotEntity.
					local slotEntity = self.characterSlotGroup.characterSlotList[slotIndex].Entity
					-- Loads the worldPosition of the slotEntity under slotPos.
					local slotPos = slotEntity.TransformComponent.WorldPosition
					-- Calculates the distance between itself, the dragEntity, and the slot.
					local dist = Vector2.Distance(dropPos:ToVector2(), slotPos:ToVector2())
					-- If the distance is shorter than the already set closetDist, it's determined to be within range.
						if dist < closestDist then
							-- Sets it to the distance of the Slot that meets the condition.
							closestDist = dist
							-- Registers a slotIndex that meets the conditions to targetSlotNumber.
                            targetSlotNumber = slotIndex
                        end
                    end
			end
                
			-- Loads the previous slot number.
			local beforeSlotNumber = self.parentEntity.UnitController.currentSlot.CharacterSlotComponent:GetSlotNumber()
            -- Executes the movement if the targetSlotNumber isn't -1 and if targetSlotNumber is different from beforeSlotNumber.
			if targetSlotNumber ~= -1 and targetSlotNumber ~= beforeSlotNumber then
				self.characterSlotGroup:SwitchSlotCharacter(targetSlotNumber, self.parentEntity, beforeSlotNumber)
			end
		end
	break 
	end
end
    
    -- Restores to the original position and executes the hide function after the movement processing is complete.
    self.Entity.TransformComponent.WorldPosition = self.parentEntity.TransformComponent.WorldPosition
    self.Entity.Visible = false
end
```
