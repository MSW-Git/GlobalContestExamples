<p align="center">

### Creating Entities

- There are largely 2 ways to create entities.
    - Normal Creation of Entities: You can create an entity as a child of the map that's currently being edited.
    - Creation as a Child Entity: You can place an entity as a child of the currently-selected entity. 
- Create empty entities as needed and then set the child entities as the children of empty entities to categorize them by property.
    - The sample world has set CharacterSlotPos as the child of an entity named CharacterSlotPosGroup.
    - Through this process, the CharacterSlotPosGroup entity can serve as a kind of wrapper for its CharacterSlotPos entities.

### Assigning Components to Slot Entities

- Components are elements created so that entities serve specific functions in MapleStory Worlds.
- An entity can output images, process data, and serve other functions using Components.

<p align="center">
<img src="../../_images/MSW-100_Idle_1_015.png" alt="MSW-100_Idle_1_015.png">
</p>

- Click on the entity to add a Component to from `Hierarchy`.
- Click `Add Component` on the very bottom of the `Property` window.

<p align="center">
<img src="../../_images/MSW-100_Idle_1_016.png" alt="MSW-100_Idle_1_016.png">
</p>

- You can add Components by searching for them by name.
- Or if new ones need to be made, you can create and add Components through `New Component`.
- The sample world created it as CharacterSlotComponent.
- Assign CharacterSlotGroupComponent to the CharacterSlotPosGroup meant to manage CharacterSlotPos.
- Below are CharacterSlotComponent and CharacterSlotPosGroup Components.

```lua
@Component
script CharacterSlotComponent extends Component

property Entity currentCharacterEntity = nil

property number slotNumber = 0

@ExecSpace("ClientOnly")
method boolean CheckCanSpawnCharacter()
-- If there is no character registered to a slot, returns the character spawn available state as true.
if not(self.currentCharacterEntity) then
	return true
else
-- Returns false if that's not the case.
	return false
end
end

@ExecSpace("ClientOnly")
method void InitCharacterEntity(Entity CharacterEntity)
-- Registers currentCharacterEntity as the received entity.
self.currentCharacterEntity = CharacterEntity
end

@ExecSpace("ClientOnly")
method void InitSlotNumber(number SlotNumber)
-- Registers an assigned number to itself when the game begins.
self.slotNumber = SlotNumber
end

@ExecSpace("ClientOnly")
method number GetSlotNumber()
-- Returns the SlotNumber that was assigned to itself.
return self.slotNumber
end

end
```

> This code is written based on Plain Text.

```lua
@Component
script CharacterSlotGroupComponent extends Component

property table characterSlotList = {}

property Entity characterGroup = nil

@Description("A lock variable to check if an entity is currently being dragged")
property boolean isDragging = false

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- Searches for the child slot List when the game starts.
self:InitCharacterSlotList()
-- Searches for characterGroup when the game starts.
self:InitCharacterGroup()
end

@ExecSpace("ClientOnly")
method void InitCharacterSlotList()
-- Attempts a reset if characterSlotList is empty.
if not isvalid(self.characterSlotList) or not next(self.characterSlotList) then
	-- Loads the children of the current entity.
	local childrenCount = self.Entity.Children.Count
	-- Repeats a number of times equal to childrenCount starting from 1.
	for i = 1, childrenCount do
		-- Sets the child entity's name format.
		local entityName = "CharacterSlotPos"..i
		-- Searches its own child entity by name.
		local getChildEntity = self.Entity:GetChildByName(entityName)
		-- Registers the value if it's found normally.
		if isvalid(getChildEntity) then
			self.characterSlotList[i] = getChildEntity.CharacterSlotComponent
			self.characterSlotList[i]:InitSlotNumber(i)
			end
	end
end
end

@ExecSpace("ClientOnly")
method void InitCharacterGroup()
-- Confirms whether characterGroup is empty.
if not isvalid(self.characterGroup) then
	-- Searches for and registers CharacterGroup if empty.
	local findEntity = self.Entity:GetChildByName("CharacterGroup")
	-- Registers CharacterGroup if the search was successful.
	self.characterGroup = findEntity
end
end

@ExecSpace("ClientOnly")
method number ReturnEmptySlotNumber()
-- Starts a navigation a number of times equal to characterSlotList.
for i = 1, #self.characterSlotList do
	-- Checks if the no. i slot is empty.
	if self.characterSlotList[i]:CheckCanSpawnCharacter() then
		-- If the no. i slot is empty, returns i.
		return i
	end
end
-- Returns 0 if there is no empty slot.
return 0
end

@ExecSpace("ClientOnly")
method void SpawnCharacter(number SlotNumber, CharacterData CharacterData)
-- Copies the Model based on the received Data.
local SpawnCharacter = _SpawnService:SpawnByModelId(CharacterData.ModelID, CharacterData.CharacterID, Vector3.zero, self.characterGroup)
-- Places the spawned character's position according to the received SlotNumber.
SpawnCharacter.TransformComponent.WorldPosition = self.characterSlotList[SlotNumber].Entity.TransformComponent.WorldPosition
-- Registers the character information to the spawned character and activates it.
SpawnCharacter.UnitController:InitCharacterData(CharacterData, self.characterSlotList[SlotNumber].Entity)
-- Registers the spawned character to the received SlotNumber.
self.characterSlotList[SlotNumber]:InitCharacterEntity(SpawnCharacter)
end

@ExecSpace("ClientOnly")
method void SwitchSlotCharacter(number TargetSlotNumber, Entity TargetEntity, number BeforeSlotNumber)
if not isvalid(self.characterSlotList[TargetSlotNumber].currentCharacterEntity) then
	-- If the slot is empty, starts the transfer, since the slot that's being moved into is empty.
	TargetEntity.UnitController:ChangeSlot(self.characterSlotList[TargetSlotNumber].Entity) 
	-- Registers the received entity to the slot that it's being moved to.
	self.characterSlotList[TargetSlotNumber]:InitCharacterEntity(TargetEntity)
	-- Converts the previous slot's state to nil.
	self.characterSlotList[BeforeSlotNumber]:InitCharacterEntity(nil)
else
	-- If another entity already exists in the slot, the previous entity that was inside the target slot is saved to the variable.
	local existingEntity = self.characterSlotList[TargetSlotNumber].currentCharacterEntity
        
	-- The existing entity is moved to an empty Before slot position.
	existingEntity.UnitController:ChangeSlot(self.characterSlotList[BeforeSlotNumber].Entity)
        
	-- Moves the dragged entity to the target slot's position.
	TargetEntity.UnitController:ChangeSlot(self.characterSlotList[TargetSlotNumber].Entity)
        
	-- Exchanges each slot's information with each other.
	self.characterSlotList[BeforeSlotNumber]:InitCharacterEntity(existingEntity)
	self.characterSlotList[TargetSlotNumber]:InitCharacterEntity(TargetEntity)
end
end

@ExecSpace("ClientOnly")
method void ClearCharacterList()
-- First, confirms whether characterGroup is valid.
if isvalid(self.characterGroup) then
	local children = self.characterGroup.Children
        
	-- Iterates child entities from the back (in reverse) and deletes them.
	for i = children.Count, 1, -1 do
		local childEntity = children[i]
		if isvalid(childEntity) then
			childEntity:Destroy()
		end
	end
end

-- Resets the entity reference data remaining in characterSlotList to nil.
for i = 1, #self.characterSlotList do
	local slot = self.characterSlotList[i]
	if isvalid(slot) then
		slot:InitCharacterEntity(nil)
	end
end
end

end
```

## Playing BGM

- Components can be assigned not only to entities, but to maps as well.
- Add a new Component through `Add Component` to a map that's being edited in `Hierarchy`.
- Name the Component BGMPlayer.
- Write the following code.

```lua
@Component
script BGMPlayer extends Component

property string bgmID = ""

@ExecSpace("ClientOnly")
method void OnBeginPlay()
self:PlayBGM()
end

@ExecSpace("ClientOnly")
method void PlayBGM()
-- Plays background music based on the registered bgmID.
_SoundService:PlayBGM(self.bgmID, 1.0)
end

end
```

> This code is written based on Plain Text.

## Minimum Implementation Standards

- Compose a Map where a game that functions in a single map can be played in.
- Compose slots where characters can be placed and a path for monsters to travel down.
- Implement the game so that the player outputs background music.

<br>

## Usage and Extension Direction

- Set a variable so that the background music can be controlled through settings.
- Implement a function so the background music changes based on map.
- Compose a position where the character will be and a path for monsters to travel in a format that differs from the sample world.
