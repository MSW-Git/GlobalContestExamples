### Creating a Timer

<p align="center">
<img src="../../_images/MSW-100_Idle_10_003.png" alt="MSW-100_Idle_10_003.png">
</p>

- The LeftTime entity inside **InGameUI** fulfills the role of outputting the remaining time for the sample world.
- The LeftTime entity outputs the background image for the timer that displays the time remaining.
- The TimerText, the child entity for LeftTime, displays the time left.
- Each entity has the following Components.
- **LeftTime**
    - `SpriteGUIRendererComponent`: The component needed for image output.
- **TimerText**
    - `TextGUIRendererComponent`: The Component needed to output the remaining time as text.

<br>

- Write a script to activate the timer to **InGameUIController**.
- The remaining time is being displayed through UpdateTimer in the sample world.
- The following is the UpdateTimer code.

```lua
@ExecSpace("ClientOnly")
method void UpdateTimer(number deltaTimer)
-- Updates the remaining time UI based on the received deltaTimer value.
if self.timerEntity.Enable == false then
	self.timerEntity.Enable = true
end

local timeString = string.format("%.2f", deltaTimer)

self.timerText.Text = "LeftTime\n"..timeString
end
```

> This code is written based on Plain Text.

<br>

- Display the remaining time in a format like 15.5 though string.format.
- If the remaining time is calculated from GameLogic, the UI is updated through that Method.

### Composing a Currency UI

<p align="center">
<img src="../../_images/MSW-100_Idle_10_004.png" alt="MSW-100_Idle_10_004.png">
</p>

- The SummonTokken from InGameUI is in charge of the UI that outputs the summon token count in the sample world.
- The following is the summoning token UI composition.
- **SummonTokken**
    - The entity needed to output the summoning token's frames.
    - Owns `SpriteGUIRendererComponent` and outputs frames.
- **IconImage**
    - The entity needed to output the summoning token icon.
    - The child entity of **SummonTokken**.
    - Has `SpriteGUIRendererComponent` in order to output the summoning token icon.
- **SummonTokkenText**
    - The entity needed to output the number of summoning tokens.
    - The child entity of **IconImage**.
    - Has `TextGUIRendererComponent` to output the number of summoning tokens.
- The number of remaining summoning tokens are output through UpdateSummonTokkenUI from `InGameUIController`.
- The following is the UpdateSummonTokkenUI code.

```lua
@ExecSpace("ClientOnly")
method void UpdateSummonTokkenUI(number TokkenValue)
-- Attempts a reset if summonTokkenText is nil.
if not isvalid(self.summonTokkenText) then
	self:InitSummonTokken()
end
-- Updates the remaining token count UI based on the received TokkenValue.
self.summonTokkenText.Text = tostring(math.floor(TokkenValue))
end
```

> This code is written based on Plain Text.

### Composing the Results UI

<p align="center">
<img src="../../_images/MSW-100_Idle_10_005.png" alt="MSW-100_Idle_10_005.png">
</p>

- The results UI is output through **ResultUI** in the sample world.
- **ResultUI** has the following composition.
- **NonClickBG**
    - The entity created to visually block the other UI.
    - Owns `SpriteGUIRendererComponent`.
- **ResultText**
    - The text entity needed to indicate that it is UI for results.
    - Has `TextGUIRendererComponent`.
- **GoalFrame**
    - The frame entity needed to output the results.
    - Has `SpriteGUIRendererComponent`.
- **GoalText**
    - The entity needed to output the result as text.
    - Has `TextGUIRendererComponent`.
- **RestartButton**
    The button entity that executes the restart function.
    - Has `SpriteRendererComponent` and `ButtonComponent`.
- **ButtonText**
    - The entity needed to output the name of the restart button.
    - Has `TextGUIRendererComponent`.

- **ResultUI** has **ResultUIController** to use the composition of the target UI.
- The following is the **ResultUIController** code.

```lua
@Component
script ResultUIController extends Component

property TextGUIRendererComponent goalText = nil

@ExecSpace("ClientOnly")
method void OnBeginPlay()
self:InitGoalText()
end

@ExecSpace("ClientOnly")
method void InitGoalText()
-- Tests whether goalText is nil.
if not isvalid(self.goalText) then
	-- Searches for and registers a GoalText entity.
	local findEntity = _EntityService:GetEntityByPath("/ui/ResultUI/GoalFrame/GoalText")
	-- Confirms whether findEntity has been registered normally.
	if isvalid(findEntity) then
		-- Registers findEntity's TextGUIRendererComponent.
		self.goalText = findEntity.TextGUIRendererComponent
	end
end
end

@ExecSpace("ClientOnly")
method void UpdateResultText(number AchieveGoalCount, number BestGoalCount)
-- Attempts to update the UI with the received value for the result text.
self.goalText.Text = _LocalizationService:GetTextFormat("UI_ResultWave", AchieveGoalCount, BestGoalCount)
end

@ExecSpace("ClientOnly")
method void Show()
self.Entity.Enable = true
end

@ExecSpace("ClientOnly")
method void Hide()
self.Entity.Enable = false
end

@EventSender("Entity", "336d7e78-d49b-4d6e-8f66-4cec32b01c85")
handler HandleButtonClickEvent(ButtonClickEvent event)
-- Requests GameLogic for a restart when the restart button is pressed.
self:Hide()
_GameLogic:RestartGame()
end

end
```

> This code is written based on Plain Text.

## Creating a Logic to Manage the UI
- It's too much hassle for a Component to search for a UI entity in order to access the UI.
- So the Components that manage the UI can be saved to a single Logic, so functions can be requested from that Logic or the UI can be turned on and off through the Logic.
- The sample world created **UIManageLogic** for this purpose.


<br>

## Minimum Implementation Standards
- The UI that shows the results of the game must be shown with the results themselves.
- The UI must be composed in a way that the player can see the number of summoning tokens.
- If the summoning of the wave's monsters is complete, there must be a function that shows the remaining time.
- The following is the UIManageLogic code.

```lua
@Logic
script UIManageLogic extends Logic

property InGameUIController ingameUIController = nil

property ResultUIController resultUIController = nil

@ExecSpace("ClientOnly")
method void OnBeginPlay()
self:InitIngameUIController()
self:InitResultUIController()
end

@ExecSpace("ClientOnly")
method void InitIngameUIController()
-- Searches for InGameUI from the UI group and registers Component.
if not isvalid(self.ingameUIController) then
	local findUI = _EntityService:GetEntityByPath("/ui/InGameUI")
	if isvalid(findUI) then
		self.ingameUIController = findUI.InGameUIController
	end
end
end

@ExecSpace("ClientOnly")
method void UpdateMonsterCount(number CurrentMonsterCount, number MaxMonsterCount)
-- Requests a reset if ingameUIController is nil.
if not isvalid(self.ingameUIController) then
	self:InitIngameUIController()
end
-- Updates the current monster status UI based on the received value.
self.ingameUIController:CountLeftMonster(CurrentMonsterCount, MaxMonsterCount)
end

@ExecSpace("ClientOnly")
method void UpdateWaveCount(number WaveCount)
-- Requests a reset if ingameUIController is nil.
if not isvalid(self.ingameUIController) then
	self:InitIngameUIController()
end
-- Requests an update for the current Wave.
self.ingameUIController:UpdateWaveCount(WaveCount)
end

@ExecSpace("ClientOnly")
method void DisableTimer()
-- Requests TimerUI to be hidden.
self.ingameUIController:DisableTimer()
end

@ExecSpace("ClientOnly")
method void InitResultUIController()
-- If resultUIController is nil, searches for ResultUI from ui and registers it.
if not isvalid(self.resultUIController) then
	local findEntity = _EntityService:GetEntityByPath("/ui/ResultUI")
	self.resultUIController = findEntity.ResultUIController
end
end

@ExecSpace("ClientOnly")
method void ShowResultUI(number CurrentWave, number BestWave)
-- The currently-delivered WaveCount and the highest Wave value that is synced with storage are handed over together.
self.resultUIController:UpdateResultText(CurrentWave, BestWave)
self.resultUIController:Show()
end

@ExecSpace("ClientOnly")
method void UpdateSummonTokken(number TokkenValue)
-- Updates the summon token UI.
self.ingameUIController:UpdateSummonTokkenUI(TokkenValue)
end

@ExecSpace("ClientOnly")
method void UpdateTimer(number TimerValue)
-- Requests for a Timer update.
self.ingameUIController:UpdateTimer(TimerValue)
end

end
```

> This code is written based on Plain Text.
