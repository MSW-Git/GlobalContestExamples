- 필요에 따라 직접 데미지 계산 공식을 수정하고, 결과값을 반환할 수 있는 Logic을 제작합니다.

## Logic 활용하기
<p align="center">
<img src="../../_images/MSW-100_Adventure_Extend_3_001.png" alt="MSW-100_Adventure_Extend_3_001.png">
</p>

- 메이플스토리 월드의 **Logic**은 엔티티가 존재하지 않아도 실행되는 Script입니다.
- 또한 **Map**이 변경되어도 실행할 수 있다는 장점이 있습니다.
- 샘플 월드에서는 이러한 특성을 활용하여 **데미지 계산**을 전담하는 Logic을 제작하여 사용하고 있습니다.
- 아래는 **DamageCalcLogic**의 코드 전문입니다.

```lua
@Logic
script DamageCalcLogic extends Logic

method integer CalculateNormalDamage(Entity attacker, Entity defender)
-- 기본 공격 데미지: 플레이어 공격력 - 몬스터 방어력
---@type PlayerStatComponent
local attackerStat = attacker:GetComponent("script.PlayerStatComponent")
---@type MonsterStatComponent
local defenderStat = defender:GetComponent("script.MonsterStatComponent")
if not isvalid(attackerStat) or not isvalid(defenderStat) then
	log_error("DamageCalcLogic: Stat Component를 찾을 수 없습니다.")
	return 0
end
local damage = attackerStat.playerStat.CharacterAtkValue - defenderStat.monsterStat.Def
if damage <= 0 then damage = 0 end
return damage
end

method integer CalculateSkillDamage(Entity attacker, Entity defender, number skillValue)
-- 스킬 데미지: SkillValue * 플레이어 공격력
---@type PlayerStatComponent
local attackerStat = attacker:GetComponent("script.PlayerStatComponent")
---@type MonsterStatComponent
local defenderStat = defender:GetComponent("script.MonsterStatComponent")
if not isvalid(attackerStat) then
	log_error("DamageCalcLogic: 공격자의 PlayerStatComponent를 찾을 수 없습니다.")
	return 0
end
local damage = skillValue * attackerStat.playerStat.CharacterAtkValue - defenderStat.monsterStat.Def
if damage <= 0 then damage = 0 end
return damage
end

method integer CalculateMonsterAttack(Entity attacker, Entity defender)
-- 기본 공격 데미지: 몬스터 공격력 - 플레이어 방어력
---@type MonsterStatComponent
local attackerStat = attacker:GetComponent("script.MonsterStatComponent")
---@type PlayerStatComponent
local defenderStat = defender:GetComponent("script.PlayerStatComponent")
if not isvalid(attackerStat) or not isvalid(defenderStat) then
	log_error("DamageCalcLogic: Stat Component를 찾을 수 없습니다.")
	return 0
end
local damage = attackerStat.monsterStat.CharacterAtkValue - defenderStat.playerStat.Def
if damage <= 0 then damage = 0 end
return damage
end

end
```

> 해당 코드는 Plain Text를 기준으로 작성된 코드입니다.

<br>

### DamageCalcLogic 살펴보기
- **DamageCalcLogic**은 총 3개의 역할을 수행합니다.
- **CalculateNormalDamage**
    - 플레이어가 기본 공격을 할 때, 데미지를 계산하는 Method입니다.
    - 플레이어의 스탯과 몬스터의 스탯을 기준으로 계산된 결과값을 반환합니다.
- **CalculateSkillDamage**
    - 플레이어가 스킬 공격을 할 때, 데미지를 계산하는 Method입니다.
    - 플레이어의 스탯과 스킬의 데미지 계수, 몬스터의 스탯을 기준으로 계산된 결과값을 반환합니다.
- **CalculateMonsterAttack**
    - 몬스터가 플레이어를 공격할 때 데미지를 계산하는 Method입니다.
    - 몬스터의 스탯과 플레이어의 스탯을 기준으로 계산된 결과값을 반환합니다.

<br>

### DamageCalcLogic의 목적
<p align="center">
<img src="../../_images/MSW-100_Adventure_Extend_3_002.png" alt="MSW-100_Adventure_Extend_3_002.png">
</p>

- 월드를 개발할 때 다양한 문제를 해결해야 합니다.
- 데미지 계산의 경우 영향을 받는 항목의 추가, 계산식의 변경 등 다양한 이유로 개발 단계에서 변경이 이뤄질 수 있습니다.
- 그러나 데미지 계산과 같은 항목을 공격 Script에 모두 입력 할 경우, 휴먼 에러로 인해 잘못된 공식이 들어가거나, 수정을 해야 할 때 누락이 발생할 수 있습니다.
- **DamageCalcLogic**과 같이 특정한 기능을 관리하는 Logic을 사용 할 경우, 하나의 Script만 수정해도 모든 Component가 영향을 받으므로 하나의 Component만 관리하면 됩니다.

<br>

## 최소 구현 기준
- Logic을 활용하여 데미지 계산을 담당하는 Logic을 구성합니다.
- 데미지를 계산하고, 이를 전달하는 Method에서 제작한 Logic을 활용하여 데미지 계산을 수행합니다.

<br>

## 응용 및 확장 방향
- 데미지 계산 외에 관리가 필요한 항목을 제작하고 관리합니다.
    - EX: 월드에서 사용하는 리소스를 관리하고, 이를 등록하는 Logic 구성하기.
    - EX: DataSet을 관리하는 Logic 구성하기.
- Logic 하나가 특정한 기능을 담당하고 관리할 수 있도록 구조를 설계합니다.
