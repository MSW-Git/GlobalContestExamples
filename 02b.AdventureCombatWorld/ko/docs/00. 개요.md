# 어드벤처 월드 전투 기능 학습 가이드 문서
<br>
<br>
<br>

## 학습 목표
- 메이플스토리 월드에서 제공하는 기능을 활용하여 전투 시스템을 구현할 수 있습니다.
- Extend를 활용하여 스크립트를 구성하는 방법에 대해 학습합니다.
- 아바타 애니메이션을 조합하여 자신만의 애니메이션을 제작할 수 있습니다.

<br>

## 학습 핵심 기능

- **Extend**: 제작된 Script를 활용하여 기능을 확장하고 싶을 때 사용할 수 있는 기능입니다.
- **AvatarAction Editor**: 메이플스토리 월드의 플레이어 캐릭터 애니메이션을 편집할 수 있는 기능입니다.

<br>

## 폴더 구성

<img src="../../_images/MSW-100_Adventure_0_001.png" alt="MSW-100_Adventure_0_001.png">
</p>

- DataTable: 어드벤처 월드에서 사용되는 데이터를 관리하기 위한 DataSet을 모아 둔 폴더입니다.
    - DataSet: 게임의 정보를 관리하는 DataSet을 담은 폴더입니다.
    - Localization: 번역과 관련된 테이블인 LocaleDataSet을 담은 폴더입니다.
- Event: 샘플 월드에서 직접 제작한 Event들을 담은 폴더입니다.
- Model: 샘플 월드에서 Model로 제작한 엔티티를 담은 폴더입니다.
- ScriptFolder: 월드에서 사용되는 모든 Script들을 담은 Folder입니다.
    - ComponentFolder: Component Script를 담은 폴더입니다. Player 폴더에는 State Component Script가 함께 있습니다.
    - LogicFolder: Logic Script를 담은 폴더입니다.
- TypeFolder: Type Script를 담은 폴더입니다.

<br>

## 구현 순서

- 💡 **기초 학습**: 메이플스토리 월드의 기초적인, 또는 해당 장르의 가장 기초적인 기능을 담은 학습 항목입니다.
- 📖 **심화 학습**: 샘플 월드에 구현된 기능을 학습하고 구현하는 항목입니다. 해당 과정의 학습을 통해 장르의 기능 확장과 학습 이해도를 넓힐 수 있습니다.

### [💡 기초 학습] 1. 기본 공격 구현하기
- Extend 기능을 활용하여 기본 공격 기능을 제작합니다.
- Extend의 특징과 사용 방법에 대해 학습합니다.

<br>

### [💡 기초 학습] 2. 적 구현하기
- Preset List의 몬스터를 활용하여 적을 구현하는 방법에 대해 학습합니다.
- 적이 공격을 받을 수 있도록 기능을 구성하는 방법에 대해 학습합니다.
- 몬스터 사망시 처리를 수행할 수 있도록 기능을 구성하는 방법에 대해 학습합니다.

<br>


### [💡 기초 학습] 3. 전투 보조 Logic 구현하기
- Logic을 활용하여 데미지 계산을 전담하는 Helper를 구현합니다.
- 유지, 보수적인 측면을 고려하여 설계할 수 있는 방법에 대해 학습합니다.

<br>

### [📖 심화 학습] 4. 스킬 구현하기
- AvatarActionEditor를 활용하여 캐릭터 애니메이션을 구성하는 방법에 대해 학습합니다.
- StateComponent를 활용하여 현재 상태에 따른 애니메이션 재생 방법에 대해 학습합니다.
- 실제 스킬이 적에게 판정을 일으킬 수 있도록 기능을 구현합니다.
