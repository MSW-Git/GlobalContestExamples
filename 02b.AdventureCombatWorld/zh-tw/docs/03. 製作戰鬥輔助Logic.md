## 運用Logic
<p align="center">
<img src="../../_images/MSW-100_Adventure_Extend_3_001.png" alt="MSW-100_Adventure_Extend_3_001.png">
</p>

- 楓之谷世界的**Logic**是不需要實體存在也會執行的Script。
- 另外，即使**Map**變更也能執行，是它的優點。
- 範例世界中運用這種特性，製作並使用了專門負責**傷害計算**的Logic。
- 以下是**DamageCalcLogic**的完整程式碼。

```lua
@Logic
script DamageCalcLogic extends Logic

method integer CalculateNormalDamage(Entity attacker, Entity defender)
-- 基本攻擊傷害：玩家攻擊力 - 怪物防禦力
---@type PlayerStatComponent
local attackerStat = attacker:GetComponent("script.PlayerStatComponent")
---@type MonsterStatComponent
local defenderStat = defender:GetComponent("script.MonsterStatComponent")
if not isvalid(attackerStat) or not isvalid(defenderStat) then
	log_error("DamageCalcLogic：找不到Stat Component。")
	return 0
end
local damage = attackerStat.playerStat.CharacterAtkValue - defenderStat.monsterStat.Def
if damage <= 0 then damage = 0 end
return damage
end

method integer CalculateSkillDamage(Entity attacker, Entity defender, number skillValue)
-- 技能傷害：SkillValue * 玩家攻擊力
---@type PlayerStatComponent
local attackerStat = attacker:GetComponent("script.PlayerStatComponent")
---@type MonsterStatComponent
local defenderStat = defender:GetComponent("script.MonsterStatComponent")
if not isvalid(attackerStat) then
	log_error("DamageCalcLogic：找不到攻擊者的PlayerStatComponent。")
	return 0
end
local damage = skillValue * attackerStat.playerStat.CharacterAtkValue - defenderStat.monsterStat.Def
if damage <= 0 then damage = 0 end
return damage
end

method integer CalculateMonsterAttack(Entity attacker, Entity defender)
-- 基本攻擊傷害：怪物攻擊力 - 玩家防禦力
---@type MonsterStatComponent
local attackerStat = attacker:GetComponent("script.MonsterStatComponent")
---@type PlayerStatComponent
local defenderStat = defender:GetComponent("script.PlayerStatComponent")
if not isvalid(attackerStat) or not isvalid(defenderStat) then
	log_error("DamageCalcLogic：找不到Stat Component。")
	return 0
end
local damage = attackerStat.monsterStat.CharacterAtkValue - defenderStat.playerStat.Def
if damage <= 0 then damage = 0 end
return damage
end

end
```

> 該程式碼是以Plain Text為基準編寫而成。

<br>

### 查看DamageCalcLogic
- **DamageCalcLogic**總共執行3個角色。
- **CalculateNormalDamage**
    - 玩家進行基本攻擊時，計算傷害的Method。
    - 以玩家屬性與怪物屬性為基準，回傳計算後的結果值。
- **CalculateSkillDamage**
    - 玩家進行技能攻擊時，計算傷害的Method。
    - 以玩家屬性、技能傷害係數、怪物屬性為基準，回傳計算後的結果值。
- **CalculateMonsterAttack**
    - 怪物攻擊玩家時計算傷害的Method。
    - 以怪物屬性與玩家屬性為基準，回傳計算後的結果值。

<br>

### DamageCalcLogic的目的
<p align="center">
<img src="../../_images/MSW-100_Adventure_Extend_3_002.png" alt="MSW-100_Adventure_Extend_3_002.png">
</p>

- 開發世界時，必須解決各種問題。
- 傷害計算的情況下，可能會因為新增受影響的項目、變更計算公式等各種理由，在開發階段發生變更。
- 但是如果把傷害計算這類項目全部輸入到攻擊Script中，可能會因為人為錯誤而放入錯誤公式，或是在需要修改時發生遺漏。
- 使用像**DamageCalcLogic**這樣管理特定功能的Logic時，只要修改一個Script，所有Component都會受到影響，因此只需要管理一個Component即可。

<br>

## 最低製作標準
- 運用Logic組成負責傷害計算的Logic。
- 在計算傷害並造成傷害的Method中，運用製作好的Logic執行傷害計算。

<br>

## 應用與進階應用
- 製作並管理傷害計算以外需要管理的項目。
    - EX：建立管理並登錄世界中使用資源的Logic。
    - EX：建立管理DataSet的Logic。
- 設計讓一個Logic負責並管理特定功能的結構。
