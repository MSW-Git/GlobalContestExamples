# Adventure World Combat Function Learning Guide Document
<br>
<br>
<br>

## Learning Goals
- You can implement a combat system using the functions provided by MapleStory Worlds.
- Let's learn how to implement scripts using Extend.
- You can create your own animation by combining avatar animations.

<br>

## Learning Core Functions

- **Extend**: A function used when you wish to extend a function using a created Script.
- **AvatarAction Editor**: A function that can edit a player character animation in MapleStory Worlds.

<br>

## Folder Composition

</p>

- DataTable: The folder that contains the DataSets that manage the data used in the adventure world.
    - DataSet: The folder containing DataSet, which controls the game's information.
    - Localization: The folder containing the LocaleDataSet, the table related to translation.
- Event: The folder that contains the Events created in the sample world.
- Model: The folder holding the entities created with Model in the sample world.
- ScriptFolder: The Folder containing all the Scripts used in the world.
    - ComponentFolder: A folder containing Component Script. The State Component Script is also in the Player folder.
    - LogicFolder: The folder containing Logic Script.
- TypeFolder The folder containing Type Script.

<br>

## Implementation Order

- 💡 **Basic Training**: These are the training materials for the most basic functions for MapleStory Worlds or for the relevant genre.
- 📖 **Advanced Training**: These are the training materials for learning and implementing functions visible in the sample world. Using these materials can expand the functions for the genre and understanding of the training materials.

### [💡 Basic Training] 1. Implementing Basic Attacks
- Create a basic attack function using the Extend function.
- Learn about Extend's characteristics and how to use it.

<br>

### [💡 Basic Training] 2. Implementing Enemies
- Learn how to implement enemies using the monsters in the Preset List.
- Learn how to implement a function that allows the character to be attacked by the enemy.
- Learn how to implement a function so that processing can be done when a monster dies.

<br>


### [💡 Basic Training] 3. Implementing Combat Support Logic
- Implement Helper that is in charge of calculating damage using Logic.
- Learn how to plan things with consideration for maintenance and repairs.

<br>

### [📖 Advanced Training] 4. Implementing Skills
- Learn how to implement character animations using AvatarActionEditor.
- Learn how to play animations based on the current status using StateComponent.
- Implement a function that can trigger a detection for skills when it lands on an enemy.
