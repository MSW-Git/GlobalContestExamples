- Create a Logic that manages the **MonsterData** DataSet to load monster information.
- The sample world uses a Logic named **MonsterDataLogic**.
- The following is the **MonsterDataLogic** code.
```lua
@Logic
script MonsterDataLogic extends Logic

property table monsterData = {}

@ExecSpace("ClientOnly")
method void OnBeginPlay()
self:InitMonsterData()
end

@ExecSpace("ClientOnly")
method void InitMonsterData()
-- Determines whether monsterData is in an empty state.
if not isvalid(self.monsterData) or not next(self.monsterData) then
	-- Loads DataSet if empty.
	local getData = _DataService:GetTable("MonsterData")
	-- Determines whether the DataSet exists normally.
	if not isvalid(getData) then
		-- Leaves an error log if it doesn't exist.
		log_error("MonsterData doesn't exist!")
		return
	end
	for i = 1, getData:GetRowCount() do
		local rowData = StatData()
		local monsterID = getData:GetCell(i, "MonsterID")
		rowData.MaxHP = tonumber(getData:GetCell(i, "MaxHP"))
		rowData.Def = tonumber(getData:GetCell(i, "Def"))
		rowData.CharacterAtkValue = tonumber(getData:GetCell(i, "CharacterAtkValue"))
		rowData.CriticalRate = tonumber(getData:GetCell(i, "CriticalRate"))
		rowData.CriticalRes = tonumber(getData:GetCell(i, "CriticalRes"))
		self.monsterData[monsterID] = rowData
	end
end
end

@ExecSpace("ClientOnly")
method StatData GetMonsterDataByMonsterID(string MonsterID)
if isvalid(self.monsterData[MonsterID]) then
	return self.monsterData[MonsterID]
else
	log_error("MonsterData doesn't have a "..MonsterID"!")
	return nil
end
end

end
```

> This code is written based on Plain Text.

- Lastly, a Component must be assigned to a monster entity so that a monster can register and use its own stats.
- The sample world created and uses **MonsterStatComponent** to fulfill this function.
- The following is the **MonsterStatComponent** code.

```lua
@Component
script MonsterStatComponent extends Component

property StatData monsterStat = StatData()

property integer currentHp = 100

property integer maxHp = 100

property any animEndHandler = nil

property boolean isDead = false

property string monsterID = ""

@ExecSpace("ClientOnly")
method void OnBeginPlay()
self:InitMonsterData()
end

method Entity GetSpriteEntity()
-- Returns the saved spriteEntity. Returns a root entity if there is none.
if self._T.spriteEntity ~= nil and isvalid(self._T.spriteEntity) then
	return self._T.spriteEntity
end
return self.Entity
end

method void InitMonsterData()
-- Determines whether monsterID is in a nil state.
if _UtilLogic:IsNilorEmptyString(self.monsterID) then
	log("monsterID is nil!")
	return
end
-- Loads information from MonsterDataLogic.
local getData = _MonsterDataLogic:GetMonsterDataByMonsterID(self.monsterID)
-- Updates the information if the value is loaded normally.
if isvalid(getData) then
	self.monsterStat = getData
	self.currentHp = self.monsterStat.MaxHP
end

self.Entity.StateComponent:ChangeState("IDLE")
end

@ExecSpace("ClientOnly")
@EventSender("Self")
handler HandleHitEvent(HitEvent event)
-- Processes damage taken.
local damage = event.TotalDamage
self.currentHp = self.currentHp - damage
log("MonsterStatComponent: [" .. self.Entity.Name .. "] Taken - Damage: " .. tostring(damage) .. " / Remaining HP: " .. tostring(self.currentHp))

local stateComp = self.Entity.StateComponent

-- Executes death processing when HP is 0 or below.
if self.currentHp <= 0 then
	self.currentHp = 0
	self.isDead = true
	log("MonsterStatComponent: [" .. self.Entity.Name .. "] Dead - Convert to DEAD State")
	if isvalid(stateComp) then
		stateComp:ChangeState("DEAD")
	end
	return
end

-- Converts to HIT state if surviving.
if isvalid(stateComp) then
	stateComp:ChangeState("HIT")
end
end

@EventSender("Self")
handler HandleSpriteAnimPlayerEndFrameEvent(SpriteAnimPlayerEndFrameEvent event)
-- Halts code execution if there is no active entity.
if not isvalid(self.Entity) then return end
-- Loads StateComponent to load the current state.
local stateComponent = self.Entity.StateComponent
-- If the State is DEAD, deactivates the entity, since the death animation was played last.
if stateComponent.CurrentStateName == "DEAD" then
	self.Entity:SetEnable(false)
end
end

end
```

> This code is written based on Plain Text.

- The function must be composed so that the monster attacks the player last.
- Next, extend **AttackComponent** to create a **MonsterAttackComponent**.
- The following is the **MonsterAttackComponent* code.

```lua
@Component
script MonsterAttackComponent extends AttackComponent

method boolean CalcCritical(Entity attacker, Entity defender, string attackInfo)
-- Returns whether a hit is a critical hit by calculating the critical hit chance.
---@type MonsterStatComponent
local attackerStat = attacker:GetComponent("script.MonsterStatComponent")
---@type PlayerStatComponent
local defenderStat = defender:GetComponent("script.PlayerStatComponent")
if not isvalid(attackerStat) or not isvalid(defenderStat) then return false end
local criRate = _UtilLogic:RandomIntegerRange(1, 100)
local calcValue = attackerStat.monsterStat.CriticalRate - defenderStat.playerStat.CriticalRes
if calcValue <= 0 then
	return false
elseif calcValue >= criRate then
	return true
else
	return false
end
end

method integer CalcDamage(Entity attacker, Entity defender, string attackInfo)
return _DamageCalcLogic:CalculateMonsterAttack(self.Entity, defender)
end

@ExecSpace("ClientOnly")
@EventSender("Self")
handler HandleTriggerEnterEvent(TriggerEnterEvent event)
-- Halts execution if the monster is in a dead state.
if self.Entity.MonsterStatComponent.isDead then
	return
end
-- Places the collided entity (target) with the variable.
local targetEntity = event.TriggerBodyEntity
-- First checks whether the target entity is valid (if it wasn't destroyed). (Most important)
if isvalid(targetEntity) and targetEntity == _UserService.LocalPlayer then
	-- If a Component normally exists, prepares for damage delivery.
	local isCritical = self:CalcCritical(self.Entity, targetEntity, "")
	local getDamage = self:CalcDamage(self.Entity, targetEntity,"")
	-- If all necessary elements are contained in HitEvent, delivers the event to PlayerEntity.
	_UserService.LocalPlayer.HitComponent:OnHit(self.Entity, getDamage, isCritical, "", 1)
end
end

end
```
> This code is written based on Plain Text.

## Learning Monster Attack Methods
- Checks the **moment** when a collision between monsters and the player happens.
- Since it is a one-off instance of damage, it's not a continuous attack.
- However, damage calculation happens each time the player makes an attack.
- As such, the damage calculation method shouldn't simply rely on the **TriggerEnterEvent** for **TriggerComponent** and look for other methods.
    - Example: Performing an attack at regular intervals when the player enters the attack range.
    - Example 2: Performing an attack using Attack if the player enters the attack range.
    - Change the attack target to nil so that attacks aren't repeatedly made in empty space when the player leaves the attack range.

<br>

## Minimum Implementation Standards
- The monster must have their own unique stats, and they must be usable.
- The player and monster must attack each other, and damage calculation must happen accordingly.

<br>

## Usage and Extension Direction
- Change the function so that monsters can make continuous attacks.
