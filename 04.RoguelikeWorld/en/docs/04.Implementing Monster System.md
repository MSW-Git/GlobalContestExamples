> The presence of monsters is a means of providing stress to the player, but also a sense of accomplishment when overcome.

- If there's no threat in the game, players will get bored.
- Monsters are obstacles that prevent players from surviving.
- However, when monsters are killed, the player gains EXP, which increases the player's level.
- Also, if the player gets stronger as they level up, the player is rewarded with a sense of accomplishment and a feeling of being stronger.

#### Creating a Monster's Controller

```lua
@Component
script MonsterController extends Component

property boolean isAlive = true

property MonsterDataType monsterData = MonsterDataType()

property number currentHP = 0

property MovementComponent movementComponent = nil

property number timerID = 0

@ExecSpace("ClientOnly")
method void OnBeginPlay()
self:InitDefault()
end

@ExecSpace("ClientOnly")
method void InitDefault()
-- Determines whether the Monster's MovementComponent is nil.
if not isvalid(self.movementComponent) then
	-- Searches for and registers its own MovementComponent if nil.
	self.movementComponent = self.Entity.MovementComponent
end
-- Sets currentHP to 0.
self.currentHP = 0
-- Converts isAlive state to false.
self.isAlive = false
-- Resets monsterData.
self.monsterData = MonsterDataType()
-- Deactivates its own entity state.
self.Entity.Enable = false
end

@ExecSpace("ClientOnly")
method void SpawnMonster(MonsterDataType MonsterData, Vector3 WorldSpawnPos)
-- Registers monster information.
self.monsterData = MonsterData
-- Sets the current HP to max HP.
self.currentHP = self.monsterData.StartHP
-- Registers the monster's speed to movementComponent.
self.movementComponent.InputSpeed = self.monsterData.MoveSpeed
-- Converts isAlive state to True.
self.isAlive = true
-- Converts the monster's entity state to use.
self.Entity.Enable = true
end

@ExecSpace("ClientOnly")
method void GetDamage(number DamageValue)
-- Decreases currentHP by the amount of damage taken.
self.currentHP = self.currentHP - DamageValue
-- Processes as dead and deactivates if currentHP is 0 or lower.
if self.currentHP <= 0 then
	-- Executes an entity return request to ObjectPool.
	local objectPool = _EntityService:GetEntityByPath("/maps/InGame/ObjectPool")
	-- Calls an EXP item entity from objectPool.
	local expItem = objectPool.ObjectPoolComponent:ReturnEXPObject()
	-- Changes EXP item to user's position.
	expItem.TransformComponent.WorldPosition = self.Entity.TransformComponent.WorldPosition
	-- Activates expItem.
	expItem.Enable = true
	-- Removes all registered TimerService.
	_TimerService:ClearTimer(self.timerID)
	-- Directs GameLogic to count the number of defeated monsters.
	_GameLogic:CountKillScore()
	-- Resets an entity's state.
	self:InitDefault()
end
end

@ExecSpace("ClientOnly")
method void OnEndPlay()
-- Removes all preregistered TimerService when the game closes.
_TimerService:ClearTimer(self.timerID)
end

@ExecSpace("ClientOnly")
method void OnUpdate(number delta)
--Halts movement if GameLogic's isPlayingGame is false.
if not _GameLogic.isPlayingGame then
	self.movementComponent.Enable = false
else
	-- Activates movementComponent while the game is running.
	if self.movementComponent.Enable == false then
		self.movementComponent.Enable = true
	end
end
end

@EventSender("Self")
handler HandleTriggerEnterEvent(TriggerEnterEvent event)
-- Tests whether the collided entity is a player.
if event.TriggerBodyEntity.PlayerStatController then
	-- Loads PlayerStatController if the collided entity is a player.
	local playerStat = event.TriggerBodyEntity.PlayerStatController
	-- Checks whether the player is alive.
	if playerStat.isAlive then
		-- Calculates the damage that will be delivered to the player.
		local getDamage = _DamageCalcHelper:CalcDamageByMonsterAttack(self.monsterData.AtkValue)
		-- Executes an attack if the player is alive.
		self.timerID = _TimerService:SetTimerRepeat(function() playerStat:GetDamage(getDamage) end, self.monsterData.AttackCoolTime)
	end
end
end

@EventSender("Self")
handler HandleTriggerLeaveEvent(TriggerLeaveEvent event)
-- Tests whether the escaped entity is a player.
if event.TriggerBodyEntity.PlayerStatController then
	-- Removes the preregistered TimerService if the player exits.
	_TimerService:ClearTimer(self.timerID)
end
end

end
```

> This code is created based on Plain Text.

- Once this part is complete, create monster entities in Hierarchy as Models and delete the monsters in the Hierarchy.

## Creating Logic to Manage Monster Data


```lua
@Logic
script MonsterDataLogic extends Logic

property table monsterData = {}

@ExecSpace("ClientOnly")
method void OnBeginPlay()
self:InitMonsterData()
end

@ExecSpace("ClientOnly")
method void InitMonsterData()
-- Checks whether monsterData is nil.
if not isvalid(self.monsterData) or not next(self.monsterData) then
	-- Loads MonsterData if nil.
	local getData = _DataService:GetTable("MonsterData")
	-- Checks whether getData has occurred normally.
	if isvalid(getData) then
		-- Loads getData's rowCount.
		local rowCount = getData:GetRowCount()
		-- Loads data by iterating DataSet a number of times equal to rowCount.
		for i = 1, rowCount do
			-- Checks whether MonsterID value is still normal.
			local monsterID = tostring(getData:GetCell(i, "MonsterID"))
			if not _UtilLogic:IsNilorEmptyString(monsterID) then
				-- Registers data if there is a normal ID value.
				local data = MonsterDataType()
				data.MonsterID = monsterID
				data.ModelID = tostring(getData:GetCell(i, "ModelID"))
				data.StartHP = tonumber(getData:GetCell(i, "StartHP"))
				data.AtkValue = tonumber(getData:GetCell(i, "AtkValue"))
				data.AttackCoolTime = tonumber(getData:GetCell(i, "AttackCoolTime"))
				data.MoveSpeed = tonumber(getData:GetCell(i, "MoveSpeed"))
				-- Enters completed data to monsterData.
				self.monsterData[monsterID] = data
			end
		end
	end
end
end

@ExecSpace("ClientOnly")
method MonsterDataType GetMonsterDataByMonsterID(string MonsterID)
-- Checks whether there is a monsterData value that has MonsterID as a Key.
if isvalid(self.monsterData[MonsterID]) then
	-- Returns a value that has MonsterID as a Key.
	return self.monsterData[MonsterID]
end
end

end
```

## Spawning Monsters

<p align="center">
<img src="../../_images/MSW-100_Survivorslike_4_010.png" alt="MSW-100_Survivorslike_4_010.png">
</p>

- Create a **MonsterSpawnPool** that is responsible for spawning monsters and a **MonsterSpawnPos** to specify where the monsters spawn.
- The **MonsterSpawnPool** is placed in the center of the map where the game takes place.
- Place **MonsterSpawnPos** where you want the monster to spawn.
- Once the placement of the **MonsterSpawnPos** is finalized, register it with the **MonsterSpawnPos**. 
- Add a **MonsterSpawnPool** Component to the **MonsterSpawnPool** entity.

```lua
@Component
script MonsterSpawnPool extends Component

property table monsterSpawnPos = {}

property Entity monsterSpawnPosGroup = "b9c76cf1-8e3f-4db4-a133-5786869c73aa"

property string spawnMonsterID = "Monster_Snail"

property MonsterDataType spawnMonsterData = MonsterDataType()

property table monsterEntityTable = {}

property number createMonsterCount = 10

property number timerID = 0

property table spawnMonsterList = {"Monster_Snail", "Monster_Slime"}

property number spawnMonsterListCount = 0

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- Loads the monster's spawn position.
self:InitSpawnPosition()
-- Loads the monster's information.
self:InitMonsterData()
end

@ExecSpace("ClientOnly")
method void InitSpawnPosition()
-- Checks whether monsterSpawnPos is nil.
if not isvalid(self.monsterSpawnPos) or not next(self.monsterSpawnPos) then
	-- Attempts a reset after determining that a reset is needed if nil.
	local PosCount = self.monsterSpawnPosGroup.Children.Count
	-- Executes a repeat a number of times equal to PosCount.
	for i = 1, PosCount do
		-- Searches for a named entity a number of times equal to PosCount from MonsterSpawnPos1.
		local findPosEntity = self.monsterSpawnPosGroup:GetChildByName("MonsterSpawnPos"..i)
		-- Registers a normally-loaded value to monsterSpawnPos.
		if isvalid(findPosEntity) then
			self.monsterSpawnPos[i] = findPosEntity
		end
	end
end
end

@ExecSpace("ClientOnly")
method void InitMonsterData()
-- Loads monster information based on spawnMonsterID value.
self.spawnMonsterData = _MonsterDataLogic:GetMonsterDataByMonsterID(self.spawnMonsterID)
self.spawnMonsterListCount = 1
end

@ExecSpace("ClientOnly")
method void SpawnMonster()
-- Loads a value with spawnMonsterID as a Key from monsterEntityTable.
local monsterList = self.monsterEntityTable[self.spawnMonsterID]
-- Executes ExpandMonsterPool if the monsterList is unusable.
if not monsterList then 
	self:ExpandMonsterPool()
	-- Re-registers based on the monsterList that was additionally created.
	monsterList = self.monsterEntityTable[self.spawnMonsterID]
end
-- Collects usable (Enable = false) monsters from the current pool.
local availableMonsters = {}
for _, entity in ipairs(monsterList) do
	-- Loads an entity if it is a usable entity.
	if isvalid(entity) and entity.Enable == false then
		-- Adds an entity found in availableMonster.
		table.insert(availableMonsters, entity)
	end
end

-- Creates additional usable monsters if there aren't enough.
if #availableMonsters < #self.monsterSpawnPos then
	self:ExpandMonsterPool()
	-- Reattempts collection after creating additional monsters.
	availableMonsters = {}
	-- Resets monsterList based on the newly-generated value.
	monsterList = self.monsterEntityTable[self.spawnMonsterID]
	-- Searches for usable entities by starting another iteration.
	for _, entity in ipairs(monsterList) do
		if isvalid(entity) and entity.Enable == false then
			table.insert(availableMonsters, entity)
		end
	end
end
-- Activates a number equal to the monsterSpawnPos count and the amount of monsters that will spawn (9).
local posCount = #self.monsterSpawnPos
-- Calculates the number of monsters that will spawn.
local spawnCount = math.min(#self.monsterSpawnPos, posCount, #availableMonsters)
-- Activates an amount of monsters equal to spawnCount.
for i = 1, spawnCount do
	local monster = availableMonsters[i]
	local spawnPos = self.monsterSpawnPos[i].TransformComponent.WorldPosition
	monster.TransformComponent.WorldPosition = spawnPos
	monster.Enable = true
	monster.MonsterController:SpawnMonster(self.spawnMonsterData, self.monsterSpawnPos[i])
end
-- Changes the information of the monster that will be summoned next to the next monster.
self:UpdateNextMonster()
end

@ExecSpace("ClientOnly")
method void ResetSpawnPool()
-- Checks whether the entity exists in monsterEntityTable.
if not isvalid(self.monsterEntityTable) or not next(self.monsterEntityTable) then
	self:ExpandMonsterPool()
end
end

@ExecSpace("ClientOnly")
method void ClearSpawnPool()
-- Checks whether self.monsterEntityTable[self.spawnMonsterID] is a valid table and not nil.
if isvalid(self.monsterEntityTable[self.spawnMonsterID]) then
    local getList = self.monsterEntityTable[self.spawnMonsterID]
    
    -- The table's index starts from 1. It's safe to begin the iteration from the back, including #getList.
    for i = #getList, 1, -1 do
        local entity = getList[i]
        
        -- Checks whether entity is valid again and destroys it.
        if isvalid(entity) then
            _EntityService:Destroy(entity)
        end
    end
end
-- Removes the pre-registered Timer.
_TimerService:ClearTimer(self.timerID)
end

@ExecSpace("ClientOnly")
method void ExpandMonsterPool()
-- Resets if spawnMonsterID from monsterEntityTable isn't used as a Key.
if not self.monsterEntityTable[self.spawnMonsterID] then
	self.monsterEntityTable[self.spawnMonsterID] = {}
end
-- Creates Model equal to the number of monsters.
for i = 1, self.createMonsterCount do
	local createModel = _SpawnService:SpawnByModelId(
	self.spawnMonsterData.ModelID, 
	self.spawnMonsterID, 
	self.Entity.TransformComponent.WorldPosition, 
	self.Entity)
	if isvalid(createModel) then
		createModel.Enable = false -- Registers to the pool in a deactivated state upon creation.
		table.insert(self.monsterEntityTable[self.spawnMonsterID], createModel)
	end
end
end

@ExecSpace("ClientOnly")
method void OnEndPlay()
-- Removes all pre-registered Timers when the game ends.
_TimerService:ClearTimer(self.timerID)
end

@ExecSpace("ClientOnly")
method void UpdateNextMonster()
-- Increases spawnMonsterListCount by 1.
self.spawnMonsterListCount = self.spawnMonsterListCount + 1
-- If spawnMonsterListCount is currently larger than spawnMonsterList, reverts to 1.
if self.spawnMonsterListCount > #self.spawnMonsterList then
	self.spawnMonsterListCount = 1
end
-- Resets information with updated spawnMonsterList.
self.spawnMonsterID = self.spawnMonsterList[self.spawnMonsterListCount]
self.spawnMonsterData = _MonsterDataLogic:GetMonsterDataByMonsterID(self.spawnMonsterList[self.spawnMonsterListCount])
end

@EventSender("LocalPlayer")
handler HandleEntityMapChangedEvent(EntityMapChangedEvent event)
if event.NewMap.Name == "InGame" then
	-- Loads the monster's spawn position.
	self:InitSpawnPosition()
	-- Loads the monster's information.
	self:InitMonsterData()
	-- Attempts a reset after determining that the player entered the map.
	self:ResetSpawnPool()
	-- Creates monsters and sets a timer, so the game can start.
	self.timerID = _TimerService:SetTimerRepeat(self.SpawnMonster, 5.0)
else
	self:ClearSpawnPool()
end

end

end
```

> This code is written based on Plain Text.

- The values in **spawnMonsterList** are added based on the MonsterID values registered in MonsterData.
- The **createMonsterCount** is a value that asks how many entities should be created at a time when entities need to be created.
- Currently, it is entered as 10, which means that 10 monster entities are created at a time, and from there, returns an available entity for use.
- If the value of **createMonsterCount** is increased to 20, it will create 20 monsters at a time.

## Existence of DamageCalcHelper
- When players and monsters deliver damage, it's important that the opponent knows all the information they need to calculate the damage.
- However, if every object knows the player, and the player knows all the monsters, then there is a strong dependency problem.
- To solve this problem, use **DamageCalcHelper**, which provides calculated results by delivering only the necessary information.
- To create the **DamageCalcHelper**, use **Logic**.

```lua
@Logic
script DamageCalcHelper extends Logic

property PlayerStatController playerStat = nil

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- Loads the player's PlayerStatController Component if playerStat is nil.
if not isvalid(self.playerStat) then
	self.playerStat = _UserService.LocalPlayer.PlayerStatController
end
end

@ExecSpace("ClientOnly")
method number CalcDamageByPlayerAttack(number WeaponDamage)
-- Calculates the player's attack and weapon's attack.
local resultDamage = self.playerStat.playerAtk + WeaponDamage
-- Returns the calculated result value.
return resultDamage
end

@ExecSpace("ClientOnly")
method number CalcDamageByMonsterAttack(number MonsterDamage)
-- Decreases the monster's attack by the player's defense.
local calcDamage = MonsterDamage - self.playerStat.def
-- Converts calcDamage to 0 if the result value is lower than 0.
if calcDamage < 0 then
	calcDamage = 0
end
-- Returns the calculated result value.
return calcDamage
end

end
```

- Passing attack power through the **DamageCalcHelper** will return results based on the specified formula.
- Should the need arise in the future for various calculation formulas depending on enhancement elements or weapon options, or if the damage calculation formula itself requires change, the issue can be resolved simply by modifying **DamageCalcHelper**.
