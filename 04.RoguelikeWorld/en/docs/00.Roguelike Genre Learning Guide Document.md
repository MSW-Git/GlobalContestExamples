## Learning Goals

- Learn how to implement core adventure game functions using the guide document and the sample world.
- Learn how to utilize TriggerComponent and CollisionService to detect collisions in MapleStory Worlds.
- Learn how to utilize object pooling techniques to manage large numbers of entities.
- Modify and create a world in the form of your choosing.

<br>

## Learning Core Functions

- **Understanding TriggerComponent**: Learn about TriggerComponent, a way to check for entity collisions in MapleStory Worlds.
- **Understanding the Collisionservice**: Learn how to use the CollisionService to find specific elements at specific locations within specific ranges.

## Implementation Order

- 💡 **Basic Training**: These are the training materials for the most basic functions for MapleStory Worlds or for the relevant genre.
- 📖 **Advanced Training**: This category of training is for learning and implementing functions visible in the sample world. Using these materials can expand the functions for the genre and understanding of the training materials.

<br>

### [💡 Basic Training] Implementing a World Environment

- Learn about the traits of the RectTileMap in MapleStory Worlds.
- Learn how to place Tiles in a RectTileMap.
- Learn about the KinematicbodyComponent's Property composition and learn what role it serves.

<br>

### [💡 Basic Training] Implementing the Play Character Selection Screen

- Learn how to set up a UI that allows players to select a character.
- Learn how to configure features to automatically update the UI as data is added.
- Learn how to configure the features to ensure data can be properly registered with the selected character.

<br>

### [💡 Basic Training] Implementing a Player's Attack

- Learn how to set up a Component that can manage the player's weapons.
- Learn how to utilize the TriggerComponent and CollisionService for each weapon.
- Understand the difference between TriggerComponent and CollisionService and learn how to use them.

<br>

### [💡 Basic Training] Implementing the Monster System
- Learn how to configure monsters.
- Learn how to spawn monsters.
- Learn about object pools, an optimization technique that reuses large amounts of monsters.

<br>

### [📖 Advanced Training] Implementing Level System
- Learn how to implement a level system, a means for players to become stronger.
- Learn how to adjust and manage the amount of EXP required for each level.
- Implement EXP gain as a means of leveling up players.
<br>

### [📖 Advanced Training] Implementing an Enhance System
- Learn how to implement a feature that enhances players as they level up.
- Learn how to organize and use data to manage the enhance system.

<br>

### [📖Advanced Training] Learning DataStorage
- Learn how to save a player's high score when they achieve it.
- Learn how to retrieve stored information.
