## 等級系統
- 這是玩家直觀感受到自己正在變強的指標。
- 這是玩家擊敗敵人後獲得經驗值，且經驗值達到一定數值時等級提升的系統。
- 依照等級提升提供強化玩家的事件，製作讓玩家能夠變強的功能。

<br>

### 製作DataSet

<p align="center">
<img src="../../_images/MSW-100_Survivorslike_5_001.png" alt="MSW-100_Survivorslike_5_001.png">
</p>

- 範例世界中與等級相關的DataSet有**LevelUpData**。
- **LevelUpData**由下列組成。
    - Level：用來提供各等級資訊的值。
        - EX：若玩家等級為1，則使用NeedEXP值30。
    - NeedEXP：用來指定玩家提升至下一等級所需經驗值量的值。
- DataSet製作完成後，製作**StructType**，也就是**LevelUpDataType**。

<br>

### 製作經驗值道具
- 玩家擊敗敵人後，必須建立用來獲得經驗值的經驗值道具。
    - 💬 若打算製作成敵人死亡時直接提供經驗值的方式，則不需要製作經驗值道具，只要呼叫**PlayerStatController**Component的**AddEXPValue**Method即可。
- 經驗值道具由下列組成。

<p align="center">
<img src="../../_images/MSW-100_Survivorslike_5_002.png" alt="MSW-100_Survivorslike_5_002.png">
</p>

- **SpriteRendererComponent**：用來輸出經驗值道具圖片的Component。
    - 將玩家可辨識的圖片資源登錄至**SpriteRUID**後使用。
- **TriggerComponent**：用來設定經驗值道具碰撞範圍的Component。 
    - 依照**SpriteRendererComponent**的大小設定**BoxSize**與**ColliderOffset**。 
    - 將**CollisionGroup**設定為EXP。
- **EXPItemController**：用來持有經驗值道具所給予經驗值量的Component。
    - 如下方撰寫**EXPItemController**。
```lua
@Component
script EXPItemController extends Component

property number addExpValue = 10

@ExecSpace("ClientOnly")
method void OnBeginPlay()
self:SetDefault()
end

@ExecSpace("ClientOnly")
method void SetDefault()
self.Entity.Enable = false
end

end
```

> 該程式碼是以Plain Text為基準編寫而成。

- EXPItemController只需要持有給予的經驗值量，因此如上撰寫。
- 若製作到這裡，便將經驗值道具製作成Model。

<br>

### 製作PlayerEXPCollider實體
- 現在該製作玩家實體的子實體，用來偵測並獲得經驗值道具。
- 僅偵測**CollisionGroup**為EXP的實體，若成功偵測，便建構功能讓其獲得。
- PlayerEXPCollider實體具有下列結構。
    - **TriggerComponent**：持有用來指定碰撞範圍的**TriggerComponent**。
        - 將**CollisionGroup**變更為**PlayerEXPRange**。
    - **PlayerEXPColliderController**：當與經驗值道具碰撞時，執行處理用Method，並依照經驗值道具獲得範圍強化，執行更新碰撞範圍的功能。
- 如下製作**PlayerEXPColliderController**Component。

```lua
@Component
script PlayerEXPCollideController extends Component

property PlayerStatController playerStateController = nil

@ExecSpace("ClientOnly")
method void SetPlayerStatController(PlayerStatController PlayerStat)
-- 登錄傳入的PlayerStatController。
self.playerStateController = PlayerStat
end

@ExecSpace("ClientOnly")
method void UpdateMagnetRange()
-- 將自身TriggerComponent的BoxSize變更為PlayerStat的值。
self.Entity.TriggerComponent.BoxSize = Vector2(self.playerStateController.magnetRange, self.playerStateController.magnetRange)
end

@EventSender("Self")
handler HandleTriggerEnterEvent(TriggerEnterEvent event)
-- 檢查碰撞的實體是否為經驗值道具。
if event.TriggerBodyEntity.EXPItemController then
	-- 若為經驗值道具，則依照經驗值道具的值增加經驗值。
	self.playerStateController:AddEXPValue(event.TriggerBodyEntity.EXPItemController.addExpValue)
	-- 既然已獲得道具，便停用已獲得的經驗值道具。
	event.TriggerBodyEntity.EXPItemController:SetDefault()
end
end

end
```

> 該程式碼是以Plain Text為基準編寫而成。

- 現在**PlayerEXPCollider**與**EXPItem**實體碰撞時，會呼叫**PlayerStatController**的**AddEXPValue**Method來提升經驗值。

## 最低製作標準
- 提供提升玩家經驗值的手段，並透過獲得該手段增加經驗值。
- 當經驗值達到一定數值時，玩家等級會提升。


<br>

## 應用與進階應用
- 將玩家所需經驗值組成為以固定數值提升，避免依賴DataSet。
- 若維持DataSet形式，則思考難度曲線要如何設定並套用。
