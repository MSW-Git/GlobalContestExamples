## Registering DataSet to DataTableLogic

- Write the following code to DataTableLogic.
- The example has the code written based on PlainText.

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Shooting/MSW-100_Shooting_3_004.png" alt="MSW-100_Shooting_3_004.png">
</p>

- The PlainText can be changed through the UI button on the bottom right of the code editor window.


```lua
property table characterDefaultData = {} -- Property for managing the CharacterDefaultData dataset.

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- Resets the CharacterDefaultData dataset.
self:InitCharacterDefaultData()
end

method void InitCharacterDefaultData()
-- Item that determines whether player character parsing is complete.
if isvalid(self.characterDefaultData) == false or next(self.characterDefaultData) == nil then
	local getTableData = _DataService:GetTable("CharacterDefaultData")
	-- Displays warning text if it failed to load the data table.
	if getTableData == nil then
		log("Failed to fetch the CharacterDefaultData data table!")
		return
	end
	--Start Parsing
	local rowCount = getTableData:GetRowCount() -- Calculates the total number of Rows.
    
    for i = 1, rowCount do
        -- Plugs in a single CharacterID that will be the Key, starting at the data table Row.
        local characterID = tostring(getTableData:GetCell(i, "CharacterID"))
        
        -- Determines whether the ID is valid.
        if characterID ~= nil and characterID ~= "" then
            
            -- Bundles all of the information from a single row into a table.
            local rowData = 
			{
                CharacterID = characterID,
                StartHP = tonumber(getTableData:GetCell(i, "StartHP")),
				StartSkillCount = tonumber(getTableData:GetCell(i, "StartSkillCount")),
                StartMoveSpeed = tonumber(getTableData:GetCell(i, "StartMoveSpeed")),
                DefaultMissile = tostring(getTableData:GetCell(i, "DefaultMissile")),
				DefaultSkill = tostring(getTableData:GetCell(i, "DefaultSkill")),
				AttackInterval = tonumber(getTableData:GetCell(i, "AttackInterval"))
            }
            
            -- Save to Cache Table (Key: MissileID, Value: Data)
            self.characterDefaultData[characterID] = rowData
        end
    end
	-- Generates the Log that indicates that the data table caching is complete.
	log("CharacterDefaultData data table caching complete!")
	return
end
-- Generates the Log that indicates that the data table caching was not completed.
log("Either the CharacterDefaultData data table has already been cached or the CharacterDefaultData data table couldn't be found.")
end

method table GetCharacterDefaultDataByCharacterID(string CharacterID)
-- Attempts caching if the characterDefaultData hasn't been cached normally.
if self.characterDefaultData == nil then
	self:InitCharacterDefaultData()
end
-- Determines whether CharacterDefaultData is currently registered as intended.
if isvalid(self.characterDefaultData) and next(self.characterDefaultData) ~= nil then
	-- Returns any data that has the CharacterID value.
	if self.characterDefaultData[CharacterID] then
		return self.characterDefaultData[CharacterID]
	end
-- Generates an error log if the relevant Key's data is missing.
else
	log("Either the "..CharacterID.." value doesn't have PlayerDefaultData data or it doesn't exist!")
	return nil
end
end
```

## Resetting Values to PlayerState

- Write the following code to PlayerState.
- This code is written based on Plain Text.

```lua
@Component
script PlayerState extends Component

property number currentHP = 0 -- Property that manages the player's current HP.

property string currentMissile = "" -- Property that saves the player's current projectile's ID.

property string characterID = "" -- Property that saves the ID of the character that is currently being played.

property number attackInterval = 0.5 -- Property that manages the player's attack delay.

property number attackTimer = 0 -- Property that calculates the player's attack availability.

property any projectilePoolManager = nil

property Vector3 firePos = Vector3(0.25,0.25,0) -- Property that adjusts the player's attack launch position.

property boolean isInvincibility = false -- Property that determines whether the player is invincible.

property number invincibilityDelta = 0 -- Property that calculates invincibility duration.

property number invincibilityTime = 1.0 -- Base Property for invincibility duration. The duration can be changed by changing this value.

property boolean isAlive = false -- Property that determines the player's survival.

property string skillID = "" -- Property that saves the player's used skill ID.

property number canUseSkillCount = 0 -- Property that manages the usable skill count of the current player.

property number moveSpeed = 0 -- Property that registers the player's speed.

@ExecSpace("ClientOnly")
method void InitPlayerData(table PlayerDefaultData)
-- Generates an error log and halts the code if the received PlayerData is abnormal data.
if PlayerDefaultData == nil or next(PlayerDefaultData) == nil then
	log("PlayerDefaultData is not normal!")
    return
end
-- Resets the player's current HP.
self.currentHP = PlayerDefaultData.StartHP
-- Resets the player's usable skill ID.
self.canUseSkillCount = PlayerDefaultData.StartSkillCount
-- Resets the player's speed.
self.moveSpeed = PlayerDefaultData.StartMoveSpeed
-- Delivers to MovementComponent so that the reset player speed can be implemented as intended.
self.Entity.MovementComponent.InputSpeed = self.moveSpeed
-- Resets the player's default projectile ID.
self.currentMissile = PlayerDefaultData.DefaultMissile
-- Resets the player's character ID value.
self.characterID = PlayerDefaultData.CharacterID
-- Resets the player's attack delay.
self.attackInterval = PlayerDefaultData.AttackInterval
-- Resets the player's skill ID.
self.skillID = PlayerDefaultData.DefaultSkill
-- Resets the player's starting position.
self.Entity.TransformComponent.Position = Vector3.zero
-- Changes the player Entity's usage to true.
self.Entity.Enable = true
-- Changes the player character's Visible state to true.
self.Entity.Visible = true
end

@ExecSpace("ClientOnly")
method void OnBeginPlay()
    local getData = _DataTableLogic:GetCharacterDefaultDataByCharacterID("Pirate")
    self:InitPlayerData(getData)
    self.isAlive = true
end
```

### What is a TriggerComponent?
- A TriggerComponent is a component used to detect collisions between entities.
- The green area is the collision trigger area.
- When the areas overlap, a collision is triggered.
- So, when there is a detection that is larger or smaller than the image resource, the player may think that the collision is unfair.
- However, depending on the game, the detection area can be intentionally increased to create generous detection.
- Depending on the type of game you're making, you will need to plan whether the collision will be precise or have some room.

## Minimum Implementation Standards
- You can create a DataSet.
- You can load the desired value from the DataSet through the created DataTableLogic.
- You can deliver the loaded DataSet value to the Component and plug it in.
- You can set the collision area by editing the TriggerComponent.
<br>

## Usage and Extension Direction
- You can divide the player relation functions that will be created into units of Components.
	- Example: For attacks, you can create a PlayerAttackComponent and implement the attack-related function to the target Component.
- Add needed values for game creation to the DataSet and edit the DataTableLogic, so the added values can be loaded.
	- By learning how to do this and based on need, you will be able to expand or add a DataSet.
