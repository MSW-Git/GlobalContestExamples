<br>

## Manager Concepts

- Logic can be created as a manager that executes specific functions or roles.
- The manager of a single function or role is called a Manager.
- When there are issues with a specific function, it can be fixed quickly and conveniently by only changing the content of the Manager.
    - Case 1: When a character completes damage calculation and delivers it to a monster.
        - Each time the damage formula changes or each time a new element is added to damage calculation, the formula needs to be changed.
        - You will need to find all characters to edit and change the code entered.
    - Case 2: When making a request for damage calculation from a Logic-created Manager.
        - Change the damage formula inside the Logic.
        - The Logic handles the damage calculation of all characters and monsters, so there are no more elements that require editing.
        - Even if there are issues with the damage formula in future, editing the Manager can solve them.

## Writing GameLogic Code
```lua
@Logic
script GameLogic extends Logic

property Entity localPlayer = nil

property number killScore = 0 -- Property that manages the current number of defeated monsters from InGame.

property number clearKillCount = 9999 -- Property that manages the number of monsters that need to be defeated to clear the stage from InGame.

property boolean IsStillPlay = false -- Property that checks the current play state.

property string currentMap = "" -- Property that saves the current map's name.

property boolean needAutoFire = false -- Property that saves if it is currently in auto-fire mode from InGame.

property string currentStageName = "" -- Registers the name of the current stage.

@ExecSpace("Client")
method void RequestTeleportPlayer(string TeleportMapName)
log("GameManager RequestTeleportPlayer Start")
    
-- Searches for LocalPlayer if there is no Player currently.
if not isvalid(self.localPlayer) then
    self:InitLocalPlayer()
	-- Halts code execution if there is no LocalPlayer.
	if not isvalid(self.localPlayer) then return end
end

    -- Makes it so the UI can change based on the current map.
if TeleportMapName == "Title" then
	_UIManageLogic:ShowTitle()
elseif TeleportMapName == "InGame" then
    _UIManageLogic:ShowInGame()
end

self.currentMap = TeleportMapName
-- The Name of the player entity in MapleStory Worlds is the same as the UserId.
self:TeleportPlayer(self.localPlayer.Name, TeleportMapName)
end

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- Searches for and registers local players when the game begins.
self:InitLocalPlayer()
end

@ExecSpace("Server")
method void TeleportPlayer(string UserId, string MapName)
-- 1. Runs another search for an entity in the server via UserId.
log("TeleportPlayerEntry Success")
    local playerEntity = _UserService:GetUserEntityByUserId(UserId)
    -- Generates an error log if no playerEntity can be found.
    if not isvalid(playerEntity) then
        log("Teleport Failed: User not found.")
        return
    end

 	-- Sets the movement path.   
    local targetPath = ""
    if MapName == "Title" then
        targetPath = "/maps/Title"
    elseif MapName == "InGame" then
        targetPath = "/maps/InGame"
    end
    -- Teleports the player character through the path below if the movement path is registered correctly.
    if targetPath ~= "" then
        _TeleportService:TeleportToEntityPath(playerEntity, targetPath)
        log("Teleport Execution Complete: " .. targetPath)
    end
end

@ExecSpace("ClientOnly")
method void InitLocalPlayer()
-- Searches for and registers local players.
if not isvalid(self.localPlayer) then
	self.localPlayer = _UserService.LocalPlayer
end
end

@ExecSpace("ClientOnly")
method void RequestCharacterDataInit(string ClassName)
-- Resets PlayerState based on the ID value from the received CharacterDefaultData.
if ClassName ~= "" and ClassName ~= nil then
	-- Searches for the data table that corresponds to ClassName from DataTableManager.
	local findPlayerData = _DataTableLogic:GetCharacterDefaultDataByCharacterID(ClassName)	
	-- Resets PlayerState with any data that is found.
	if isvalid(findPlayerData) and next(findPlayerData) ~= nil then
		log("CharacterDefaultData Init request complete.")
		self.localPlayer.PlayerState:InitPlayerData(findPlayerData)
	-- If none is found, it leaves a log.
	else
		log("Abnormal CharacterDefaultData Init failed!")
	end
end
end

@ExecSpace("ClientOnly")
method void CountKillScore()
-- Increases killScore by 1 when a monster dies.
self.killScore = self.killScore + 1
-- Processes as a stage clear if the killScore is higher than clearKillCount.
if self.killScore >= self.clearKillCount then
	self.IsStillPlay = false
	self:NeedGameResult(true)
	log("Game Clear")
end
end

@ExecSpace("ClientOnly")
method void InitClearKillCount(number ClearKillCount)
-- Resets the stage clear condition to the calculated number of monsters.
self.clearKillCount = ClearKillCount
end

@ExecSpace("ClientOnly")
method void InitStage(string StageName)
-- Sets the path of the MonsterSpawnManager for the current map based on the StageName value.
local spawnManagerPath = "/maps/"..StageName.."/MonsterSpawnManager"
-- Searches for the MonsterSpawnManager entity via the pre-set path.
local stageSpawnManager = _EntityService:GetEntityByPath(spawnManagerPath)
-- Leaves a log and returns if it fails to find a MonsterSpawnManager.
if not isvalid(stageSpawnManager) then
	log("Failed to find a MonsterSpawnManager object in "StageName.."!")
	return
end
-- Calls a method so ItemHelper can register the ItemSpawnManager of the current map.
_ItemHelper:InitData()
-- Launches the game and changes the IsStillPlay value to true if the game isn't currently running.
if not self.IsStillPlay then
	stageSpawnManager.MonsterSpawnManager:StartGame()
	self.IsStillPlay = true
end
-- Resets the current monster kill count to 0.
self.killScore = 0
-- All processes are complete, so the received stage name is registered.
self.currentStageName = StageName
-- Temporarily halts all BGM.
_SoundService:StopBGM(true)
-- Generates the BGM that needs to be played in InGame.
_SoundService:PlayBGM("d155c5573a3f46a7b2ffe38629441132", 1.0)
end

@ExecSpace("ClientOnly")
method void NeedGameResult(boolean IsClear)
-- Plays the UI effect based on the delivered game clear result.
self.IsStillPlay = false
_UIManageLogic:ShowResultUI(IsClear)
end

@ExecSpace("ClientOnly")
method void ClearObjectPool()
-- Ignores the code below if the target method is called in another map other than InGame.
if not self.currentMap == "InGame" then
	return
end
-- Sets the path for Managers that manage each ObjectPool in the InGame map.
local missilePoolPath = "/maps/"..self.currentMap.."/ProjectileManager"
local monsterPoolPath = "/maps/"..self.currentMap.."/MonsterSpawnManager"

-- Searches for the Managers based on the path set above.
local missilePoolEntity = _EntityService:GetEntityByPath(missilePoolPath)
local monsterPoolEntity = _EntityService:GetEntityByPath(monsterPoolPath)
-- Deactivates entities in each object pool if the search is successful.
if isvalid(missilePoolEntity) then
	missilePoolEntity.ProjectileManager:ResetPool()
end
if isvalid(monsterPoolEntity) then
	monsterPoolEntity.MonsterSpawnManager:ClearAllChild()
end

-- Prevents errors from being triggered when the helper class is called from a place other than the InGame map.
_ItemHelper:ReleaseData()
end

@ExecSpace("ClientOnly")
method void RestartGame()
-- Searches for local players.
local findLocalPlayer = _UserService.LocalPlayer
-- Leaves a log and returns if no local players can be found.
if not isvalid(findLocalPlayer) then
	log("Couldn't find a LocalPlayer!")
	return
end
-- Generates a log and returns if there is no PlayerState component in the local player entity.
if not isvalid(findLocalPlayer.PlayerState) then
	log("Couldn't find a PlayerState component from LocalPlayer!")
	return
end

-- Searches for the current character's ID value after receiving the PlayerState.
local currentPlayerCharacter = findLocalPlayer.PlayerState.characterID
-- Resets the ObjectPool for restarts.
self:ClearObjectPool()
-- Resets the data for the stage that will be restarted.
self:InitStage(self.currentStageName)
-- Resets the data again to return the character information to its original state.
self:RequestCharacterDataInit(currentPlayerCharacter)
-- Converts the UI state to the in-game start state.
_UIManageLogic:ShowInGame()
-- Converts the IsStillPlay state to true, since the game has restarted.
self.IsStillPlay = true
end

@ExecSpace("ClientOnly")
method void ChangeNeedAutoFire()
-- Changes the needAutoFire value to the opposite value if the target function is called.
self.needAutoFire = not self.needAutoFire
end

end
```

## Writing DataTableLogic Code

```lua
@Logic
script DataTableLogic extends Logic

property table missileData = {} -- Property for managing the MissileData dataset.

property table characterDefaultData = {} -- Property for managing the CharacterDefaultData dataset.

property table characterSelectUIData = {} -- Property for managing the CharacterSelectUIData dataset.

property table monsterDefaultData = {} -- Property for managing the MonsterDefaultData dataset.

property table monsterSpawnData = {} -- Property for managing the MonsterSpawnData dataset.

property table skillData = {} -- Property for managing the SkillData dataset.

property table itemData = {} -- Property for managing the ItemData dataset.

property table itemDropData = {} -- Property for managing the ItemDropData dataset.

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- Resets the MissileData dataset.
self:InitMissileData()
-- Resets the CharacterSelectUIData dataset.
self:InitCharacterSelectUIData()
-- Resets the MonsterSpawnData dataset.
self:InitMonsterSpawnData()
-- Resets the MonsterDefaultData dataset.
self:InitMonsterDefaultData()
-- Resets the CharacterDefaultData dataset.
self:InitCharacterDefaultData()
-- Resets the SkillData dataset.
self:InitSkillData()
-- Resets the ItemData dataset.
self:InitItemData()
-- Resets the ItemDropData dataset.
self:InitItemDropData()
end

@ExecSpace("ClientOnly")
method void InitMissileData()
-- Determines whether the missile data table is parsed.
if isvalid(self.missileData) == false or next(self.missileData) == nil then
	-- Searches the MissileData data table when missile data parsing is required.
	local missileDefaultData = _DataService:GetTable("MissileData")
	if isvalid(missileDefaultData) == nil then
		-- Generates and Returns the log, since the MetaData table couldn't be found.
		log("The MissileData data table couldn't be found!")
		return
	end
	-- Calculates the total number of Rows.
	local rowCount = missileDefaultData:GetRowCount() 
	
    -- Plugs in the MissileID that will be the Key, starting at Row 1 in the data table.
    for i = 1, rowCount do
        local missileID = missileDefaultData:GetCell(i, "MissileID")
        
        -- Determines whether the ID is valid.
        if missileID ~= nil and missileID ~= "" then
            
            -- Bundles all of the information from the target row into a single table.
            local rowData = 
			{
                MissileID = missileID,
                AtkValue = tonumber(missileDefaultData:GetCell(i, "AtkValue")),
                MoveSpeed = tonumber(missileDefaultData:GetCell(i, "MoveSpeed")),
                LifeTime = tonumber(missileDefaultData:GetCell(i, "LifeTime")),
				HitEffectRUID = tostring(missileDefaultData:GetCell(i, "HitEffectRUID")),
				ModelRUID = tostring(missileDefaultData:GetCell(i, "ModelRUID"))
            }
            
            -- Registers to missileData Property. (Key: MissileID, Value: Data)
            self.missileData[missileID] = rowData
        end
    end
	-- Generates the Log that indicates that the data table caching is complete.
	log("MissileData data table caching complete!")
	return
end
-- Generates the Log that indicates that the data table caching was not completed.
log("Either the MissileData data table has already been cached or the MissileData data table couldn't be found.")
end

@ExecSpace("ClientOnly")
method void InitCharacterDefaultData()
-- Item that determines whether player character parsing is complete.
if isvalid(self.characterDefaultData) == false or next(self.characterDefaultData) == nil then
	local getTableData = _DataService:GetTable("CharacterDefaultData")
	-- Displays warning text if it failed to load the data table.
	if getTableData == nil then
		log("Failed to fetch the CharacterDefaultData data table!")
		return
	end
	--Start Parsing
	local rowCount = getTableData:GetRowCount() -- Calculates the total number of Rows.
    
    for i = 1, rowCount do
        -- Plugs in a single CharacterID that will be the Key, starting at the data table Row.
        local characterID = tostring(getTableData:GetCell(i, "CharacterID"))
        
        -- Determines whether the ID is valid.
        if characterID ~= nil and characterID ~= "" then
            
            -- Bundles all of the information from a single row into a table.
            local rowData = 
			{
                CharacterID = characterID,
                StartHP = tonumber(getTableData:GetCell(i, "StartHP")),
				StartSkillCount = tonumber(getTableData:GetCell(i, "StartSkillCount")),
                StartMoveSpeed = tonumber(getTableData:GetCell(i, "StartMoveSpeed")),
                DefaultMissile = tostring(getTableData:GetCell(i, "DefaultMissile")),
				DefaultSkill = tostring(getTableData:GetCell(i, "DefaultSkill")),
				AttackInterval = tonumber(getTableData:GetCell(i, "AttackInterval"))
            }
            
            -- Save to Cache Table (Key: MissileID, Value: Data)
            self.characterDefaultData[characterID] = rowData
        end
    end
	-- Generates the Log that indicates that the data table caching is complete.
	log("CharacterDefaultData data table caching complete!")
	return
end
-- Generates the Log that indicates that the data table caching was not completed.
log("Either the CharacterDefaultData data table has already been cached or the CharacterDefaultData data table couldn't be found.")
end

@ExecSpace("ClientOnly")

-- Checks whether the character selection window information table is cached.

        local characterID = characterSelectData:GetCell(i, "CharacterID")
        
        -- Determines whether the ID is valid.
        if characterID ~= nil and characterID ~= "" then
            
            -- Bundles all of the information from the target row into a single table.
            local rowData = 
			{
                CharacterID = characterID,
                LocalizeNameID = tostring(characterSelectData:GetCell(i, "LocalizeNameID")),
                SpriteRUID = tostring(characterSelectData:GetCell(i, "SpriteRUID"))
            }
            
            -- Save to Cache Table (Key: MissileID, Value: Data)
            self.characterSelectUIData[characterID] = rowData
        end
    end
	-- Generates the Log that indicates that the data table caching is complete.
	log("CharacterSelectUIData data table caching complete!")
	return
end
-- Generates the Log that indicates that the data table caching was not completed.
log("Either the CharacterSelectUIData data table has already been cached or the MissileData data table couldn't be found.")
end

@ExecSpace("ClientOnly")

	-- Generates a log and a code if no SkillData is found.
	if not isvalid(findData) then
		log("Failed to load SkillData!")

	local rowCount = findData:GetRowCount()
    
    for i = 1, rowCount do

        local skillID = findData:GetCell(i, "SkillID")
        
        -- Determines whether the ID is valid.
        if skillID ~= nil and skillID ~= "" then
            
            -- Bundles all of the information from a single row into a table.
            local rowData = 
			{
                SkillID = findData:GetCell(i, "SkillID"),
                SkillType = findData:GetCell(i, "SkillType"),
                IsPierce = findData:GetCell(i, "IsPierce"),
                AtkValue = tonumber(findData:GetCell(i, "AtkValue")),
				MoveSpeed = tonumber(findData:GetCell(i, "MoveSpeed")),
```

## Pros of Logic

- It can be accessed conveniently from anywhere.
- There is no need to look for specific entities like components or to check if the found entity has a component.
- Making Logic will make that Logic reliable.
- Since Logic manages functions, when issues of responsibility arise, you can solve the issue by only fixing the Logic that is responsible.

## Notes on Logic Usage
- There is a risk of a single super Logic that controls all functions.
    - Example: A Logic in charge of damage calculation also managing damage value processing, sound output, hit effect output, and more.
- In the case of a super logic, the Logic will require more information that it necessarily needs.
- This goes outside of the theory of object-oriented design, which becomes the cause of the great increase to lines of code.
- The increased lines of code reduce readability, which then makes finding the issue quickly very difficult during debugging.

<br>

## Minimum Implementation Standards
- Create a Logic that will manage and make use of future DataSets.
    - Create a sample world-based DataTableLogic to manage DataSets.
- Create a Logic that can handle processing based on game progression.
    - Create a sample world-based GameLogic to implement processing based on game state.
- Create a Logic that can manage all UIs.
    - Create a sample world-based UIManageLogic to implement a function that can manage multiple UIs.

<br>

## Usage and Extension Direction
- Create a CalcDamageLogic that calculates the Final Damage according to the formula after receiving the damage value to manage a damage calculation function.
- Use Logic to create a ConfigLogic that manages fixed values that **aren't scheduled to be changed**.
    - Example: For games that have a max of 5 lives, create a Logic that can register and use MaxHP to keep the max HP a fixed value.
