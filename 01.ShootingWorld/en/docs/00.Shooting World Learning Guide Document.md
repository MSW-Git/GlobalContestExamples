# Shooting World Learning Guide Document
<br>
<br>
<br>

## Learning Goals

- Learn how to implement core shooting game functions using the guide document and the sample world.
- Learn how to set the map up based on the game that is to be created in MapleStory Worlds.
- Understand Logic and design ways to use it.
- Modify and create a world in the form of your choosing.
<br>

---

<br>

## Learning Core Functions
- **Managing DataSet**: Learn how to use the Manager that manages a DataSet with a single Logic by utilizing DataTableLogic.
- **Managing Collisions Between Entities**: Set and use collision conditions by utilizing the TriggerComponent's Collision Group and Matrix.
- **Object Pool**: Learn the object pool technique and create one to manage multiple projectiles.

<br>

## 🔄 Core Gameplay Loop

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Shooting/MSW-100_Shooting_0_000_en.png" alt="MSW-100_Shooting_0_000_en.png">
</p>
<br>

**1. Start Game**: Start the game or learn how to play from the title screen.<br>
**2. Select Play Character**: When the Start Game button is pressed on the title screen, the UI for selecting a character is displayed.<br>
**3. Start Battle**: Proper start to the shooting game. Game interactions for shooting games like monster spawns and player attacks happen here.<br>
**4. Check Whether All Enemies Are Dead**: Checks whether the requisite number of monsters to clear the current map have been defeated.<br>
**5. Confirm Results**: Produces a results screen based on whether or not the player defeated all monsters.<br>
**6. Check for Restarts**: Go to the corresponding screen based on whether the player requested a restart or chose to return to the title.

## Implementation Order

- 💡 **Basic Training**: The training material for the most basic functions for MapleStory Worlds or for the relevant genre.
- 📖 **Advanced Training**: Category of training for learning and implementing functions visible in the sample world. Using these materials can expand the functions for the genre and understanding of the training materials.

### [💡Basic Training] 1. Setting a Map
- Learn about the types of maps provided by MapleStory Worlds.
- Learn about the relationship between the BodyComponent and map types.
- Learn about the KinematicBodyComponent.
- Learn how to compose maps by placing RectTiles.
<br>

### [💡Basic Training] 2. Declaring Logic
- Learn about the DataSet components for composing players.
- Learn how to load DataSets through DataTableLogic and how to use them.
- Learn how to create a Component that will contain the saved data and how to apply it.
- Learn how to add and edit TriggerComponent.
<br>

### [💡Basic Training]3. Creating a Playercharacter
- Learn about the DataSet components used to configure players.
- Learn how to load and use DataSets through DataTableLogic.
- Explore how to create and apply Components for storing saved data.
- Learn how to assign and edit TriggerComponents.
<br>

### [💡Basic Training] 4. Creating Monsters
- Learn about the DataSet components required to compose monsters.
- Learn how to load and use DataSets through DataTableLogic.
- Explore how to create and apply Components for storing saved data.
- Learn how to assign and edit TriggerComponents.
- Learn how to craft and use the AIChaseComponent, so the monsters chase after the player.
- Learn Modelization for reuse of created monsters.
<br>

### [💡Basic Training] 5. Creating Basic Attacks
- Learn about the DataSet components required to compose projectiles.
- Learn how to load and use DataSets through DataTableLogic.
- Explore how to create and apply Components for storing saved data.
- Learn how to assign and edit TriggerComponents.
- Learn about Collision Groups and how to edit using the Matrix.
- Add a function that makes a projectile fly in the set direction.
<br>

### [💡Basic Training] 6. Creating an Object Pool
- Understand the objective of having an object pool by learning the concepts of the object pool.
- Implement the object pool Component.
- See for yourself how the object pool functions by creating and returning one.
- Learn how to implement the player and monster projectile firing system.
<br>

### [📖Advanced Training] 7. Implementing Skills
- Learn about the DataSet components required to compose skills.
- Learn how to load skill related DataSets through DataTableLogic and how to use them.
- Learn how to create and implement Components that will contain the saved skill data.
- Learn how to add and edit a TriggerComponent to a skill entity.
- Learn how to convert a created entity into a Model and use it.
- Add a function that makes a projectile type skill fly in the set direction.
- Learn about the TriggerEvent used to implement projectile-type skill functions.
<br>

### [📖Advanced Training] 8. Implementing Items
- Learn about skill DataSet components required to compose items.
- Learn how to load an item DataSet through DataTableLogic and how to use it.
- Add and edit components to apply item data and item spawn data.
- Learn how to create a Model that composes items.
- Create an ItemHelper Logic that is in charge of an item's spawn chance and item spawns.
- Learn how to implement functions, so item effects can be processed normally.
- Learn how to spawn a Monster to apply an item spawn chance.
<br>

### [📖Advanced Training] 9. Creating a MonsterSpawn
- Implement a function, so a Monster appears in InGame based on the value entered in the DataSet.
- Learn about the DataSet structure and how to use said structure.
- Add an item drop chance to each spawning monster to implement a function that drops items based on a set chance when monsters are defeated.
<br>

### [💡Basic Training] 10. Composing UI
- Learn about UIGroup, its components, and how to edit it.
- Learn how to edit the UI by creating a title screen.
- Create a Component that controls the title screen, so the target UI's function can be processed.
- Learn how to create a SelectCharacterUI that allows the player to select a character.
- Learn how to compose a DefaultUI that controls the in-game information.
- Create a Component that controls DefaultUI to implement a function that updates the remaining HP and skill use count.
