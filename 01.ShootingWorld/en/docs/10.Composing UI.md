## Applying a Component to a UI Entity

- Like normal entities, you can add Components to UI entities to execute additional functions.
- Adding Components is done the same way as the Add Component function for regular entities.
- This lesson will talk about the often used Components.
    - **SpriteGUIRendererComponent**: A Component used when outputting an image for the UI. It's recommended to use this Component rather than SpriteRendererComponent when outputting images in the UI.
    - **TextGUIRendererComponent**: A Component used when outputting text on the UI.
    - **ButtonComponent**: A Component used when the UI needs a button function.

<br>

## Applying a Controller to a UIGroup
- The Controller is used to create a Component and manage a target UI.
- Apply a Controller Component to each UIGroup and compose functions, so each Component serves a UI-related function.
- Register each Controller to UIManageLogic and call UIManageLogic to request UI-related functions to a different UI.
- The following UIControllers were created in the sample world.
    - **DefaultUIController**: A Component used to manage the DefaultUI. It usually manages player HP and skill use count updates, and it also takes the role of registering the player's basic attacks and skill use function to each corresponding button.
    - **TitleUIController**: A Component used to compose the title screen. This Component was created to process the Start Game button and How to Play UI output functions.
    - **ResultUI**: When the GameLogic delivers the game's results to UIManagLogic, the UIManageLogic requests that target Component which results UI should be output.

## Applying Localization

- There are largely 2 ways to apply the localization function.
- You can use the TextGUIRendererComponent value or use scripts.

### How to Utilize the TextGUIRendererComponent

<p align="center">
<img src="../../_images/MSW-100_Shooting_10_007.png" alt="MSW-100_Shooting_10_007.png">
</p>

- Enter the localized value you want to apply to the created Locale DataSet.
- Enter the Locale DataSet's key to TextGUIRendererComponent's Text value.
- Change the TextGUIRendererComponent's isLocalizationKey value to the checked state.
- You can ensure that the localization function will be applied in this state.

<br>

### How to Utilize the Script

- The sample world created a LocalizeLogic for expedient use.
- The following is the code for the created LocalizeLogic.
- This code was written based on Plain Text.

```lua
@Logic
script LocalizeLogic extends Logic

@ExecSpace("ClientOnly")
method string GetLocalizeStringByKey(string StringKey)
-- Searches and returns the value in StringTable based on the received StringKey value.
return _LocalizationService:GetText(StringKey)
end

end
```

- When delivering the Locale DataSet Key value as a StringKey parameter, text that matches the language of the country that the game is running in is output.
    - Example: When the country the game is played in is an English-speaking language like America, the en value is output.

## Utilizing UIManageLogic

- If all of the UI settings are complete, then each Controller is registered to UIManageLogic, and the function must be set-up.
- The following is the UIManageLogic code.
- The following code is written based on a Plain Text environment.

```lua
@Logic
script UIManageLogic extends Logic

property TitleUIController titleUIController = nil

property SelectCharacterUIController selectCharacterUIController = nil

property ResultUIController resultUIController = nil

property DefaultUIController defaultUIController = nil

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- Searches for and registers TitleUIController when the game starts.
self:InitTitleUIController()
-- Searches for and registers SelectCharacterUIController when the game starts.
self:InitSelectCharacterUIController()
-- Searches for and registers ResultUIController when the game starts.
self:InitResultUIController()
-- Searches for and registers DefaultUIController when the game starts.
self:InitDefaultUIController()
end

@ExecSpace("ClientOnly")
method void InitTitleUIController()
-- If there is no registered TitleUIController, registers the target component.
if not isvalid(self.titleUIController) then
	local titleUIEntity = _EntityService:GetEntityByPath("/ui/TitleUI")
	-- If titleUIGroup is successfully found, registers the target entity's component.
	if isvalid(titleUIEntity) then
		local component = titleUIEntity.TitleUIController
		-- Determines whether the component has been registered normally and then assigns it.
		if isvalid(component) then
			self.titleUIController = component
		end 
	end
end
end

@ExecSpace("ClientOnly")
method void InitSelectCharacterUIController()
-- If there is no registered SelectCharacterUIController, registers the target component.
if not isvalid(self.selectCharacterUIController) then
	local selectCharacterUIEntity = _EntityService:GetEntityByPath("/ui/SelectCharacterUI")
	-- If SelectCharacterUIController is successfully found, registers the target entity's component.
	if isvalid(selectCharacterUIEntity) then
		local component = selectCharacterUIEntity.SelectCharacterUIController
		-- Determines whether the component has been registered normally and then assigns it.
		if isvalid(component) then
			self.selectCharacterUIController = component
		end 
	end
end
end

@ExecSpace("Client")
method void ShowTitle()
-- Shows the title screen.
self.titleUIController:Show()
-- Hides all other UI.
self.selectCharacterUIController:Hide()
self.resultUIController:Hide()
self.defaultUIController:Hide()
end

@ExecSpace("Client")
method void CallSelectCharacterUI()
-- Shows the character selection screen.
self.selectCharacterUIController:Show()
-- Attempts to reset the character list in the character selection screen.
self.selectCharacterUIController:InitCharacterSelectFrame()
end

@ExecSpace("Client")
method void ShowInGame()
-- Resets the defaultUI of the game screen UI.
self.defaultUIController:Show()
-- Requests a reset of the auto-attack UI.
self.defaultUIController:UpdateAutoUI()
-- Hides other UI.
self.titleUIController:Hide()
self.selectCharacterUIController:Hide()
self.resultUIController:Hide()
end

@ExecSpace("Client")
method void InitResultUIController()
-- If there is no registered ResultUIController, registers the target component.
if not isvalid(self.resultUIController) then
	local resultUIEntity = _EntityService:GetEntityByPath("/ui/ResultUI")
	-- If ResultUIController is successfully found, registers the target entity's component.
	if isvalid(resultUIEntity) then
		local component = resultUIEntity.ResultUIController
		-- Determines whether the component has been registered normally and then assigns it.
		if isvalid(component) then
			self.resultUIController = component
		end 
	end
end
end

@ExecSpace("Client")
method void ShowResultUI(boolean IsClear)
-- Displays the results UI.
self.resultUIController:Show(IsClear)
if IsClear then
	-- Play Congratulations Sound Effect
	_SoundService:PlaySound("5d57b617cfc242cca347925e209c8e05", 1.0)
else
	-- Play Failure Sound Effect
	_SoundService:PlaySound("52dccfb8889b4181b9181780dc7e9040", 1.0)
end
end

@ExecSpace("Client")
method void InitDefaultUIController()
--If there is no registered defaultUIController, registers the target component.
if not isvalid(self.defaultUIController) then
	local titleUIEntity = _EntityService:GetEntityByPath("/ui/DefaultUI")
	--If DefaultUIGroup is successfully found, registers the target entity's component.
	if isvalid(titleUIEntity) then
		local component = titleUIEntity.DefaultUIController
		-- Determines whether the component has been registered normally and then assigns it.
		if isvalid(component) then
			self.defaultUIController = component
		end 
	end
end
end

@ExecSpace("Client")
method void UpdateLifeCountUI(number PlayerLife)
-- Updates the DefaultUI's HP UI in accordance to the PlayerLife number.
self.defaultUIController:UpdateLifeUI(PlayerLife)
end

@ExecSpace("Client")
method void UpdateSkillCountUI(number LeftSkillCount)
-- Updates the DefaultUI's skill UI in accordance with the LeftSkillCount number.
self.defaultUIController:UpdateSkillUI(LeftSkillCount)
end

end
```

- The UI Group's Controllers have been registered, and the method has been created based on the UI updates needed.
- When there is a UI update request in GameLogic or PlayerState, the Controller in charge is called and executes the relevant function.
<br>

## Minimum Implementation Standards
- Compose the UIManageLogic, so the Controller that manages the UI and the Controller's functions can be used conveniently from the outside.
- An interaction must be triggered when a button-like element is clicked in the UI.
- The UI must deliver the information needed to progress in the game.
<br>

## Usage and Extension Direction
- Create an Event, so when the player gets hit, the update is triggered without making a update request to UIManageLogic.
	- This method becomes the groundwork for synchronizations when making future communication between the Server and Client.
- Delivers visual information to users when a new UI is created or by adding effects as needed.

## Closing Remarks

- The composition of UI can vary widely based on the type and direction you want to take the game.
