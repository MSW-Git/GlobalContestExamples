## Creating a MonsterSpawnManager
- An entity needs to be added to InGame to create a MonsterSpawnManager.
- Also, the MonsterSpawnManager Component must be composed.
- The following is the code that composes the MonsterSpawnManager Component.
- This code was written based on Plain Text.

```lua
@Component
script MonsterSpawnManager extends Component

property number stageID = 0 -- Property that categorizes stages.

property number needKillCount = 0 -- Property that calculates and saves the number of monsters that can be defeated when the stage starts.

property table timerTable = {} -- Table that saves the time when the monsters appear.

@ExecSpace("Client")
method void StartGame()
-- Resets the number of monsters that need to be defeated to clear the stage to 0 first.
self.needKillCount = 0
-- Resets the timerTable that contains the stage's monster appearance times.
self.timerTable = {}
-- Sets the stageID to 1, so the game can run as intended if stageID is 0.
if self.stageID == 0 then
	self.stageID = 1
	-- Notifies through a log that the stageID is currently registered as 0.
	log("StageID hasn't been registered to the SpawnManager!")
	return
end
-- Fetches the monster spawn data from DataTableLogic according to stageID.
local getData = _DataTableLogic:GetMonsterSpawnDataTableByStageID(self.stageID)
-- Generates an error through the log if the getData is unusable.
if not isvalid(getData) or next(getData) == nil then
	log("Couldn't load the table value from the "self.stageID.." data table!")
	return
end
-- Counts the number of getData found and processes the getData values one at a time.
for i = 1, #getData do
	-- Registeres the data at index i from getData to data.
    local data = getData[i]
	-- Attempts to spawn monsters through the data values if data is usable.
    if data then
		-- Increases the number of monsters that must be defeated to clear the stage by 1, since there is a usable monster.
		self.needKillCount = self.needKillCount + 1
        -- Sets the timer for monster spawns.
        Sself.timerTable[i] = _TimerService:SetTimerOnce(function()
			-- Requests the data of monsters that have to be spawned from DataTablelogic.
            local monsterData = _DataTableLogic:GetMonsterDefaultDataByMonsterID(data.MonsterID)
            
            -- Creates monsters that need to be created.
            local monster = _SpawnService:SpawnByModelId(
                -- Searches for the Model through the monster's ID and creates the target Model.
				monsterData.ModelRUID,
				- Changes the entity's name to MonsterID.
                monsterData.MonsterID, 
				-- Sets the creation position of the monster that you are trying to create.
                Vector3(data.SpawnPosX, data.SpawnPosY, 0), 
                -- Sets the entity that will be created as its child in the Hierarchy.
				self.Entity
            )
            -- Resets the value if a monster was created normally.
            if monster then
				-- Resets the monster's position to the MOnsterSpawnData again one more time.
				monster.TransformComponent.Position = Vector3(data.SpawnPosX, data.SpawnPosY, 0)
				-- Resets the monster data according to MonsterDefaultData.
                monster.MonsterState:InitData(monsterData, data.ItemDropRate, data.MustDropItem)
            end
        end,
		-- Registers the time, so the creation can happen based on the spawn time registered in MonsterSpawnData.	 
		data.EntranceTime)
    end
end
-- Delivers the number of monsters that must be defeated to clear the stage to Gamelogic if all monster creation reservations are complete.
_GameLogic:InitClearKillCount(self.needKillCount)
end

@ExecSpace("Client")
method void ClearAllChild()
-- Searches for all of the child entities and registers them to the chidList.
local childList = self.Entity.Children
-- Immediately ends the code if the childList is nil.
if childList == nil then return end
-- Navigates and processes the amount of time equal to the number of childList since chidList holds 1 or more.
for i, child in pairs(childList) do
	-- Removes the child element if the entity at index i is usable.
	if isvalid(child) then
		_EntityService:Destroy(child)
	end
end
-- Starts a navigation of the timerTable elements if there are elements in timerTable.
if self.timerTable ~= nil and next(self.timerTable) ~= nil then
	-- Removes the scheduled timer at index i.
	for i = 1, #self.timerTable do
		_TimerService:ClearTimer(self.timerTable[i])
	end
end
end

end
```

## Minimum Implementation Standards
- Change MonsterSpawnData to adjust the portions related to Monster spawns.
- You must be able to add Monsters to spawn a variety of Monsters.
- Adjust the item drop chances for each monster through ItemDropRate and MustDropItem.
<br>

## Usage and Extension Direction
- Manage stage progression through number in GameLogic and, when InGame begins, change the StageID value of MonsterSpawnManager.
- Implement a function that changes the Monster that spawns based on the MonsterSpawnData's StageID value.
