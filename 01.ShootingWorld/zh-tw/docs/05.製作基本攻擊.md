## 撰寫MissileComponent腳本
- 如下撰寫腳本。
- 該腳本是以Plain Text為基準撰寫。

```lua
@Component
script MissileComponent extends Component

property number moveSpeed = 0 -- 用於儲存投射體速度的Property。

property number atkValue = 0 -- 用於儲存投射體攻擊力的Property。

property number lifeTime = 0 -- 用於儲存投射體持續時間的Property。

property boolean isShotPlayer = false -- 用於區分投射體發射主體的Property。

property string hitEffectRUID = "" -- 用於儲存投射體命中時要輸出的特效的Property。

property Vector2 fireDirection = Vector2(0,0) -- 用於儲存投射體發射方向的Proeprty。

property number deltaTimer = 0 -- 用於計算投射體產生時間的Property。

property string missileID = "" -- 用於儲存目前投射體ID的Property。

property any poolManager = nil

@ExecSpace("ClientOnly")
method void InitData(table MissileData)
-- 若傳入的MissileData是不可使用的值，則輸出錯誤日誌並結束程式碼。
if MissileData == nil or next(MissileData) == nil then
	log("MissileData是空的。")
	return
end

-- 從傳入的資料中儲存投射體的ID。
self.missileID = MissileData.MissileID
-- 從傳入的資料中儲存投射體的攻擊力。
self.atkValue = MissileData.AtkValue
-- 從傳入的資料中儲存投射體的移動速度。
self.moveSpeed = MissileData.MoveSpeed
-- 從傳入的資料中儲存投射體的持續時間。
self.lifeTime = MissileData.LifeTime
-- 從傳入的資料中儲存投射體碰撞時要輸出的特效ID。
self.hitEffectRUID = MissileData.HitEffectRUID 
end

@ExecSpace("ClientOnly")
method void OnUpdate(number delta)
-- 若實體為不可使用狀態，則立即結束程式碼。
if self.Entity.Enable == false then
	return
end
-- 若遊戲狀態不是進行中狀態，則立即結束程式碼。
if not _GameLogic.IsStillPlay then
	return
end

-- 取得投射體目前位置。
local transform = self.Entity.TransformComponent
-- 計算依移動速度與時間應移動的距離。
local moveVec = Vector3(self.fireDirection.x, self.fireDirection.y, 0) * self.moveSpeed * delta
-- 將投射體目前位置移動到應移動的位置。
transform.Position = transform.Position + moveVec
    
-- 將delta時間加入deltaTimer。
self.deltaTimer = self.deltaTimer + delta
-- 若deltaTimer大於lifeTime，則回收投射體。
if self.deltaTimer >= self.lifeTime then
	self:ReturnSelf()
end
end

@ExecSpace("ClientOnly")
method void ReturnSelf()
    -- 將投射體回收到ProjectileManager。
    if self.poolManager and isvalid(self.poolManager) then
        self.poolManager:ReturnMissile(self.Entity)
    else
		-- 若poolManager為nil，則銷毀投射體。
        _EntityService:Destroy(self.Entity)
    end
end

@ExecSpace("Client")
method void FireMissile(Vector2 FireDirection, boolean IsShotPlayer, Vector3 FireStartPos)
-- 將deltaTimer初始化為0。
self.deltaTimer = 0 
-- 初始化投射體的發射方向。
self.fireDirection = FireDirection
-- 初始化投射體的發射主體。若投射體的發射主體是玩家，則儲存為true。
self.isShotPlayer = IsShotPlayer
-- 將投射體目前位置變更為發射位置。
self.Entity.TransformComponent.Position = FireStartPos
-- 將投射體的使用狀態切換為true。
self.Entity.Enable = true
end

@ExecSpace("ClientOnly")
@EventSender("Self")
handler HandleTriggerEnterEvent(TriggerEnterEvent event)
-- 取得偵測到碰撞的實體。    
local trigger = event.TriggerBodyEntity
-- 將用於儲存是否可碰撞的hitSuccess初始化為false。
local hitSuccess = false
-- 當玩家發射的投射體與怪物碰撞時，進行處理。
if isvalid(trigger.MonsterState) and self.isShotPlayer then
	-- 若碰撞實體持有HitComponent，且處於存活狀態，則請求進行傷害計算。
	if trigger.HitComponent and trigger.MonsterState.isAlive then
		trigger.HitComponent:OnHit(self.Entity, self.atkValue, false, self.hitEffectRUID, 1)
		hitSuccess = true
    end
        
-- 當怪物發射的投射體擊中玩家時，進行處理。
elseif isvalid(trigger.PlayerState) and self.isShotPlayer == false then
    -- 檢查玩家是否持有HitComponent、是否為存活狀態，以及目前是否為無敵狀態。
	if trigger.HitComponent and trigger.PlayerState.isAlive and not trigger.PlayerState.isInvincibility then
		-- 若為可受傷狀態，則呼叫OnHit請求進行傷害計算。
		trigger.HitComponent:OnHit(self.Entity, self.atkValue, false, self.hitEffectRUID, 1)
		hitSuccess = true
    end
end

-- 若已完成傷害計算處理，則再次停用實體。
if hitSuccess then
	self:ReturnSelf()
end
end

end
```

## 設定TriggerComponent

- 可透過變更TriggerComponent的組成要素，來變更Collision Group與Collision Group之間的碰撞關係。

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Shooting/MSW-100_Shooting_5_002.png" atl="MSW-100_Shooting_5_002.png">
</p>

- 找到已製作實體的TriggerComponent後，點擊CollisionGroup右側的開啟面板按鈕。

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Shooting/MSW-100_Shooting_5_003.png" atl="MSW-100_Shooting_5_003.png">
</p>

- 在Collision Groups視窗中點擊Add Collision Group以新增CollisionGroup。
    - **Player**：用於指定玩家的Collision Group。
    - - **Monster**：用於指定敵人的Collision Group。
    - **Missile**：用於指定投射體的Collision Group。
    - **Skill**：用於指定技能的Collision Group。
    - **Item**：用於指定會給玩家有利效果的Collision Group。
- 完成上述設定後，移動到Matrix。

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Shooting/MSW-100_Shooting_5_003.png" atl="MSW-100_Shooting_5_003.png">
</p>

- 如上圖所示設定Matrix。
- 該Matrix會形成如下碰撞關係。
    - Player會檢查與Monster、Missile、Item的碰撞。
    - Monster會檢查與Player、Missile、Skill的碰撞。
    - Missile會檢查與Player、Monster、Skill的碰撞。
    - Skill會檢查與Monster、Missile的碰撞。
    - Item會檢查與Player的碰撞。

## 指定Matrix的原因
- 碰撞運算是經常發生的檢查要素之一。
- 若新增不必要的CollisionGroup，並讓所有CollisionGroup都進行碰撞檢查，就會增加不必要的運算。
- 因此，為了最佳化效能，可以關閉不必要的碰撞檢查，只檢查必要碰撞，以提升效能。
<br>

## 最低實作標準
- 必須製作投射體Model，且至少要存在3個以上可使用的投射體。
- 必須透過投射體的InitData正常輸入投射體資料。
- 若以FireMissile發射透過InitData輸入數值的投射體，則投射體必須能正常發射。
- 投射體必須與Monster碰撞後消失。
<br>

## 應用與擴展方向
- 透過多樣化新增投射體移動方式來製作模式。
- 可透過各種投射體來建立新角色。
- 可讓每個敵人發射不同的投射體來製作模式。
