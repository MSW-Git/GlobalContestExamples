## 製作MonsterSpawnManager
- 為了製作MonsterSpawnManager，必須在InGame中新增實體。
- 此外還必須構成MonsterSpawnManager Component。
- 構成MonsterSpawnManager的程式碼如下。
- 該程式碼是以Plain Text為基準撰寫。

```lua
@Component
script MonsterSpawnManager extends Component

property number stageID = 0 -- 這是用來區分Stage的Property。

property number needKillCount = 0 -- 這是用來在Stage開始時，計算並儲存可擊殺怪物數量的Property。

property table timerTable = {} -- 這是用來儲存怪物出現時間的table。

@ExecSpace("Client")
method void StartGame()
-- 先將Stage通關所需的怪物擊殺數初始化為0。
self.needKillCount = 0
-- 初始化存放Stage中怪物出現時間的timerTable。
self.timerTable = {}
-- 若stageID為0，為了讓遊戲能正常執行，會暫時設為1。
if self.stageID == 0 then
	self.stageID = 1
	-- 此外也會以Log告知目前stageID被登錄為0。
	log("SpawnManager中未登錄StageID！")
	return
end
-- 依照stageID，從DataTableLogic取得怪物產生資料。
local getData = _DataTableLogic:GetMonsterSpawnDataTableByStageID(self.stageID)
-- 若getData不可使用，則透過log輸出錯誤。
if not isvalid(getData) or next(getData) == nil then
	log("無法取得資料表中"..self.stageID.."的值！")
	return
end
-- 計算取得的getData數量，並逐一處理getData的值。
for i = 1, #getData do
	-- 將getData的第i筆資料登錄到data中。
    local data = getData[i]
	-- 若data可使用，則透過data的值嘗試產生怪物。
    if data then
		--由於存在可用怪物數量，因此為了通關，將需要擊殺的數量增加1。
		self.needKillCount = self.needKillCount + 1
        -- 設定怪物產生用的計時器。
        self.timerTable[i] = _TimerService:SetTimerOnce(function()
			-- 向DataTableLogic請求要產生之怪物的資料。
            local monsterData = _DataTableLogic:GetMonsterDefaultDataByMonsterID(data.MonsterID)
            
            -- 產生要建立的怪物。
            local monster = _SpawnService:SpawnByModelId(
                -- 透過怪物的ID尋找Model，並產生該Model。
				monsterData.ModelRUID,
				-- 將實體名稱變更為MonsterID。
                monsterData.MonsterID, 
				-- 設定要出現怪物的出現位置。
                Vector3(data.SpawnPosX, data.SpawnPosY, 0), 
                -- 將要建立的實體在Hierarchy中設為自己的子實體。
				self.Entity
            )
            -- 若monster已正常建立，則初始化其數值。
            if monster then
				-- 再次將怪物的位置初始化為MonsterSpawnData中的位置。
				monster.TransformComponent.Position = Vector3(data.SpawnPosX, data.SpawnPosY, 0)
				-- 依照MonsterDefaultData初始化怪物資料。
                monster.MonsterState:InitData(monsterData, data.ItemDropRate, data.MustDropItem)
            end
        end,
		-- 登錄時間，使其依照MonsterSpawnData中登錄的出現時間產生。	 
		data.EntranceTime)
    end
end
-- 當所有怪物產生預約完成後，將通關所需的怪物擊殺數傳遞給GameLogic。
_GameLogic:InitClearKillCount(self.needKillCount)
end

@ExecSpace("Client")
method void ClearAllChild()
-- 尋找所有作為自己子實體的實體，並登錄到chidList中。
local childList = self.Entity.Children
-- 若childList為nil，則立即結束程式碼。
if childList == nil then return end
-- 由於chidList的數量大於等於1，因此開始依childList數量進行搜尋與處理。
for i, child in pairs(childList) do
	--若第i個實體可使用，則移除要素child。
	if isvalid(child) then
		_EntityService:Destroy(child)
	end
end
-- 若timerTable中存在要素，則開始搜尋timerTable中的要素。
if self.timerTable ~= nil and next(self.timerTable) ~= nil then
	-- 解除第i個已預約的計時器。
	for i = 1, #self.timerTable do
		_TimerService:ClearTimer(self.timerTable[i])
	end
end
end

end
```

## 最低實作標準
- 可透過修改MonsterSpawnData來調整與Monster產生相關的部分。
- 必須能加入Monster，讓各種Monster都能產生。
- 可透過ItemDropRate與MustDropItem調整每個怪物的道具掉落機率。
<br>

## 應用與擴展方向
- 在GameLogic中以number管理Stage進度，並在InGame開始時變更MonsterSpawnManager的StageID值。
- 實作功能，使依照MonsterSpawnData的StageID值而出現的Monster有所不同。
