## 在DataTableLogic中登錄DataSet

- 在DataTableLogic中如下撰寫程式碼。
- 程式碼範例是以PlainText為基準撰寫。

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Shooting/MSW-100_Shooting_3_004.png" alt="MSW-100_Shooting_3_004.png">
</p>

- PlainText可透過程式碼編輯器視窗右下角的UI按鈕進行切換。


```lua
property table characterDefaultData = {} -- 用來管理CharacterDefaultData DataSet的Property。

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- 初始化CharacterDefaultData DataSet。
self:InitCharacterDefaultData()
end

method void InitCharacterDefaultData()
-- 用於檢查玩家角色解析是否完成的項目
if isvalid(self.characterDefaultData) == false or next(self.characterDefaultData) == nil then
	local getTableData = _DataService:GetTable("CharacterDefaultData")
	--若取得資料表失敗則輸出警告訊息
	if getTableData == nil then
		log("無法取得CharacterDefaultData資料表！")
		return
	end
	--開始解析
	local rowCount = getTableData:GetRowCount() -- 計算全部列數。
    
    for i = 1, rowCount do
        -- 先從資料表Row中代入一個作為Key的CharacterID。
        local characterID = tostring(getTableData:GetCell(i, "CharacterID"))
        
        -- 檢查是否為有效ID。
        if characterID ~= nil and characterID ~= "" then
            
            -- 將該列的所有資訊綁成table。
            local rowData = 
			{
                CharacterID = characterID,
                StartHP = tonumber(getTableData:GetCell(i, "StartHP")),
				StartSkillCount = tonumber(getTableData:GetCell(i, "StartSkillCount")),
                StartMoveSpeed = tonumber(getTableData:GetCell(i, "StartMoveSpeed")),
                DefaultMissile = tostring(getTableData:GetCell(i, "DefaultMissile")),
				DefaultSkill = tostring(getTableData:GetCell(i, "DefaultSkill")),
				AttackInterval = tonumber(getTableData:GetCell(i, "AttackInterval"))
            }
            
            -- 儲存到快取table中(Key：MissileID, Value：資料)
            self.characterDefaultData[characterID] = rowData
        end
    end
	-- 輸出表示資料表快取完成的Log。
	log("CharacterDefaultData資料表快取完成！")
	return
end
-- 由於尚未進行資料表快取，因此輸出提示該情況的日誌。
log("CharacterDefaultData資料表已經快取，或找不到CharacterDefaultData資料表。")
end

method table GetCharacterDefaultDataByCharacterID(string CharacterID)
-- 若characterDefaultData尚未正常快取，則嘗試進行快取。
if self.characterDefaultData == nil then
	self:InitCharacterDefaultData()
end
-- 檢查目前CharacterDefaultData是否已正常登錄。
if isvalid(self.characterDefaultData) and next(self.characterDefaultData) ~= nil then
	-- 當有具有CharacterID值的資料時，回傳該資料。
	if self.characterDefaultData[CharacterID] then
		return self.characterDefaultData[CharacterID]
	end
-- 若沒有對應Key的資料，則輸出錯誤日誌。
else
	log("沒有PlayerDefaultData資料，或是不存在"..CharacterID.."值！")
	return nil
end
end
```

## 初始化PlayerState的值

- 在PlayerState中如下輸入程式碼。
- 該程式碼是以Plain Text為基準撰寫。

```lua
@Component
script PlayerState extends Component

property number currentHP = 0 -- 用來管理玩家目前體力的Property。

property string currentMissile = "" -- 用來儲存玩家目前投射體ID的Property。

property string characterID = "" -- 用來儲存目前遊玩角色ID的Property。

property number attackInterval = 0.5 -- 用來管理玩家攻擊延遲的Property。

property number attackTimer = 0 -- 用來計算玩家是否可攻擊的Property。

property any projectilePoolManager = nil

property Vector3 firePos = Vector3(0.25,0.25,0) -- 用來調整玩家攻擊發射位置的Property。

property boolean isInvincibility = false -- 用來區分玩家是否處於無敵狀態的Property。

property number invincibilityDelta = 0 -- 用於計算無敵時間的Property。

property number invincibilityTime = 1.0 -- 無敵持續時間的基準Property。可透過修改該值來變更無敵時間。

property boolean isAlive = false -- 用來區分玩家是否存活的Property。

property string skillID = "" -- 用來儲存玩家使用技能ID的Property。

property number canUseSkillCount = 0 -- 用來管理目前玩家可使用技能次數的Property。

property number moveSpeed = 0 -- 用來登錄玩家移動速度的Property。

@ExecSpace("ClientOnly")
method void InitPlayerData(table PlayerDefaultData)
-- 若傳入的PlayerData不是正常資料，則輸出錯誤日誌並中止程式執行。
if PlayerDefaultData == nil or next(PlayerDefaultData) == nil then
	log("PlayerDefaultData不正常！")
    return
end
-- 初始化玩家目前體力。
self.currentHP = PlayerDefaultData.StartHP
-- 初始化玩家可使用的技能ID。
self.canUseSkillCount = PlayerDefaultData.StartSkillCount
-- 初始化玩家移動速度。
self.moveSpeed = PlayerDefaultData.StartMoveSpeed
-- 為了正常套用初始化後的玩家移動速度，將其傳遞給MovementComponent。
self.Entity.MovementComponent.InputSpeed = self.moveSpeed
-- 初始化玩家基本投射體ID。
self.currentMissile = PlayerDefaultData.DefaultMissile
-- 初始化玩家角色ID值。
self.characterID = PlayerDefaultData.CharacterID
-- 初始化玩家攻擊延遲。
self.attackInterval = PlayerDefaultData.AttackInterval
-- 初始化玩家技能ID。
self.skillID = PlayerDefaultData.DefaultSkill
-- 初始化玩家起始位置。
self.Entity.TransformComponent.Position = Vector3.zero
-- 將玩家Entity的使用狀態改為true。
self.Entity.Enable = true
-- 將玩家角色的Visible狀態改為true。
self.Entity.Visible = true
end

@ExecSpace("ClientOnly")
method void OnBeginPlay()
    local getData = _DataTableLogic:GetCharacterDefaultDataByCharacterID("Pirate")
    self:InitPlayerData(getData)
    self.isAlive = true
end
```

### 什麼是TriggerComponent？
- TriggerComponent是用來偵測實體之間碰撞的Component。
- 綠色區域是碰撞判定區域。
- 當該區域互相交錯的瞬間，就會被判定為發生碰撞。
- 因此若判定比圖片資源更大或更小，玩家可能會覺得是不合理的判定。
- 但依照遊戲方式，有時也會故意放寬判定，誘導較寬鬆的處理。
- 必須依照想要製作的遊戲性質，思考並設計要完全貼合判定，還是保留寬裕空間。
<br>

## 最低實作標準
- 可以製作DataSet。
- 可透過製作完成的DataTableLogic載入DataSet中想要的值。
- 可將載入的DataSet值傳遞到Component並進行指定。
- 可透過編輯TriggerComponent來設定碰撞範圍。
<br>

## 應用與擴展方向
- 可以將之後要製作的與玩家相關功能分離為Component單位。
	- EX：若由攻擊負責，則可製作PlayerAttackComponent，並將與攻擊相關的功能實作在該Component中。
- 將遊戲製作所需的值新增至DataSet，並修改DataTableLogic以載入新增的值。
	- 透過學習並使用該方法，可依需求擴充或新增DataSet。
