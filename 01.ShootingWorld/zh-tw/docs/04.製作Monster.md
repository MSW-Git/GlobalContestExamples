## 學習目標
- 可建立作為玩家威脅要素的敵人，為遊戲營造緊張感。
- 可建立實體並新增Component來構成敵人。

## 構成MonsterDataSet

- 建立用來儲存與Monster相關資訊的DataSet。
- 在範例世界中，將該DataSet名稱製作為MonsterDefaultData。
- 若不知道如何製作DataSet，請參考本文件的製作PlayerCharacter來進行製作。

## 構成怪物實體

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Shooting/MSW-100_Shooting_4_001.png" alt="MSW-100_Shooting_4_001.png">
</p>

- 在Hierarchy中對map01按右鍵。
- 點擊Create Entity。
- 點擊Create Empty，將空實體建立為map01的子實體。
- 可以變更已建立實體的名稱。
- 在範例世界中，為了示範，名稱製作為Monster_Bat。

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Shooting/MSW-100_Shooting_4_002.png" alt="MSW-100_Shooting_4_002.png">
</p>

- 將以下Component新增到已製作的實體上。
- **SpriteRendererComponent**：用來輸出Monster圖片的Component。
- **MovementComponent**：Monster移動所需的Component。AIChaseComponent會利用該Component追蹤玩家。
- **KinematicBodyComponent**：讓怪物可在RectTileMap中移動。Monster需將EnableTileCollision值改為false，以便沒有不可移動區域。
- **AIChaseComponent**：這是楓之谷世界提供的Component。具有該Component的實體可以追蹤玩家。
- **HitComponent**：被投射體擊中時，用來計算傷害的Component。
- **MonsterState**：這是需要直接製作的Component。該Component和PlayerState一樣，是用來承載Monster資料，或負責攻擊、死亡處理等功能的Component。
- **TriggerComponent**：用來指定Monster碰撞區域的Component。可透過該Component指定怪物的碰撞區域，並檢查是否與投射體或技能發生碰撞。

## 設定讓怪物可以追蹤玩家
- 為了讓怪物追蹤玩家，必須套用以下要素。

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Shooting/MSW-100_Shooting_4_006.png" alt="MSW-100_Shooting_4_006.png">
</p>
- 必須在Property中啟用Localize。
    - 範例世界是以客戶端驅動為基礎製作的。- 因此必須勾選Localize，讓Entity可在本機端運作。

<p align="center">
<img src="https://develrocket-bucket.s3.ap-northeast-2.amazonaws.com/learning/MSW-100/Shooting/MSW-100_Shooting_4_007.png" alt="MSW-100_Shooting_4_007.png">
</p>

- 必須將AIChaseComponent內的UpdateAuthority變更為Client。
    - 若該值為Server，則在以客戶端驅動為基礎的範例世界中，可能無法正常追蹤玩家。
- 可依需要增加DetectionRange的值，以擴大敵人辨識玩家的範圍。


## 構成MonsterState Component

- 必須撰寫加在Model中的MonsterState Component程式碼。
- 透過該程式碼，Monster可找到MonsterDefaultData後取得數值。
- 如下撰寫程式碼。
- 該程式碼是以Plain Text為基準撰寫。

```lua
@Component
script MonsterState extends Component

property number currentHP = 0 -- 用來管理怪物目前體力的Property。

property number attackInterval = 0 -- 用來儲存怪物攻擊延遲的Property。

property boolean isAlive = true -- 用來檢查怪物是否存活的Property。

property string defaultMissile = "" -- 用來儲存怪物發射之投射體ID的Property。

property ProjectileManager projectileManager = nil

property Vector2 firePos = Vector2(0,0) -- 用來指定投射體發射位置的Property。

property number deltaTimer = 0 -- 用來計算怪物投射體發射延遲的Property。

property number itemDropRate = 0 --用來計算擊殺怪物時道具掉落機率的Property。

property string mustDropItemValue = "" -- 若怪物必定要掉落道具時，用來指定道具的Property。

@ExecSpace("Client")
method void InitData(table MonsterData, number ItemDropRate, string MustDropItem)
-- 檢查傳入的MonsterData是否為nil。
if MonsterData == nil or next(MonsterData) == nil then
	log("傳入的table MonsterData是nil！")
	return
end

-- 檢查傳入的MonsterData中的必要要素是否具有正常的值。
if MonsterData.StartHP == nil or MonsterData.DefaultMissile == nil  or MonsterData.DefaultMissile == "" then
	log("怪物的初始體力、投射體類型尚未設定！")
end
self:FindProjectileManager()


-- 若有填入必要值則開始初始化
-- 在怪物開始時，將目前體力初始化為最大體力。
self.currentHP = MonsterData.StartHP
-- 初始化怪物的初始投射體ID。
self.defaultMissile = MonsterData.DefaultMissile
-- 設定怪物的攻擊延遲。若接收到的值為nil，則初始化為1.0秒。
self.attackInterval = MonsterData.AttackInterval or 1.0
-- 將怪物的存活狀態初始化為true。
self.isAlive = true
-- 初始化道具掉落機率。
self.itemDropRate = ItemDropRate
-- 當存在必定要掉落的道具時，初始化該值。
self.mustDropItemValue = MustDropItem
-- 初始化怪物的移動速度。
self.Entity.MovementComponent.InputSpeed = MonsterData.StartMoveSpeed
end

method void ShowMonster()
-- 將怪物的Enable狀態變更為true。
self.Entity.Enable = true
end

@ExecSpace("ClientOnly")
method void OnUpdate(number delta)
-- 若遊戲狀態不是Play狀態，則立即結束程式碼。 
if not _GameLogic.IsStillPlay then
	self.Entity.MovementComponent.Enable = false
	return
end
-- 若目前怪物存活，且遊戲狀態為Play狀態，則進行處理。
if self.isAlive and _GameLogic.IsStillPlay then
	-- 若怪物的MovementComponent為停用狀態，則將其啟用。
	if self.Entity.MovementComponent.Enable == false then
		self.Entity.MovementComponent.Enable = true
	end
	-- 將delta時間流逝量加到deltaTimer中。
	self.deltaTimer = self.deltaTimer + delta
	-- 若deltaTimer大於攻擊延遲，則發射投射體，並將deltaTimer初始化為0。
	if self.deltaTimer >= self.attackInterval then
		self:FireMissile()
		self.deltaTimer = 0
	end
end
end

@ExecSpace("Client")
method void FindProjectileManager()
    -- 尋找位於InGame地圖中的MissileManager實體。
	local currentMap = self.Entity.CurrentMapName
    local poolEntity = _EntityService:GetEntityByPath("/maps/"..currentMap.."/ProjectileManager")
    -- 若正常找到poolEntity，則以poolEntity初始化missileManager。
    if isvalid(poolEntity) then
        self.projectileManager = poolEntity.ProjectileManager
        self.isAlive  = true
    else
	-- 若在InGame中找不到ProjectileManager，則輸出錯誤日誌。
        log("錯誤：在InGame地圖中找不到ProjectileManager。")
    end
end

@ExecSpace("Client")
method void FireMissile()
-- 若沒有projectileManager，則中止程式執行。
if self.projectileManager == nil then return end

-- 檢查projectileManager是否為nil，以及是否已登錄基本投射體。
if self.projectileManager == nil or self.defaultMissile == nil or self.defaultMissile == "" then
	-- 若其中任一條件未滿足，則留下錯誤日誌。
	log("玩家MissileData初始化失敗！")
end

-- 從ProjectileManager取得可使用的defaultMissile實體。
local missileEntity = self.projectileManager:GetMissile(self.defaultMissile)
    
-- 當projectileManager傳來的實體可使用時，執行程式碼。
if isvalid(missileEntity) then
-- 取得傳來實體的MissileComponent。
local missileComp = missileEntity.MissileComponent
	if missileComp then
		-- 決定投射體的發射方向。
		local fireDir = 1
		-- 由於基本資源是朝左，因此若實體的FlipX為停用狀態，則設定為朝左飛行。
		if self.Entity.SpriteRendererComponent.FlipX == false then
			fireDir = -1
		end
		-- 取得目前怪物的位置。
		local monsterPos = self.Entity.TransformComponent.Position
		-- 將怪物目前位置傳遞給投射體。
		local firePos = Vector3(monsterPos.x, monsterPos.y, 0)
		-- 命令投射體發射。
    	missileComp:FireMissile(Vector2(fireDir, 0), false, firePos)
	end
end
end

@ExecSpace("Client")
method void SendCalcDropItem()
-- 當怪物死亡時，傳遞給ItemHelper以計算是否掉落道具。
_ItemHelper:CalcDropItemData(self.itemDropRate, self.mustDropItemValue, self.Entity.TransformComponent.Position)
end

@ExecSpace("ClientOnly")
@EventSender("Self")
handler HandleHitEvent(HitEvent event)
-- 若怪物狀態為死亡狀態，則不執行程式碼。
if not self.isAlive then
	return
end
-- 取得發生碰撞的投射體實體。
local attackerEntity = event.AttackerEntity
-- 取得投射體傳遞的傷害。
local totalDamage = event.TotalDamage
-- 為了輸出Hit特效，登錄特效輸出位置。
local effectSpawnPos = Vector3(attackerEntity.TransformComponent.Position.x, attackerEntity.TransformComponent.Position.y, 0)
-- 進行傷害計算。
self.currentHP = self.currentHP - totalDamage
-- 若命中，則輸出Hit特效。
_EffectService:PlayEffect(event.Extra, self.Entity, effectSpawnPos, 0, Vector3(0.5, 0.5, 0.5))
-- 播放受擊音效。可透過變更第一個參數值來播放其他音效。
_SoundService:PlaySound("5873f227d7604a63997546a92824c135", 1.0)
-- 若體力變為0，則進行死亡處理。
if self.currentHP <= 0 then
	-- 將存活狀態切換為false。
	self.isAlive = false
	-- 由於怪物已死亡，因此執行是否掉落道具。
	self:SendCalcDropItem()
	-- 輸出死亡時要顯示的特效。可透過變更第一個參數值來變更死亡時輸出的特效。
	_EffectService:PlayEffect("f67f25d5f8e14d2c9962be0fa42808f7", self.Entity, effectSpawnPos, 0, Vector3(0.5, 0.5, 0.5))
	-- 將怪物是否被擊殺傳遞給GameLogic，以檢查是否滿足條件。
	_GameLogic:CountKillScore()
	-- 刪除自己本身，讓實體消滅。
	_EntityService:Destroy(self.Entity)
end
end

end
```

<br>

### ModelRUID的作用是什麼？

- ModelRUID的作用是為了找到WorkSpace中的Model，並複製該Model。
- 這部分會在進階學習項目實作道具中製作MonsterSpawnManager時使用。
- 學習透過ModelRUID的值來複製Model的方法後，就可以召喚各種Monster，或依需求複製其他Model。
<br>

## 最低實作標準
- 必須先製作構成Monster的Model。
- 製作完成的Monster Model必須能追蹤玩家。
<br>

## 應用與擴展方向
- 製作具有各種型態與數值的Monster Model，以多樣化準備Monster。
- 不使用AIChase來實作Monster的移動。
- 為每個Monster實作移動方式，以製作怪物的移動模式。
