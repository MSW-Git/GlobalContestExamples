## Learning Goals

- Learn how to compose various map formats in a single world by using the function provided by MapleStory Worlds.
- Understand MapleStory Worlds map formats and define the rules for the world you're trying to make.
- Learn how to make entities and models to be able to create and manufacture any needed entities.
- Implement map transition methods as needed based on the understanding of the map movement method.

<br>

## Learning Core Functions
- Learn about the map formats and characteristics in MapleStory Worlds.
- Learn about the PortalComponent and TeleportService map transition methods to select and use as needed.

## Implementation Order

- 💡 **Basic Training**: These are the training materials for the most basic functions for MapleStory Worlds or for the relevant genre.
- 📖 **Advanced Training**: These are the training materials for learning and implementing functions visible in the sample world. Using these materials can expand the functions for the genre and understanding of the training materials.

<br>

### [💡 Basic Training] Implementing Map Transitions
- Learn about MapleStory Worlds's Component and PortalComponent.
- Learn about the map transition method using TeleportService.
- Learn about the differences between PortalComponent and TeleportService.

<br>

### [💡 Basic Training] Placing RectTileMap
- Learn about the map method provided by MapleStory Worlds.
- Learn about the RectTileMap, which is necessary to implement the sample world mini game CoinRush.
- Learn how to create and use the TileSet required to compose RectTileMap.
- Learn about the BodyComponent required to interact with RectTileMap.

<br>

### [💡 Basic Training] Creating Obstacles
- Learn how to create obstacle entities that impede the player.
- Learn about the TriggerComponent's characteristics and how to use it.
- Create a necessary Component to fulfill the function of an obstacle.

<br>

### [💡 Basic Training] Spawning Obstacles
- Learn how to spawn obstacles at regular intervals and how to use them.
- Learn how to create the Component that's in charge of obstacle creation.

<br>

### [💡 Basic Training] Creating Score Items
- Learn how to create score items that make the player take risks.
- Learn about the collision settings via TriggerComponent.
- Learn how to create the generated entities as models.
- Implement a function that spawns score items at regular intervals.

<br>

### [💡 Basic Training] Implementing UI
- Learn how to display the current score to the player in the game.
- Learn how to display the time UI that shows the game's time left.
- Learn how to create the results UI that displays the game's results.

<br>

### [📖 Advanced Training] Learning About DataStorage
- Learn how to save the player's high score.
- Learn how to load the player's high score.
- Learn what to keep in mind when implementing the save and load functions.
