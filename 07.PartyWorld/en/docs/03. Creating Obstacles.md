## Entity Training
<p align="center">
<img src="../../_images/MSW-100_PartyGame_3_001.png" alt="MSW-100_PartyGame_3_001.png">
</p>

- Entities serve various functions in MapleStory Worlds.
- Implementing a character image and the ability to interact with it makes one an NPC.
- Implementing a character image and the ability to attack makes one a monster.
- Or implementing a function to manage the current map's settings without assigning an image makes one a Controller.
- Entities can be created and used in various ways.

<br>

### Composing Entities
- Entities are largely composed of its main body entity and the Component, where functions can be assigned.
- An entity by itself won't perform any function.
- If there is only a Component, there is no entity to perform the function, so the Component won't function.
- So when making an entity, you need to consider what you wish for one to do and what relationships it should have.

<br>

## Composing Obstacle Entities

<p align="center">
<img src="../../_images/MSW-100_PartyGame_3_005.png" alt="MSW-100_PartyGame_3_005.png">
</p>

- The sample world uses the Log_1, Log_2, and Log_3 entities as obstacles.
- These entities move from the top of the screen to the bottom in regular intervals once the game begins in the CoinRush map. When colliding with the player, it temporarily immobilizes the player character.
- Each entity has the following Components.
    - `TransformComponent`: The Component that determines the default position of an entity when one is created.
    - `SpriteRendererComponent`: The Component needed for the entity to display an image.
    - `TriggerComponent`: The Component needed to define the entity's collision area.
    - `TweenLineComponent`: The Component added to make sure that an entity moves from the top to the bottom at a specified speed and time.

<br>

#### What is a CollisionGroup?
<p align="center">
<img src="../../_images/MSW-100_PartyGame_3_012.png" alt="MSW-100_PartyGame_3_012.png">
</p>

- The CollisionGroup is an element that designates the group that detects collisions.
- It reduces the number of calculations needed by managing entities with the same properties into a singular group.
- It also reduces the number of unnecessary calculations by determining the collision check status between groups in advance.
- It is composed of **Default**, **TriggerBox**, and **HitBox** as a default. 
- The sample world additionally uses **Player**, **Coin**, and **Log**.
    - **Default**: A CollisionGroup that's not being used in the sample world.
    - **TriggerBox**: A CollisionGroup that's not being used in the sample world.
    - **HitBox**: A CollisionGroup that's not being used in the sample world.
    - **Player**: A CollisionGroup meant to be assigned to a player character.
    - **Coin**:: A CollisionGroup created to manage scoring items as a singular group.
    - **Log**: A CollisionGroup created to perform the role of colliding with the player as obstacles.

<br>

<p align="center">
<img src="../../_images/MSW-100_PartyGame_3_013.png" alt="MSW-100_PartyGame_3_013.png">
</p>

- Click `Add Collision Group` to create a new CollisionGroup.
- If there is an unnecessary CollisionGroup or if one is mistakenly created, click the `-` button on the right to delete it.
    - However, the **Default**, **TriggerBox**, and **HitBox** that are provided as a default can't be removed.

### Setting the Matrix

<p align="center">
<img src="../../_images/MSW-100_PartyGame_3_014.png" alt="MSW-100_PartyGame_3_014.png">
</p>

- The Matrix is an item that determines whether or not collision checks are performed between Collision Groups.
- If the box is un-checked, a collision between the relevant CollisionGroups will not be detected.
- To read a Matrix, you need to go from left to right one at a time like you're reading a book.
    - When you look over the Player, you can see that Player is requesting calculation status with Log, Coin, and Player.
    - Similar to other Collision Groups, you must configure whether or not collisions should be checked in each matrix by matching the elements from the left with the elements above, one by one.
- The Player will be forced to collide with Log and Coin in the Matrix.
- If all settings are complete, close the Collision Groups window and change the TriggerComponent's CollisionGroup to Log.
- Click DefaultPlayer under `Hierarchy` and change the TriggerComponent's CollisionGroup to Player.

- The sample world's Log has adjusted the following values, so it moves around itself.
    - **TweenType**: Uses Linear to make the movement speed consistent.
    - **Duration**: Enter 5 so that it moves to the destination over the course of 5 seconds.
    - **StopType**: Defined as One way, so only one movement happens when the obstacle is executed.
    - **DestinationCoordinateType**: The Relative was designed so that, when an entity's position is defined, it moves from that specified position.
    - **Positions**: The entity's position was placed on the top of the map and x = 0, y = -10 was applied to make it so that the entity moves from top to bottom.
    - **SyncType**: Define as ClientOnly to ensure it only executes in an app environment.

#### ⚠️ Notes on Using DestinationCoordinateType
- Absolute
    - Designated as absolute coordinates.
    - Moves to the specified position while ignoring the current entity's position.
    - You may see some unnatural movements if the entity's current position isn't designated as the starting point.
- Relative
    - Designated as relative coordinates.
    - Moves to the position registered to Position based on the current entity's coordinates.
    - Regardless of the starting position, it moves to the position that was +ed from its own position.

## Creating a PlayerCoinRushComponent
- This Component is designed to process the function when the player collides with various elements in the CoinRush map.
- This Component performs the processing needed when a collision with coins or obstacles happens in the sample world.

### Assigning a Component
<p align="center">
<img src="../../_images/MSW-100_PartyGame_3_017.png" alt="MSW-100_PartyGame_3_017.png">
</p>

- Click DefaultPlayer in the `Hierarchy` window.
- Click Add Component in the `Property` window.
- Click `New Component`, `New Component`and then register the Component with the name PlayerCoinRushComponent.
- Write the following content to PlayerCoinRushComponent.
```lua
@Component
script PlayerCoinRushComponent extends Component

property number playerScore = 0

property number timerID = 0

property number hitRecoveryTime = 1.0

@ExecSpace("ClientOnly")
method void AddCoinScore(number coinScore)
local event = GetCoinRushCoin()
event.CoinScoreValue = coinScore
self.Entity:SendEvent(event)
self.playerScore = self.playerScore + coinScore
end

@ExecSpace("ClientOnly")
method void PausePlayer()
if self.timerID ~= 0 then
	_TimerService:ClearTimer(self.timerID)
end
-- Temporarily pauses the player's MovementComponent.
self.Entity.MovementComponent.Enable = false
-- Converts the player's animation state.
local body = self.Entity.AvatarRendererComponent:GetBodyEntity()
local event = ActionStateChangedEvent("alert", "alert", 1, SpriteAnimClipPlayType.Loop)
body:SendEvent(event)
-- Removes the immobile state after a set duration.
self.timerID = _TimerService:SetTimerOnce(function()
	event = ActionStateChangedEvent("stand1", "stand1", 1, SpriteAnimClipPlayType.Loop)
	self.Entity.MovementComponent.Enable = true
end, self.hitRecoveryTime)
end

@ExecSpace("ClientOnly")
method void ResetScore()
self.playerScore = 0
end

@EventSender("Self")
handler HandleTriggerEnterEvent(TriggerEnterEvent event)
-- Determines whether the collided entity is a coin.
if isvalid(event.TriggerBodyEntity.CoinRushCoin) then
	-- Loads the Component related to coins.
	local coinComponent = event.TriggerBodyEntity.CoinRushCoin
	-- Delivers the player's AddCoinScore with the received value.
	self:AddCoinScore(coinComponent:GetCoinValue())
end
end

@EventSender("Self")
handler HandleTriggerEnterEvent2(TriggerEnterEvent event)
-- If the target they collide with is a CoinRush wooden log, it temporarily immobilizes the player.
if self.Entity.CurrentMapName == "CoinRush" then
	if  event.TriggerBodyEntity.Name ~= "Coin"then
	self:PausePlayer()
	-- Displays the hit taken effect.
	_EffectService:PlayEffect("e9175650f9c0425e96333602842080cd", self.Entity, self.Entity.TransformComponent.WorldPosition, 0, Vector3.one, false)
	-- Plays the damage taken sound effect.
	_SoundService:PlaySound("849328dbd156473099f90b12d36b667e", 1.0)
	-- The wooden log they collide with will be deactivated.
	event.TriggerBodyEntity.Enable = false
	end
end
end

end
```

> This code is written based on Plain Text.

## Minimum Implementation Standards
- Compose an entity that will be used as an obstacle against the player.
- Compose a function that will immobilize the player for a specified duration when the player collides with the entity.
- Design the entity composition to allow it to move to a position that it determines itself.
<br>

## Usage and Extension Direction
- Compose various obstacles by making a wide variety of entities.
- Change the TweenLine composition so that obstacles can approach players in various ways.
