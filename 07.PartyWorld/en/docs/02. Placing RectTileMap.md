## Understanding Map Types
<p align="center">
<img src="../../_images/MSW-100_PartyGame_2_001.png" alt="MSW-100_PartyGame_2_001.png">
</p>

> You can select various map types following the rules of the map you're trying to create.

- MapleStory Worlds provides various map formats.
- The creator can select the specified map in accordance with the world format that's being made and create it.

<br>

### TileMap

<p align="center">
<img src="../../_images/MSW-100_PartyGame_2_002.png" alt="MSW-100_PartyGame_2_002.png">
</p>

- A map format that is designated as the default when creating a world for the first time in MapleStory Worlds.
- A world that is best suited for the feel of MapleStory.
- Formulate a map by utilizing Tiles provided by MapleStory Worlds to create platforms and place entities.
- Create a ramp based on how the tiles are placed.
- A useful map format when you want to make a side scrolling-type game reminiscent of MapleStory.
<br>

### RectTileMap
<p align="center">
<img src="../../_images/MSW-100_PartyGame_2_003.png" alt="MSW-100_PartyGame_2_003.png">
</p>

- A map format that is effective in making top-down view type games.
- Create your own TileSet or use the TileSet resources provided by MapleStory Worlds to formulate a map.
- You can formulate a map by placing tiles in a gridded format.
- You can create mobile and immobile areas with individual tiles.
- Create a game where you can move in 4 or 8 directions, unlike with the TileMap and SideViewRectTileMap methods.
<br>

### SideViewRectTileMap
<p align="center">
<img src="../../_images/MSW-100_PartyGame_2_004.png" alt="MSW-100_PartyGame_2_004.png">
</p>

- A map format that is effective in making side scrolling-type games.
- Create your own TileSet or use the TileSet resources provided by MapleStory Worlds to formulate a map.
- You can formulate a map by placing tiles in a gridded format.
- Unlike RectTileMap, characters can **pass through** the TileSet that prevents movement.
- So if you formulate a map with SideViewRectTileMap, the TileSet that prevents movement must be used to create **platforms**.

<br>

## Understanding BodyComponent

<p align="center">
<img src="../../_images/MSW-100_PartyGame_2_005.png" alt="MSW-100_PartyGame_2_005.png">
</p>

- MapleStory Worlds uses a physics engine based on various maps.
- There is a Body Component that's required for each of the 3 maps.
- RigidbodyComponent, KinematicbodyComponent, and SideviewbodyComponent respond to each map type.

<br>

### ⚠️ If There Is No Body Component
<p align="center">
<img src="../../_images/MSW-100_PartyGame_2_006.png" alt="MSW-100_PartyGame_2_006.png">
</p>

- If there is no bodyComponent that responds to the map that the entity currently exists in, normal functions will not take place.
- There may not be interactions with the foothold Tile that's placed on the map.
- If there is no Body Component that responds to the Player's DefaultPlayer setting, it displays an error message, and the character will be frozen.
- So for entities that need to interact with the map's Tile, a Body Component that responds to the map that's being currently edited must be assigned to them.

<br>

### RigidBodyComponent

<p align="center">
<img src="../../_images/MSW-100_PartyGame_2_007.png" alt="MSW-100_PartyGame_2_007.png">
</p>


- Controls the character's physics with MapleStory Worlds's TileMap method.
- If the map is a TileMap but doesn't have a RigidBodyComponent, the character and tiles will not interact.
- Provides various physics property values that control the jumps, gravity, and more for characters within RigidBodyComponent.
- The target values can be changed to change the physics methods.
<br>

### KinematicBodyComponent

<p align="center">
<img src="../../_images/MSW-100_PartyGame_2_008.png" alt="MSW-100_PartyGame_2_008.png">
</p>

- Controls the character's physics for the MapleStory Worlds's RectTileMap type.
- If the map is RectTileMap but there is no KinematicBodyComponent, no interactions will happen with the RectTileMap tiles.
- You can adjust the speed, jump availability, shadow status, etc. for characters within KinematicBodyComponent.
<br>

### SideViewRectTileMap

<p align="center">
<img src="../../_images/MSW-100_PartyGame_2_009.png" alt="MSW-100_PartyGame_2_009.png">
</p>

- Controls the character's physics if MapleStory Worlds is using the SideViewRectTileMap method.
- If this component doesn't exist, the character won't be able to interact with the map's tiles.
- Controls the character's jump speed and gravitational acceleration.

<br>

## Changing Map Formats

<p align="center">
<img src="../../_images/MSW-100_PartyGame_2_010.png" alt="MSW-100_PartyGame_2_010.png">
</p>

- Right-click the map you want to change from the Hierarchy window.
- Click Switch To RectTileMap or Switch To SideViewRectTileMap.
    - If the current map isn't a TileMap, Swith To TileMap will be visible, and the conversion to the current map state will be hidden.
- The sample world's CoinRush map is created with a RectTileMap, so you can click Switch to RectTileMape to change it.

### Placing a RectTileMap

<p align="center">
<img src="../../_images/MSW-100_PartyGame_2_011.png" alt="MSW-100_PartyGame_2_011.png">
</p>

- You need a TileSet to compose a RectTileMap.
- The TileSet is a kind of palette that holds a number of Tiles in a single space.
- Creators can place Tiles like paint onto a single palette and select the Tile of choice to then stamp them on the map.

<p align="center">
<img src="../../_images/MSW-100_PartyGame_2_012.png" alt="MSW-100_PartyGame_2_012.png">
</p>

- Click the `+` button in the TileSet edit window while in RectTileMap mode.
- Use the resources provided by MapleStory Worlds and click `Create TileSet From Template` to create a TileSet.
- Select the resources from the extended menu to create a TileSet.

<p align="center">
<img src="../../_images/MSW-100_PartyGame_2_013.png" alt="MSW-100_PartyGame_2_013.png">
</p>

- If the creation was completed normally, then the Tile list will be visible in the TileSet edit window.

<p align="center">
<img src="../../_images/MSW-100_PartyGame_2_014.png" alt="MSW-100_PartyGame_2_014.png">
</p>

- Select the TileSet's Tiles and place it in the Scene to compose a map.

<br>

### Changing the Tile Properties

- When placing Tiles, you may want to have some areas that can't be reached by the players.
- You can implement this by changing the Tile's properties.

<p align="center">
<img src="../../_images/MSW-100_PartyGame_2_015.png" alt="MSW-100_PartyGame_2_015.png">
</p>

- Click the pencil button in the TileSet edit window.
- Click `Movability`.
- Click the green cross icon on the Tile for which you want to disable movability so that it becomes a **red** cross icon.

<br>

## Editing KinematicbodyComponent
- Proceed with editing the KinematicbodyComponent, which is a Component needed to interact with RectTileMap.
- Edit each value to match the map properties with the world that is being created, so they can be used.

<p align="center">
<img src="../../_images/MSW-100_PartyGame_2_016.png" alt="MSW-100_PartyGame_2_016.png">
</p>

- KinematicbodyComponent
    - **SpeedFactor**: The value that controls the character's speed. Control the horizontal or vertical speed based on the X and Y values.
    - **EnableJump**: Determines whether or not characters can jump. If this value is un-checked, the character won't be able to jump.
    - **JumpSpeed**: Control the character's jump speed. The larger the value, the higher and faster the character can jump.
    - **JumpDrag**: Control the character's gravitational acceleration. The smaller the value, the weaker gravity becomes, which makes the character return to the ground more slowly.
    - **ApplyClimbableRotation**: A value that determines whether or not the character is spun when the character interacts with elements like ladders and ropes based on whether the ladder or rope is rotated.
    - **EnableShadow**: Determines whether or not the character shadow is visible. When the value is removed, the character's shadow is removed.
    - **ShadowColor**: Change the color of the shadow.
    - **ShadowOffset**: Change the display position of the shadow.
    - **ShadowSize**: Define the size of the shadow.
    - **ShadowScalingRatio**: Change how much the shadow shrinks when the character jumps. The smaller the value, the smaller the shadow becomes.
    - **EnableTileCollision**: The character will be able to **ignore** RectTileMap tiles that prevent movement.

## Minimum Implementation Standards
- Create at least 1 map where the player can play a mini game.
- Compose a map so that even when the player character enters a map with a different format, they can interact with Tiles placed on the map.

<br>

## Usage and Extension Direction
- Utilize various map formats for each mini game to create mini games.
- Implement the function so that the Body Component values, which are in charge of the physics based on the composition and rules of various maps, can be edited.
