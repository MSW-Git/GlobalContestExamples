## Composing UI

<p align="center">
<img src="../../_images/MSW-100_PartyGame_6_001.png" alt="MSW-100_PartyGame_6_001.png">
</p>

- The UI displays information to the player in a quickly changing world environment.
- Provide a variety of information visually, such as the player character's remaining HP, cooldowns, enemy HP, and more.
- A good UI will allow the player to view information quickly and efficiently.
- But if there is no UI or if there's an unnecessary UI element, it will be too cluttered to convey information effectively.
- So, when designing the UI, you must consider proper placement, ratio settings, color contrast, and other such elements.

<br>

### Creating UI Entities

<p align="center">
<img src="../../_images/MSW-100_PartyGame_6_004.png" alt="MSW-100_PartyGame_6_004.png">
</p>

- Right-click the UI Group that's being edited from `Hierarchy`.
- Click `Create Entity` and `Create UIEmpty` to create an empty UI entity.

<p align="center">
<img src="../../_images/MSW-100_PartyGame_6_005.png" alt="MSW-100_PartyGame_6_005.png">
</p>

- Unlike the existing MapEmpty, UIEmpty doesn't have a `TransformComponent`.
- Instead, it has a `UITransformComponent`.
- `UITransformComponent` has the following properties.
    - There is an **Anchor** setting that can define what will be the center of the screen.
    - Following the **Anchor** settting, you can define the PosX, PosY, Width, and Height values or adjust the Left, Right, Center, and Bottm values to control the entity's position and size.
    - Use **Pivot** to change the center of the UI image.
    - Use the **ActivePlatform** value to detemine whether the UI will only be visible on PC, only on mobile, or on both platforms.

<br>

#### Displaying UI Images

<p align="center">
<img src="../../_images/MSW-100_PartyGame_6_006.png" alt="MSW-100_PartyGame_6_006.png">
</p>

- `SpriteGUIRendererComponent` is used to display an image in the UI.
- Enter the resource ID into ImageRUID to select the image, similar to `SpriteRendererComponent`.
- ⚠️ `SpriteRendererComponent` VS `SpriteGUIRendererComponent`
    - `SpriteRendererComponent` is a Component that's used to display images in the map.
    - **Displaying** `SpriteRendererComponent` images can can be **halted** depending on **character movement**.
    - `SpriteGUIRendererComponent` will not disappear even if the character moves.
    - The display location and size of `SpriteGUIRendererComponent` can change based on the screen size.

<br>

#### Ouputting Text

<p align="center">
<img src="../../_images/MSW-100_PartyGame_6_007.png" alt="MSW-100_PartyGame_6_007.png">
</p>

- If text needs to be displayed in the UI, use `TextGUIRendererComponent` to display text.
- Enter the text you want to display in Text.
- Control the size of the text with FontSize.
- Change the color of the text with FontColor.

### Composing CoinRushUI

<p align="center">
<img src="../../_images/MSW-100_PartyGame_6_008.png" alt="MSW-100_PartyGame_6_008.png">
</p>

- **ScoreFrame**: Uses SpriteGUIRendererComponent to display the scoreboard.
- **ScoreText**: Uses TextGUIRendererComponent to display the current score on the scoreboard.
- CoinRushUI has a CoinRushUIController Component to manage its own elements.
- The following is the CoinRushUIController code.

```lua
@Component
script CoinRushUIController extends Component

property TextGUIRendererComponent scoreText = nil

property number currentScore = 0

@ExecSpace("ClientOnly")
method void OnBeginPlay()
self:InitScoreText()
end

@ExecSpace("ClientOnly")
method void InitScoreText()
-- Determines whether scoreText is in a nil state.
if not isvalid(self.scoreText) then
	-- Searches for and registers scoreText if it is in a nil state.
	local findTextEntity = _EntityService:GetEntityByPath("/ui/CoinRushUI/ScoreFrame/ScoreText")
	-- Determines whether the entity is found.
	if isvalid(findTextEntity) then
		-- If an entity is normally found, registers findTextEntity's TextGUIRendererComponent.
		local findTextComponent = findTextEntity.TextGUIRendererComponent
		-- Verifies whether TextGUIRendererComponent was found normally.
		if isvalid(findTextComponent) then
			-- Registers the found findTextComponent to scoreText.
			self.scoreText = findTextComponent
		else
			-- Generates an error log and halts code execution since TextGUIRendererComponent wasn't found normally.
			log_warning("Couldn't find ScoreText's TextGUIRendererComponent!")
			return
		end
	else
		log_warning("The ScoreText entity wasn't found!")
		return
	end
end
end

@ExecSpace("ClientOnly")
method void ResetScoreUI()
self.scoreText.Text = "0"
self.currentScore = 0
self.Entity.Enable = true
end

@EventSender("LocalPlayer")
handler HandleGetCoinRushCoin(GetCoinRushCoin event)
self.currentScore = self.currentScore + event.CoinScoreValue
self.scoreText.Text = string.format("Score : %d", self.currentScore)
end

end
```

> This code is written based on Plain Text.

- The function is designed to update the score on the UI when the LocalPlayer obtains a scoring item.

### Composing TimerUI

<p align="center">
<img src="../../_images/MSW-100_PartyGame_6_009.png" alt="MSW-100_PartyGame_6_009.png">
</p>

- **Timer_3**, **Timer_2**, **Timer_1**, **Timer_0**: Uses `SpriteGUIRendererComponent` for the countdown effect before the mini game starts.
- **StartButton**: Uses `SpriteGUIRendererComponent` to compose the start button's frame.
- **StartBUttonText**: Uses `TextGUIRendererComponent` to display the start button's name.
- **TimerFrame**: Uses `SpriteGUIRendererComponent` to compose a frame to display the remaining time.
- **TimerText**: Uses `TextGUIRendererComponent` to display the time left in text.
- TimerUI has a TimerUIController Component to manage its own elements.
- The following is the TimerUIController Component code.

```lua
@Component
script TimerUIController extends Component

property table timerEntity = {}

property string countSoundEffectID = "5dc17871a4e749e093beef9ab1096243"

property string startSoundEffectID = "9925041d48474aeeab6df6e0c4368097"

property Entity startButton = nil

property TextGUIRendererComponent timerText = nil

property Entity timerFrame = nil

@ExecSpace("ClientOnly")
method void OnBeginPlay()
    -- Assigns the child entities in an array from 1 to 4.
    for i = 1, 4 do
        local entityName = "Timer_"..(i - 1)
        local findEntity = self.Entity:GetChildByName(entityName)
        
        if isvalid(findEntity) then
            self.timerEntity[i] = findEntity
            -- All Count Images Deactivated at Starting Point
            findEntity.Enable = false
        else
            log("Could not find " .. entityName .. ". Please check the hierarchy structure.")
        end
    end
-- Searches for and registers the entity if StartButton is nil.
if not isvalid(self.startButton) then
	local findEntity = self.Entity:GetChildByName("StartButton", true)
	if isvalid(findEntity) then
		self.startButton = findEntity
		self.startButton.Enable = false
	end
end
-- Searches for and registers timerEntity if timerEntity is nil.
if not isvalid(self.timerFrame) then
	local findEntity = self.Entity:GetChildByName("TimerFrame", true)
	if isvalid(findEntity) then
		self.timerFrame = findEntity
		self.timerFrame.Enable = false
	end
end


-- Searches for and registers timerText if timerText is nil.
if not isvalid(self.timerText) then
	local findEntity = self.Entity:GetChildByName("TimerText", true)
	if isvalid(findEntity) then
		self.timerText = findEntity.TextGUIRendererComponent
	end
end
end

@ExecSpace("ClientOnly")
method void StartTimer()
self.Entity.Enable = true
local localPlayer = _UserService.LocalPlayer
if not isvalid(localPlayer) then return end

-- Set the timer meant to check game time.
_TimerLogic:SetTimer(60)
    
-- Temporarily restricts player movement.
localPlayer.MovementComponent.Enable = false
    
-- Starts a countdown.
for countNumber = 4, 1, -1 do
	local target = self.timerEntity[countNumber]
        
	if isvalid(target) then
		-- 1. Activates the current number entity.
		target.Enable = true
            
		-- 2. Plays the sounds.
		if countNumber > 1 then
    		_SoundService:PlaySound(self.countSoundEffectID, 1.0)
		else
			_SoundService:PlaySound(self.startSoundEffectID, 1.0)    
		end
            
		-- 3. Stands by for 1 second.
		wait(1.0)
            
		-- 4. Deactivates the current number.
		if isvalid(target) then
			target.Enable = false
		end
	end
end
    
-- Allows player movement again.
localPlayer.MovementComponent.Enable = true
-- Activates the timer UI.
self.timerFrame.Enable = true
-- Activates the timer.
_TimerLogic:StartTimer()

end

@ExecSpace("ClientOnly")
method void ShowTimerUI()
self.startButton.Enable = true
self.timerFrame.Enable = false
-- Converts the timer effect entity into an inactive state.
for i = 1, #self.timerEntity do
	self.timerEntity[i].Enable = false
end
end

@ExecSpace("ClientOnly")
method void OnUpdate(number delta)
-- Halts code execution if there is no active timer.
if not _TimerLogic.isRunning then
	return
end

local time = _TimerLogic.remainTime
local min = math.floor(time / 60)
local sec = _TimerLogic.remainTime % 60
self.timerText.Text = string.format("%02d:%02d", min, sec)
end

@ExecSpace("ClientOnly")
@EventSender("Entity", "8708457c-646e-469d-95a5-c10703f14ed4")
handler HandleButtonClickEvent(ButtonClickEvent event)
self.startButton.Enable = false
self:StartTimer()
end

end
```

> This code is written based on Plain Text.

- The sample world uses the Logic that is in charge of calculating the time left.

<p align="center">
<img src="../../_images/MSW-100_PartyGame_6_010.png" alt="MSW-100_PartyGame_6_010.png">
</p>

- Right-click `Hierarchy` and `MyDesk`.
- Create a Logic via `Create Scripts` and `Create Logic`.
- Declare the name of the created Logic to be TimerLogic.
- The following is the TimerLogic code.

```lua
@Logic
script TimerLogic extends Logic

property number remainTime = 0

property boolean isRunning = false

@ExecSpace("ClientOnly")
method void StartTimer()
-- Changes the timer's activation status to activated.
self.isRunning = true

-- Tests whether the current map is CoinRush and launches the game if the current map is CoinRush.
local localPlayer = _UserService.LocalPlayer
if localPlayer.CurrentMapName == "CoinRush" then
	local coinRushController = _EntityService:GetEntityByPath("/maps/CoinRush/CoinRushController")
	coinRushController.CoinRushController:StartGame()
	local coinRushUI = _EntityService:GetEntityByPath("/ui/CoinRushUI")
	coinRushUI.CoinRushUIController:ResetScoreUI()
	
end

-- Decreases the time using loops.
while self.remainTime > 0 and self.isRunning do
	wait(1.0)
	self.remainTime = self.remainTime - 1
end

-- Requests that the results UI be displayed if the time runs out.
if self.isRunning then
	self.isRunning = false
	localPlayer.MovementComponent.Enable = false
	local coinRushController = _EntityService:GetEntityByPath("/maps/CoinRush/CoinRushController")
	coinRushController.CoinRushController:FinishGame()
	local resultUI = _EntityService:GetEntityByPath("/ui/ResultUI")
	resultUI.ResultUIController:ShowResultUI(localPlayer.PlayerCoinRushComponent.playerScore)
end
end

@ExecSpace("ClientOnly")
method void SetTimer(number SetTime)
self.remainTime = SetTime
end

end
```

> This code is written based on Plain Text.

### Composing ResultUI

<p align="center">
<img src="../../_images/MSW-100_PartyGame_6_011.png" alt="MSW-100_PartyGame_6_011.png">
</p>

- **NonClickBG**: The UI created with SpriteGUIRendererComponent to prevent the results UI from touching the UI behind it when the results UI is displayed.
- **ResultText**: The UI created with TextGUIRendererComponent to assign the title of the UI.
- **ResultFrame**: Uses SpriteGUIRendererComponent necessary for the frame to display the final score.
- **ResultScoreText**: Uses TextGUIRendererComponent to display the final score.
- **ReturnButton**: Uses SpriteGUIRendererComponent to display the button of the image needed to move to the sample world based map.
- **TextComponent**: Uses TextGUIRendererComponent to display the name of the return button.
- ResultUI uses TextGUIRendererComponent to manage its own elements.
- The following is the ResultUIController code.

```lua
@Component
script ResultUIController extends Component

property TextGUIRendererComponent resultText = nil

@ExecSpace("ClientOnly")
method void OnBeginPlay()
self:InitResultText()
end

@ExecSpace("ClientOnly")
method void InitResultText()
-- Searches for and registers resultText if resultText is nil.
if not isvalid(self.resultText) then
	local findEntity = self.Entity:GetChildByName("ResultScoreText", true)
	if isvalid(findEntity)then
		self.resultText = findEntity.TextGUIRendererComponent
	end
end
end

@ExecSpace("ClientOnly")
method void ShowResultUI(number ResultValue)
local playerProfileID = _UserService.LocalPlayer.PlayerComponent.ProfileCode
if ResultValue > _DataStorageLogic.clientBestScore then
	_DataStorageLogic:RequestSaveScore(playerProfileID, ResultValue)
	self.resultText.Text = _LocalizationService:GetTextFormat("UI_Result", ResultValue, ResultValue)
else
	self.resultText.Text = _LocalizationService:GetTextFormat("UI_Result", ResultValue, _DataStorageLogic.clientBestScore)
end
self.Entity.Enable = true
end

@ExecSpace("ClientOnly")
@EventSender("Entity", "03be7e6d-2983-4972-a95e-10bad9a57892")
handler HandleButtonClickEvent(ButtonClickEvent event)
-- Loads the player entity.
local findLocalPlayer = _UserService.LocalPlayer
-- Deactivates the UI after loading TimerUI.
local timerUI = _EntityService:GetEntityByPath("/ui/TimerUI")
timerUI.Enable = false
-- Deactivates the UI after loading CoinRushUI.
local coinRushUI = _EntityService:GetEntityByPath("/ui/CoinRushUI")
coinRushUI.CoinRushUIController:ResetScoreUI()
coinRushUI.Enable = false
-- Moves the player to the game selection map.
findLocalPlayer.MovementComponent.Enable = true
findLocalPlayer.PlayerTeleportComponent:RequestPlayerChoiceMap(findLocalPlayer)
self.Entity.Enable = false
end

end
```

> This code is written based on Plain Text.

### Displaying the UI when Moving Maps

<p align="center">
<img src="../../_images/MSW-100_PartyGame_6_012.png" alt="MSW-100_PartyGame_6_012.png">
</p>

- Creates and uses an InteractionPortal Component for portal entities so that, when the player uses the sample world's portal, it's detected and the UI is updated.
- The following is the INteractionPortal code.

```lua
@Component
script InteractionPortal extends Component

@EventSender("Self")
handler HandlePortalUseEvent(PortalUseEvent event)
-- Activates the TimerUI if portals are used.
if event.PortalUser == _UserService.LocalPlayer then
	local timerUI = _EntityService:GetEntityByPath("/ui/TimerUI")
	event.PortalUser.PlayerCoinRushComponent:ResetScore()
	timerUI.Enable = true
	timerUI.Visible = true
	timerUI.TimerUIController:ShowTimerUI()
	-- Changes the background music.
	_SoundService:PlayBGM("ae1e81ea94f5421580ecbdf1b0fddfaf", 1.0)
end

end

end
```

> This code is written based on Plain Text.
