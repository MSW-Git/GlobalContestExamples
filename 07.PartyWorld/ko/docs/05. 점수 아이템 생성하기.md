- 이는 플레이어가 월드에 대한 흥미를 빠르게 잃게 되는 원인이 됩니다.
- 따라서 샘플 월드에서는 플레이어가 위험 요소인 장애물을 극복해야 하는 목적으로 점수 아이템을 사용하고 있습니다.

### 점수 아이템 엔티티의 구성

<p align="center">
<img src="../../_images/MSW-100_PartyGame_5_002.png" alt="MSW-100_PartyGame_5_002.png">
</p>

- 점수 아이템의 엔티티는 다음과 같은 Component를 구성 요소로 가지고 있습니다.
    - **TransformComponent**: 엔티티의 위치를 지정하기 위한 Component입니다.
    - **SpriteRendererComponent**: 점수 아이템의 이미지를 출력하기 위한 Component입니다.
    - **TriggerComponent**: 점수 아이템이 플레이어와 충돌을 인지하도록 기능을 구성합니다.
    - **CoinRushCoin**: 점수 아이템이 가지는 점수를 반환하거나 위치를 지정하는 기능을 수행하기 위한 제작 Component입니다.
- SpriteRendererComponent의 SpriteRUID 값을 변경하여 점수 아이템의 이미지를 등록합니다.
- TriggerComponent의 값을 수정하여 등록한 이미지의 크기에 맞춰 충돌 범위를 수정합니다.
    - CollisionGroup을 Coin으로 변경합니다.
    - IsPassive를 체크하여 충돌 연산을 줄입니다.
- 이어서 CoinRushCoin의 코드를 다음과 같이 작성합니다.

```lua
@Component
script CoinRushCoin extends Component

property number coinValue = 10

@ExecSpace("ClientOnly")
method void DisableCoin()
-- 코인이 충돌되었을 때 코인이 비활성화되도록 기능을 수행합니다.
self.Entity.Enable = false
end

@ExecSpace("ClientOnly")
method number GetCoinValue()
-- coinValue를 반환합니다.
self:DisableCoin()
return self.coinValue
end

@ExecSpace("ClientOnly")
method void SetCoinPosition(Vector3 SetPosition)
-- 코인의 위치를 전달받은 위치로 변환합니다.
self.Entity.TransformComponent.WorldPosition = SetPosition
-- 코인의 상태를 활성화합니다.
self.Entity.Enable = true
end

end
```

> 해당 코드는 Plain Text를 기준으로 작성된 코드입니다.

### Model 제작하기
- 제작한 엔티티는 반복적으로 사용하기 위한 Model로 제작할 수 있습니다.
- Model은 동일한 구조, 형식을 사용하는 엔티티를 매번 제작할 필요 없이 Model로 제작한 엔티티를 복제하여 사용할 수 있도록 합니다.

<p align="center">
<img src="../../_images/MSW-100_PartyGame_5_003.png" alt="MSW-100_PartyGame_5_003.png">
</p>

- Model로 제작하려는 엔티티를 마우스 우클릭한 뒤 `Create Model From Entity`를 클릭하여 Model로 제작할 수 있습니다.

### Event 등록하기

- Event는 특정한 주체가 어떤 사건이 일어났음을 알리는 기능입니다.
- 해당 주체를 구독하고 있는 상태에서 이벤트가 발동했을 경우, 해당 엔티티를 바라보고 있던 Event Handler가 이를 수신하여 기능을 수행합니다.
- 메이플스토리 월드에서는 원하는 Event를 생성할 수 있습니다.

<p align="center">
<img src="../../_images/MSW-100_PartyGame_5_004.png" alt="MSW-100_PartyGame_5_004.png">
</p>

- `Hierarchy`에서 `MyDesk`를 마우스 우클릭합니다.
- `Create Scripts`를 클릭한 뒤 `Create EventType`을 클릭합니다.
- 생성된 Event의 이름을 GetCoinRushCoin으로 선언합니다.

<br>

#### Event의 기능
<p align="center">
<img src="../../_images/MSW-100_PartyGame_5_005.png" alt="MSW-100_PartyGame_5_005.png">
</p>

- 생성한 Event는 이름 자체가 하나의 Key 역할을 수행합니다.
- 이벤트가 발생했을 때 어떤 이벤트인지 구분하는 기준을 Event의 이름이 수행합니다.
    - 제작한 Event인 GetCoinRushCoin의 경우 GetCoinRushCoin이 Key의 역할을 수행합니다.
- 제작한 Event 내에 Property, Method를 등록하여 필요한 기능을 수행, 필요한 값을 등록하여 전달하는 역할로 수행할 수 있습니다.
- 샘플 월드의 경우 습득한 점수 아이템의 점수를 전달하기 위해 CoinScoreValue라는 값을 사용하고 있습니다.

### CoinRushCoin 코드 작성하기

- CoinRushCoin에서 StartGame을 수신하면 이에 맞춰 점수 아이템이 스폰 되도록 기능을 수정해야 합니다.
- 코드를 아래와 같이 수정하여 점수 엔티티가 생성될 수 있도록 기능을 수정합니다.
- 아래는 CoinRushController의 코드 전문입니다.

```lua
@Component
script CoinRushController extends Component

property table coinModel = {}

property number coinSpawnDelay = 5

property string coinModelID = "model://1433b985-a5dc-496f-9b67-5c4ed6883bb2"

property number coinSpawnCount = 10

property number coinTimerID = 0

property number logCallTimer = 5.0

property number specialLogTime = 3

property number specialLogTimeCount = 0

property integer logTimerID = 0

property table logTable = {}

@ExecSpace("ClientOnly")
method void OnBeginPlay()
self:InitCoinModel()
self:InitLog()
end

@ExecSpace("ClientOnly")
method void InitCoinModel()
-- coinModel이 빈 상태인지 점검합니다.
if not isvalid(self.coinModel) or not next(self.coinModel) then
	-- 비어 있는 상태일 경우 새롭게 코인 모델을 제작합니다.
	for i=1, self.coinSpawnCount do
		-- coinModelID를 통해 Model을 복제합니다.
		local spawnModel = _SpawnService:SpawnByModelId(self.coinModelID, "Coin", Vector3.zero, self.Entity)
		-- 생성한 Model을 비활성화 합니다.
		spawnModel.CoinRushCoin:DisableCoin()
		-- coinModel에 Model을 추가합니다.
		self.coinModel[i] = spawnModel
	end
end
end

@ExecSpace("ClientOnly")
method void InitLog()
-- 통나무의 개수만큼 반복문을 실행합니다.
for i = 1, 3 do
	-- 경로를 각 통나무의 이름에 맞춰 호출합니다.
	local entityName = "/maps/CoinRush/Log_"..i
	-- 경로를 기준으로 각 통나무 엔티티를 찾습니다.
	local findEntity = _EntityService:GetEntityByPath(entityName)
	if isvalid(findEntity) then
		self.logTable[i] = findEntity
	end
end
end

@ExecSpace("ClientOnly")
method void CheckLeftCoin()
-- 미리 코인 재생산이 필요한 상태로 값을 등록합니다.
local needRespawn = true
-- 남은 사용 가능한 코인이 있는지 점검합니다.
for i = 1, #self.coinModel do
	---@type Entity
	if self.coinModel[i].Enable then
		needRespawn = false
		break
	end
end
-- 만약 needRespawn이 true일 경우 재생산을 예약합니다.
if needRespawn then
	self.coinTimerID = _TimerService:SetTimerOnce(function()
	self:ReservationCoinSpawn()	
	end, self.coinSpawnDelay)
end
end

@ExecSpace("ClientOnly")
method void SpawnCoin(number coinNumber)
-- 맵의 범위에 맞춰 랜덤한 X 위치값을 가져옵니다.
local randPosX = _UtilLogic:RandomIntegerRange(-200, 200)
-- 실제 좌표와 맞추기 위해 100을 나눈 몫 값을 사용합니다.
randPosX = randPosX / 100
-- 맵의 범위에 맞춰 랜덤한 Y 위치값을 가져옵니다.
local randPosY = _UtilLogic:RandomIntegerRange(-150, 250)
-- 실제 좌표와 맞추기 위해 100을 나눈 몫 값을 사용합니다.
randPosY = randPosY / 100
-- 생성한 좌표를 Vector3로 설정합니다.
local SetVector3 = Vector3(randPosX, randPosY, 0)
-- 코인의 위치를 생성한 좌표로 지정합니다.
self.coinModel[coinNumber].CoinRushCoin:SetCoinPosition(SetVector3)
end

@ExecSpace("ClientOnly")
method void ReservationCoinSpawn()
for i = 1, #self.coinModel do
	self:SpawnCoin(i)
end
end

@ExecSpace("ClientOnly")
method void StartLogLogic()
-- logTimerID가 0이 아닐 경우 초기화를 시도합니다.
if self.logTimerID ~= 0 then
	_TimerService:ClearTimer(self.logTimerID)
	self.logTimerID = 0
end
-- 통나무가 스폰 될 수 있도록 TimerService를 활용합니다.
self.logTimerID = _TimerService:SetTimerRepeat(function()
	self:SpawnLog()
end, self.logCallTimer, self.logCallTimer)
end

@ExecSpace("ClientOnly")
method void SpawnLog()
if self.specialLogTimeCount >= self.specialLogTime then
	-- 통나무 1개를 설정합니다.
	local firstLogPos = _UtilLogic:RandomIntegerRange(1, 3)
	-- 다른 통나무 1개를 처음 뽑은 통나무와 다른 번호로 뽑습니다.
	local secondLogPos = 0
	repeat
		secondLogPos = _UtilLogic:RandomIntegerRange(1, 3)
	until secondLogPos ~= firstLogPos
	-- 선택된 2개의 통나무를 활성화 한 뒤 재생시킵니다.
	self.logTable[firstLogPos].Enable = true
	self.logTable[secondLogPos].Enable = true
	self.logTable[firstLogPos].TweenLineComponent:Stop(true)
	self.logTable[firstLogPos].TweenLineComponent:Play()
	self.logTable[secondLogPos].TweenLineComponent:Stop(true)
	self.logTable[secondLogPos].TweenLineComponent:Play()
	-- 일정 시간이 지나면 자동으로 통나무를 비활성화 시키도록 Timer를 설정합니다.
	_TimerService:SetTimerOnce(function()
		self.logTable[firstLogPos].TweenLineComponent:Stop(true)
		self.logTable[secondLogPos].TweenLineComponent:Stop(true)
		self.logTable[firstLogPos].Enable = false
		self.logTable[secondLogPos].Enable = false
	end, self.logTable[firstLogPos].TweenLineComponent.Duration)
	self.specialLogTimeCount = 0
else
	-- 통나무 1개를 설정합니다.
	local firstLogPos = _UtilLogic:RandomIntegerRange(1, 3)
	-- 선택된 통나무를 재생시킵니다.
	self.logTable[firstLogPos].Enable = true
	self.logTable[firstLogPos].TweenLineComponent:Stop(true)
	self.logTable[firstLogPos].TweenLineComponent:Play()
	-- 특수 통나무 카운트를 1개 상승시킵니다.
	self.specialLogTimeCount = self.specialLogTimeCount + 1
	-- 일정 시간이 지나면 자동으로 통나무를 비활성화 시키도록 Timer를 설정합니다.
	_TimerService:SetTimerOnce(function()
		self.logTable[firstLogPos].TweenLineComponent:Stop(true)
		self.logTable[firstLogPos].Enable = false
	end, self.logTable[firstLogPos].TweenLineComponent.Duration)
end
end

@ExecSpace("ClientOnly")
method void StartGame()
self:StartLogLogic()
self:ReservationCoinSpawn()
end

@ExecSpace("ClientOnly")
method void FinishGame()
-- 코인 모델들을 모두 비활성화합니다.
for i = 1, #self.coinModel do
	self.coinModel[i].Enable = false
end
-- 통나무 모델들을 모두 비활성화합니다.
for i = 1, #self.logTable do
	self.logTable[i].TweenLineComponent:Stop(true)
	self.logTable[i].Enable = false
end
-- 예약해둔 타이머 이벤트를 모두 해제합니다.
_TimerService:ClearTimer(self.coinTimerID)
_TimerService:ClearTimer(self.logTimerID)
end

@EventSender("LocalPlayer")
handler HandleGetCoinRushCoin(GetCoinRushCoin event)
self:CheckLeftCoin()
end

end
```

> 해당 코드는 Plain Text로 작성된 코드입니다.

## Model을 사용하는 이유

<p align="center">
<img src="../../_images/MSW-100_PartyGame_5_007.png" alt="MSW-100_PartyGame_5_007.png">
</p>

- 반복적으로 사용되는 엔티티를 매번 스크립트로 생성하고 Component를 부여하는 행위는 굉장히 무거운 작업입니다.
- Model을 사용하면 동일한 형태의 엔티티를 빠르고 편하게 사용할 수 있습니다.
- 또한 원하는 타이밍, 상황에 언제든지 호출하여 사용할 수 있습니다.
- 이를 통해 하나의 월드에서 동일한 형식의 엔티티가 필요할 경우 미리 Model로 생성한 뒤 이를 복제하는 형태로 사용하는 방법이 더욱 적합합니다.

<br>

## 최소 구현 기준
- CoinRushController의 특정 Method 실행 시 점수 아이템이 스폰 되도록 기능을 구성합니다.
- 맵에 배치된 모든 점수 아이템을 습득했을 경우 일정 시간이 지난 뒤 다시 스폰 될 수 있도록 기능을 구성합니다.

## 응용 및 확장 방향
- 점수 아이템 중 특정한 아이템은 더 많은 점수를 주는 형태로 기능을 제작합니다.
- 점수 아이템이 혼합하여 출력되도록 기능을 구성합니다.
