## 學習實體
<p align="center">
<img src="../../_images/MSW-100_PartyGame_3_001.png" alt="MSW-100_PartyGame_3_001.png">
</p>

- 實體在楓之谷世界中可以執行各種不同的角色。
- 若製作角色圖片與互動功能，便能成為NPC。
- 若製作角色圖片與攻擊功能，則能成為怪物。
- 或者不賦予圖片，而是製作管理目前地圖設定的功能，則可製作Controller。
- 實體可以透過各種方式製作與使用。

<br>

### 製作實體
- 實體主要由本體實體以及用來賦予功能的Component所組成。
- 只有實體存在時，無法執行任何功能。
- 若只有Component存在，因沒有可執行它的實體，因此Component也無法運作。
- 因此製作實體時，必須依據目的建立實體並設定其關係。

<br>

#### 建立實體
<p align="center">
<img src="../../_images/MSW-100_PartyGame_3_002.png" alt="MSW-100_PartyGame_3_002.png">
</p>

- 對目前編輯中的地圖按滑鼠右鍵。
    - 編輯中的地圖左側會顯示「>」符號或「V」符號。
- 點擊「Create Entity」開啟展開選單。
- 點擊「Create Empty」即可建立空白實體。

<p align="center">
<img src="../../_images/MSW-100_PartyGame_3_003.png" alt="MSW-100_PartyGame_3_003.png">
</p>

- 建立完成的實體預設名稱為**MapEmpty**。
    - 若是在**ui**中建立空白實體，則會建立名為**UIEmtpy**的空白實體。
- 建立完成的實體預設會擁有TransformComponent。

<br>

#### 賦予Component

<p align="center">
<img src="../../_images/MSW-100_PartyGame_3_004.png" alt="MSW-100_PartyGame_3_004.png">
</p>

- 點擊欲賦予Component的實體後，在「Property」視窗中可看到「Add Component」。
- 點擊「Add Component」後，可從分類中尋找所需Component並登錄，也可透過搜尋直接找到Component並加入。
- 此外也可點擊「New Component」自行製作並登錄Component。

## 製作障礙物實體

<p align="center">
<img src="../../_images/MSW-100_PartyGame_3_005.png" alt="MSW-100_PartyGame_3_005.png">
</p>

- 範例世界中使用Log_1、Log_2、Log_3實體作為障礙物。
- 當CoinRush地圖中的遊戲開始後，這些實體會定期從畫面上方移動到下方，並在與玩家碰撞時使玩家角色暫時無法移動。
- 各實體擁有以下Component。
    - 「TransformComponent」：建立實體時預設附加，用來指定位置的Component。
    - 「SpriteRendererComponent」：讓實體顯示圖片的Component。
    - 「TriggerComponent」：指定實體碰撞範圍的Component。
    - 「TweenLineComponent」：讓實體能以固定速度與時間從上往下移動而額外加入的Component。

<br>

### 編輯SpriteRendererComponent
<p align="center">
<img src="../../_images/MSW-100_PartyGame_3_006.png" alt="MSW-100_PartyGame_3_006.png">
</p>

- 在「SpriteRendererComponent」中編輯以下項目。
    - **SpriteRUID**：指定SpriteRendererComponent要顯示哪張圖片的數值。
    - **Color**：指定覆蓋在顯示圖片上的顏色。
    - **FlipX**、**FlipY**：指定圖片左右翻轉、上下翻轉。

### 設定CollisionGroup

<p align="center">
<img src="../../_images/MSW-100_PartyGame_3_011.png" alt="MSW-100_PartyGame_3_011.png">
</p>

- 點擊CollisionGroup右側的開啟面板按鈕。
- 可以在Collision Groups視窗中編輯Collision Group。

<br>

#### CollisionGroup是什麼?
<p align="center">
<img src="../../_images/MSW-100_PartyGame_3_012.png" alt="MSW-100_PartyGame_3_012.png">
</p>

- CollisionGroup是用來設定需要進行碰撞偵測之群組的項目。
- 透過將具有相同性質的物件統一管理在同一群組中，以減少運算量。
- 同時也可事先設定群組與群組之間是否需要進行碰撞檢查，以減少不必要的運算。
- 預設由**Default**、**TriggerBox**、**HitBox**組成。 
- 範例世界另外使用了**Player**、**Coin**、**Log**。
    - **Default**：範例世界中未使用的CollisionGroup。
    - **TriggerBox**：範例世界中未使用的CollisionGroup。
    - **HitBox**：範例世界中未使用的CollisionGroup。
    - **Player**：用於玩家角色的CollisionGroup。
    - **Coin**：為了將分數道具統一管理在同一群組而建立的CollisionGroup。
    - **Log**：作為障礙物並與玩家進行碰撞而建立的CollisionGroup。

<br>

<p align="center">
<img src="../../_images/MSW-100_PartyGame_3_013.png" alt="MSW-100_PartyGame_3_013.png">
</p>

- 若要新增CollisionGroup，可點擊「Add Collision Group」建立。
- 若產生了不需要的CollisionGroup或建立錯誤，可點擊右側的「-」按鈕刪除。
    - 但系統預設提供的**Default**、**TriggerBox**、**HitBox**無法刪除。

<br>

### 設定Matrix

<p align="center">
<img src="../../_images/MSW-100_PartyGame_3_014.png" alt="MSW-100_PartyGame_3_014.png">
</p>

- Matrix是用來設定Collision Group之間是否進行碰撞檢查的項目。
- 若核取方塊未勾選，則不會偵測對應CollisionGroup之間的碰撞。
- 閱讀Matrix時，需要抱持著由左至右逐一閱讀的方式理解。
    - 以Player為例，Player會要求檢查自己是否需要與Log、Coin、Player進行運算。
    - 其他CollisionGroup也同樣要從左側開始，逐一與上方項目連結並設定是否需要進行碰撞檢查。
- 在Matrix中，設定Player需與Log、Coin發生碰撞。
- 完成所有設定後，關閉Collision Groups視窗，並將TriggerComponent的CollisionGroup更改為Log。
- 點擊「Hierarchy」中的DefaultPlayer，將TriggerComponent的CollisionGroup更改為Player。

<br>

- 範例世界中的Log為了讓其以自身為基準移動，因此修改了以下數值。
    - **TweenType**：為了以固定速度移動，使用Linear。
    - **Duration**：輸入5，讓其在5秒內移動至指定位置。
    - **StopType**：設定為One way，讓障礙物執行後只移動一次。
    - **DestinationCoordinateType**：只需指定實體位置即可從該位置開始移動，因此設定為Relative。
    - **Positions**：為了讓其由上往下移動，將實體放置於地圖上方後，設定x = 0、y = -10。
    - **SyncType**：為了讓其在Client環境執行，因此設定為ClientOnly。

#### ⚠️ 使用DestinationCoordinateType時的注意事項
- Absolute
    - 設定為絕對座標。
    - 忽略目前實體的位置，直接移動至指定位置。
    - 若未將實體目前位置配置到正確起始點，可能出現異常移動現象。
- Relative
    - 設定為相對座標。
    - 會以目前實體座標為基準，移動至Position中登錄的位置。
    - 無論從哪個位置開始，都會以自身位置為基準移動至+後的位置。

## 製作PlayerCoinRushComponent
- 此Component用於當玩家在CoinRush地圖中與各種元素碰撞時進行相關處理。
- 在範例世界中，此Component負責處理金幣取得與障礙物碰撞等情況。

### 賦予Component
<p align="center">
<img src="../../_images/MSW-100_PartyGame_3_017.png" alt="MSW-100_PartyGame_3_017.png">
</p>

- 在「Hierarchy」視窗中點擊DefaultPlayer。
- 在「Property」視窗中點擊Add Component。
- 點擊「New Component」、「New Component」後，將Component名稱設定為PlayerCoinRushComponent。
- 將以下內容撰寫在PlayerCoinRushComponent中。
```lua
@Component
script PlayerCoinRushComponent extends Component

property number playerScore = 0

property number timerID = 0

property number hitRecoveryTime = 1.0

@ExecSpace("ClientOnly")
method void AddCoinScore(number coinScore)
local event = GetCoinRushCoin()
event.CoinScoreValue = coinScore
self.Entity:SendEvent(event)
self.playerScore = self.playerScore + coinScore
end

@ExecSpace("ClientOnly")
method void PausePlayer()
if self.timerID ~= 0 then
	_TimerService:ClearTimer(self.timerID)
end
-- 暫時停止玩家的MovementComponent。
self.Entity.MovementComponent.Enable = false
-- 切換玩家的動畫狀態。
local body = self.Entity.AvatarRendererComponent:GetBodyEntity()
local event = ActionStateChangedEvent("alert", "alert", 1, SpriteAnimClipPlayType.Loop)
body:SendEvent(event)
-- 經過一定時間後解除無法移動狀態。
self.timerID = _TimerService:SetTimerOnce(function()
	event = ActionStateChangedEvent("stand1", "stand1", 1, SpriteAnimClipPlayType.Loop)
	self.Entity.MovementComponent.Enable = true
end, self.hitRecoveryTime)
end

@ExecSpace("ClientOnly")
method void ResetScore()
self.playerScore = 0
end

@EventSender("Self")
handler HandleTriggerEnterEvent(TriggerEnterEvent event)
-- 檢查碰撞到的實體是否為金幣。
if isvalid(event.TriggerBodyEntity.CoinRushCoin) then
	-- 取得與金幣相關的Component。
	local coinComponent = event.TriggerBodyEntity.CoinRushCoin
	-- 將接收到的值傳遞給玩家的AddCoinScore。
	self:AddCoinScore(coinComponent:GetCoinValue())
end
end

@EventSender("Self")
handler HandleTriggerEnterEvent2(TriggerEnterEvent event)
-- 若碰撞對象為CoinRush的原木，則暫時使玩家無法行動。
if self.Entity.CurrentMapName == "CoinRush" then
	if  event.TriggerBodyEntity.Name ~= "Coin"then
	self:PausePlayer()
	-- 播放受擊特效。
	_EffectService:PlayEffect("e9175650f9c0425e96333602842080cd", self.Entity, self.Entity.TransformComponent.WorldPosition, 0, Vector3.one, false)
	-- 播放受擊音效。
	_SoundService:PlaySound("849328dbd156473099f90b12d36b667e", 1.0)
	-- 將發生碰撞的原木設為停用。
	event.TriggerBodyEntity.Enable = false
	end
end
end

end
```

> 該程式碼是以Plain Text為基準編寫而成。

## 最低製作標準
- 建構作為玩家干擾要素使用的實體。
- 當實體與玩家碰撞時，建構使玩家在指定時間內無法移動的功能。
- 設計實體結構，使實體能自行移動至指定位置。

<br>

## 應用與進階應用
- 製作多種類型的實體，以建構更多樣化的障礙物。
- 修改TweenLine設定，讓障礙物能以各種不同方式接近玩家。
