## Creating Auto Currency
<p align="Center">
<img src="../../_images/MSW-100_Defense_7_001.png" alt="MSW-100_Defense_7_001"
</p>

- Every second after entering the **MainGame**, players and enemy (AI) bases can automatically produce currency to create units to fight.
- Automatically produces as much currency per second per stage as recorded in the **StageData** DataSet.
- Utilize the **isUser** variable declared in the BaseComponent to leverage the data value of the required amount of goods produced.

```lua
How the BaseComponent's AutoGetGold Function Works

Property:
-- A state variable to determine if the base belongs to the user (player).
[None]
boolean isUser
-- A variable to store the value of currency created per second.
[None]
integer goldPerSecond
-- A timer that measures how much currency to produce after certain amount of time.
[None]
number goldTimer
-- A variable to record the amount of gold accumulated at each base.
[None]
integer gold

Method:
[clientOnly]
void OnUpdate(number delta)
{
    -- Call the AutoGetGold function every frame.
    self:AutoGetGold(number delta)
}

[clientOnly]
void Init()
{
    -- The Init function, which is called when the stage starts, sets the production of currency for the stage as follows

    self.goldTimer = 0
    self.gold = 0

    if isUser == true then
        self.goldPerSecond = _DataSetLogic.stageData[_StageLogic.currentStage].PlayerGoldPerSecond
    else
        self.goldPerSecond = _DataSetLogic.stageData[_StageLogic.currentStage].EnemyGoldPerSecond
    end
}

[clientOnly]
void AutoGetGold(number delta)
{
    -- Increases the timer value to measure in units of 1 second.
    self.goldTimer += delta

    -- Record the value of the max amount of currency you can carry for the current stage.
    -- ---@ type to indicate that the data type is an integer.
    ---@ type integer
    local maxGold = _DataSetLogic.stageData[_StageLogic.currentStage].MaxGold

    -- If it's 1 second or more,
    if self.goldTimer >= 1 and self.gold < maxGold then
        -- Reset the timer back to 0.
        self.goldTimer = 0
        -- Adds the set gold value per second to the current gold value.
        self.gold += self.goldPerSecond
        self.gold = math.clamp(self.gold,0,maxGold)
    end
}
```

### Creating DeckLoader Component
- This component is used to initialize the internal deck elements with information based on the current user's set deck data when entering the MainGame map.
- The DeckLoader component is registered with and utilized by the **DeckContainer**.
- The code for the DeckLoader component is written as follows.
- The target code is based on Plain Text.

```lua
@Component
script DeckLoader extends Component

property string deckItemEntryID = "model://7ed4ff59-e40b-4ff9-a9bf-d22a306afb70" -- The Model EntryID value of the UI Deck for creating the unit.

@ExecSpace("ClientOnly")
method void Init()
-- Function to initialize the DeckLoader that manages multiple Decks.

-- Retrieve the table with information about the user decks registered in GameLogic.
---@type table
local userDecks = _GameLogic.userDeck
-- See how many decks are already registered.
-- This is to create a Deck UI entity, since the deck is not configured when first entering the game.
local currentDeckCount = #self.Entity.Children
-- Check how many decks you currently need to create.
local needDeckCount = #userDecks - currentDeckCount
-- Create as many Decks as needed.
self:RegistDeckItem(needDeckCount)

-- Initialize each deck by sequentially accessing the child entities (Deck).
for index, child in pairs(self.Entity.Children) do
	local deck = child.Deck
	-- The initialization of each deck is set to the unit names registered within the deck table registered in GameLogic.
	deck:Init(userDecks[index])
	-- Since this deck will be utilized within the MainGame, attach a SpawnRequester component to the base that has the ability to spawn units registered in the deck's information.
	deck.Entity:AddComponent("SpawnRequester")
end
end

@ExecSpace("ClientOnly")
method void RegistDeckItem(integer count)
-- Function to register the requested number of decks.

-- Parameter 1 count: The number of decks you want to create.

-- Proceed with production only if the required quantity is greater than zero.
if count > 0 then

	for i = 1, count, 1 do
		_SpawnService:SpawnByModelId(self.deckItemEntryID,"Deck",Vector3.zero,self.Entity)
	end
	
end
end

end
```

<br>

<p align="Center">
<img src="../../_images/MSW-100_Defense_7_007.png" alt="MSW-100_Defense_7_007"
</p>

- The Deck UI itself has the following registered components.
- SpriteGUIComponent: A component for representing the layout of the Deck UI.
- Deck: A component for registering information that should be UI represented as a unit.
- ButtonComponent: A component for interacting with the user via button input.
- The code for the Deck component is written as follows.
- The target code is based on Plain Text.

```lua
@Component
script Deck extends Component

property string deckUnitName = "" -- Records the name of unit registered in one Deck.

@ExecSpace("ClientOnly")
method void Init(string unitName)
-- Function to initialize the Deck.

-- Parameter 1: Receives the name of the unit to be included in the deck.

-- Record the name of the unit as internal member.
self.deckUnitName = unitName

-- Retrieve all the tables from DataSetLogic that hold all the information for that unit.
---@type table
local unitData = _DataSetLogic.unitData[unitName]
-- Record the RenderID value that determines the appearance of the unit.
local unitRenderID = unitData["RenderID"]
-- Record the animated RUID value of the target unit's IDLE state.
local unitIDLE_RUID = _DataSetLogic.unitRenderData[unitRenderID].IDLE
-- Record the creation cost of the target unit.
local unitCost = unitData["Cost"]

-- Retrieve the SpriteGUIRenderer component where the unit's appearance is registered from the child entity.
local imageRenderer = self.Entity:GetChildByName("Image").SpriteGUIRendererComponent
-- Retrieve the Text component where the unit's name is registered from the child entity.
local nameText = self.Entity:GetChildByName("Name").TextComponent
-- Retrieve the Text component where the unit's creation cost is registered from the child entity.
local costText = self.Entity:GetChildByName("Cost").TextComponent

-- Set the RUID value of the SpriteGUIRenderer component to the IDEL resource value of the unit.
imageRenderer.ImageRUID = unitIDLE_RUID
-- Set the text of the Text component where the name is entered to the unit name.
nameText.Text = unitName
-- Set the text of the Text component where the creation cost is entered to the value of the creation cost.
costText.Text = unitCost

-- Ensure that the unit is rendered solely as a static image for the SpriteGUIRenderer component
-- by setting the frame playback speed to 0.
imageRenderer.PlayRate = 0
end

end
```

## Creating Units Using Currency
- The condition for creating a unit is that the value of the current accumulated currency is greater than the cost of the unit you want to create.
- To create a unit that is placed on the field, the player can create the actual unit through a ButtonComponent registered in the Deck UI.
- Enemies (AI) accumulate currency every second and will automatically create units when they accumulate to equal the creation cost of the unit it wants to produce.

<br>

### Enemy Base Unit Creation Using Currency
- Every second, the enemy base also accumulates currency, and if it exceeds the creation cost of the set units, it will spawn target units, consuming its resources.
- For more information about the Unit AutoSpawn feature, see the reference in the previous section, '4. Implementing Unit Spawn System'.
- The ability to auto-produce enemies through currency works as follows.

### Creating Player's Unit Creation Feature
- The player's unit creation method is performed when the **ClickEvent** of the ButtonComponent of the Deck UI entity occurs.
- When a Deck UI entity is created via the DeckLoader component of the DeckContainer entity utilized in the MainGame map, a **SpawnRequester** component is registered in real-time that requests the BaseComponent to create units.

### Requesting Unit Spawn
- Within the SpawnRequester component, implement the **HandleButtonClickEvent** function that is called when a button click is detected.
- Check the unit name recorded in Deck component, find the player's BaseComponent, and send a request to create the unit.

```lua
SpawnRequester

Event Handler:
[self]
HandleButtonClickEvent(ButtonClickEvent event)
{
    -- Records the name currently being recorded by the Deck component.
    local unitName = self.Entity.Deck.deckUnitName

    -- Record the player's baseComponent.
    local playerBaseComponent = _EntityService:GetEntityByPath("/maps/MainGame/MyBase").BaseComponent
    -- When the Deck button is clicked, it will request the creation of the units registered as internal members.
    playerBaseComponent:PlayerRequestSpawn(unitName)
}

```

## Usage and Extension Direction
- To make your game more strategic, you can add an 'Upgrade Base' button that permanently increases the amount of currency produced per second or the maximum amount of currency you can hold by paying a certain amount of currency.
- Evolve the Deck UI to intuitively recognize when players are out of currency by dimming images or blocking button inputs when they are low on currency.
- The enemy AI will spawn units as soon as they collect currency, but you can extend the conditional to implement a 'wave' type pattern that collects currency until a certain timing and then spawns multiple units at once.
