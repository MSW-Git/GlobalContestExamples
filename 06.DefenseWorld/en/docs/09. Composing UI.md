## UI Group
<p align="Center">
<img src="../../_images/MSW-100_Defense_9_001.png" alt="MSW-100_Defense_9_001"
</p>

- A UI Group acts as a **folder and container of sorts** that bundles multiple UI entities (buttons, text, images, etc.) together.
- You can control the visibility of all UI entities within a group on a group basis, with the advantage of disabling an entire group of UIs rather than turning off each UI individually.
- You can enable the UI Groups popup via Panels - UI Groups at the top of the editor.

<br>
<br>

<p align="Center">
<img src="../../_images/MSW-100_Defense_9_002.png" alt="MSW-100_Defense_9_002"
</p>

- You can create a new UI Group via the '+' button at the bottom of the 'UI Groups' popup.
- The UI Groups utilized in the Defense sample world controls the total three groups: 'Title', 'MainGame', and 'Result'.

<br>

## Creating UI Logic
- Create Logic scripts for each UI Group to enable/disable the right UI Group at the right time for each game situation (title, main game, results screen) and act as a control tower to update the data inside the UI (currency, wave information, results, etc.) in real-time.

<br>

### UI Title Logic
<p align="Center">
<img src="../../_images/MSW-100_Defense_9_003.png" alt="MSW-100_Defense_9_003"
</p>

- Logic for managing the UI required to configure the 'Title' screen.
- The script for the 'UI_Title' Logic is written as follows. 
- The target code is based on Plain Text.

```lua
@Logic
script UI_Title extends Logic

property Entity titleUIEntity = "275fd157-6ae2-4e34-a285-a5641234ff9c"

property Entity gameStartButton = "e753b827-d9d8-4ef1-bf34-34b98d4d8de5"

property Entity editDeckButton = "884bfac2-2231-4d35-a7c5-c0717a73ddb8"

property Entity editDeckPopup = "b887294b-9d5c-44fd-9c14-f830cbd749c3"

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- This function is called when the world is launched.

-- Connect an event so that the EnterMainGame function is called when the 'Start Game' button on the title screen is clicked.
self.gameStartButton:ConnectEvent(ButtonClickEvent,self.EnterMainGame)
self.editDeckButton:ConnectEvent(ButtonClickEvent,self.ShowEditDeckPopup)
end

@ExecSpace("Server")
method void EnterMainGame()
-- Function to switch to the MainGame map.

-- Direct TelePortLogic to switch to 'MainGame'.
_TelePortLogic:TelePort("MainGame")
end

@ExecSpace("ClientOnly")
method void Show(boolean active)
-- Function that outputs the UI Group that should be shown in the title state.

-- Parameter 1 active: Determines whether to enable the popup.

-- Reflects the active state of the titleUIEntity group exactly as it is.
self.titleUIEntity.Enable = active
end

@ExecSpace("ClientOnly")
method void ShowEditDeckPopup()
self.editDeckPopup.Enable = true
self.editDeckPopup.DeckEditor:InitUserDeck()
end

end
```

### UI MainGame Logic
<p align="Center">
<img src="../../_images/MSW-100_Defense_9_004.png" alt="MSW-100_Defense_9_004"
</p>

- Logic for managing the UI required to configure the 'Title' screen.
- The script for the 'UI_MainGame' Logic is written as follows. 
- The target code is based on Plain Text.

```lua
@Logic
script UI_MainGame extends Logic

property DeckLoader deckLoader = "00df9b64-aa74-4d67-818e-852aae7160a6"

property TextComponent goldText = "3af7e818-674a-4c83-b39e-2431afc4db30"

property Entity mainGameUIEntity = "7c66c8c8-90de-423e-8add-8a5af46b08cb"

property TextComponent stageText = "ba8541f6-7acd-4fb5-b116-6b13cfa8e62d"

@ExecSpace("ClientOnly")
method void DeckInit()
-- When entering the MainGame, initialize the deck's information.

-- Proceed with the initialization of the DeckLoader component.
self.deckLoader:Init()
end

@ExecSpace("ClientOnly")
method void UpdateGoldText(integer gold)
-- This function updates the visible currency information in the MainGame environment.

-- Parameter 1 gold: Passes the received parameter (currency value) in an already possessed state.

-- Record the value of the max amount of currency you can have per stage.
local maxGold = _DataSetLogic.stageData[_StageLogic.currentStage].MaxGold
-- Since we don't need the decimal value, we utilize the math.floor function to output only the integer part.
gold = math.floor(gold)

-- Register the 'current gold/max gold' value in the TextUI.
self.goldText.Text = gold.."/"..maxGold
end

@ExecSpace("ClientOnly")
method void Show(boolean active)
-- Function that determines the Enable state of the MainGame UI Group.

-- Parameter 1 active: Determine enable as it is with this variable.

-- Set the MainGame UI Group entity to the parameter value.
self.mainGameUIEntity.Enable = active
end

@ExecSpace("ClientOnly")
method void UpdateStageNumberText()
self.stageText.Text = tostring(_StageLogic.currentStage)
end

end
```

### UI Result Logic
<p align="Center">
<img src="../../_images/MSW-100_Defense_9_005.png" alt="MSW-100_Defense_9_005"
</p>

- Logic for managing the UIs required to configure the 'Result' state screen.
- The script for the 'UI_Result' Logic is written as follows. 
- The target code is based on Plain Text.

```lua
@Logic
script UI_Result extends Logic

property Entity resultUIEntity = "58f610ca-687c-402e-a236-9a0ecaba20f3"

property Entity clearTextEntity = "d2b4dfa2-3936-4535-9edb-536fde51e227"

property Entity defeatTextEntity = "e5b2c909-0029-4bb9-9923-139155b3e095"

property Entity clearButtons = "af66debb-69c0-4272-87f6-298c18b21a75"

property Entity defeatButtons = "1901f087-e074-430e-b549-5c07200b25ed"

property Entity nextStageButton = "d6ca8901-a8bf-43e0-917b-d42c05b0bb8b"

property Entity retryButton = "675afdd5-dd71-482c-9628-af3c04e24b08"

property Entity toTitleButton_win = "b148778c-64c9-4470-9612-bd7619199924"

property Entity toTitleButton_lose = "a06b5b49-7a0a-4a39-b5df-da62f56e80c8"

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- This function is called when the world is launched.

-- Register an event to call the OpenNextStage function when clicking the 'Next Stage' button.
self.nextStageButton:ConnectEvent(ButtonClickEvent,_StageLogic.OpenNextStage)
-- Register an event to call the StageReset function when clicking the 'Try Again' button.
self.retryButton:ConnectEvent(ButtonClickEvent,_StageLogic.StageReset)

-- Register an event to call the ToTitle function when clicking the "Back to Main Menu" button that appears when a battle is won.
self.toTitleButton_win:ConnectEvent(ButtonClickEvent,self.ToTitle)
-- Register an event to call the ToTitle function when clicking the "Back to Main Menu" button that appears when a battle is lost.
self.toTitleButton_lose:ConnectEvent(ButtonClickEvent,self.ToTitle)
end

@ExecSpace("ClientOnly")
method void ShowWithWinInfo(boolean isWin)
-- Function that displays a result window at the end of the game with the player's win or loss.

-- Parameter 1 isWin: Receives the player's win and loss values.

-- Enable UI Groups for the results window popup.
self.resultUIEntity.Enable = true

-- The enable state of clearTextEntity is reflected by its isWin state value.
self.clearTextEntity.Enable = isWin
-- The enable state of clearButtons is reflected by the isWin state value.
self.clearButtons.Enable = isWin

-- Make defeatTextEntity's enabled state reflect the opposite value of isWin.
self.defeatTextEntity.Enable = not isWin
-- Make defeatButtons enable state reflect the opposite value of isWin.
self.defeatButtons.Enable = not isWin
end

@ExecSpace("ClientOnly")
method void Hide()
-- Function to disable the results window popup.

-- Disable UI Groups in the results window popup.
self.resultUIEntity.Enable = false
end

@ExecSpace("Server")
method void ToTitle()
-- Function to return to the title map.

-- Direct TeleportLogic to switch to the 'Title' map.
_TelePortLogic:TelePort("Title")
end

end
```

<br>

## Minimum Implementation Standards
- Screen elements belonging to each UI (Title, MainGame, Result) should be turned on or off all at once based on the group's 'Enable' state.
- Upon entering the MainGame screen, the player deck information should be loaded, and the deck UI should be properly displayed at the bottom of the screen.
- At the end of the game, the ShowWithInfo function of 'UI_Result' should be called accordingly to the condition (base destruction), and depending on the value of the parameter 'isWin' (true/false), the 'win' and 'lose' phrases and the associated buttons should be contextually displayed.

<br>

## Usage and Extension Direction
- In addition to a simple text display, you can represent the remaining wave progress in the UI as a visual gauge bar using a sliderComponent by calculating the number of enemies currently killed relative to the total number of enemies.
- Instead of simply displaying text when the Result screen lights up, you can add simple UI animations using Tweens and more to enhance your game.
