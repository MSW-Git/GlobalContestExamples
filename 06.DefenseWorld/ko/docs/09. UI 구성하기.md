## UI Group
<p align="Center">
<img src="../../_images/MSW-100_Defense_9_001.png" alt="MSW-100_Defense_9_001"
</p>

- UI Group은 여러 UI 엔티티를(버튼, 텍스트, 이미지 등)을 하나로 묶어서 관리하는 **일종의 폴더이자 컨테이너 역할**을 합니다.
- 그룹 내에 속한 모든 UI 엔티티의 화면 표시 여부를 그룹 단위로 제어할 수 있으며, 개별 UI를 일일이 끄는 것보다 UI 그룹 전체를 비활성화 처리할 수 있는 장점이 있습니다.
- 에디터 상단의 Panels - UI Groups를 통해 UI Groups 팝업을 활성화할 수 있습니다.

<br>
<br>

<p align="Center">
<img src="../../_images/MSW-100_Defense_9_002.png" alt="MSW-100_Defense_9_002"
</p>

- 'UI Groups' 팝업 하단의 `+`버튼을 통해 새로운 UI Group을 생성할 수 있습니다.
- 디펜스 샘플 월드에서 활용되는 UI Group은 'Title','MainGame','Result'로 총 3개의 그룹을 제어합니다.

<br>

## UI Logic 제작하기
- 각 UI Group 별 Logic 스크립트를 제작하여 각 게임 상황(타이틀, 메인 게임, 결과 화면)에 알맞은 UI 그룹을 적절한 타이밍에 활성화/비활성화하고, UI 내부의 데이터(재화, 웨이브 정보, 결과 등)를 실시간으로 갱신하는 제어 타워 역할을 수행하도록 합니다.

### UI Title Logic
<p align="Center">
<img src="../../_images/MSW-100_Defense_9_003.png" alt="MSW-100_Defense_9_003"
</p>

- 'Title' 화면을 구성하는데 필요한 UI들을 관리하기 위한 Logic입니다.
- `UI_Title` Logic의 스크립트는 다음과 같습니다. 
- 해당 코드는 Plain Text 환경으로 작성되었습니다.

```lua
@Logic
script UI_Title extends Logic

property Entity titleUIEntity = "275fd157-6ae2-4e34-a285-a5641234ff9c"

property Entity gameStartButton = "e753b827-d9d8-4ef1-bf34-34b98d4d8de5"

property Entity editDeckButton = "884bfac2-2231-4d35-a7c5-c0717a73ddb8"

property Entity editDeckPopup = "b887294b-9d5c-44fd-9c14-f830cbd749c3"

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- 월드 실행 시 호출되는 함수입니다.

-- 타이틀 화면에서 보이는 '게임 시작'버튼 클릭시 EnterMainGame 함수가 호출되도록 이벤트를 연결합니다.
self.gameStartButton:ConnectEvent(ButtonClickEvent,self.EnterMainGame)
self.editDeckButton:ConnectEvent(ButtonClickEvent,self.ShowEditDeckPopup)
end

@ExecSpace("Server")
method void EnterMainGame()
-- MainGame 맵으로 전환하는 함수입니다.

-- TelePortLogic에게 'MainGame'으로 전환해달라고 요청합니다.
_TelePortLogic:TelePort("MainGame")
end

@ExecSpace("ClientOnly")
method void Show(boolean active)
-- 타이틀 상태에서 보여야할 UI Group을 출력하는 함수입니다.

-- 매개변수 1 active : 팝업 활성화 여부를 결정합니다.

-- titleUIEntity 그룹의 활성화 여부를 active상태 그대로 반영합니다.
self.titleUIEntity.Enable = active
end

@ExecSpace("ClientOnly")
method void ShowEditDeckPopup()
self.editDeckPopup.Enable = true
self.editDeckPopup.DeckEditor:InitUserDeck()
end

end
```

### UI MainGame Logic
<p align="Center">
<img src="../../_images/MSW-100_Defense_9_004.png" alt="MSW-100_Defense_9_004"
</p>

- 'Title' 화면을 구성하는데 필요한 UI들을 관리하기 위한 Logic입니다.
- `UI_MainGame` Logic의 스크립트는 다음과 같습니다. 
- 해당 코드는 Plain Text 환경으로 작성되었습니다.

```lua
@Logic
script UI_MainGame extends Logic

property DeckLoader deckLoader = "00df9b64-aa74-4d67-818e-852aae7160a6"

property TextComponent goldText = "3af7e818-674a-4c83-b39e-2431afc4db30"

property Entity mainGameUIEntity = "7c66c8c8-90de-423e-8add-8a5af46b08cb"

property TextComponent stageText = "ba8541f6-7acd-4fb5-b116-6b13cfa8e62d"

@ExecSpace("ClientOnly")
method void DeckInit()
-- MainGame에 진입했을 시, 덱의 정보를 초기화를 진행합니다.

-- DeckLoader 컴포넌트의 초기화를 진행합니다.
self.deckLoader:Init()
end

@ExecSpace("ClientOnly")
method void UpdateGoldText(integer gold)
-- MainGame 환경에서 보이는 재화정보를 갱신하는 함수입니다.

-- 매개변수 1 gold : 전달받는 매개변수(재화값)을 소지하고 있는 상태로 전달합니다.

-- 스테이지 별 소지가능한 최대 재화량 값을 기록합니다.
local maxGold = _DataSetLogic.stageData[_StageLogic.currentStage].MaxGold
-- 소수점 값은 필요 없으므로, math.floor기능을 활용해 정수 부분만 출력되도록 설정합니다.
gold = math.floor(gold)

-- TextUI에 '현재골드/최대골드' 값을 등록합니다.
self.goldText.Text = gold.."/"..maxGold
end

@ExecSpace("ClientOnly")
method void Show(boolean active)
-- MainGame UI Group의 Enable 상태를 결정하는 함수입니다.

-- 매개변수 1 active : 해당 변수로 enable을 그대로 결정합니다.

-- MainGame UI Group 엔티티를 매개변수 값으로 설정합니다.
self.mainGameUIEntity.Enable = active
end

@ExecSpace("ClientOnly")
method void UpdateStageNumberText()
self.stageText.Text = tostring(_StageLogic.currentStage)
end

end
```

### UI Result Logic
<p align="Center">
<img src="../../_images/MSW-100_Defense_9_005.png" alt="MSW-100_Defense_9_005"
</p>

- 'Result' 상태의 화면을 구성하는데 필요한 UI들을 관리하기 위한 Logic입니다.
- `UI_Result` Logic의 스크립트는 다음과 같습니다. 
- 해당 코드는 Plain Text 환경으로 작성되었습니다.

```lua
@Logic
script UI_Result extends Logic

property Entity resultUIEntity = "58f610ca-687c-402e-a236-9a0ecaba20f3"

property Entity clearTextEntity = "d2b4dfa2-3936-4535-9edb-536fde51e227"

property Entity defeatTextEntity = "e5b2c909-0029-4bb9-9923-139155b3e095"

property Entity clearButtons = "af66debb-69c0-4272-87f6-298c18b21a75"

property Entity defeatButtons = "1901f087-e074-430e-b549-5c07200b25ed"

property Entity nextStageButton = "d6ca8901-a8bf-43e0-917b-d42c05b0bb8b"

property Entity retryButton = "675afdd5-dd71-482c-9628-af3c04e24b08"

property Entity toTitleButton_win = "b148778c-64c9-4470-9612-bd7619199924"

property Entity toTitleButton_lose = "a06b5b49-7a0a-4a39-b5df-da62f56e80c8"

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- 월드 실행 시 호출되는 함수입니다.

-- '다음 스테이지' 버튼 클릭시 OpenNextStage 함수가 호출되도록 이벤트를 등록합니다.
self.nextStageButton:ConnectEvent(ButtonClickEvent,_StageLogic.OpenNextStage)
-- '다시하기' 버튼 클릭시 StageReset 함수가 호출되도록 이벤트를 등록합니다.
self.retryButton:ConnectEvent(ButtonClickEvent,_StageLogic.StageReset)

-- 전투에서 승리했을 시 나타나는 '메인 메뉴로' 버튼 클릭시 ToTitle 함수가 호출되도록 이벤트를 등록합니다.
self.toTitleButton_win:ConnectEvent(ButtonClickEvent,self.ToTitle)
-- 전투에서 패배했을 시 나타나는 '메인 메뉴로' 버튼 클릭시 ToTitle 함수가 호출되도록 이벤트를 등록합니다.
self.toTitleButton_lose:ConnectEvent(ButtonClickEvent,self.ToTitle)
end

@ExecSpace("ClientOnly")
method void ShowWithWinInfo(boolean isWin)
-- 게임 종료 시 플레이어의 승패와 함께 결과창이 출력되는 함수입니다.

-- 매개변수 1 isWin : 플레이어의 승, 패값을 전달 받습니다.

-- 결과창 팝업의 UI Group을 활성화합니다.
self.resultUIEntity.Enable = true

-- clearTextEntity의 활성화 상태를 isWin 상태값으로 그대로 반영합니다.
self.clearTextEntity.Enable = isWin
-- clearButtons의 활성화 상태를 isWin 상태값으로 그대로 반영합니다.
self.clearButtons.Enable = isWin

-- defeatTextEntity의 활성화 상태를 isWin 반대값으로 반영하도록 합니다.
self.defeatTextEntity.Enable = not isWin
-- defeatButtons의 활성화 상태를 isWin 반대값으로 반영하도록 합니다.
self.defeatButtons.Enable = not isWin
end

@ExecSpace("ClientOnly")
method void Hide()
-- 결과창 팝업이 비활성화하는 함수입니다.

-- 결과창 팝업의 UI Group을 비활성화합니다.
self.resultUIEntity.Enable = false
end

@ExecSpace("Server")
method void ToTitle()
-- 타이틀 맵으로 돌아가는 함수입니다.

-- TeleportLogic에게 'Title' 맵으로 전환을 요청합니다.
_TelePortLogic:TelePort("Title")
end

end
```

## 최소 구현 기준
- 각 UI(Title,MainGame,Result)에 속한 화면 요소들이 그룹의 `Enable` 상태에 따라 한번에 켜지거나 꺼져야 합니다.
- MainGame 화면 진입 시, 플레이어 덱 정보를 불러와 화면 하단에 덱 UI가 정상적으로 출력되어야 합니다.
- 게임 종료 시 조건(기지 파괴)에 맞게 `UI_Reuslt`의 ShowWithInfo 함수가 호출되어야 하며, 매개변수 `isWin`값(true/false)에 따라 '승리'문구와 '패배'문구 및 관련 버튼들이 상황에 맞게 출력되어야 합니다.

## 응용 및 확장 방향
- 단순 텍스트 표기 외에, 전체 적의 숫자 대비 현재 처치한 적의 숫자를 계산하여 sliderComponent를 활용한 시각적인 게이지 바 형태로 남은 웨이브 진행도를 UI에 표현해 볼 수 있습니다.
- Result 화면이 켜질 때 단순히 텍스트만 나타나는 것이 아니라, Tween 등을 활용해 간단한 UI 애니메이션 연출을 추가하여 게임의 완성도를 높여볼 수 있습니다.
