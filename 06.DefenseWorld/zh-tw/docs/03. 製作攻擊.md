## 登錄TriggerComponent
<p align="Center">
<img src="../../_images/MSW-100_Defense_3_001.png" alt="MSW-100_Defense_3_001"
</p>

- 需要TriggerComponent功能，以便偵測接近對方英雄的情況。
- 若對方英雄與自己的TriggerComponent的Collider偵測到碰撞(範圍內)，即可運用TriggerComponent的事件功能。

<br>

### 設定Collider範圍
<p align="Center">
<img src="../../_images/MSW-100_Defense_3_002.png" alt="MSW-100_Defense_3_002"
</p>

- 需要設定用於偵測對方TriggerComponent的英雄Collider大小、範圍。
  - BoxSize：可分配X、Y軸值，設定碰撞方塊大小。
  - ColliderOffset：設定碰撞方塊中心點位置距離實體基準點的值。
  - Collider：可視覺化確認目前設定的範圍，並以滑鼠拖曳或放下設定Size或Offset值。
- 若Collider範圍太大，英雄可能會以像是遠距離攻擊的動作運作。

<br>

### 設定Collision Group
- 玩家生成的英雄只應攻擊對方英雄或基地，因此必須透過TriggerComponent設定為只能偵測對方Collider。

### 新增Collision Group
<p align="Center">
<img src="../../_images/MSW-100_Defense_3_003.png" alt="MSW-100_Defense_3_003"
</p>

- 若要生成新的Collision Group，請點擊**TriggerComponent**的**CollisionGroup**面板啟用按鈕，確認**Collsion Groups**面板。
- 可透過CollsionGroups分頁下方**Add Collsion Group**生成新的Collsion Group。  

<br>

### 設定碰撞Matrix

<p align="Center">
<img src="../../_images/MSW-100_Defense_3_004.png" alt="MSW-100_Defense_3_004"
</p>

- 玩家生成的英雄會將CollisionGroup設定為「Player」，並在Matrix中設定為Player無法偵測Player英雄之間的碰撞。
- 從敵方基地生成的英雄會將CollisionGroup設定為「Enemy」，並在Matrix中設定為Player與Enemy可以互相偵測碰撞。

<br>

## 處理英雄死亡動畫
<p align="Center">
<img src="../../_images/MSW-100_Defense_3_006.gif" alt="MSW-100_Defense_3_006"
</p>

- 執行英雄受擊處理後，若體力降到0以下，必須在死亡動畫播放後移除或停用實體。
- 若透過登錄於英雄的CustomState元件切換為DEAD狀態的同時移除實體，可能會發生動畫無法播放的問題。

<br>

### HandleSpriteAnimPlayerEndFrameEvent
- 運用SpriteRendererComponent提供的SpriteAnimPlayerEndFrameEvent時，可在動畫結束的最後一格播放時呼叫該事件函式。

```lua
CustomState元件的HandleSpriteAnimPlayerEndFrameEvent事件函式運用範例

Property:

string currentState = ""



Event Handler:

[self]
HandleSpriteAnimPlayerEndFrameEvent(SpriteAnimPlayerEndFrameEvent event)
{
    -- 目前播放中動畫的最後一格時呼叫的事件函式
    
    -- 若目前英雄狀態為「DEAD」(DEAD動畫最後一格的情況)
    if self.currentState == "DEAD" then
        -- 停用自身實體。
        self.Entity.Enable = false
    end
}
```

## 最低製作標準
- 為了執行英雄之間的互動，必須登錄TriggerComponent。
- 玩家生產的英雄必須攻擊敵方英雄，敵方英雄必須攻擊玩家生產的英雄，因此需要TriggerComponent的Maxtrix設定。

<br>

## 應用與進階應用
- 可以追加英雄能力值中的防禦力能力值，新增受擊時另外計算傳入傷害值的過程。
- 可設定Matrix並追加英雄混亂狀態，使我方英雄能攻擊我方英雄。
