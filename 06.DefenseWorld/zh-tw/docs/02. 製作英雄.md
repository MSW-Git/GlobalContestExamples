### 什麼是Logic?
<p align="Center">
<img src="../../_images/MSW-100_Defense_2_008_tw.png" alt="MSW-100_Defense_2_008_tw"
</p>

- 是楓之谷世界提供的腳本形式之一。
- 與一般元件腳本不同，不需要登錄於特定實體，也能自行執行功能動作。
- 不需要額外參照，可透過全域存取在世界執行期間隨時呼叫。

<br>

### 在表格內登錄資料
<p align="Center">
<img src="../../_images/MSW-100_Defense_2_009.png" alt="MSW-100_Defense_2_009"
</p>

- 必須製作資料表格，將所有儲存英雄的資料依英雄分類並記錄於一個表格內，之後外部需要使用資料時，能用直覺的方式取出資料。
- 在以Logic製作的**DataSetLogic**腳本的**Property**空間中，生成保存英雄各資料的表格變數。
- 世界執行時，執行可讀取DataSet中登錄之所有資料的初始化函式。

<br>

```lua
資料表格變數宣告
DataSetLogic{
Property:
    [None]
    table unitData = {} -- 生成用來存放英雄資料的空表格。

Method:
    void OnBeginPlay() -- 世界執行時呼叫的「OnBeginPlay」生命週期函式。
    {
        local dataSetName = "UnitData"
        local rowCount = _DataService:GetRowCount(dataSetName)

        -- 從資料第一列1開始，依資料總Row數進行巡覽。
        for i = 1, rowCount, 1 do
            -- 生成用來存放各資訊的一個內部表格。
            local data = {
                Useable = _DataService:GetCell(dataSetName,i,"Useable"),
                RenderID = tonumber(_DataService:GetCell(dataSetName,i,"RenderID")),
                Hp = tonumber(_DataService:GetCell(dataSetName,i,"Hp")),
                Attack = tonumber(_DataService:GetCell(dataSetName,i,"Attack")),
                Speed = tonumber(_DataService:GetCell(dataSetName,i,"Speed")),
                Skill = tonumber(_DataService:GetCell(dataSetName,i,"Skill")),
                SkAttack = tonumber(_DataService:GetCell(dataSetName,i,"SkAttack")),
                AtkCooltime = tonumber(_DataService:GetCell(dataSetName,i,"AtkCooltime")),
                SkCooltime = tonumber(_DataService:GetCell(dataSetName,i,"SkCooltime")),
                Cost = tonumber(_DataService:GetCell(dataSetName,i,"Cost"))
            }
            
            -- 記錄目標英雄名稱。
            local unitName = _DataService:GetCell(dataSetName,i,"Name")
            
            -- 以英雄名稱作為unitData表格的Key值儲存，並在內部記錄包含符合該英雄之各資訊的表格。
            self.unitData[unitName] = data
        end
            }

}
```
<br>

### 取得已登錄資料
- 若要取得儲存於**DataSetLogic**的unitData表格中各項所需資料，請如下撰寫程式碼。

```lua
取得Tiger英雄的Cost值
    local tigerUnitCost = _DataSetLogic.unitData["Tiger"].Cost

取得Panda英雄的移動速度值
    local pandaMoveSpeed = _DataSetLogic.unitData["Panda"].Speed
```

### AnimationController元件
<p align="Center">
<img src="../../_images/MSW-100_Defense_2_015.png" alt="MSW-100_Defense_2_015"
</p>

- 動畫元件會在英雄初始化時，將設定好的英雄動畫儲存到一個表格中，並執行播放外部請求動畫的角色。
- 必須如下撰寫程式碼。
- 該程式碼是在Plain Text環境下撰寫。

```lua
@Component
script AnimationController extends Component

property SpriteRendererComponent renderer = nil

property table actionSheet = {} -- 表格Key：各狀態名稱，值：符合各狀態的動畫GUID。 

property number hitTiming = 0 -- 攻擊動畫播放時，應執行對方英雄受擊處理的時機值。

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- 世界執行時呼叫的函式。

-- 在自身實體上登錄的元件中尋找SpriteRendererComponent，並登錄為內部成員。
self.renderer = self.Entity.SpriteRendererComponent
end

@ExecSpace("ClientOnly")
method void ChangeAnimation(string animName)
-- 將動畫狀態更改為參數值(State)。

-- 參數1 animName：要套用的動畫Key值。(ex：IDLE，MOVE，ATTACK)

-- 將SpriteRenderer的GUID值更改為登錄於內部的動畫GUID值。
self.renderer.SpriteRUID = self.actionSheet[animName]
end

@ExecSpace("ClientOnly")
method void SetAnimTable(string unitName)
-- 將內部成員actionSheet表格登錄為，以參數名稱登錄之英雄的UnitRenderData的 
-- 原樣取得存放動畫GUID值的表格。

-- 參數1 unitName：目前登錄英雄的名稱值。

-- 這是存放英雄應被渲染之動畫資訊的表格(UnitRenderData各ID編號)編號。
local unitRenderID = _DataSetLogic.unitData[unitName].RenderID

-- 將內部成員表格原樣登錄為UniRenderData索引對應的表格。
self.actionSheet = _DataSetLogic.unitRenderData[unitRenderID]

-- 將登錄於UnitRenderData的「AttackPick」資料原樣儲存為成員。
self.hitTiming = self.actionSheet["AttackPick"]
end

end
```

### CustomState元件
<p align="Center">
<img src="../../_images/MSW-100_Defense_2_016.gif" alt="MSW-100_Defense_2_016"
</p>

1.CustomState元件會接收執行英雄核心功能的UnitComponent狀態切換請求。
2.判斷是否能切換為收到的狀態，若可切換，則將目前英雄狀態記錄為新狀態。
3.向**AnimationController**元件請求播放各狀態所需動畫。

- 必須如下撰寫程式碼。
- 該程式碼是在Plain Text環境下撰寫。
```lua
@Component
script CustomState extends Component

property string currentState = "" -- 表示目前角色狀態的記錄用變數。

property AnimationController animation = nil

@ExecSpace("ClientOnly")
method void Init()
-- 初始化CustomState元件。

-- 將目前狀態儲存為待機狀態。
self.currentState = "IDLE"
-- 因為狀態更改時動畫也必須更改，所以將動畫控制器元件登錄為成員。
self.animation = self.Entity.AnimationController
end

@ExecSpace("ClientOnly")
method void ChangeState(string stateName)
-- 切換為參數狀態的函式。

-- 參數1 stateName：想要更改的狀態名稱。

-- 若原本狀態是攻擊中，且必須切換為受擊狀態時
if self.currentState == "ATTACK" and stateName == "ONHIT" then
	-- 不執行任何處理。
	-- 若攻擊動作被中斷，連續發生受擊情況時可能出現不自然動畫。
	return
end

-- 將目前狀態記錄為透過參數收到的狀態。
self.currentState = stateName
-- 請求播放符合收到狀態的動畫。
self.animation:ChangeAnimation(stateName)
end

@EventSender("Self")
handler HandleSpriteAnimPlayerEndFrameEvent(SpriteAnimPlayerEndFrameEvent event)
-- 動畫結束時呼叫的事件函式。

-- 若目前英雄狀態為「ATTACK」
if self.currentState == "ATTACK" then
	-- 將英雄狀態自動切換為IDLE狀態。
	self:ChangeState("IDLE")
	
-- 若目前英雄狀態為「DEAD」 
elseif self.currentState == "DEAD" then
	-- 停用英雄實體。
	-- 這與FrameEnd代表動畫已全部播放完畢的理由相同。
	self.Entity.Enable = false
	-- 將英雄重新歸還至物件池。
	_ObjectPoolLogic:ReturnUnit(self.Entity)
end
end

end
```

### UnitComponent

- UnitComponent是直接處理英雄細部動作及功能的元件。
- 若在自己設定的碰撞範圍內沒有偵測到對象，會向CustomState元件請求切換為「'MOVE'」狀態；若偵測到對象，則請求切換為「'ATTACK'」等狀態。
- 必須如下撰寫程式碼。
- 該程式碼是在Plain Text環境下撰寫。
```lua
@Component
script UnitComponent extends Component

property boolean isMine = false -- 設定英雄是否屬於使用者的記錄用變數。

property CustomState state = nil

property integer direction = -1 -- 代表英雄前進方向。

property number attackTimer = 0 -- 測量、管理基本攻擊冷卻時間的計時器變數。

property number skillTimer = 0 -- 測量、管理技能攻擊冷卻時間的計時器變數。

property table unitStat = {} -- 存放英雄資訊的表格。原樣取得登錄於DataSet的英雄資訊表格。

property boolean found = false -- 確認是否偵測到對方英雄的變數。

property boolean waiting = false -- 記錄目前英雄是否處於等待狀態，以便攻擊後進行下一次攻擊的變數。

property number hitTimer = 0 -- 用於向對方傳遞攻擊值的計時器變數。

property boolean isSendHit = false -- 記錄是否已向對方傳遞攻擊值的變數。

property UnitComponent targetUnit = nil

property BaseComponent targetBase = nil

property integer hp = 0 -- 英雄目前體力。

property integer power = 0 -- 英雄攻擊力。英雄目前有兩種攻擊(基本、技能)，每次攻擊時值都會更改。

property number damageTimer = 0 -- 受擊時用於更改Sprite透明度的計時器變數。

property boolean changedSpriteAlpha = false -- 表示SpriteAlpha值是否已更改的狀態變數。

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- 世界執行時呼叫的函式。

-- 將登錄於英雄實體的CustomState元件儲存為內部成員。
self.state = self.Entity.CustomState
-- 初始化CustomState元件。
self.state:Init()
end

@ExecSpace("ClientOnly")
method void Init(string unitName, boolean isMine)
-- 執行英雄初始化的函式。

-- 設定該英雄是否為玩家英雄。
self.isMine = isMine

-- 若「isMine」變數值為true(屬於使用者)
if self.isMine == true then
	-- 將英雄前進方向設定為正數值。(右方)
	self.direction = 1
	-- 將這個英雄TriggerComponent的Collision Group設定為Player。
	-- 用於Player與Enemy碰撞互動的設定
	self.Entity.TriggerComponent.CollisionGroup = CollisionGroups.Player
	-- 以X軸為基準反轉英雄精靈圖圖片。
	self.Entity.SpriteRendererComponent.FlipX = true
else
	-- 將英雄前進方向設定為負數值。(左方)
	self.direction = -1
	-- 將這個英雄TriggerComponent的Collision Group設定為Enemy。
	self.Entity.TriggerComponent.CollisionGroup = CollisionGroups.Enemy
	-- 以X軸為基準反轉英雄精靈圖圖片。
	self.Entity.SpriteRendererComponent.FlipX = false
end

-- 設定SpriteRenderer Component的FlipX屬性值。
--self.Entity.SpriteRendererComponent.FlipX = self.isMine

-- 原樣取得存放英雄資訊值的表格作為內部成員。
self.unitStat = _DataSetLogic.unitData[unitName]

-- 初始化進行時，設定符合英雄的動畫表格。(符合UnitRenderData的英雄動畫表格)
self.Entity.AnimationController:SetAnimTable(unitName)

-- 初始化基本攻擊計時器。
self.attackTimer = 0
-- 初始化技能攻擊計時器。
self.skillTimer = 0
-- 將英雄初始體力值設定為UnitData的「Hp」值。
self.hp = self.unitStat["Hp"]

self.Entity.RigidbodyComponent.Enable = true
-- 啟用實體上登錄的TriggerComponent，使其可使用。
self.Entity.TriggerComponent.Enable = true
-- 將SpriteRenderer Component色彩值的透明度設定為1狀態，初始化為不透明。
self.Entity.SpriteRendererComponent.Color.a = 1
-- 設定英雄不是待機狀態。
self.waiting = false;
end

@ExecSpace("ClientOnly")
method void OnUpdate(number delta)
-- 每一格呼叫的函式。

-- 若因受擊而導致SpriteRenderer色彩值的透明度已更改，
if self.changedSpriteAlpha == true then
	-- 若受擊時設定的damageTimer為0以下(恢復狀態)
	if self.damageTimer <= 0 then
		-- 設定Sprite色彩值的透明度沒有更改。
		self.changedSpriteAlpha = false
		-- 將SpriteRenderer Component透明度值設定為1，使其成為不透明狀態。
		self.Entity.SpriteRendererComponent.Color.a = 1
	else
		-- 受擊時設定的計時器仍有剩餘時間，因此減少計時器值直到抵達0。
		self.damageTimer -= delta	
	end
end

-- 若沒有體力
if self.hp <= 0 then
	-- 設定不執行後續行動功能。
	return
end


-- 英雄存活期間，基本、技能攻擊的冷卻時間會持續循環。
-- 這是為了在移動、待機、受擊時，所有情況下都循環冷卻時間。
self.attackTimer += delta
self.skillTimer += delta

-- 若英雄已進入攻擊狀態(正在執行攻擊動畫)
if self.state.currentState == "ATTACK" then
		-- 若尚未向對方造成傷害
		if self.isSendHit == false then
			-- 在抵達向對方傳遞該英雄傷害的時間點前，將delta值追加到hitTimer。
			self.hitTimer += delta
			
			-- 若hitTimer值大於登錄於UnitRenderData DataSet的AttackPick值(進行傷害傳遞)
			if self.hitTimer >= self.Entity.AnimationController.hitTiming then
				
				-- 若有偵測到目標英雄
				if self.targetUnit ~= nil then
					-- 向目標英雄造成傷害。
					self.targetUnit:OnDamage(self.power)
				
				-- 若有偵測到目標基地
				elseif self.targetBase ~= nil then
					-- 向目標基地造成傷害。
					self.targetBase:OnDamage(self.power)
				
				end
				
				-- 因已造成傷害，切換狀態。
				-- 這是為了防止一次Attack執行時連續造成傷害。
				self.isSendHit = true
				-- 清空偵測到的目標英雄資訊。
				self.targetUnit = nil
				-- 清空偵測到的目標基地資訊。
				self.targetBase = nil
			
			end
		
		end
	-- 若為攻擊狀態，則設定為只執行負責攻擊的功能，不執行後續邏輯。
	return
end
	

-- 若TriggerComponent未偵測到對方
if self.found == false then
	-- 執行移動功能。
	self:Move(delta)

	-- 若TriggerComponent偵測到對方
else
	-- 若基本攻擊冷卻時間與技能攻擊冷卻時間值中，沒有任何一項達到可用狀態
	if(self.attackTimer < self.unitStat["AtkCooltime"]) and (self.skillTimer < self.unitStat["SkCooltime"]) then
		
		-- 將英雄切換為待機中狀態。	
		self.waiting = true
		-- 將英雄目前狀態切換為IDLE狀態。
		self.state:ChangeState("IDLE")
		
	-- 若攻擊行為(基本攻擊或技能攻擊)的冷卻時間已填滿
	else
		
		-- 將英雄切換為不是待機中的狀態。	
		self.waiting = false
		-- 若技能攻擊冷卻時間已完成	
		if self.skillTimer >= self.unitStat["SkCooltime"] then
			-- 執行英雄技能攻擊。 
			self:Skill()
		-- 若不是技能攻擊，而是基本攻擊冷卻時間已完成
		elseif self.attackTimer >= self.unitStat["AtkCooltime"] then
			-- 執行英雄基本攻擊。
			self:Attack()
		end
		
		-- 因已執行攻擊，重新將英雄狀態更改為待機中。
		self.waiting = true
	
	end

end


end

@ExecSpace("ClientOnly")
method void Move(number delta)
-- 執行英雄移動。

-- 將英雄狀態切換為不是待機中。
self.waiting = false
-- 在CustomStateComponent中將角色目前狀態切換為MOVE。
self.state:ChangeState("MOVE")

-- 確認英雄目前絕對座標值。
local currentPos = self.Entity.TransformComponent.WorldPosition
-- 考慮移動速度、方向，計算應更新到英雄上的位置值。
local movePos = currentPos + Vector3(delta*self.direction*self.unitStat["Speed"],0,0)
-- 透過RigidbodyComponent設定英雄絕對座標值。
self.Entity.RigidbodyComponent:SetWorldPosition(movePos:ToVector2())
end

@ExecSpace("ClientOnly")
method void Skill()
-- 執行英雄技能功能。

-- 技能攻擊時也一起初始化基本攻擊計時器。
self.attackTimer = 0
-- 初始化技能攻擊計時器。
self.skillTimer = 0
-- 將英雄狀態更改為ATTACK。
self.state:ChangeState("ATTACK")
-- 初始化傷害傳遞計時器。
self.hitTimer = 0
-- 初始化為「尚未造成傷害」。
self.isSendHit = false

local skillFX_ID = self.unitStat["Skill"]
local skillFX_RUID = _DataSetLogic.skillData[skillFX_ID].EffectRUID

_EffectService:PlayEffect(skillFX_RUID,self.Entity,self.Entity.TransformComponent.WorldPosition,0,Vector3.one)
_SoundService:PlaySound("83529166c98f420092183aa310b2d660",0.5)

-- 將英雄攻擊力設定為技能攻擊力值。
self.power = self.unitStat["SkAttack"]
end

@ExecSpace("ClientOnly")
method void Attack()
-- 初始化基本攻擊計時器。
self.attackTimer = 0
-- 將英雄狀態更改為ATTACK。
self.state:ChangeState("ATTACK")
-- 初始化傷害傳遞計時器。
self.hitTimer = 0
-- 初始化為「尚未造成傷害」。
self.isSendHit = false

-- 將英雄攻擊力設定為基本攻擊力值。
self.power = self.unitStat["Attack"]

_SoundService:PlaySound("ddd8caea18a04c88a7a9cf9627a91f86",0.35)
end

@ExecSpace("ClientOnly")
method void OnDamage(integer damage)
-- 執行英雄受擊處理的函式。

-- 參數1 damage：接收的傷害值。

-- 從目前體力中扣除參數值。
self.hp -= damage
-- 將英雄目前狀態切換為ONHIT狀態。
self.state:ChangeState("ONHIT")

-- 將SpriteRenderer元件Alpha值降低為0.4。
self.Entity.SpriteRendererComponent.Color.a = 0.4
-- 將受擊計時器設定為0.15秒。(0.15秒後恢復為原狀。)
self.damageTimer = 0.15
-- 以內部狀態設定目前精靈圖已更改。
self.changedSpriteAlpha = true

-- 若體力為0以下
if self.hp <= 0 then
	-- 停用英雄實體的TriggerComponent。
	self.Entity.TriggerComponent.Enable = false
	-- 將英雄目前狀態切換為DEAD狀態。
	self.state:ChangeState("DEAD")
end
end

@EventSender("Self")
handler HandleTriggerLeaveEvent(TriggerLeaveEvent event)
-- 在碰撞範圍內原本偵測到的東西消失時發生的事件函式。

-- 將狀態切換為「沒有偵測到對方英雄」。
self.found = false

-- 清空所有偵測目標資訊。
self.targetUnit = nil
self.targetBase = nil
end

@EventSender("Self")
handler HandleTriggerStayEvent(TriggerStayEvent event)
-- 在碰撞範圍內持續被偵測到的每一瞬間發生的事件函式。

-- 若碰撞對象上有UnitComponent或BaseComponent(確認是否為對方英雄、基地)
if event.TriggerBodyEntity.UnitComponent ~= nil or event.TriggerBodyEntity.BaseComponent then
	-- 設定為「已偵測到對方英雄」。
	self.found = true
end

-- 若偵測對象上有UnitComponent
if event.TriggerBodyEntity.UnitComponent ~= nil then
	-- 將攻擊目標英雄設定為目前偵測到的英雄。
	self.targetUnit = event.TriggerBodyEntity.UnitComponent
end

-- 若偵測對象上有BaseComponent
if event.TriggerBodyEntity.BaseComponent ~= nil then
	-- 將攻擊目標基地設定為目前偵測到的基地。
	self.targetBase = event.TriggerBodyEntity.BaseComponent
end
end

end
```

- 世界執行期間，若要即時生成新的英雄實體，需要SpawnService功能。

## 最低製作標準
- 為了與對方基地或英雄互動並進行戰鬥，需要製作基本英雄實體並登錄Model。
- 若要執行英雄功能動作，需要製作及登錄UnitComponent、CustomState腳本。

<br>

## 應用與進階應用
- 不只地面戰英雄，也可以製作執行空中戰的英雄。
- 可以追加英雄更多各種能力值資訊(防禦力、屬性攻擊等)，讓玩家能考慮更多不同策略方式。
