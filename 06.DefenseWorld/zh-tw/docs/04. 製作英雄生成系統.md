## 設定玩家可用英雄
<p align="Center">
<img src="../../_images/MSW-100_Defense_4_001.png" alt="MSW-100_Defense_4_001"
</p>

- 防禦範例世界可透過DataSet限制使用者可用於戰鬥的英雄。
- 設定選項中，若要在登錄於**UnitData**DataSet的所有英雄列表中，設定為不提供給使用者，請將**Usable**值登錄為F值。
- 若要製作此類功能，可撰寫如下程式碼。

```lua
void RegistUseableDecks()
{
    -- 取得登錄於DataSet的所有英雄資料表格。
    local unitData = _DataSetLogic.unitData

    -- 巡覽整個表格。
    for unitName,unitData in pairs(unitData)
        -- 若該資料的「Useable」值登錄為「F」
        if unitData["Useable"] == "F" then
            -- 進入下一次巡覽。
            continue
        end

        -- 若值為「T」，則進行呼叫生成Deck的函式。
        RegistDeckItem(unitName)
    end
}
```

## 設定敵方(AI)生產的英雄
<p align="Center">
<img src="../../_images/MSW-100_Defense_4_002.png" alt="MSW-100_Defense_4_002"
</p>

- 可將登錄於**UnitData**DataSet的所有英雄登錄並運用為可從敵方基地生產的英雄。
- **StageData**中不會受UnitData的Usable值影響，而是登錄Unit名稱來設定各關卡可生產的英雄。
- **StageData**最前方的**ID**值會作為各關卡編號運用。
  - 第2關卡中敵方可生產的英雄列表：Panda、Pepe
- 整理敵方英雄列表為表格的過程，可如下列程式碼撰寫。

```lua
Property:
Integer currentStage = 2

table GetEnemyUnitTable()
{
    -- 取得目前關卡中敵方可生產的英雄資料。
    -- 收到的資料為String字串形式。
    local enemyUnitData = _DataSetLogic.stageData[currentStage].EnemyUnit -- string : "Panda,Pepe"

    -- 使用UtilLogic的Split函式分割字串並轉換為表格。
    -- 以逗號(,)值為基準分割enemyUnitData("Panda,Pepe")並儲存為表格。
    -- table { "Panda" , "Pepe" }
    return _UtilLogic:Split(enemyUnitData,",")
} 
```

## 英雄自動生產
<p align="Center">
<img src="../../_images/MSW-100_Defense_4_004.gif" alt="MSW-100_Defense_4_004"
</p>

- 從敵方基地生產的英雄無法由玩家直接控制，因此必須製作週期性生產會執行戰鬥之英雄的系統。

### 生成Base的生成點
<p align="Center">
<img src="../../_images/MSW-100_Defense_4_003.png" alt="MSW-100_Defense_4_003"
</p>

- 生成並配置表示從Player、Enemy各基地生產之英雄生成點的子實體。

### 選定要生產的英雄過程

1.- 從**StageData**中登錄於EnemyUnit的英雄中隨機選定英雄。
2.等待直到滿足所選英雄的生產條件(Cost)。
3.若有足夠生產目標英雄的資源，則生產英雄。
4.從EnemyUnit列表中重新隨機選定下一個要生產的英雄。
5.從第2個過程開始重新反覆。

- 登錄於各基地的BaseComponent程式碼會如下撰寫。
- 該程式碼是在Plain Text環境下撰寫。
```lua
@Component
script BaseComponent extends Component

property boolean isUser = true -- 表示該基地是否為使用者所有的變數。

property integer hp = 0 -- 表示該基地目前體力值。

property Entity spawnLocation = nil

property number gold = 0 -- 可生產英雄的資源值。

property number goldTimer = 0 -- 為了每隔固定時間生產資源而測量的計時器。

property number goldPerSecond = 0 -- 決定每秒生產多少黃金的變數。

property string nextSpawnUnitName = "" -- 下一個應生產的英雄。(Enemy專用變數)

property integer needGold = 0 -- 表示行動時所需資源值。

@ExecSpace("ClientOnly")
method void OnBeginPlay()
-- 世界執行時立即呼叫的函式。

-- 進行自身初始化。
self:Init()
end

@ExecSpace("ClientOnly")
method void Init()
-- 執行元件初始化。

-- 在子實體中尋找並登錄決定英雄生成位置的「SpawnLocation」實體。
self.spawnLocation = self.Entity:GetChildByName("SpawnLocation")

-- 將目前資源值初始化為0。
self.gold = 0
-- 將用於生產資源的計時器值設定為0。
self.goldTimer = 0

-- 若該基地屬於使用者，
if self.isUser == true then
	-- 將每秒資源生產量設定為StageData的PlayerGoldPerSecond值。(以目前關卡編號為基準。)
	self.goldPerSecond = _DataSetLogic.stageData[_StageLogic.currentStage].PlayerGoldPerSecond
	-- 設定玩家必須守護的基地初始體力值。
	self.hp = _DataSetLogic.stageData[_StageLogic.currentStage].PlayerBaseHp
	
	_UI_MainGame:UpdateGoldText(self.gold)
	
-- 若該基地屬於敵方
else
	-- 將每秒資源生產量設定為StageData的EnemyGoldPerSecond值。(以目前關卡編號為基準。) 
	self.goldPerSecond = _DataSetLogic.stageData[_StageLogic.currentStage].EnemyGoldPerSecond
	-- 決定下一個應生產的英雄。
	self.nextSpawnUnitName = self:SelectRandomUnitForEnemyName()
	-- 設定敵方必須守護的基地初始體力值。
	self.hp = _DataSetLogic.stageData[_StageLogic.currentStage].EnemyBaseHp
	-- 記錄下一個應生產英雄所需的資源量值。
	self.needGold = _DataSetLogic.unitData[self.nextSpawnUnitName].Cost
end
end

@ExecSpace("ClientOnly")
method void SpawnUnit(string unitName)
-- 生成英雄的函式。

-- 參數1 unitName：接收要生產英雄的名稱值。

-- 請求從物件池接收英雄實體。
-- 傳遞參數，使收到的實體父物件設定為自己。
local unit = _ObjectPoolLogic:GetUnit(self.Entity)

-- 將英雄實體的位置座標設定為與子實體SpawnLocaion的位置相同。
unit.TransformComponent.Position = self.spawnLocation.TransformComponent.Position
-- 存取Unit的UnitComponet並進行初始化。
unit.UnitComponent:Init(unitName,self.isUser)
end

@ExecSpace("ClientOnly")
method void OnDamage(integer damageValue)
-- 因對方英雄造成受擊時呼叫的函式。

-- 參數1 damageValue：決定從對方接收多少受擊傷害。

-- 減少體力值。
self.hp -= damageValue

-- 若體力為0以下
if self.hp <= 0 then
	-- 執行破壞功能。
	self:Destory()
	-- 設定關卡進行已結束。
	_StageLogic:SetStageState(false)
end
end

@ExecSpace("ClientOnly")
method void Destory()
-- 執行該實體破壞的函式。

-- 若被破壞的實體是使用者基地，則顯示輸出敗北結果的彈出視窗資訊。
_UI_Result:ShowWithWinInfo(not self.isUser)

-- 停用附加元件的實體。
self.Entity.Enable = false
end

@ExecSpace("ClientOnly")
method void OnUpdate(number delta)
-- 每一格呼叫的函式。

-- 若關卡已結束
if _StageLogic.isStageStart == false then
	-- 不執行後續功能並結束。
	return
end

-- 讓資源在遊戲進行期間自動累積。
self:AutoGetGold(delta)
end

@ExecSpace("ClientOnly")
method void AutoGetGold(number delta)
-- 自動累積資源的函式。

-- 參數1 delta：接收格與格之間時間變化量的值。

-- 增加用於測量1秒單位的計時器值。
self.goldTimer += delta

-- 記錄目前關卡可擁有的最大資源量值。
-- 透過---@ type設定該資料型態為整數。
---@ type integer
local maxGold = _DataSetLogic.stageData[_StageLogic.currentStage].MaxGold

-- 若狀態為1秒以上
if self.goldTimer >= 1 and self.gold < maxGold then
	-- 將計時器重新初始化為0。
	self.goldTimer = 0
	-- 將設定的每秒Gold值追加到目前Gold值。
	self.gold += self.goldPerSecond
	self.gold = math.clamp(self.gold,0,maxGold)
	
		-- 若該Base是敵方基地
		if self.isUser == false then
			-- 執行自動英雄生成函式。
			self:EnemyAutoSpawn()
		-- 若該Base是使用者基地
	elseif self.isUser == true then
			-- 更新表示資源資訊的UI文字值。
			_UI_MainGame:UpdateGoldText(self.gold)
		end
end
end

@ExecSpace("ClientOnly")
method string SelectRandomUnitForEnemyName()
-- 從StageData中登錄的符合目前關卡EnemyUnit中，取得隨機英雄名稱的函式。

-- 生成用來存放英雄名稱的表格。
local enemyUnits = {} 
-- 從DataSetLogic中原樣取得目前關卡可生成的英雄名稱表格。
enemyUnits = _DataSetLogic.stageData[_StageLogic.currentStage].EnemyUnit

-- 從表格第1個元素到表格最後一個元素中生成隨機索引值。
local selectRandomIndex = _UtilLogic:RandomIntegerRange(1,#enemyUnits)

-- 取得符合該索引的英雄名稱。
local randomUnitName = enemyUnits[selectRandomIndex]

-- 回傳該英雄名稱。
return randomUnitName
end

@ExecSpace("ClientOnly")
method void EnemyAutoSpawn()
-- 敵方基地專用函式，自動生成英雄。

-- 若敵方基地的黃金值滿足下一個英雄生成所需黃金值
if self.gold >= self.needGold then
	-- 生成所需英雄。
	self:SpawnUnit(self.nextSpawnUnitName)
	-- 從目前資源中扣除所需資源值。
	self.gold -= self.needGold
	-- 重新選擇下一個要生成的英雄。
	self.nextSpawnUnitName = self:SelectRandomUnitForEnemyName()
end
end

@ExecSpace("ClientOnly")
method void PlayerRequestSpawn(string unitName)
-- 請求生成作為參數傳入的英雄的函式。(玩家專用函式)

-- 參數1 unitName：想生成英雄的英雄名稱

-- 確認目標英雄的生產費用值。
local targetUnitCost = _DataSetLogic.unitData[unitName].Cost

-- 若目前擁有黃金值高於目標英雄的生產費用
if self.gold >= targetUnitCost then
	-- 請求原樣生成目標英雄。
	self:SpawnUnit(unitName)
	-- 從目前資源量中扣除英雄生產費用的資源量。
	self.gold -= targetUnitCost
	-- 將顯示資源量的TextUI更新為消耗後的目前資源量。
	_UI_MainGame:UpdateGoldText(self.gold)
end
end

@ExecSpace("ClientOnly")
method void ReturnAllUnit()
-- 將生產出的所有英雄重新歸還至物件池的函式。

-- 將子實體中登錄了UnitComponent的實體記錄為Table。
local units = self.Entity:GetChildComponentsByTypeName("UnitComponent")

-- 巡覽整個表格。
for _, unit in pairs(units) do
	-- 將該英雄歸還至物件池。
	_ObjectPoolLogic:ReturnUnit(unit.Entity)
end
end

end
```

## 最低製作標準
- 為了與敵方進行戰鬥，必須從敵方基地自動生產英雄。
- 必須製作至少一個以上玩家、敵方(AI)可生產英雄的環境。

<br>

## 應用與進階應用
- 可以生成敵方基地的多個生成點，在一個關卡中演出多種情況。
